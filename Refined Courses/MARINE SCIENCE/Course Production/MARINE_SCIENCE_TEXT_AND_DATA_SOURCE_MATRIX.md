# Marine Science Text and Data Source Matrix

## Purpose

This matrix provides production guidance for future Marine Science lesson development. It identifies recommended text, model, map, image, and data source categories by unit. It does not create lesson content, assessment content, HTML content, JSON content, GIFT content, or LMS pages.

## Source Category Matrix

| Unit | Unit Title | Recommended Source Categories | Production Guidance |
|---:|---|---|---|
| 1 | Marine Science Foundations and Ocean Inquiry | Marine lab safety scenarios; ocean investigation prompts; sampling plans; water-quality tables; ocean maps; simple data graphs; source reliability examples | Use sources that support inquiry, safe procedures, marine data interpretation, models, claims, and evidence-based communication. |
| 2 | Ocean Structure, Chemistry, and Physical Systems | Bathymetry maps; ocean zone diagrams; current maps; tide and wave data; salinity and density data; pH and nutrient tables; coastal erosion maps | Use sources that support ocean basins, zones, currents, salinity, density, water quality, marine geology, coasts, and ocean-atmosphere interactions. |
| 3 | Marine Ecosystems and Biodiversity | Coral reef profiles; estuary data; mangrove and seagrass resources; open-ocean and deep-sea organism profiles; biodiversity charts; invasive species data | Use sources that support marine habitat comparison, organism distribution, biodiversity, adaptation, and ecosystem change. |
| 4 | Marine Processes, Food Webs, and Energy Flow | Marine food webs; trophic pyramids; population graphs; primary productivity data; dissolved oxygen data; nutrient-cycle diagrams; plankton bloom data | Use sources that support populations, limiting factors, species interactions, trophic energy transfer, productivity, cycling, and water-quality effects. |
| 5 | Human Impacts, Fisheries, and Marine Conservation | Fisheries data; bycatch data; aquaculture case summaries; plastic pollution data; runoff and oil-spill cases; coral bleaching records; monitoring data; conservation plans | Use sources that support human impact analysis, resource tradeoffs, monitoring, policy, conservation, restoration, and sustainability decisions. |
| 6 | Ocean Exploration, Marine Technology, and Global Ocean Systems | Sonar maps; satellite ocean data; ROV observations; sensor data; global current maps; deep-sea exploration cases; marine career texts; technical communication examples | Use sources that support exploration tools, remote evidence, mapping, global ocean systems, marine technology, career readiness, and full-course synthesis. |

## Recommended Source Controls

| Control | Requirement |
|---|---|
| Authoritative science source preference | Prioritize CPALMS-aligned state resources, NOAA, NASA, USGS, NSF, university extension resources, Sea Grant resources, peer-reviewed summaries, and government scientific data sources where appropriate. |
| Data integrity | Use data sets with clear units, dates, location, method, scale, and limitations whenever available. |
| Visual integrity | Maps, diagrams, satellite images, model visuals, food webs, and graphs must be legible and aligned to the target standard. |
| Marine identity | Sources must preserve Marine Science identity. Biology, Chemistry, Environmental Science, and Earth/Space Science sources may be used only when supporting ocean-focused standards. |
| Reading level | Texts should support high-school science literacy and include opportunities for evidence citation, inference, technical vocabulary, and data interpretation. |
| Embedded-source requirement | Any passage, data table, map, scenario, graph, or source set required for a lesson or assessment must be included directly where students need it. |
| Lesson production boundary | This matrix is guidance only and does not create lesson text, assessments, HTML, JSON, GIFT, or LMS pages. |
