# Marine Science Phase 3A-A: Mapping Framework

## Executive Summary

This framework defines how Marine Science standards are distributed across six units and 48 lessons. It protects workload balance, Marine Science identity, laboratory/data expectations, and mastery-based online learning. It does not create lessons or assessments.

## Required Lab, Visual, Simulation, and Resource Matrix

The mapping framework must be used with:

- `PHASE_3A_B_3_LAB_VISUAL_SIMULATION_MAPPING.md`

That companion matrix is required before lesson development, assessment development, Moodle XML production, or Moodle transfer. It controls lesson-level marine labs, field-data practices, maps, graphs, bathymetry, water-quality data, food webs, population models, coastal models, technology diagrams, simulation review, safety controls, direct resource requirements, and assessment stimulus requirements.

## Mapping Philosophy

| Mapping Element | Rule |
|---|---|
| Primary standard | The main standard directly taught and assessed in a lesson. |
| Support standard | A standard used to support the lesson without becoming the main mastery target. |
| Spiral standard | A standard reinforced across units through data, vocabulary, field/lab reasoning, or evidence explanation. |
| Lesson 8 | Synthesis only; introduces no new primary standard. |
| Marine identity | Every mapping decision must stay anchored in oceans, coasts, marine ecosystems, ocean data, or marine technology. |
| Lab, visual, simulation, and resource matrix | Verify `PHASE_3A_B_3_LAB_VISUAL_SIMULATION_MAPPING.md` is used before lesson, assessment, or Moodle transfer work. |

## Lesson Load Rules

- Lessons 1-7 should normally contain one primary standard.
- Two primary standards are allowed only when they are naturally inseparable, such as salinity/density or fisheries/sustainability.
- Support standards must not overload the lesson.
- Lab/data standards should spiral frequently but should not replace the marine content focus.
- Lesson 8 may list multiple standards only because it synthesizes the unit.

## Unit Structure Rules

| Component | Mapping Rule |
|---|---|
| Unit Pretest | Diagnostic; aligns to the unit's primary standards. |
| Lessons 1-7 | Introduce and practice new primary standards. |
| Guided Practice | Aligns to the lesson's primary standard and key support standards. |
| Notebook Evidence | Captures marine vocabulary, data reasoning, models, and evidence explanations. |
| Checkpoint Submission | Requires independent standard application. |
| Lesson Quiz | Used only in Lessons 1-7. |
| Lesson 8 | Putting It All Together; unit synthesis and Unit Assessment only. |
| Unit Assessment | Aligns to standards taught in Lessons 1-7. |

## Workload Protection Rules

| Risk | Protection |
|---|---|
| Benchmark overload | Limit new primary standards in Lessons 1-7. |
| Reading overload | Use concise marine source sets, maps, or data displays rather than excessive text. |
| Data overload | Teach the graph/map/model type before asking students to interpret it independently. |
| Chemistry drift | Keep pH, salinity, density, nutrients, and gases in marine water-quality contexts. |
| Biology drift | Keep organisms tied to marine habitats, ecosystems, adaptations, and biodiversity. |
| Environmental Science drift | Keep human impacts tied to oceans, coasts, fisheries, conservation, and marine monitoring. |
| Earth/Space Science drift | Keep geology and climate support tied to ocean basins, coastal systems, currents, and marine conditions. |

## Readiness Rules

Every unit must reinforce marine data interpretation, evidence-based scientific reasoning, technical vocabulary, graph/map/model reading, source reliability, scientific explanation, workforce communication, and scientific literacy.

## Recommendations for Phase 3A-B

Proceed to unit-level and lesson-level mapping using the approved six-unit structure. Preserve Lesson 8 protection, avoid content drift, and keep the course anchored in Marine Science.
