# ESS Text and Data Source Matrix

## Purpose

This matrix provides production guidance for future Earth/Space Science lesson development. It identifies recommended text, model, map, image, and data source categories by unit. It does not create lesson content, assessment content, HTML content, JSON content, GIFT content, or LMS pages.

## Source Category Matrix

| Unit | Unit Title | Recommended Source Categories | Production Guidance |
|---:|---|---|---|
| 1 | Scientific Thinking and Earth Systems Foundations | Lab safety scenarios; Earth-system models; maps; graphs; data tables | Use sources that support inquiry, field/lab safety, map and graph interpretation, model use, Earth-sphere interactions, and evidence-based claims. |
| 2 | Geology, Plate Tectonics, and Earth's Structure | Plate boundary maps; Florida geology resources; Earth layer diagrams; geologic feature maps | Use sources that show Earth layers, plate boundaries, surface processes, Florida geology, geologic features, and ocean-basin structures without drifting into a full environmental or marine course. |
| 3 | Weather, Climate, Oceans, and Atmosphere | NOAA weather data; hurricane data; climate graphs; ocean current maps; atmospheric data | Use sources that support weather prediction, severe weather, climate controls, ocean-atmosphere interactions, uncertainty, and Florida-specific atmospheric/oceanic influences. |
| 4 | Earth History and Change Over Time | Fossil evidence; geologic time scale resources; Earth history models; scientific theory resources | Use sources that support fossil evidence, geologic time, Earth history models, scientific theories, origin-of-life explanations at course level, and evidence of change over time. |
| 5 | Astronomy, Solar System, and Stars | NASA astronomy resources; solar system models; stellar evolution diagrams; Hubble imagery | Use sources that support Big Bang evidence, matter distribution, astronomical distances, star evolution, Sun-Earth relationships, planetary systems, and Earth-Moon-Sun interactions. |
| 6 | Galaxies, Space Exploration, and Earth-Space Systems | Space exploration case studies; electromagnetic spectrum resources; NASA mission data; remote sensing resources | Use sources that support space exploration, Florida economy/culture connections, electromagnetic evidence, radiation, waves, remote sensing, mission data, motion, gravity, and applied Earth-space systems. |

## Recommended Source Controls

| Control | Requirement |
|---|---|
| Official or authoritative science source preference | Prioritize CPALMS-aligned state resources, NOAA, NASA, USGS, NSF, university extension resources, and peer-reviewed or government scientific data sources where appropriate. |
| Data integrity | Use data sets with clear units, dates, location, method, scale, and limitations whenever available. |
| Visual integrity | Maps, diagrams, satellite images, model visuals, and graphs must be legible and aligned to the target standard. |
| Reading level | Texts should support high-school science literacy and include opportunities for evidence citation, inference, and technical vocabulary development. |
| Identity control | Sources must preserve Earth/Space Science identity. Biology, Chemistry, and Physics sources may be used only when supporting CPALMS Earth/Space Science benchmarks. |
| Lesson production boundary | This matrix is guidance only and does not create lesson text, assessments, HTML, JSON, GIFT, or LMS pages. |
