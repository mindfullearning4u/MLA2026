# Earth/Space Science Phase 2A-B: Crosswalk Draft

## Crosswalk Purpose

This crosswalk connects every MLA Earth/Space Science standard to Florida Earth/Space Science standards, Common Core Literacy in Science and Technical Subjects expectations, ACT Science readiness, SAT science reading/data expectations, college readiness, workforce readiness, and scientific literacy.

This document is architecture only. It does not create lessons, assessments, HTML content, JSON content, legacy assessment-bank content, or LMS pages.

## Common Cross-Framework Abbreviations

| Abbreviation | Meaning |
|---|---|
| CCSS-RST | Common Core Reading Standards for Literacy in Science and Technical Subjects: cite evidence, determine central ideas, follow technical procedures, analyze data/visuals, evaluate explanations, compare sources, read technical texts. |
| CCSS-WHST | Common Core Writing Standards for Literacy in Science and Technical Subjects: write explanations/arguments, use evidence, conduct research, gather information, write routinely. |
| ACT-SCI | ACT Science readiness: interpretation of data, scientific investigation, evaluation of models/inferences/experimental results. |
| SAT-SCI | SAT science-related reading and data expectations: command of evidence, words in context, analysis of quantitative information, interpretation of graphics, synthesis across texts/data. |
| College Ready | Entry-level postsecondary science readiness: technical reading, model-based reasoning, quantitative reasoning, lab/data reasoning, academic communication, and Earth/space systems thinking. |
| Workforce Ready | Career readiness: safety, procedures, measurement, data recording, map/model use, quality control, collaboration, source evaluation, technical communication, and applied systems reasoning. |
| Scientific Literacy | Public-facing science literacy: evidence evaluation, model understanding, uncertainty, Earth-system claims, climate/weather claims, space-science claims, and science-informed civic reasoning. |
