Instructions

Use this source description for all parts: A website page titled "How to Prepare for a Community Presentation" uses headings for audience, notes, visuals, and rehearsal. Each section gives short practical advice.

Part A

Identify two source features and explain what each feature helps the reader find.

Part B

Explain the source purpose and the likely audience.

Part C

Describe how a speaker could use this source in a speech about presentation preparation.

Independent Work Planning Support

Lesson focus: Structures, features, and source purpose

Mapped standard focus: MLA.SPEECH.LST.01

Use this checklist before completing Parts A, B, and C so your independent work stays aligned to the lesson standard.

  1. Identify the audience before choosing words, tone, or examples. A strong speaker adapts to what listeners need and expect.
  2. State the purpose in one clear sentence so every communication choice supports that goal.
  3. Choose voice and tone deliberately. Ask whether the language sounds respectful, appropriate, and useful for the situation.
  4. Check that the final message fits the audience, purpose, and setting without becoming too casual, too vague, or too formal.

P06 independent work quality check: Before you submit, make sure Part A shows the basic skill, Part B applies the skill to a communication situation, and Part C explains your reasoning. A strong response does not only complete the task; it shows why your choices fit the audience, purpose, evidence, and communication goal.

  • Use complete, specific responses instead of one-word answers.
  • Connect each answer to the lesson focus and mapped standard.
  • Reread your work as if an audience, listener, or collaborator will use it.
