Checkpoint Task

Write one paragraph explaining a source for a professional briefing. Include the evidence, one reasonable inference, and a clear explanation of how the source supports the speaker's message.

Mastery Criteria

  • The paragraph identifies source evidence accurately.
  • The inference is reasonable and does not exaggerate the source.
  • The explanation connects the source to the communication purpose.
  • The response is clear enough for an audience to follow.
