🗣 SPEECH | Unit 01 | Lesson 08

P04 Worked Example

Example 1: Identify Tone

Excerpt: "Together, we can make every discussion more respectful."

Answer: The tone is encouraging because the speaker uses "together" and focuses on improvement.

Example 2: Paraphrase

Speaker: "The audience needs a clear definition before the evidence."

Answer: The audience should hear the definition first so the evidence makes sense.

Example 3: Explain Rhetoric

Excerpt: "Our survey showed that most students want more practice time."

Answer: The speaker uses logic because survey evidence supports the request for more practice time.

Common Mistake - Incorrect

Incorrect: "The answer is correct because it sounds good."

This does not explain the communication skill or use evidence from the scenario.

Common Mistake - Correct

Correct: "The answer is correct because it matches the audience, purpose, and evidence in the scenario."

This explains the reasoning clearly.
