Deeper Communication Thinking

When questions combine skills, ask which skill is being tested first. If the question asks about restating meaning, think paraphrase. If it asks about attitude, think tone. If it asks how words affect an audience, think rhetoric.

Embedded Example

Speaker: "We need a calmer tone because our audience may already feel nervous about presenting."

Best response: "You are saying the tone should calm the audience because they may feel nervous."

This is a paraphrase that also shows audience and tone awareness.

Notebook Directions

Write one example question that tests tone and one example question that tests active listening.

Common Mistake - Incorrect

Incorrect: "All communication questions ask the same thing."

This is incorrect because each question focuses on a specific skill, such as tone, paraphrase, audience, academic language, or rhetoric.

Common Mistake - Correct

Correct: "First identify the skill the question asks about, then choose the answer that best matches that skill."

This keeps your thinking focused and accurate.
