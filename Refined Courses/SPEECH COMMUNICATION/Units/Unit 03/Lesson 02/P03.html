Deeper Communication Thinking

A complete rhetorical explanation should not say only, "This is logos." That names the strategy, but it does not teach the reader anything about how the strategy works.

Use this sequence: choice + evidence + effect. Example: The speaker uses a rhetorical question, "why would we skip it," to push listeners to agree that rehearsal is necessary.

Common Mistake

Incorrect: The speaker uses rhetoric because the speech is persuasive.

The incorrect answer is too general. It does not name the specific choice, evidence, or audience effect.

Correct Example

Correct: The speaker uses a rhetorical question to make listeners think about why rehearsal matters.

This correction works because it uses the lesson skill deliberately instead of guessing.
