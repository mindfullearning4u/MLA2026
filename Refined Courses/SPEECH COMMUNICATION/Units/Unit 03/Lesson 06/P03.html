Continued Notebook Application

Evidence is not finished when you place it in a speech. The speaker must explain why it matters. Without explanation, the audience may not understand how the evidence supports the argument.

Use this frame: This evidence matters because ___.

Common Mistake - Incorrect

Incorrect: Peer feedback helps because it helps.

The incorrect version repeats the claim instead of explaining how the evidence supports reasoning.

Common Mistake - Correct

Correct: Peer feedback helps because a listener can point out unclear transitions before the final presentation.

This correction uses the lesson skill clearly and respectfully.
