P03 Notebook Task Part 2

Continued Notebook Application

Clarity and cohesion work together. A sentence can be grammatically correct but still disconnected from the rest of the speech. A speaker should revise so each sentence helps the audience move from one idea to the next.

Deeper Communication Thinking

Standard English does not mean sounding robotic. It means choosing language that fits the situation. A formal presentation needs more polished wording than a casual conversation, but it should still sound understandable.

Embedded Example

Unclear: "This helps and it is good for people."

Clearer: "This rehearsal strategy helps speakers identify unclear points before the audience hears the final presentation."

Common Mistake

Incorrect: My speech has transitions, so it is automatically clear.

Correct: My speech uses transitions and explains how each idea connects to the next.

Transitions help, but the ideas still need clear explanation.
