P02 Notebook Task Part 1

Notebook Title

Designing Slides That Support a Speech

Vocabulary

  • Digital presentation: slides or digital visuals used to support a spoken message.
  • Coherence: the clear connection among ideas.
  • Visual support: an image, chart, keyword, or layout that helps explain an idea.
  • Slide focus: the main idea one slide should communicate.

Presentation Example

Speech purpose: explain how students can prepare for presentations.

Slide sequence: 1. Organize notes. 2. Practice with a timer. 3. Preview the room. 4. Use visuals that clarify.

Step-by-Step Teaching

A digital presentation should support the speaker, not replace the speaker. Each slide needs one clear focus. The slide order should match the speech order. Visuals should clarify ideas, not fill space.

  1. Start with the speech central idea.
  2. Divide the speech into main points.
  3. Create one slide focus for each point.
  4. Use brief text or visuals that support the spoken explanation.
  5. Check that the slide order feels logical.

Model Example

Slide title: Practice with a Timer.

Slide content: three keywords: time limit, section length, revision.

Speaker explanation: A timer helps the speaker decide which sections need to be shortened or expanded.
