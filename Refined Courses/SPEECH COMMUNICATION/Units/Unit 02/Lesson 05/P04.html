P04 Worked Example

Study each example to see how structures and features guide audience meaning.

Example 1: Chronological Structure

Speech idea: How to prepare note cards.

Step 1: Choose key points.

Step 2: Write short cues.

Reasoning: Time order helps the audience understand a process.

Example 2: Cause and Effect Structure

Speech idea: Practice lowers nervousness.

Cause: The speaker rehearses several times.

Effect: The speaker feels more prepared.

Reasoning: The structure explains why the result happens.

Example 3: Feature That Signals Meaning

Sentence: "However, practice alone is not enough; speakers also need organized notes."

Feature: However.

Reasoning: The word however signals a contrast, so the audience expects a different idea.

Common Mistake

Incorrect: Signal words are decorative and do not affect understanding.

Signal words are not decoration. They tell the audience how ideas relate.

Correct Example

Correct: Signal words such as first, because, and however guide the audience through order, cause, and contrast.

This is correct because features help listeners interpret relationships between ideas.
