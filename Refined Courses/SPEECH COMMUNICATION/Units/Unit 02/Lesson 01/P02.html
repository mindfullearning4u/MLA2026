P02 Notebook Task Part 1

Notebook Title: Building a Focused Speech Plan

Vocabulary

  • Coherent focus: one clear main idea that all parts of a speech support.
  • Logical organization: arranging ideas in an order that makes sense.
  • Main point: one major idea that supports the focus.
  • Transition: a word or phrase that connects ideas.
  • Conclusion: the ending that reminds the audience of the main idea.

Step 1: Choose One Clear Focus

A speech should not feel like several unrelated comments. Start by naming one main idea. Every example, reason, and explanation should support that idea.

Focused topic: School announcements should be short, clear, and easy to hear.

Step 2: Put Ideas in an Order the Audience Can Follow

  1. Begin with the focus.
  2. Give the first main point.
  3. Use a transition.
  4. Give the next main point.
  5. End by reminding the audience of the focus.

Communication Example

Speech plan: Focus: Practice helps speakers improve. Point 1: Practice helps timing. Transition: Next, practice also helps confidence. Point 2: Practice helps speakers feel prepared. Conclusion: Practicing before presentation day helps the whole group succeed.

This plan is organized because every part supports the same focus.

Notebook Directions and Model Example

Copy the vocabulary. Then write one focused speech topic and two main points that support it.

Model answer: Focus: Clear discussion rules help groups work better. Point 1: Rules help people take turns. Point 2: Rules help people listen before responding.

Step-by-Step Teaching Support

Lesson focus: Logical speech organization and coherent focus

Mapped standard focus: MLA.SPEECH.SPK.01

Use this sequence before completing the notebook task. It shows how to approach the communication skill without guessing or skipping steps.

  1. Begin with the central focus of the speech. The audience should know what the speech explains and why it matters.
  2. Organize information in a logical order such as problem-solution, cause-effect, chronological order, or main-point order.
  3. Use transitions to show how ideas connect. Listeners need verbal signposts because they cannot reread a speech.
  4. Check whether each section supports the speech purpose instead of adding unrelated details.
