P03 Notebook Task Part 2

Continued notebook application: Fixing unfocused speech plans.

Deeper Communication Thinking

A speech loses focus when the main points do not support the same idea. If a point is interesting but unrelated, save it for another speech. A focused speech is easier for the audience to understand.

Embedded Example

Unfocused plan: Topic: School clubs. Point 1: Clubs help students meet people. Point 2: Lunch should be longer. Point 3: Clubs help students learn skills.

Fix: Remove the lunch point because it does not support the focus on clubs.

Notebook Directions

Write one unfocused speech plan with three points. Then revise it so all three points support one focus.

Common Mistake - Incorrect

Incorrect: "A speech is organized if it has a lot of ideas."

Many ideas do not automatically create organization. The ideas must connect to one focus.

Common Mistake - Correct

Correct: "A speech is organized when each idea supports the same focus and appears in an order the audience can follow."

This explains both focus and order.
