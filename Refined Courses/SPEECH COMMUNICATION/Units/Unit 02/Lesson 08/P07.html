Submission Workflow

  1. Review P02-P06.
  2. Complete the synthesis checkpoint task.

Checkpoint Task

Write a final Unit 2 readiness statement. Include one skill you feel confident about, one skill you reviewed, and one sentence explaining how Unit 2 skills help a speaker plan an informative speech.

Mastery Criteria

  • The response names specific Unit 2 skills.
  • The explanation connects skills to informative speech planning.
  • The student identifies a review need honestly and clearly.
  • The response is ready before the Unit Assessment.
