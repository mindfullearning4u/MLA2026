P03 Notebook Task - Part 2

Continued Notebook Application

A paraphrase must be accurate. That means it cannot add a new idea, remove an important idea, or change the meaning. In speech communication, inaccurate paraphrasing can cause a speaker to explain the wrong information to an audience.

Step 1: Underline the key idea in the source.

Step 2: Decide which academic words must stay.

Step 3: Restate the idea using a new sentence structure.

Step 4: Compare your paraphrase to the source to check accuracy.

Embedded Example

Source sentence: Clear transitions help listeners understand how one point connects to the next point in a speech.

Accurate paraphrase: Transitions guide an audience by showing the relationship between speech points.

The paraphrase is shorter, but it keeps the same meaning: transitions help listeners follow connections.

Common Mistake

Incorrect: Transitions are not important because audiences already know how points connect.

This is inaccurate because it changes the meaning of the source. The source says transitions help listeners; the incorrect version says they are not important.

Correct Example

Correct: Transitions help an audience follow the connection between one speech point and the next.

This is accurate because it keeps the source meaning and uses new wording.

Deeper Learning Support

Lesson focus: Paraphrase for speech notes and summaries

Use this second-pass routine to check whether your thinking is specific, audience-aware, and connected to the lesson skill.

  1. Start with the speech question or information need. Research should answer a purpose, not collect random facts.
  2. Check source reliability, relevance, and usefulness before adding information to speech notes.
  3. Paraphrase source information accurately so the speech sounds natural and avoids copying.
  4. Explain how the source evidence supports the speech point, central idea, or inference.
