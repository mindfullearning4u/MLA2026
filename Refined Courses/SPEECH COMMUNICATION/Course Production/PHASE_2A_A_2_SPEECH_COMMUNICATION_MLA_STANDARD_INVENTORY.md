# Phase 2A-A-2: Speech Communication MLA Standard Assignment

## Executive Summary

This report establishes the official MLA Speech Communication standard inventory using the approved MLA numbering framework:

`MLA.[COURSE].[DOMAIN].[NUMBER]`

For Speech Communication, the course identifier is `SPEECH`. Standards are numbered within the Speech Communication domains:

- `COM` = Communication
- `SPK` = Speaking
- `LST` = Listening and Rhetorical Evaluation
- `PRES` = Presentation
- `RES` = Research
- `DIG` = Digital Communication

Primary source: CPALMS public course record for `Speech 1 (#1007300)`, current version `2025 - And Beyond`, course detail ID `24723`.

Progression reference: CPALMS public course record for `Speech 2 (#1007310)`, current version `2025 - And Beyond`, course detail ID `24725`.

This inventory is architecture only. It does not create lessons, assessments, HTML files, quizzes, GIFT files, lesson JSON files, quiz JSON files, LMS pages, or student-facing instructional content.

## Speech 1 to Speech 2 Progression Note

Speech Communication is built from the Speech 1 standards because the requested course is a foundational Speech Communication architecture package. Speech 2 was reviewed only to confirm progression: Speech 2 advances the Grade 9 Speech 1 framework into Grade 10 expectations, including more formal/objective argument tone, audience-specific revision, research synthesis, historical American speeches and essays, digital presentations that improve understanding, and multimedia integration. This architecture therefore preserves a foundational-to-advanced speaking progression without importing Speech 2 benchmark wording into the Speech Communication standard inventory.
