# Phase 3A-B-2: Speech Communication Lesson-Level Mapping

## Executive Summary

This document creates the Speech Communication lesson-level mapping using the verified standard inventory, crosswalk draft, unit-level mapping, and approved English I-IV production structures.

This is mapping only. It does not create lesson objectives, lesson content, activities, assessments, HTML files, quizzes, GIFT files, quiz JSON files, lesson JSON files, LMS pages, or student-facing instructional content.

The mapping preserves the approved course structure:

- 6 units
- 8 lessons per unit
- Lessons 1-7 contain Lesson Quiz
- Lesson 8 = Putting It All Together
- Lesson 8 contains Unit Assessment only
- Lesson 8 introduces no new primary standard
