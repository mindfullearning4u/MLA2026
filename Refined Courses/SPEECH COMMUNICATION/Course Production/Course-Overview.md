# Speech Communication Course Overview

## Course Identity

Speech Communication is a high-school oral communications course built from the verified CPALMS `Speech 1 (#1007300)` standards record. The course develops student facility in structuring speeches, researching information, analyzing audiences, presenting speeches, critiquing speeches, and building public speaking confidence.

This overview is architecture only. It does not create lessons, assessments, HTML files, quizzes, GIFT files, quiz JSON files, lesson JSON files, LMS pages, or student-facing instructional content.

## Standards Framework

| Framework Element | Course Decision |
|---|---|
| Primary official source | CPALMS `Speech 1 (#1007300)`, current version |
| Standards count | 25 official CPALMS-listed standards |
| MLA standard prefix | `MLA.SPEECH` |
| Domains | `COM`, `SPK`, `LST`, `PRES`, `RES`, `DIG` |
| Progression reference | CPALMS `Speech 2 (#1007310)` |

## Course Structure

| Unit | Unit Title | Core Focus |
|---:|---|---|
| 1 | Foundations of Communication, Audience, and Listening | Communication norms, active listening, voice/tone, language access, and rhetoric foundations |
| 2 | Speech Structure, Organization, and Informative Speaking | Logical organization, coherent focus, expository communication, paraphrase, and format-specific quality |
| 3 | Rhetoric, Argument, and Persuasive Speaking | Rhetorical appeals, opposing arguments, claims, reasoning, counterclaims, rebuttal, and evidence |
| 4 | Research-Supported Speaking and Source Use | Research questions, reliable sources, complex texts, inference, central idea support, and source-based speech planning |
| 5 | Delivery, Revision, Digital Presentation, and Publication | Feedback-based revision, conventions, vocabulary precision, digital presentation, and online collaborative publication |
| 6 | Professional, Multimedia, and Integrated Communication | Professional communication, interviews, discussions, multimedia presentation, research-supported briefing, and course synthesis |
