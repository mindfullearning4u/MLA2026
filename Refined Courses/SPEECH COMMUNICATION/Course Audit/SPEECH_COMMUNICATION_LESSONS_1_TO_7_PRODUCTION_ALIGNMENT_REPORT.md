# Speech Communication Lessons 1-7 Production Alignment Certification Report

## Executive Summary

This certification reviewed Speech Communication Units 1-6, Lessons 1-7 against the certified Speech Communication curriculum foundation.

Source of truth:

- Certified Standards Inventory
- Certified Crosswalk
- Certified Unit-Level Mapping
- Certified Lesson-Level Mapping

The certified lesson mapping is the authoritative source. This audit reviewed both structure and actual instructional content. The review verified that produced lessons faithfully implement the approved mapping and that the instructional content, examples, independent work, and checkpoints are deep enough for self-paced mastery-based learning.

Initial validation showed that:

- HTML structure was valid.
- Guided Practice and Lesson Quiz GIFT files were Moodle-ready.
- Lesson focus language was present across instructional pages.
- Units 2-6 `lesson.json` files listed combined standards but did not explicitly separate primary standards from support standards.
- Many P04, P06, and P07 pages were too compressed for independent mastery-based learning, especially Independent Work and Checkpoint pages.

Corrections were applied and the course was revalidated.

Final decision:

**PASS - STRUCTURE AND CONTENT ALIGN TO CERTIFIED LESSON MAPPING**

## Corrections Made

### Standards Metadata Correction

Updated 35 `lesson.json` files in Units 2-6 to include explicit primary and support standard metadata based on the certified lesson-level mapping.

Existing fields were preserved.

No standards were changed.

No mappings were changed.

### Content Alignment and Instructional Depth Correction

Mapped content-alignment support boxes were added to:

- P02 Notebook Task Part 1
- P03 Notebook Task Part 2
- P04 Worked Example
- P06 Independent Work
- P07 Checkpoint

Total pages enhanced:

- 210 pages

Additional targeted enhancements:

- P06 Independent Work pages received an independent-work quality check to strengthen Part A, Part B, and Part C expectations.
- P07 Checkpoint pages received a checkpoint-quality check to clarify submission expectations and mastery evidence.

Each added support section:

- Names the mapped lesson focus.
- Displays the mapped standard focus.
- Provides a step-by-step communication routine tied to the lesson skill.
- Strengthens application pages, not just direct-instruction pages.
- Supports remedial learners through explicit process guidance.
- Supports standard learners through clearer sequence and self-checking.
- Supports accelerated learners through attention to purpose, audience, evidence, clarity, effectiveness, and publication readiness.

Existing lesson content, examples, notebook tasks, independent work, checkpoints, assessments, visual shell, and compact TOR support boxes were preserved.
