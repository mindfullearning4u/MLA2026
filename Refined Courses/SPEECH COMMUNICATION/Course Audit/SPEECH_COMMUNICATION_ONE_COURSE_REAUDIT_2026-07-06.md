# Speech Communication One-Course Reaudit and Moodle Transfer Readiness Report

**Course:** Speech Communication  
**Audit Date:** 2026-07-06  
**Final Decision:** PASS  

## Audit Scope

This reaudit applied the current MLA course-production expectations to the full Speech Communication course before Moodle transfer.

The audit reviewed:

- Unit and lesson mapping alignment
- P01-P07 lesson workflow
- Step-by-step student-facing lesson rigor
- No-teacher-teaching language
- Visible standards on lesson pages
- Student support through TOR language only
- P02 visual organizer support
- Assessment format conversion to Moodle XML
- Assessment question counts, answer structure, feedback, and embedded context
- Lesson, pretest, quiz, guided practice, and unit assessment standard alignment

## Corrections Made

1. Converted all 102 legacy assessment banks to Moodle XML files in sibling `Moodle XML` folders.
2. Updated all 102 production JSON files so active assessment metadata points to Moodle XML instead of GIFT.
3. Normalized lesson support language from `Teacher of Record` wording to `TOR` wording to reinforce that the course is self-paced and there is no teacher-led instruction inside the lesson.
4. Added missing visible standard-alignment boxes to lesson pages that did not display `MLA.SPEECH` standards.
5. Added P02 visual organizer tables where the notebook task needed a clear organizer for communication analysis.
6. Replaced remaining language that described the written lesson as a teacher with self-paced lesson language.
7. Verified assessment standards against the lesson mapping and unit mapping.
