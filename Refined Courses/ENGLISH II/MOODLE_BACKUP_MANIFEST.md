## Course Structure

- Unit 1: Foundations of Close Reading, Evidence, and Academic Voice

- Unit 4: Research, Source Synthesis, and Expository Writing
- Unit 5: Language, Vocabulary, Style, and Revision
- Unit 6: Synthesis, Presentation, and Digital Communication

Each unit contains eight lessons. Each lesson contains exactly six pages:

1. `P01.html` — Lesson Overview
2. `P02.html` — Vocabulary and Definitions
3. `P03.html` — Lesson
4. `P04.html` — Worked Example
5. `P05.html` — Independent Work
6. `P06.html` — Checkpoint

The `lesson.json` file in each lesson directory records the Moodle course-module ID, current page titles, and Moodle page IDs used during synchronization.

## Dashboard Activities and Assessments

The existing unit assessment assets remain in each unit directory. The current Moodle dashboard sequence is:

- Unit pretest
- Lesson
- Notebook Evidence Submission
- Checkpoint Submission
- Lesson quiz for Lessons 1–7
- Unit assessment after Lesson 8

Notebook Evidence consists only of lesson vocabulary with definitions plus Independent Work. Checkpoint work is submitted separately. Both submissions use lesson-specific, student-visible rubrics with TOR-only answer guides and an 80% completion requirement.

Lesson quizzes use five random questions from a 25-question lesson-specific bank, permit one attempt, and require 80%. Unit assessments use ten random questions from a 40-question unit bank, permit one attempt, and require 80%.
