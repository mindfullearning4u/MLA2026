Notebook Task Part 1: Unit 4 Workflow Review

Notebook Title: Unit 4 Lesson 8 - Research to Publication Synthesis

Vocabulary

  • Inquiry: the process of asking and refining a research question.
  • Credibility: the trustworthiness of a source.
  • Synthesis: combining information from sources to explain a larger idea.
  • Expository writing: writing that explains information clearly.
  • Publication: sharing a polished product with an intended audience.

Unit 4 Source Set

Source A: A district pilot report found fewer unwanted trays after staff prepared meals from student pre-order selections.

Source B: A cafeteria manager explained that reminders helped more students complete the pre-order form after the first week.

Source C: A student feedback summary said students understood the purpose of the form more clearly when the message used simple wording and a labeled chart.

Research Question: How can student pre-order forms help reduce unwanted lunch trays?

Step-by-Step Teaching

  1. Start with the research question so every source detail has a purpose.
  2. Check source credibility and select evidence that directly answers the question.
  3. Paraphrase accurately so the meaning stays faithful to the source.
  4. Synthesize by explaining how the sources work together.
  5. Write an expository explanation with clear organization and voice.
  6. Revise for audience, conventions, and publication format.

Notebook Directions

Make a six-step Unit 4 workflow chart: Question, Source Check, Notes, Synthesis, Expository Draft, Publication.

Model Example: Source Check - I should use the pilot report because it directly answers the question with evidence about unwanted trays.
