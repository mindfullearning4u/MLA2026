Independent Work

Instructions

Use the source set below to complete Parts A, B, and C.

Research Question and Sources

Question: How could pre-order lunch forms reduce cafeteria food waste during one semester?

Source A: A district report says a pre-order pilot reduced unwanted trays because staff prepared meals from student selections.

Source B: A cafeteria manager interview says student reminders helped more students complete the form after the first week.

Part A

Write one useful note from Source A and one useful note from Source B.

Part B

Paraphrase Source A in one accurate sentence.

Part C

Write one synthesis sentence that combines Source A and Source B to answer the research question.
