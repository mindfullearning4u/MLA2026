Text A: The Empty Chair

After the debate captain graduated, nobody sat in her chair. Priya finally moved it into the circle and invited members to rotate leadership each week. The team stopped waiting for one replacement and discovered that several students could guide practice.

Text B: The Unmarked Trail

When a storm erased the trail markers, Caleb waited for the experienced hikers to choose a direction. None were certain. He studied the slope, stream, and sun, then suggested a route. Others added observations, and together they found the campsite.

Checkpoint Questions

  1. State the central conflict in each text.
  2. How does Priya respond to uncertainty?
  3. How does Caleb respond to uncertainty?
  4. State a theme for Text A.
  5. State a theme for Text B.
  6. Identify a shared theme.
  7. Select one supporting detail from each text.
  8. Compare how group action develops the theme.
  9. Explain the symbolic meaning of the empty chair.
  10. Explain the significance of the erased trail markers.
  11. Write a comparative claim identifying one similarity and one difference.
  12. Write a three-sentence comparison using evidence from both texts.
