P03 Notebook Task - Part 2: Word Families in Context

Now you will use word parts to understand and paraphrase sentences.

Context Sentence

After the storm damaged the outdoor stage, volunteers worked together to reconstruct it before the school performance.

Step-by-Step Application

  1. Identify the target word: reconstruct.
  2. Break the word into parts: re + construct.
  3. Use word-part meanings: re means again, and construct means build.
  4. Use the sentence context: the stage was damaged, so volunteers had to build it again.
  5. Paraphrase: Volunteers worked together to rebuild the outdoor stage.

Common Mistake

Incorrect Example:

Reconstruct means to destroy again because the stage was damaged.

Correct Example:

Reconstruct means to build again because re means again and construct means build.

Teachable Explanation: The incorrect example guesses from only one context clue. The correct example uses both word parts and context, which gives a more accurate meaning.
