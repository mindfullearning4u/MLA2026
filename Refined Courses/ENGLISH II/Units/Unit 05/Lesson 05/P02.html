Notebook Task Part 1: Understanding Useful Feedback

Notebook Title: Unit 5 Lesson 5 - Feedback and Revision for Audience Needs

Vocabulary

  • Feedback: information a writer uses to improve a draft.
  • Actionable feedback: feedback that tells the writer what to improve and why.
  • Audience needs: what readers need in order to understand and trust the writing.
  • Revision: changing writing to improve meaning, clarity, organization, or audience fit.

Draft and Feedback

Audience: school leaders.

Draft: The library should stay open later. Students need it. It would be good.

Feedback: Explain what students need the library for, and use a more formal tone for school leaders.

Step-by-Step Teaching

  1. Identify the audience: school leaders.
  2. Identify the purpose: persuade leaders to keep the library open later.
  3. Read the feedback for action. The writer must add explanation and improve tone.
  4. Revise vague words such as "it" and "good."
  5. Keep the main idea but make the reason clearer and more formal.

Notebook Directions

Create a two-column chart. In the first column, write the feedback. In the second column, write the revision action you should take.

Model Example: Feedback: use a more formal tone. Revision action: replace "It would be good" with a specific academic reason.
