Notebook Task Part 2: Reference Materials and Context

Now you will decide how to use a thesaurus responsibly.

Thesaurus Entry

Important synonyms: meaningful, serious, major, valuable, necessary.

Sentence: The principal made an _____ announcement about changes to the exam schedule.

Step-by-Step Application

  1. Do not choose a synonym only because it appears in a thesaurus.
  2. Read the context. An exam schedule change is something students need to know.
  3. Test each word. "Necessary announcement" sounds awkward because the announcement itself is not necessary in the same way a supply is necessary.
  4. "Major announcement" fits if the change is large, but it may overstate the meaning.
  5. "Important announcement" is precise because the announcement matters to students.

Common Mistake

Incorrect Example:

Choose any synonym from a thesaurus because all synonyms are interchangeable.

Correct Example:

Use the thesaurus to find options, then use context and precise meaning to choose the word that fits best.

Teachable Explanation: Synonyms are related, but they do not always mean exactly the same thing. Context decides which word is accurate.
