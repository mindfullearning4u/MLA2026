P06 — Checkpoint

Checkpoint Submission: Read both new arguments and answer all 10 questions separately.

Should the Town Replace Printed Notices with Digital Alerts?

Shared information: Digital alerts reach 78% of households within ten minutes. Printed notices reach nearly every address but require two days and cost $18,000 annually. Fourteen percent of residents report unreliable internet; emergency phone alerts remain available.

Argument A: Digital alerts should become the primary system because they are faster, less expensive, and easier to update. Savings can support emergency services. Printed notices should be reserved for residents who request them.

Argument B: Printed notices should remain primary because public information must reach residents regardless of internet access or technology skill. Speed matters, but a system that misses vulnerable households is not fully reliable. The town should add digital alerts without reducing printed delivery.

Questions

  1. State each claim neutrally.
  2. Identify three shared facts.
  3. How does A use cost data?
  4. How does B use the internet-access statistic?
  5. What assumption supports A’s request-only solution?
  6. What assumption supports B’s universal-print position?
  7. What additional evidence would test whether phone alerts solve the access problem?
  8. Identify one strength and one limitation in each argument.
  9. Which argument uses the shared information more validly? Explain.
  10. Write a balanced judgment using at least three facts and an explanation of the reasoning.
