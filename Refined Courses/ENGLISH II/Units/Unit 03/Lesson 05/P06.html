P06 Independent Work

Complete Part A, Part B, and Part C in complete sentences.

Instructions

Read both arguments. Then compare claims, evidence, and reasoning.

Paired Arguments

Shared Information: The school has funds for one improvement. The gym roof leaks during heavy rain. The auditorium sound system often fails during assemblies.

Argument A: The school should repair the gym roof first because water leaks can damage the floor and create safety problems for classes and teams.

Argument B: The school should replace the auditorium sound system first because assemblies, concerts, and presentations are harder to understand when microphones fail.

Part A

Write each argument's claim.

Part B

Identify the evidence and reasoning each argument uses.

Part C

Explain which argument is more urgent and why. Use evidence, not personal preference.
