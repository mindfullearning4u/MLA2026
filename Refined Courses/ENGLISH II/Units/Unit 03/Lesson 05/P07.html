P07 Checkpoint

This checkpoint shows whether you can compare opposing arguments and evaluate support.

Teacher of Record Reminder

Ask your Teacher of Record for help before submitting if you are relying on opinion instead of evidence.

Submission Workflow

  1. Review P02-P04.
  2. Complete the checkpoint in complete sentences.
  3. Check that your response includes claims, evidence, and reasoning.
  4. Submit according to your course directions.

Checkpoint Task

In one paragraph, compare Argument A and Argument B from P06. Explain which argument is more urgent and better supported. Include evidence from both arguments.

Mastery Criteria

  • Identifies both claims accurately.
  • Uses evidence from both arguments.
  • Evaluates validity using evidence and reasoning.
  • Uses clear academic sentences.
