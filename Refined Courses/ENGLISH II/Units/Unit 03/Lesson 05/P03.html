P03 — Lesson: Evaluating Opposing Arguments

Direct Teaching

Fair evaluation begins by representing each argument accurately. Then compare claims, shared evidence, reasoning, assumptions, relevance, and source credibility before reaching a judgment.

A Six-Step Evaluation

  1. State each author’s claim neutrally.
  2. Identify shared facts or information.
  3. Trace how each author connects evidence to the claim.
  4. Test relevance, sufficiency, and credibility.
  5. Identify assumptions, omissions, or logical weaknesses.
  6. Judge which argument is better supported and explain why.

Example 1 — Same Fact, Different Conclusion

Shared fact: Library visits fall after 7:00 p.m.

Argument A: Close at 7 because few people attend later. Argument B: Keep one branch open because workers and students need evening access.

Evaluation: Both use the same attendance fact, but B requires additional evidence about unmet need. A explains efficiency; B explains equity. Neither is complete without cost and user data.

Example 2 — Valid and Invalid Reasoning

Claim: The city should add protected bike lanes. Evidence: On one protected route, bicycle injuries fell 28 percent.

Valid reasoning: A protected design may reduce conflicts between cars and bicycles. Invalid reasoning: Because one route improved, every street will become completely safe. The second conclusion overgeneralizes.

Example 3 — Source and Relevance

A transportation engineer’s crash analysis directly supports a road-safety claim. A restaurant owner’s opinion may reveal business concerns but does not alone prove whether the design reduces injuries. Evidence can be sincere yet insufficient or irrelevant to a particular conclusion.

Common Mistakes

  • Choosing the position you prefer instead of evaluating support.
  • Treating a fact as proof without examining the reasoning.
  • Calling an argument invalid merely because it acknowledges limits.
  • Ignoring important evidence the author omits.
