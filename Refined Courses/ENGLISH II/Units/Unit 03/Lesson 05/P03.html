P03 Notebook Task - Part 2

Now you will evaluate validity by checking whether evidence and reasoning match the claim.

Read the Paired Passages

Shared Information: A school can add either a debate club or a quiet study room. A student survey showed 62 percent wanted more study space and 38 percent wanted more public speaking activities.

Argument A: Add a Quiet Study Room

The school should add a quiet study room because most surveyed students asked for more study space. A study room would help students complete homework, read independently, and prepare for tests. Since 62 percent selected study space, this option responds to the larger need.

Argument B: Add a Debate Club

The school should add a debate club because public speaking is useful. Some students want more speaking activities, and debate can help them organize ideas. The study room might help more students, but debate builds confidence that can last beyond one class.

Deeper Learning

Step 1: Argument A uses the survey majority as evidence.

Step 2: Argument B uses usefulness and long-term confidence as reasoning.

Step 3: Both arguments are understandable, but Argument A more directly uses the shared data.

Step 4: Argument B is not invalid, but it has less direct evidence from the survey.

Step 5: A careful evaluation recognizes both strengths and explains why one is better supported.

Notebook Application

  1. Identify each claim.
  2. Write the evidence used by each argument.
  3. Explain which argument uses the survey data more directly.
  4. Write one sentence that fairly describes the weaker argument's strength.

Common Mistake

Incorrect: Argument B is wrong because I do not like debate.

Correct: Argument B has a reasonable purpose, but Argument A is better supported by the survey because 62 percent of students asked for study space.

Why this matters: Validity is about evidence and reasoning, not personal preference.
