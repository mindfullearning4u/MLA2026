P02 Notebook Task Part 1

Notebook Title: Comparing Opposing Arguments

Vocabulary

Claim means the position or main argument an author wants readers to accept.

Opposing argument means an argument that takes a different position on the same issue.

Evidence means facts, examples, data, or details used to support a claim.

Reasoning means the explanation that connects evidence to the claim.

Validity means the argument is logical, relevant, and supported by evidence.

Step-by-Step Teaching

Step 1: Identify the issue. Both authors must be discussing the same problem or decision.

Step 2: Identify each claim. Ask, "What does each author want readers to believe or support?"

Step 3: Find the evidence each author uses.

Step 4: Examine reasoning. Ask whether the evidence truly proves the claim.

Step 5: Compare validity. A stronger argument uses relevant evidence and explains it clearly.

Read the Paired Passages

Shared Information: The town has money for one transportation project this year. The west bus route serves 900 riders each week. The river trail is used by walkers and cyclists and needs safety repairs.

Argument A: Improve the Bus Route

The town should improve the west bus route first. Nine hundred riders use that route each week, including workers, students, and older residents who do not drive. If the town adds shelters and more frequent service, the project will help people reach school, jobs, and medical appointments. The trail matters, but bus service affects daily access for more residents.

Argument B: Repair the River Trail

The town should repair the river trail first. The trail gives walkers and cyclists a safe path away from traffic, and damaged sections now create a safety risk. A repaired trail would support exercise, reduce short car trips, and improve the river area. The bus route is important, but the trail is a public space used by many ages.

Notebook Directions

  1. Write the notebook title.
  2. Copy the vocabulary words and meanings.
  3. Create a chart with columns for Argument A and Argument B.
  4. Write each author's claim.
  5. List one piece of evidence and one reasoning statement from each argument.

Model Example

Argument A claim: The town should improve the west bus route first.

Evidence: The route serves 900 riders each week.

Reasoning: Because many residents rely on the bus for school, work, and medical appointments, improving the bus route would affect daily access.
