P03 Notebook Task - Part 2: Turn Reading Analysis Into Argument Writing

In this part, you will use the same passage to build a formal argument response.

Included Passage Reminder

Community Library Proposal: The library is deciding between extending evening hours and purchasing lobby display screens. Evening hours would help residents who cannot visit before 5:00 p.m. Display screens could advertise events. Attendance records show steady program participation, while sign-in logs show frequent requests for later access. The passage recommends extending evening hours first because access to resources is the more documented need.

Step-by-Step Application

Step 1: Write the claim. The library should extend evening hours before purchasing display screens.

Step 2: Choose evidence. Sign-in logs show frequent requests for later access.

Step 3: Explain reasoning. Later access matters because residents cannot benefit from library resources if the building is closed when they are available.

Step 4: Add the counterclaim. Some people may argue that display screens should come first because they could advertise library events.

Step 5: Add the rebuttal. However, event participation is already steady, while the need for later access is documented in sign-in logs.

Notebook Directions

  1. Write one claim about which library improvement should come first.
  2. Copy one piece of evidence from the passage.
  3. Write one reasoning sentence that explains the evidence.
  4. Write one fair counterclaim.
  5. Write one rebuttal that answers the counterclaim using evidence.

Common Mistake

Incorrect: Only people who do not care about the library would buy display screens first.

Why this is incorrect: This attacks people instead of responding to the opposing argument. It does not use evidence, and it creates a biased tone.

Correct: Although display screens could help advertise events, extending evening hours should come first because sign-in logs show frequent requests for later access.

Why this is correct: This sentence fairly presents the counterclaim, uses evidence, and keeps an objective tone.
