P03 Notebook Task Part 2

Now you will move from understanding academic vocabulary to using it in a reading response.

Read the Passage

Volunteers at the community center organized donated books by topic before placing them on shelves. This system allowed visitors to locate books more efficiently and encouraged more families to use the reading room.

Direct Teaching

A strong academic response does not need to sound complicated. It needs to be clear and precise.

Vague response: The volunteers did a good thing with the books.

Stronger response: The volunteers created an organized system that helped visitors locate books more efficiently.

Notebook Directions

  1. Write the word efficiently.
  2. Explain what efficiently means in the passage.
  3. Write one vague response about the passage.
  4. Revise it by adding at least one academic vocabulary word from the passage.

Common Mistake

Incorrect: The books were better because people did stuff faster.

This is too vague. Words like better, stuff, and faster do not clearly explain the idea from the passage.

Correct: The organized system helped visitors locate books more efficiently.

This is stronger because it uses academic vocabulary from the passage and explains the idea clearly.
