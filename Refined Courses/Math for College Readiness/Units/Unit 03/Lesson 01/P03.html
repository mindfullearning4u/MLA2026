Notebook Title

Notebook Task Part 2: Data Displays and Representations

Build the Reasoning

A good data display helps a reader compare, count, or notice a pattern. A bar graph compares categories. A histogram shows how numerical values are distributed across intervals. A line graph shows how a quantity changes over time. A two-way table organizes two categorical variables at the same time.

A complete data explanation should include the context, the value or display you used, and a sentence explaining what the result means. A number without a context sentence is not enough for mastery.

Common Mistake

Incorrect: Choosing a display or summary because it looks familiar, without checking the data type or context.

Correct: First identify what the data represent, then choose the display or summary that answers the question clearly. The correction is to match method to meaning.

Notebook Task

Write one incorrect data decision and one corrected decision. Explain why the corrected version is stronger.
