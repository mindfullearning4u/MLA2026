Notebook Title

Notebook Task Part 1: Comparing Data Sets

Vocabulary

  • Distribution: the overall pattern of data values.
  • Center: a typical value, often described by the mean or median.
  • Variability: how spread out the data values are.
  • Outlier: a value far away from the rest of the data.
  • Shape: the visual pattern of data, such as clustered, spread out, or skewed.
  • Comparison statement: a sentence that explains how two data sets are alike or different.

Learn the Idea

When comparing data sets, do not choose a winner by looking at only one value. A strong comparison uses center, variability, shape, and outliers. The center tells what is typical, while variability tells how consistent or spread out the values are.

  1. Read the context and identify the variables.
  2. Decide what each value or point represents.
  3. Choose the summary, graph, or model that matches the question.
  4. Write an interpretation using context and units when available.

Teacher-Style Thinking Guide

In Comparing Data Sets, treat the notebook task as a worked investigation, not a quick answer. First identify what the problem gives you, what it asks you to find or decide, and which representation is most useful: equation, table, graph, diagram, probability model, financial comparison, or written claim.

Next, explain the reason for each step. For example, if you divide, state what rate, unit, probability, or comparison the division creates. If you choose a formula or model, state why the context fits that model and what each variable represents.

This synthesis work should connect back to the unit standards, so every answer must show the calculation, representation, or explanation that justifies the decision.

A strong notebook entry includes labeled work, a final interpretation sentence, and a quick reasonableness check. Ask yourself whether the answer is too large, too small, outside a possible range, missing a unit, or unsupported by the evidence shown.
