P04 Guided Practice / Worked Example

Example 1: Compare centers

Problem: Set A has median 75. Set B has median 75.

  1. Identify the median of each set.
  2. Both medians are 75.
  3. The typical score is the same for both sets.

Answer: The centers are equal because both medians are 75.

Example 2: Compare variability

Problem: Set A range is 10. Set B range is 35.

  1. Find each range using greatest minus least.
  2. Set A: 80 - 70 = 10.
  3. Set B: 95 - 60 = 35.

Answer: Set B has greater variability because its range is larger.

Example 3: Explain an outlier effect

Problem: A data set is 8, 9, 10, 10, 48.

  1. Most values are close to 8, 9, and 10.
  2. The value 48 is far away from the rest.
  3. The mean and range will be pulled upward by 48.

Answer: The outlier makes the data look more spread out and raises the mean.

Common Mistake

Incorrect: Giving only a number, graph direction, or model with no explanation.

Correct: State the result and explain what it means in the data context. Data answers must communicate meaning.
