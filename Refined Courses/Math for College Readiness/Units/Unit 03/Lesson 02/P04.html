P04 Guided Practice / Worked Example

Step-by-step explanation: Follow each example in order. Notice how the work identifies the context, selects a strategy, calculates carefully, and interprets the result.

Worked Example 1: Find the mean

Problem: Find the mean of 6, 8, 10, 12.

  1. Step 1: Add the values: 6 + 8 + 10 + 12 = 36.
  2. Step 2: Count the values: there are 4 values.
  3. Step 3: Divide: 36 / 4 = 9.

Answer: The mean is 9.

Worked Example 2: Find the median

Problem: Find the median of 14, 9, 11, 20, 10.

Visual: order the data before finding the middle

  1. Step 1: Order the data: 9, 10, 11, 14, 20.
  2. Step 2: Find the middle value because there are 5 values.
  3. Step 3: The middle value is 11.

Answer: The median is 11.

Worked Example 3: Describe variability

Problem: Compare the ranges of Set A: 20, 21, 22, 23 and Set B: 10, 18, 25, 33.

  1. Step 1: Set A range: 23 - 20 = 3.
  2. Step 2: Set B range: 33 - 10 = 23.
  3. Step 3: The larger range means Set B is more spread out.

Answer: Set B has greater variability because its range is 23, compared with 3 for Set A.

Common Mistake

Incorrect: Writing only the final number or graph choice with no explanation.

Correct: State the answer and explain what it means in the context. Data answers must communicate meaning, not just procedure.
