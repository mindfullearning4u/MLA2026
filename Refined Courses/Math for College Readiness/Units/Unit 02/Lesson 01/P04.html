P04 Worked Example

Study all three worked examples carefully. Each example shows the thinking, not just the final answer.

Example 1

Problem: A phone repair costs $30 plus $18 per hour. The total cost is $102. Find the number of hours.

  1. Define the variable: h = number of repair hours.
  2. Write the equation: 30 + 18h = 102.
  3. Subtract 30 from both sides: 18h = 72.
  4. Divide by 18: h = 4.
  5. The repair took 4 hours.

Final check: The answer is connected back to the real-world situation.

Example 2

Problem: A membership costs $25 to join plus $15 each month. The total paid is $85. Find the number of months.

  1. Define the variable: m = number of months.
  2. Write the equation: 25 + 15m = 85.
  3. Subtract 25: 15m = 60.
  4. Divide by 15: m = 4.
  5. The membership lasted 4 months.

Final check: The answer is connected back to the real-world situation.

Example 3

Problem: A taxi charges $5 plus $2 per mile. The total cost is $23. Find the number of miles.

  1. Define the variable: m = number of miles.
  2. Write the equation: 5 + 2m = 23.
  3. Subtract 5: 2m = 18.
  4. Divide by 2: m = 9.
  5. The taxi traveled 9 miles.

Final check: The answer is connected back to the real-world situation.

Common Mistake

Incorrect:

30 + 18h = 102, so h = 102 - 18

Why it is wrong: The student subtracted the rate instead of undoing the fixed fee first. In a two-step equation, undo addition or subtraction before undoing multiplication.

Correct:

30 + 18h = 102, 18h = 72, h = 4

Correction: Use the relationship described in the problem, not just the numbers or symbols that appear first.
