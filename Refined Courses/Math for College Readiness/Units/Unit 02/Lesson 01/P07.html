Checkpoint Task: Linear Equations in Context

A gym charges $20 to join and $12 each month. A student pays $80 total. Write an equation, solve for the number of months, and interpret the answer.

  1. List the quantities and units.
  2. Define the variable or input.
  3. Write or use the appropriate model.
  4. Solve or interpret the model.
  5. Explain why the answer is reasonable.

Mastery Criteria

  • Identifies quantities, units, and variables accurately.
  • Uses a model aligned to the lesson standard.
  • Shows organized step-by-step work.
  • Interprets the answer in context.
  • Checks reasonableness using the situation.

Alignment

MLA.MCR.AR.1: I can write and solve multi-step linear equations that model real-world situations.
