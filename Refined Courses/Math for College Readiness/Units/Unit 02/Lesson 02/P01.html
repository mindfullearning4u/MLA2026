P01 Lesson Overview

Lesson Title

Lesson 2: Linear Functions and Graph Interpretation

In this lesson, you will write and interpret linear equations from tables, descriptions, graphs, and real-world relationships.

Standards Covered in This Lesson

MLA.MCR.AR.2: I can write linear equations from graphs, tables, descriptions, and real-world relationships.

MLA.MCR.AR.3: I can solve, graph, and interpret linear function models with key features and constraints.

Florida Benchmarks: MA.912.AR.2.2; MA.912.AR.2.5

Common Core Alignment: HSA-CED.A.2; HSF-LE.A.2; HSF-IF.B.4; HSF-IF.C.7a

What You Will Learn

  • How slope and intercept describe a linear relationship.
  • How to write equations from tables and descriptions.
  • How to interpret graph features in context.
  • How constraints limit real-world function values.

What You Will Do

  • Find rates of change from tables.
  • Write equations in the form y = mx + b.
  • Interpret slope, intercept, and output values.
  • Explain domain restrictions in context.

How You Will Show Mastery

  • Submit notebook evidence with equations and interpretations.
  • Submit a checkpoint using a linear function model.
  • Demonstrate at least 80% mastery on the lesson quiz.

Student-Friendly Standard Connection

MLA.MCR.AR.2 and MLA.MCR.AR.3: These standards help you model constant-change relationships and interpret what the model means.

In student language: I can write and interpret a linear function from a real-world situation.
