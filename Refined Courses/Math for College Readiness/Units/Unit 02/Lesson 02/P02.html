Lesson 2: Linear Functions and Graph Interpretation

Linear Function Form

A linear function can often be written as y = mx + b.

  • m is the slope or rate of change.
  • b is the starting value or y-intercept.
  • x is the input.
  • y is the output.

Example from a Description

A delivery company charges $15 plus $2 per mile.

Input: miles m

Output: cost C

Equation: C = 2m + 15

Meaning: The slope is $2 per mile and the intercept is the $15 starting fee.

Vocabulary

  • Linear function: A relationship with a constant rate of change.
  • Slope: The rate of change.
  • Y-intercept: The starting value when input is 0.
  • Constraint: A limit on possible input or output values.
