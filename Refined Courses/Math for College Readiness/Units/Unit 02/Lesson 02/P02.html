Notebook Title

Lesson 2: Linear Functions and Graph Interpretation

Vocabulary

  • Linear function: A relationship with a constant rate of change.
  • Slope: The rate of change in a linear relationship.
  • Y-intercept: The starting value when x = 0.
  • Input: The value substituted into a function.
  • Output: The value produced by a function.
  • Constraint: A restriction on values that make sense in context.

Why This Lesson Matters

Algebra is useful when a real-world situation has an unknown value or a relationship that changes in a predictable way.

Before calculating, identify what each number means and decide what the variable represents.

A plan that starts at $20 and increases by $15 each month can be modeled by C = 15m + 20, where 15 is the rate and 20 is the starting value.

Step-by-Step Thinking Process

  1. Read the problem and identify the question being asked.
  2. Define the variable or input.
  3. Identify constants, rates, or starting values.
  4. Write the equation or model.
  5. Solve, evaluate, or interpret the model.
  6. Check whether the answer makes sense in context.
