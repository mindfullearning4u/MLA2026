Independent Work

  1. Write an equation for a cost of $20 plus $5 per item.
  2. Identify the slope and intercept in C = 5n + 20.
  3. Evaluate C(8) = 5(8) + 20 and interpret it.
  4. Find the rate of change from a table with points (2, 14) and (6, 30).

Checkpoint Task

  1. Write a linear function for total cost.
  2. Identify the slope and intercept.
  3. Find the cost for 4 hours.
  4. Interpret the meaning of the slope.
