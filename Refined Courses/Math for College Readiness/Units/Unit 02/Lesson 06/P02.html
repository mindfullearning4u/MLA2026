Notebook Title

Lesson 6: Piecewise Relationships and Step Functions

Vocabulary

  • Piecewise function: A function that uses different rules for different input intervals.
  • Interval: A set of input values where one rule applies.
  • Step function: A piecewise function that stays constant over intervals and jumps at boundaries.
  • Boundary: The input value where a rule changes.
  • Constraint: A restriction that tells which inputs are allowed.
  • Open endpoint: A boundary value not included in an interval.
  • Closed endpoint: A boundary value included in an interval.

Why This Lesson Matters

Many real-world situations do not change by simple addition every time. Some multiply by a factor, and some change rules depending on the input.

Before solving, identify the starting value, rule, interval, multiplier, or boundary that controls the model.

A parking garage may charge $5 for the first hour and $3 for each additional hour. The rule changes after the first hour, so a piecewise model is useful.

Step-by-Step Thinking Process

  1. Read the situation and identify what changes.
  2. Identify the starting value, multiplier, interval, or boundary.
  3. Write the model or choose the correct rule.
  4. Evaluate or interpret the model one step at a time.
  5. Write the answer with units and context.
  6. Check whether the answer is reasonable.
