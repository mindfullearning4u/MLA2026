P04 Worked Example

Study all three worked examples carefully. Each example shows the thinking, not just the final answer.

Example 1

Problem: A phone plan costs $30 plus $12 per month. Find the cost for 5 months.

  1. Identify the model type: linear cost model.
  2. Write C = 30 + 12m.
  3. Substitute m = 5.
  4. C = 30 + 12(5) = 90.
  5. The cost for 5 months is $90.

Final check: The solution is interpreted in the real-world situation.

Example 2

Problem: A budget is at most $75. Tickets cost $15 each. Find possible ticket counts.

  1. Identify the model type: inequality.
  2. Write 15t = 75.
  3. Divide by 15: t = 5.
  4. Ticket counts must be whole numbers.
  5. The person can buy 0, 1, 2, 3, 4, or 5 tickets.

Final check: The solution is interpreted in the real-world situation.

Example 3

Problem: Two plans are A = 20 + 10m and B = 50 + 5m. Find the break-even point.

  1. Identify the model type: system or break-even equation.
  2. Set the models equal: 20 + 10m = 50 + 5m.
  3. Subtract 5m and 20: 5m = 30.
  4. Divide by 5: m = 6.
  5. The plans cost the same after 6 months.

Final check: The solution is interpreted in the real-world situation.

Common Mistake

Incorrect:

The answer is 6

Why it is wrong: A number alone is not enough in a real-world model. The answer must include units and context.

Correct:

The plans cost the same after 6 months

Correction: The final answer must be mathematically correct and meaningful in the situation.
