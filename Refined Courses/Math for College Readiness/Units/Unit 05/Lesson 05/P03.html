P03 Notebook Task Part 2

Order Matters or Not?

If first place, second place, and third place are awarded, order matters. That is a permutation. If a committee of 3 people is chosen and everyone has the same role, order does not matter. That is a combination.

Ask: Would changing the order create a different result? If yes, order matters. If no, order does not matter.

Common Mistake - Incorrect

Incorrect: Choosing Ana then Ben is always different from choosing Ben then Ana.

This is only true if order matters, such as first and second place.

Common Mistake - Correct

Correct: For a two-person committee, Ana and Ben is the same group as Ben and Ana.

When order does not matter, avoid counting the same group more than once.

Notebook Task

Write one situation where order matters and one situation where order does not matter. Explain each choice.
