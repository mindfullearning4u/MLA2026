Connecting Events

Some probability questions compare more than one event. The words matter. The word or usually points to a union because the outcome can be in the first event, the second event, or both. The word and usually points to an intersection because the outcome must satisfy both event descriptions at the same time.

Use this sample space for a number cube: {1, 2, 3, 4, 5, 6}.

  • Event A: rolling an even number = {2, 4, 6}
  • Event B: rolling a number greater than 4 = {5, 6}
  • A or B = {2, 4, 5, 6}
  • A and B = {6}

Complement

A complement is the event not happening. If Event A is rolling an even number, then the complement of A is rolling a number that is not even. On a number cube, the complement of {2, 4, 6} is {1, 3, 5}.

A helpful check is this: the event and its complement should cover the whole sample space with no overlap.

Common Mistake - Incorrect

Incorrect: For a number cube, A or B means only the outcomes that are in both A and B.

This mixes up union and intersection. The word or is broader than and.

Common Mistake - Correct

Correct: A or B includes outcomes in A, outcomes in B, and outcomes in both. A and B includes only outcomes shared by both events.

Always translate the words first. Then list the outcomes so your answer is supported by evidence from the sample space.

Notebook Task

In your notebook, write one example of a complement, one example of a union, and one example of an intersection using the same sample space.
