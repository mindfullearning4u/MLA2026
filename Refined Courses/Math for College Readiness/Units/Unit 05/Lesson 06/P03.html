Fairness

A fair decision has expected value 0 for the player after cost and payoff are included. If expected value is positive, the player has an advantage on average. If expected value is negative, the player loses on average over time.

Example: Pay $2 to play. Win $6 with probability 1/2 and win $0 with probability 1/2. Net payoff if win is $4 because $6 - $2 = $4. Net payoff if lose is -$2. Expected value is (1/2)($4) + (1/2)(-$2) = $1.

Common Mistake - Incorrect

Incorrect: If a game pays $6, use $6 as the win value even when it costs $2 to play.

This ignores the cost. Expected value should use net gain or loss.

Common Mistake - Correct

Correct: If a game costs $2 and pays $6, the net win is $4.

Always subtract the cost before deciding whether the decision is fair.

Notebook Task

Write a short explanation of why cost must be included when deciding whether a game is fair.
