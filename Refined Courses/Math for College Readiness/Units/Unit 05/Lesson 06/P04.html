P04 Guided Practice / Worked Example

Step-by-step explanation: Follow each example in order. Notice how the work identifies the context, selects a strategy, calculates carefully, and interprets the result.

Worked Example 1

Question: A game has a 1/2 chance to win $4 and a 1/2 chance to win $0. What is the expected value?

  1. Step 1: Multiply each value by its probability.
  2. Step 2: (1/2)($4) = $2.
  3. Step 3: (1/2)($0) = $0.
  4. Step 4: Add: $2 + $0 = $2.

Worked Example 2

Question: A game costs $3. It pays $9 with probability 1/3 and pays $0 with probability 2/3. What is the expected net value?

  1. Step 1: Net win is $9 - $3 = $6.
  2. Step 2: Net loss is -$3.
  3. Step 3: Expected value: (1/3)($6) + (2/3)(-$3).
  4. Step 4: $2 + (-$2) = $0. The game is fair.

Worked Example 3

Question: A choice has a 1/4 chance to gain $20 and a 3/4 chance to lose $4. Is the expected value positive?

  1. Step 1: (1/4)($20) = $5.
  2. Step 2: (3/4)(-$4) = -$3.
  3. Step 3: Add: $5 + (-$3) = $2.
  4. Step 4: The expected value is positive, so the decision is favorable on average.

Common Mistake - Incorrect

Incorrect: A positive prize always means the game is favorable.

This ignores probability and cost. A large prize may still have a negative expected value if it is very unlikely or expensive to play.

Common Mistake - Correct

Correct: Compare probability-weighted gains and losses.

Expected value uses both chance and payoff, then interprets the long-run average result.
