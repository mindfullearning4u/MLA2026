Addition Rule for Or

When events do not overlap, add the probabilities. On a number cube, rolling a 1 or a 6 has probability 1/6 + 1/6 = 2/6 = 1/3.

When events overlap, subtract the overlap so it is not counted twice. Rolling an even number or a number greater than 4 gives even {2, 4, 6}, greater than 4 {5, 6}, and overlap {6}. The probability is 3/6 + 2/6 - 1/6 = 4/6 = 2/3.

Multiplication Rule for And

When independent events both need to happen, multiply the probabilities. If a coin is flipped and a number cube is rolled, the probability of heads and a 4 is 1/2 Ã— 1/6 = 1/12.

The multiplication rule works here because the coin result does not change the chance of rolling a 4.

Common Mistake - Incorrect

Incorrect: Rolling an even number or a number greater than 4 has probability 3/6 + 2/6 = 5/6.

This counts 6 twice because 6 is both even and greater than 4.

Common Mistake - Correct

Correct: Subtract the overlap once: 3/6 + 2/6 - 1/6 = 4/6 = 2/3.

Before adding probabilities, check whether any outcome belongs to both events.
