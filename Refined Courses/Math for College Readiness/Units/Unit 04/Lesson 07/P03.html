Notebook Title

Notebook Task Part 2: Spreadsheet-Supported Financial Decisions

Build the Reasoning

Profit is found by subtracting cost from revenue. If revenue is greater than cost, there is profit. If cost is greater than revenue, there is a loss. In a spreadsheet, the same formula can be copied down rows to compare several scenarios. A responsible financial decision uses the results and the constraints together.

A complete financial answer includes the amount, the label, the tradeoff, and the constraint. This makes the calculation useful for decision making.

Common Mistake

Incorrect: Choosing an option from one number only without checking cost, time, risk, formula, and constraints.

Correct: Compare the full decision and explain why the result fits the financial context.

Notebook Task

Write one incomplete financial decision and one corrected decision. Explain why the corrected version is stronger.
