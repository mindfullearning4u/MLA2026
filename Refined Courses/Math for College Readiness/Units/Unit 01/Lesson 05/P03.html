Function Notation

Function notation names an input and an output. If C(h) = 15h + 20, then h is the input and C(h) is the output.

Context: A service call costs $20 plus $15 per hour.

Evaluate: C(4) = 15(4) + 20 = 80

Interpret: A 4-hour service call costs $80.

Example: Interpret an Output

Function: B(m) = 30m

Context: B(m) gives the total cost in dollars for m months of a membership.

Evaluate: B(6) = 30(6) = 180

Answer: A 6-month membership costs $180.

Common Mistake to Avoid

Do not report only the number. A function output must be interpreted in context.

Incomplete: C(4) = 80.

Complete: C(4) = 80, so a 4-hour service call costs $80.
