Lesson 5: Formulas, Variables, and Function Notation in Context

Variables and Formulas

A variable represents a quantity that can change or is unknown. A formula shows a relationship between quantities.

Example: d = rt means distance equals rate times time.

  • d represents distance.
  • r represents rate.
  • t represents time.

Rearranging a Formula

Problem: Use d = rt to solve for time.

Start: d = rt

Divide both sides by r: d/r = t

Result: t = d/r

Meaning: Time equals distance divided by rate.

Vocabulary

  • Variable: A symbol representing a quantity.
  • Formula: An equation showing how quantities are related.
  • Isolate: Get a variable by itself.
  • Input: The value put into a function.
  • Output: The value produced by a function.
