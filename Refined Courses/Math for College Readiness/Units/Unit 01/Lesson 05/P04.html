P04 Worked Example

Study all three worked examples carefully. Each example shows the thinking, not just the final answer.

Example 1

Problem: Evaluate C = 12m + 20 when m = 5.

  1. Identify the input: m = 5.
  2. Substitute 5 for m: C = 12(5) + 20.
  3. Calculate: 60 + 20 = 80.
  4. The cost is $80.

Final check: The answer includes the correct unit and matches the question.

Example 2

Problem: Solve d = rt for r.

  1. Start with d = rt.
  2. r is multiplied by t.
  3. Divide both sides by t.
  4. r equals distance divided by time.

Final check: The answer includes the correct unit and matches the question.

Example 3

Problem: If f(x) = 3x + 10, find f(4).

  1. f(4) means use input 4.
  2. Substitute 4 for x: 3(4) + 10.
  3. 12 + 10 = 22.
  4. The output is 22.

Final check: The answer includes the correct unit and matches the question.

Common Mistake

Incorrect:

f(4) = f ï¿½ 4

Why it is wrong: Function notation names an input-output relationship. It is not multiplication by the letter f.

Correct:

f(4) means the output when x = 4

Correction: Use the relationship described in the problem, not just the numbers that appear first.
