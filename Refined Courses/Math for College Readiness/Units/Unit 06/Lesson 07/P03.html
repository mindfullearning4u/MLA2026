P03 Notebook Task Part 2

Combining Steps

Many design problems require more than one formula. For example, a storage project might require finding volume first and then checking whether the object fits within a height constraint. A landscaping problem might require area first and then cost.

Write one step per line. Each line should answer a small question that helps solve the final problem.

Reasonableness and Constraints

A correct calculation can still fail the context. If a design must fit through a 36-inch doorway and the model is 40 inches wide, the design does not meet the constraint. If a floor area answer is in cubic feet, the unit does not match the measurement type.

Always ask: Does the unit match? Does the answer fit the limit? Does the size make sense?

Common Mistake - Incorrect

Incorrect: A student finds a room area of 120 cubic feet and accepts the answer because the multiplication is correct.

The unit is wrong. Room area is flat space, so the answer should use square feet.

Common Mistake - Correct

Correct: A room area should be written in square feet because it measures two-dimensional floor space.

The unit check is part of the solution, not an extra step after the answer.
