P04 Guided Practice / Worked Example

Example 1

Question: A triangle has a side of 6 inches. A similar triangle has the matching side of 18 inches. What is the scale factor?

  1. Compare new length / original length.
  2. Write 18 / 6.
  3. Divide: 18 / 6 = 3.
  4. The scale factor is 3.

Example 2

Question: A rectangle with width 5 cm is enlarged by a scale factor of 4. What is the new width?

  1. A scale factor is a multiplier.
  2. Multiply the original width by 4.
  3. 5 × 4 = 20.
  4. The new width is 20 cm.

Example 3

Question: On a scale drawing, 2 inches represents 10 feet. How many feet are represented by 7 inches?

  1. Find the real length for 1 inch: 10 / 2 = 5 feet.
  2. Each inch represents 5 feet.
  3. Multiply 7 × 5 = 35.
  4. 7 inches represents 35 feet.

Common Mistake - Incorrect

Incorrect: If 2 inches represents 10 feet, then 7 inches represents 15 feet because 7 is 5 more than 2.

This adds the difference instead of using the scale relationship. Scale problems use multiplication and division.

Common Mistake - Correct

Correct: If 2 inches represents 10 feet, then 1 inch represents 5 feet, so 7 inches represents 35 feet.

A scale drawing uses a constant rate, so every inch must represent the same real distance.
