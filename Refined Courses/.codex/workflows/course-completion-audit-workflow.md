# Course Completion Audit Workflow

## Purpose

Run this workflow after all units are complete.

## Sequence

1. Confirm all unit completion audits exist.
2. Re-check current course files directly.
3. Validate mapping traceability.
4. Validate full course structure.
5. Validate all lesson pages.
6. Validate all metadata JSON.
7. Validate all assessments.
8. Validate all assessment visuals.
9. Validate all answer patterns and feedback.
10. Validate all Lesson 8 synthesis lessons.
11. Validate all resource/simulation reviews.
12. Validate accreditation and compliance evidence.
13. Produce final course completion audit.

## Rule

Prior reports are not enough. Current files must be checked directly before certification.
