# Course Completion Audit Workflow

## Purpose

Run this workflow after all units are complete.

## Sequence

1. Confirm all unit completion audits exist.
2. Confirm the required unit/category subagent coverage table is complete.
3. Confirm each subagent PASS cites approved mapping evidence and current-file evidence.
4. Re-check current course files directly.
5. Validate mapping traceability for every unit, lesson, page, standard, and assessment question.
6. Validate full course structure.
7. Validate all lesson pages.
8. Validate all metadata JSON.
9. Validate all assessments.
10. Validate all assessment visuals as a blocking certification gate.
11. Validate all answer patterns and feedback.
12. Validate all Lesson 8 synthesis lessons.
13. Validate all resource/simulation reviews.
14. Validate accreditation and compliance evidence.
15. Confirm every valid subagent finding was fixed and rerun.
16. Produce final course completion audit.

## Rule

Prior reports are not enough. Current files must be checked directly before certification.

Subagent coverage is also required. Current-file scripts and main-agent direct inspection are necessary, but they do not replace unit/category subagent audits. Do not certify a course unless each unit has instructional rigor, structure/workflow, assessment alignment, assessment visual/XML, and metadata/LMS audit evidence.

Assessment visual validation must produce PASS before final certification. If any math or science assessment question requires a graph, table, number line, diagram, model, data display, or other visual representation and that representation is missing from the question, the course completion audit must stop with FAIL.

Mapping validation must produce PASS before final certification. If any mapped standard is missing from instruction or assessment evidence, or any lesson/assessment uses standards or topics outside the approved mapping, the course completion audit must stop with FAIL.

If the subagent coverage table is missing, incomplete, or unsupported by evidence, the course completion audit must stop with FAIL.
