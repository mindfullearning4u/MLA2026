# Course Verification Workflow

## Purpose

Use this workflow after corrections are made.

## Verification Checks

1. Validate mapping traceability.
2. Validate all files exist.
3. Validate JSON.
4. Validate P01-P07 page roles.
5. Validate P04 has three worked examples.
6. Validate P06/P07 workflow.
7. Validate final synthesis lesson: Lesson 8 for 1.0-credit courses or Lesson 5 for 0.5-credit courses.
8. Validate Moodle XML mechanics.
9. Validate answer pattern.
10. Validate feedback quality.
11. Validate visual necessity decisions.
12. Validate resource/simulation review completed.
13. Validate unit completion audits.
14. Validate full course completion audit.
15. Validate final report.

## Rule

Do not rely on prior certification reports. Validate current files directly.
