# Seven-Page Lesson Model: P01-P07

## Purpose

Every lesson must follow the approved seven-page MLA lesson model. ALG1 Math Department is the current high-standard visual and workflow reference.

## P01 Lesson Overview

Required sections:

- Course/unit/lesson header
- `P01 Lesson Overview`
- Lesson Title
- Standards Covered in This Lesson
- What You Will Learn
- What You Will Do
- How You Will Show Mastery
- Student-Friendly Standard Connection
- Teacher of Record support box

P01 must tell the student exactly what the lesson is about, what standard is being learned, and how mastery will be shown.

## P02 Notebook Task Part 1

Required sections:

- `P02 Notebook Task - Part 1`
- Notebook Title
- Vocabulary
- detailed teaching sequence
- actual mathematical or subject objects
- explicit explanations
- Teacher of Record support box

P02 begins instruction. It must not assume a live teacher is present.

## P03 Notebook Task Part 2

Required sections:

- `P03 Notebook Task - Part 2`
- continued detailed teaching sequence
- examples or guided notes
- actual mathematical or subject objects
- Common Mistake
- Incorrect example in red
- Correct example in green when applicable
- Teachable Explanation
- Teacher of Record support box

P03 deepens instruction and addresses likely confusion.

## P04 Worked Example

Required sections:

- `P04 Worked Example`
- Worked Example 1
- Worked Example 2
- Worked Example 3
- actual problem for each example
- step-by-step explanation for each example
- why each step is done
- interpretation of the answer
- necessary visual in sequence with the example
- Common Mistake
- Incorrect example in red
- Correct example in green
- detailed teachable explanation
- Teacher of Record support box

P04 must never contain vague examples. Three worked examples are required.

## P05 Guided Practice

Required sections:

- `P05 Guided Practice`
- student-facing readiness or practice language
- standards display when required by department model
- clear reference to Moodle Guided Practice
- no visible backend `.gift` filenames
- Teacher of Record support box

The actual Guided Practice bank must be in the matching `.gift` file and follow the assessment standard.

## P06 Independent Work

Required sections:

- `P06 Independent Work`
- opening independent work workflow language
- notebook evidence language
- instructions
- Part A
- Part B
- Part C
- actual tasks or problems
- self-contained work
- Teacher of Record support box

P06 must function like an independent practice worksheet. Do not use vague phrases such as "complete several problems" without providing the actual problems.

## P07 Checkpoint

Required sections:

- `P07 Checkpoint`
- Teacher of Record Graded
- Checkpoint Task
- Notebook Evidence Submission
- Checkpoint Submission
- Submission Workflow
- Mastery Criteria
- 80% mastery requirement
- correction/resubmission language
- TOR intervention language
- Teacher of Record support box

The checkpoint task must be clear, self-contained, and specific.

## Page Consistency Checks

For each lesson:

- Exactly one TOR support box per page.
- No empty containers.
- No text outside intended containers.
- No backend filenames displayed.
- No broken HTML layout.
- No missing page heading.
- Page role matches page number.
