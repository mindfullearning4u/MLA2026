# Lesson 8 Synthesis Standard

## Purpose

Lesson 8 in each unit must be a true synthesis lesson. It prepares students for the Unit Assessment by integrating Lessons 1-7.

## Lesson 8 Is Not

Lesson 8 is not:

- review only
- reteaching only
- assessment launch only
- isolated skill practice
- a place to introduce major new standards
- a page that displays backend assessment filenames

## Lesson 8 Must

Lesson 8 must:

- integrate Lessons 1-7
- combine unit standards, concepts, skills, vocabulary, reasoning, and communication
- use only standards taught in Lessons 1-7
- include synthesis tasks on P02-P07
- preserve the MLA workflow
- include Guided Practice before Unit Assessment
- prepare students for the Unit Assessment
- keep assessment references student-facing and not backend-facing

## Lesson 8 Page Checks

Check:

- P01 identifies synthesis purpose
- P02/P03 include mixed unit tasks
- P04 includes three synthesis worked examples
- P05 prepares students for Guided Practice/Unit Assessment
- P06 includes independent synthesis work
- P07 includes checkpoint synthesis task and mastery criteria
