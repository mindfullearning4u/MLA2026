# Final Course Certification Report Standard

## Purpose

Every course build or audit must end with a final report that states what was reviewed, what was corrected, what remains, and whether the course passes.

## Required Report Location

Recommended location:

`[COURSE]/Course Audit/[COURSE]_FINAL_COURSE_CERTIFICATION_REPORT.md`

Use the course's existing audit folder naming pattern when one exists.

## Required Sections

Include:

1. Course
2. Date
3. Scope
4. Sources used
5. Units reviewed
6. Lessons reviewed
7. Mapping traceability result
8. Lesson structure result
9. P01-P07 page model result
10. Instructional rigor result
11. Final synthesis lesson result: Lesson 8 for 1.0-credit courses or Lesson 5 for 0.5-credit courses
12. Visual/resource result
13. Assessment result
14. Assessment visual audit result
15. Answer pattern and feedback result
16. JSON/metadata result
17. LMS/HTML formatting result
18. External resources/simulation suggestions
19. Files corrected
20. Files not changed due to locked content
21. Remaining issues
22. Final decision: PASS or FAIL

## PASS/FAIL Rules

PASS means all required checks passed and no blockers remain.

FAIL means at least one required area has unresolved issues.

PASS WITH SUGGESTIONS may be used only when all required structural and compliance checks pass, but optional instructional/resource improvements remain.

## Evidence Requirement

Reports must reference exact files and exact unit/lesson locations. Do not make broad claims without file evidence.
