# Answer Pattern and Feedback Standard

## Purpose

Assessment banks must avoid predictable answer patterns and must use feedback as a teachable moment.

## No Answer Pattern

Correct answers must not:

- repeat in obvious sequences
- cluster excessively
- follow ABCD cycles
- always be the longest option
- always be the most detailed option
- always use the same position for certain problem types

## Distribution Expectations

Default targets:

- Guided Practice: balanced as much as possible across 5 questions
- Lesson Quiz: balanced across 20 questions
- Unit Pretest: balanced across 10 questions
- Unit Assessment: balanced across 40 questions

Distribution alone is not enough. Sequence must also be checked.

## Feedback Standard

Correct feedback must:

- explain the reasoning
- reference the method or concept
- reinforce mastery language

Incorrect feedback must:

- identify the misconception
- explain why the choice is not correct
- point toward the correct reasoning

## Guided Practice Priority

Guided Practice feedback must be especially teachable because it supports learning before quiz/mastery decisions.

## Audit Output

Report:

- answer distribution by file
- answer sequence concerns
- repeated choice patterns
- generic feedback
- missing feedback
- weak feedback needing revision
- duplicate choices
- duplicate stems
