# Instructional Rigor and Mastery Standard

## Purpose

Lessons must be written for asynchronous mastery learning. Students should be able to learn from the lesson without a live teacher filling in missing steps.

## Veteran Teacher Standard

Every lesson should read like a veteran teacher is teaching the student directly:

- clear sequence
- precise vocabulary
- actual examples
- explicit steps
- explanation of why each step is used
- interpretation of answers
- anticipation of misconceptions
- connection to the standard
- enough support for remedial, standard, and accelerated students

## Required Question for Agents

For each lesson, ask:

What else does the student need so everything is clear?

Then ask:

- What resources does the student need to understand this material?
- What would Dr. Annie want included so students understand and gain mastery?
- What confusion might the student have before asking for help?
- What example, visual, table, graph, passage, explanation, or practice task would prevent that confusion?

## Worked Example Requirements

Every worked example must:

- state the actual problem
- show the mathematical or subject object
- explain Step 1, Step 2, Step 3, etc.
- explain why each step is done
- use correct notation
- interpret the final answer
- connect back to the lesson objective

## Vague Instruction Prohibition

Do not leave vague directions such as:

- "Apply the rule."
- "Use the method."
- "Complete the problem."
- "Graph the inequality."
- "Simplify the expression."
- "Practice today's skill."

Unless the actual problem, method, and expected work are fully shown.

## Rigor Audit Output

Classify each finding:

- PASS: lesson teaches clearly and completely
- REQUIRED STRUCTURAL FIX: missing required section or label
- SUGGESTION ONLY: content would need rewriting, expansion, or new examples
- BLOCKED: mapping/source conflict prevents judgment

When content is locked, report rigor improvements as suggestions only.
