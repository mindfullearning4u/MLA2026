# Mathematical and Instructional Visual Standard

## Purpose

Visuals must support understanding. They must not be decorative, generic, or included only for consistency.

## Decision Rule

Ask:

What mathematical or subject object is being taught in this exact example, question, or task?

The object is the visual.

## Use Visuals When Needed

Use:

- actual tables
- actual graphs
- actual coordinate planes
- actual number lines
- actual equations
- actual algebraic expressions
- actual diagrams
- actual statistical displays
- actual geometric figures
- actual science models
- actual lab setups or data displays

## Do Not Use

Do not use:

- generic summary graphics
- decorative visuals
- repeated visuals for consistency only
- placeholder process graphics
- visuals that do not directly support the task
- external images unless explicitly approved
- JavaScript widgets inside Moodle lesson pages

## Math Graph Requirements

Graphs must include:

- x-axis label
- y-axis label
- numbered tick marks
- plotted points when needed
- intercepts labeled when relevant
- mathematically accurate scale
- clear line, curve, region, or data display

Use inline SVG or Moodle-safe HTML tables/diagrams. No external graphing tools embedded in lesson HTML unless approved.

## Visual Placement

Place the visual in sequence with the example or task it supports. Do not dump visuals at the end if that disrupts teaching flow.

## Visual Audit Output

For each suggested visual, report:

- lesson/page/question
- mathematical or subject object
- visual type needed
- why it is needed
- whether the current file already includes it
- whether adding it would change locked content
- recommendation: required structural fix or suggestion only
