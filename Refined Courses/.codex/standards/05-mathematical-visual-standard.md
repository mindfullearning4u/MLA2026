# Mathematical and Instructional Visual Standard

## Purpose

Visuals must support understanding. They must not be decorative, generic, or included only for consistency.

In math courses, visuals are part of the instruction and assessment standard. Lessons and questions must show what a veteran teacher would show: graphs, tables, number lines, diagrams, geometric figures, data displays, and step-by-step representations wherever those representations clarify the concept, remove ambiguity, or help students build mastery.

## Decision Rule

Ask:

What mathematical or subject object is being taught in this exact example, question, or task?

The object is the visual.

If a student may reasonably ask "where can I see that?", "what does that look like?", "how is the pattern organized?", or "which representation are they referring to?", then the lesson or assessment needs the representation directly in sequence.

## Use Visuals When Needed

Use:

- actual tables
- actual graphs
- actual coordinate planes
- actual number lines
- actual equations
- actual algebraic expressions
- actual diagrams
- actual statistical displays
- actual geometric figures
- actual science models
- actual lab setups or data displays

## Required Math Visual Categories

Use the appropriate representation when teaching or assessing:

- integer comparison or movement: number line
- sign rules or operation patterns: formatted rule table
- proportional relationships: ratio table or graph when helpful
- linear relationships: table, coordinate graph, slope triangle, intercept labels, or rate-of-change table as appropriate
- inequalities: number line or coordinate-plane shading when graphing is part of the question
- systems: graph with intersection or organized table when relevant
- functions: mapping/table/graph when determining structure, domain/range, intercepts, or notation meaning
- quadratics: table, graph/parabola, vertex/intercepts, or area model when relevant
- exponential models: table/graph showing multiplicative change when relevant
- statistics: dot plot, histogram, box plot, scatterplot, two-way table, or data table when relevant

## Do Not Use

Do not use:

- generic summary graphics
- decorative visuals
- repeated visuals for consistency only
- placeholder process graphics
- visuals that do not directly support the task
- external images unless explicitly approved
- JavaScript widgets inside Moodle lesson pages

## Math Graph Requirements

Graphs must include:

- x-axis label
- y-axis label
- numbered tick marks
- plotted points when needed
- intercepts labeled when relevant
- mathematically accurate scale
- clear line, curve, region, or data display

Use inline SVG or Moodle-safe HTML tables/diagrams. No external graphing tools embedded in lesson HTML unless approved.

## Visual Placement

Place the visual in sequence with the example or task it supports. Do not dump visuals at the end if that disrupts teaching flow.

## Visual Audit Output

For each suggested visual, report:

- lesson/page/question
- mathematical or subject object
- visual type needed
- why it is needed
- whether the current file already includes it
- whether adding it would change locked content
- recommendation: required structural fix or suggestion only

Mandatory visuals are not optional. A missing mandatory visual blocks certification.
