# World History Rigor and Visual Repair Audit

Course: World History
Date: 2026-07-09
Reason: Follow-up audit found that the course was structurally complete, but the lesson implementation relied too heavily on generic step language and table-based organizers. The course needed stronger asynchronous teaching support and embedded visuals where visual reasoning improves student understanding.

## Repair Scope

- Units reviewed: 6
- Lessons reviewed: 48
- Lesson HTML pages preserved: 336
- JSON files preserved: 96
- Moodle XML files preserved: 102
- GIFT files: 0

## Repairs Completed

| Area | Requirement | Repair Completed |
|---|---|---|
| Step-by-step lesson rigor | Lessons must read like a veteran teacher is guiding the student without live instruction. | Replaced generic P02 step sections with lesson-specific steps tied to each lesson title, standard set, required visual, and historical reasoning task. |
| Visual learning support | Lessons must include visuals when they help students understand maps, timelines, cause/effect, comparison, source reasoning, or historical relationships. | Added one embedded Moodle-safe inline SVG instructional visual to every P02 lesson page. Visual type is selected from the lesson's required visual/stimulus mapping. |
| Deeper explanation | Students must receive clarification before confusion appears. | Added Teacher-Level Clarification sections to every P03 page. Each section tells students how to move from context to evidence to relationship to standard-bound mastery. |
| Worked examples | Worked examples must teach how to use visual/source evidence, not only list generic steps. | Added Worked Visual Check sections to every P04 page. Students are told how to read labels, identify evidence type, point to the clue, explain the relationship, and avoid drifting outside the lesson standard. |
| Standards boundary | Lessons and assessments must stay inside the unit and lesson mapping. | Each added rigor section names the mapped standards and tells students not to bring in unrelated historical facts. |
| TOR support | The course may encourage Teacher of Record support, but must not depend on live teacher instruction. | Added support language that directs students to ask the Teacher of Record for help when they cannot explain the answer with the visual and standard. |

## Visual Coverage

Every lesson now contains an enhanced instructional visual aligned to the required visual/stimulus map:

- Map-style visuals for geography, routes, borders, regions, migration, alignment, and theater lessons.
- Timeline-style visuals for chronology, escalation, development, and sequence lessons.
- Cause-effect diagrams for decline, revolution, industrialization, conflict, and decision-consequence lessons.
- Source-reasoning visuals for inquiry, source analysis, evidence portfolios, and historical responsibility lessons.
- Comparison visuals for belief systems, civilizations, monarchies, ideologies, societies, and institutions.
