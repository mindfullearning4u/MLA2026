# ENV Lab and Virtual Lab Matrix

## Purpose

This matrix documents recommended laboratory and virtual-laboratory experience types for future Environmental Science lesson development. It is architecture guidance only and does not create lab instructions, student-facing lesson content, assessment questions, HTML content, JSON content, legacy assessment-bank content, or LMS pages.
