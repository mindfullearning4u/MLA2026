Teacher-Style Explanation

This lesson focuses on Environmental Data, Maps, and Models. The standard is MLA.ENV.LAB.02, so the work must stay inside this lesson: Use tables, graphs, maps, and models..

A strong environmental science answer does more than state an opinion. It reads the required map, graph, table, model, source, or case evidence; names the pattern; explains the environmental relationship; and limits the conclusion to what the evidence can support.

  1. Identify the environmental question being asked.
  2. Read the assigned visual, model, map, graph, table, source excerpt, or case data.
  3. Name the evidence pattern that supports the claim.
  4. Explain the environmental cause, effect, tradeoff, or system relationship.
  5. State one limitation so the conclusion does not go beyond the evidence.
