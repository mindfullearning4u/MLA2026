# Foundations of Art Visual and Source Mapping

Required supports are embedded directly in lesson HTML and Moodle XML when needed. Students must not need to search elsewhere for a visual required to answer a question.

| Support Type | Course Use |
|---|---|
| Composition diagrams | focal point, balance, movement, space, design revision |
| Color swatches | hue, value, intensity, temperature, harmony, contrast |
| Critique organizers | describe, analyze, interpret, judge |
| Media/process tables | tool safety, planning, experimentation, revision |
| Portfolio organizers | selection, documentation, reflection, presentation |

External simulations are not required by default for Foundations of Art. Free museum or design resources may be suggested for enrichment only when directly aligned and student-safe.
