P04 Worked Example

Embedded Scenario

Embedded Multimedia Publication Scenario: A senior project team is preparing to publish a multimedia text about youth financial literacy. The final product will include a short written introduction, an infographic showing common budgeting mistakes, a two-minute narration, source credits, and a shareable digital format for classmates and community partners. The team must decide how to combine words, visuals, audio, evidence, and publication choices so the message is accurate, accessible, ethical, and useful for the intended audience.

Example 1: Match Mode to Purpose

Question: Why include an infographic?

Modeled thinking: The topic includes patterns and mistakes. Visual organization can make patterns easier to understand.

Answer: The infographic should show common budgeting mistakes in a concise visual format that supports the introduction and narration.

Example 2: Plan Source Credits

Question: Why include source credits?

Modeled thinking: Publication requires ethical sharing. Viewers need to know where facts, visuals, and ideas came from.

Answer: Source credits protect credibility and show responsible use of borrowed material.

Example 3: Choose a Sharing Format

Question: What makes a format shareable?

Modeled thinking: Classmates and community partners need a format they can open easily and understand without extra directions.

Answer: A shareable format should load reliably, include readable visuals, provide clear audio or transcript support, and preserve source credits.

Common Mistake

Incorrect example: The narration should repeat every word from the written introduction.

Correct example: The narration should explain or emphasize key ideas that the written introduction and infographic introduce.

Teachable explanation: Each mode should add value. Repeating the same information in every mode can weaken the audience experience.
