P02 Notebook Task Part 1

Notebook Title

Integrated Evidence and Academic Voice

Vocabulary

  • Integration: combining parts so they work together.
  • Academic voice: clear, precise, formal communication appropriate for school, college, and work.
  • Evidence: source information that supports a claim.
  • Rationale: reasoning that explains why evidence matters.
  • Coherent: logically organized and easy to follow.

Embedded Passage

Passage: Responsible Technology Use

Digital tools can expand learning when students use them with purpose. A note-taking application can help a student organize source ideas, and a shared document can make peer feedback more efficient. However, technology does not automatically improve learning. If students copy information without paraphrasing, accept suggestions without evaluating them, or use digital tools to avoid careful thinking, the tool weakens rather than strengthens academic work. Responsible technology use requires students to preserve source meaning, evaluate support, and communicate conclusions clearly.

Detailed Teaching

Step 1: Find the passage's central claim: digital tools help learning only when used with purpose and careful thinking.

Step 2: Paraphrase without weakening the qualification. The passage does not reject technology; it warns that technology must be used responsibly.

Step 3: Select relevant evidence. The examples of copying without paraphrasing and accepting suggestions without evaluation show irresponsible use.

Step 4: Use academic vocabulary such as preserve, evaluate, responsible, and coherent to explain the evidence.

Notebook Directions and Model

  1. Write the notebook title and vocabulary.
  2. Paraphrase the passage's central claim.
  3. Select one relevant piece of evidence.
  4. Explain why the evidence supports the claim.

Model: The passage argues that digital tools improve learning only when students use them thoughtfully. The warning about copying without paraphrasing supports this claim because it shows how technology can weaken academic work when students avoid careful thinking.
