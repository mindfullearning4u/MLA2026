P04 Worked Example

Example 1: Root and Word Family

Word: credible

Clue: The root cred relates to belief.

Meaning: Credible means believable or trustworthy.

Modeled thinking: If a report is credible, readers have reason to trust it.

Example 2: Foreign Phrase

Phrase: status quo

Meaning: the existing state of things.

Sentence: The proposal challenged the status quo by asking the school to revise a long-standing policy.

Paraphrase: The proposal challenged the current way things were done.

Example 3: Derivation

Word family: prescribe, description, transcript, inscription

Shared clue: The root scribe/script relates to writing.

Reasoning: A transcript is a written record, and an inscription is writing placed on a surface.

Common Mistake

Incorrect: Status quo means a new change or future plan.

Correct: Status quo means the current or existing state of things.

Teachable explanation: A proposal that challenges the status quo challenges what already exists; it does not describe the new change itself.
