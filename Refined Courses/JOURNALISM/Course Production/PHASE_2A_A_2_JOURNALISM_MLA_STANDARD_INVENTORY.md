# Phase 2A-A-2: Journalism MLA Standard Assignment

## Executive Summary

This report establishes the official MLA Journalism standard inventory using the approved MLA numbering framework:

`MLA.[COURSE].[DOMAIN].[NUMBER]`

For Journalism, the course identifier is `JOUR`. Standards are numbered within the Journalism domains:

- `NEWS` = News Writing
- `REP` = Reporting
- `MED` = Media Literacy
- `INT` = Interviewing and Source Communication
- `ETH` = Journalism Ethics and Management
- `PUB` = Publication
- `DIG` = Digital Journalism
- `COM` = Communication

Primary source: CPALMS public course record for `Journalism 1 (#1006300)`, current version, course detail ID `23541`.

This inventory is architecture only. It does not create lessons, assessments, HTML files, quizzes, GIFT files, lesson JSON files, quiz JSON files, LMS pages, or student-facing instructional content.
