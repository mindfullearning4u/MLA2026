# Phase 3A-B-1: Journalism Unit-Level Mapping

## Executive Summary

This document maps all 33 verified Journalism MLA standards to the approved six-unit course architecture. Every standard appears at the unit level, and no unit introduces student-facing lesson content, assessments, HTML files, quizzes, GIFT files, quiz JSON files, lesson JSON files, or LMS pages.
