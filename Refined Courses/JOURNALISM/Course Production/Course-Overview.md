# Journalism Course Overview

## Course Identity

Journalism is a high-school factual communication and publication course built from the verified CPALMS `Journalism 1 (#1006300)` standards record. The course develops fundamental skills in the production of journalism across print, multimedia, web, and broadcast/radio platforms, with attention to journalism history, ethics, media literacy, reporting, source verification, audience awareness, digital journalism, and publication.

This overview is architecture only. It does not create lessons, assessments, HTML files, quizzes, GIFT files, quiz JSON files, lesson JSON files, LMS pages, or student-facing instructional content.

## Course Structure

| Unit | Unit Title | Core Focus |
|---:|---|---|
| 1 | Foundations of Journalism, News Judgment, and Ethics | Journalism purpose, ethics, newsroom norms, media history, design trends, source communication, and language access |
| 2 | Reporting, Source Verification, and Interviewing | Reporting questions, source reliability, complex source comprehension, inference, paraphrase, evidence, and interviewing |
| 3 | News, Feature, and Editorial Writing | News/expository writing, feature writing, editorial argument, revision, conventions, vocabulary, style, and reporting presentation |
| 4 | Media Literacy, Rhetoric, and Audience | Media structures, central idea support, author purpose, opposing claims, language effects, rhetoric, and audience analysis |
| 5 | Digital Journalism, Multimedia, and Publication | Digital presentation, sequential media, visual accuracy, collaborative publication, production workflow, and team media package development |
| 6 | Newsroom Portfolio, Publication, and Multimedia Synthesis | Portfolio planning, verification, revision, audience check, multimedia package preparation, publication readiness, and final synthesis |
