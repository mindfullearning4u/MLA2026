📰 JOURNALISM | Unit 02 | Lesson 07

P06 Independent Work

Instructions

Use the cafeteria ordering scenario to create a short reporting and interview plan. Your work should show that you can organize information before writing or publishing.

Part A

Create a list of three confirmed details from the source file. For each detail, name the source who provided it.

Part B

Create a list of three details that still need verification. Explain why each detail matters to the story.

Part C

Write three neutral interview questions. Each question must connect to one missing detail from Part B and must avoid assuming the answer.

Mastery Support Checklist

  • Did I separate confirmed information from missing information?
  • Did I connect each interview question to a reporting purpose?
  • Did I avoid leading or accusatory wording?
  • Did I preserve source meaning?
