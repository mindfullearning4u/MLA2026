P05 Guided Practice

Guided Practice

Complete the Guided Practice questions in Moodle. Each question gives feedback that teaches the reasoning step. Use the feedback before moving to independent work.

  1. Identify the journalism responsibility.
  2. Connect the responsibility to the standard.
  3. Select the choice that best protects accuracy and audience understanding.

Before You Answer

Use this three-part thinking routine for every guided practice item.

Step 1: Name the broad topic in the prompt.

Step 2: Decide whether the answer narrows the topic into a focused reporting question or useful scope decision.

Step 3: Reject any answer that is too broad, opinion-only, impossible to verify, or unrelated to the audience need.

If you miss a question, read the feedback and write one sentence explaining the reporting step you skipped.

Mastery Check Before Moving On

Before independent work, make sure you can say this aloud: My reporting question is focused because it names one information need, can be answered with sources, and has a clear boundary. If your answer cannot do all three, return to P02 and revise the question before continuing.
