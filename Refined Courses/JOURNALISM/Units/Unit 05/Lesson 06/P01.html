P01 Lesson Overview

Lesson Title

Lesson 6: Collaborative media package production

This lesson teaches how a journalism team creates a cohesive media package through collaboration, compromise, accurate visuals, and publication-ready planning. A strong package feels unified even when multiple people create different parts.

Standards Covered in This Lesson

Primary Standard: MLA.JOUR.ETH.02 - Collaborative Media Production.

Support Standards: MLA.JOUR.DIG.02 - Sequential Images and Media in Motion; MLA.JOUR.PUB.01 - Online Collaborative Publication.

What You Will Learn

  • How collaborative choices create a cohesive media package.
  • How respectful compromise solves production conflict.
  • How sequence, tone, visuals, and captions work together.
  • How to prepare team-produced media for publication.

What You Will Do

  • Study an embedded Spirit Week media package scenario.
  • Identify team conflict and audience needs.
  • Practice choosing compromises that preserve accuracy and cohesion.
  • Complete guided practice, independent work, checkpoint, and quiz.

How You Will Show Mastery

  • Recommend respectful compromises.
  • Explain how package parts should be ordered.
  • Protect cohesive tone and accurate captions.
  • Submit checkpoint evidence aligned to MLA.JOUR.ETH.02.

Student-Friendly Standard Connection

In student language: I can work with a media team to create a cohesive, accurate, publication-ready package.
