P03 Notebook Task - Part 2

Continued Notebook Application

Now evaluate package order. A collaborative package needs an order that helps the audience understand the topic and move through the media logically.

Deeper Learning

Step 1: Start with context. The article should introduce the recap so readers know what the package covers.

Step 2: Add motion after context. The video can show energy once the audience understands the topic.

Step 3: Add gallery for detail. Photos let readers explore moments after the main idea is clear.

Step 4: Use the quote card strategically. The quote card can highlight student leadership if it is captioned accurately.

Step 5: Resolve conflict respectfully. A decision should explain audience benefit, not simply declare one team member the winner.

Embedded Source Reminder

Embedded Collaboration Scenario: Multimedia Spirit Week Package

Project: A student media team is creating a multimedia package about Spirit Week for the school website.

Package Parts: A short article, a 20-second recap video, a photo gallery, and a captioned quote card from the student council president.

Team Conflict: The video editor wants fast music and quick cuts. The reporter wants slower pacing so the quote is clear. The photo editor wants the gallery first because the photos are strong. The web editor says the package needs a consistent tone, accurate captions, and a logical order for readers.

Audience: Students, families, and staff who want a clear recap of the week.

Collaboration Need: The team must compromise respectfully, maintain a cohesive package, use accurate visuals, and prepare publication-ready work.

Common Mistake

Incorrect: Put the photo gallery first because the photo editor likes the photos best.

Correct: Start with the article for context, then use video, gallery, and quote card to add energy and detail.

Teachable Explanation: Team preference is not enough. Package order should serve the audience and keep the project cohesive.

Notebook Directions

Write one proposed package order and explain why each part belongs in that position. Include one respectful compromise for the team conflict.
