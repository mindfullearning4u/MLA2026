P03 Notebook Task Part 2

Integrated Digital Publication Package

Embedded Source Reminder

Digital Publication Package. Project: The journalism team is preparing a web package called Cafeteria Changes Explained. Required parts: a short explanatory article, one accurate feature photo, a three-image sequence showing the lunch line process, a 30-second audio caption, and a publication checklist. Audience: students and families who need clear, accurate information before Monday. Visual Accuracy Concern: one photo shows an old menu board that is no longer used. Workflow Concern: the package must be reviewed, captioned, exported, and submitted by Friday at 3:00 p.m. Publication Goal: the final package must use accurate visuals, clear sequence, coherent digital presentation, and an organized online layout.

Deeper Learning: How to Judge Publication Readiness

A digital package is not ready just because every part exists. It is ready when every part serves the audience and supports the same accurate message.

Ask three questions:

  1. Does this media part tell the truth clearly?
  2. Does this media part connect to the purpose of the package?
  3. Has this media part been checked before the deadline?

If the answer to any question is no, the team needs revision before publication.

Common Mistake

Incorrect: Publish the old menu-board photo because it is bright and fills the page.

Correct: Replace or recaption the image so the visual record matches the current cafeteria change.

Teachable explanation: The incorrect choice treats visual appeal as more important than accurate reporting. The correct choice protects audience trust. A publication-ready package should never use a misleading image just because it looks good.

Notebook Directions

In your notebook, write one paragraph explaining why the old menu-board photo creates a publication risk. Then write one sentence explaining how to fix the problem without delaying the whole package.
