P05 Guided Practice

Integrated Digital Publication Package

Embedded Source

Digital Publication Package. Project: The journalism team is preparing a web package called Cafeteria Changes Explained. Required parts: a short explanatory article, one accurate feature photo, a three-image sequence showing the lunch line process, a 30-second audio caption, and a publication checklist. Audience: students and families who need clear, accurate information before Monday. Visual Accuracy Concern: one photo shows an old menu board that is no longer used. Workflow Concern: the package must be reviewed, captioned, exported, and submitted by Friday at 3:00 p.m. Publication Goal: the final package must use accurate visuals, clear sequence, coherent digital presentation, and an organized online layout.

Guided Practice Directions

Answer the guided practice questions in Moodle. Use the embedded source in each item. Read the question, identify the standard, eliminate choices that weaken accuracy or publication readiness, and choose the best answer.
