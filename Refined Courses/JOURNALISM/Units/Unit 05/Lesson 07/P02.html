P02 Notebook Task Part 1

Integrated Digital Publication Package

Notebook Title

Notebook Task Part 1: Build a Publication-Ready Digital Package

Vocabulary

  • Digital package: a published set of connected media pieces that work together.
  • Publication-ready: accurate, complete, organized, edited, and ready for an audience.
  • Visual accuracy: the image correctly represents the person, place, event, or information.
  • Sequence: the order of images, clips, or steps that helps the audience understand.
  • Export: prepare a digital file or package for submission or publication.

Embedded Source

Digital Publication Package. Project: The journalism team is preparing a web package called Cafeteria Changes Explained. Required parts: a short explanatory article, one accurate feature photo, a three-image sequence showing the lunch line process, a 30-second audio caption, and a publication checklist. Audience: students and families who need clear, accurate information before Monday. Visual Accuracy Concern: one photo shows an old menu board that is no longer used. Workflow Concern: the package must be reviewed, captioned, exported, and submitted by Friday at 3:00 p.m. Publication Goal: the final package must use accurate visuals, clear sequence, coherent digital presentation, and an organized online layout.

Step-by-Step Teaching

Step 1: Identify the audience. Students and families need clear information before Monday, so the package must be practical, accurate, and easy to follow.

Step 2: Identify the required media parts. The article explains the change, the photo shows the setting, the three-image sequence explains the process, and the audio caption adds a concise explanation.

Step 3: Check visual accuracy before design preference. A bright photo is not useful if it shows an old menu board. Journalism values accuracy before decoration.

Step 4: Check the sequence. The lunch line images should move in a clear order: entry, selection, checkout. A random order makes the audience work too hard.

Step 5: Check the workflow. Friday at 3:00 p.m. is the deadline. Review, captions, export, and submission must happen before that time, not after.

Notebook Directions

In your notebook, create a four-row publication checklist with these headings: audience need, visual accuracy, media sequence, and deadline step. Under each heading, write one action the team must take before publishing.

Model Example

Audience need: Students and families need clear cafeteria information before Monday.

Visual accuracy: Replace the old menu-board photo because it no longer represents the current cafeteria.

Media sequence: Place lunch line images in process order.

Deadline step: Complete captions and export before Friday at 3:00 p.m.
