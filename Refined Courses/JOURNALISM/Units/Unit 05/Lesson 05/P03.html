P03 Notebook Task - Part 2

Continued Notebook Application

Now turn the task list into a production schedule. A schedule is not just a list. It shows order, dependency, and responsibility.

Deeper Learning

Step 1: Find tasks that must happen before others. Verification must happen before final export.

Step 2: Identify tasks that can happen at the same time. The video editor can cut interview clips while the copy editor verifies the name.

Step 3: Sequence revision before final production. The script transition should be fixed before the final package is assembled.

Step 4: Reserve time for quality control. Export settings and captions need a final check.

Step 5: Communicate responsibility. Every task should have one owner so the team does not assume someone else completed it.

Embedded Source Reminder

Embedded Production Scenario: Friday Broadcast Package Workflow

Project: The newsroom must publish a two-minute Friday broadcast package about the school supply drive.

Deadline: Final package must be submitted by Thursday at 3:30 p.m. for Friday morning release.

Team Tasks: Reporter drafts the script, video editor cuts interview clips, photo editor adds two accurate still images, copy editor checks names and captions, and producer exports the final file.

Current Status: The interview clips are recorded, but one student name needs spelling confirmation. The script is missing a transition between the donation total and the volunteer quote. The still image caption does not identify the collection table location. The export settings have not been checked.

Workflow Need: The team must prioritize tasks, protect accuracy, meet the deadline, and avoid publishing before verification is complete.

Common Mistake

Incorrect: Export the package first because the deadline is close, then fix the name spelling if there is time.

Correct: Verify the name spelling before export because accuracy problems must be fixed before publication.

Teachable Explanation: Speed cannot replace verification. A production workflow must protect both deadline and credibility.

Notebook Directions

Write a five-step production schedule for the broadcast package. Each step must include the task owner and the reason the step belongs in that position.
