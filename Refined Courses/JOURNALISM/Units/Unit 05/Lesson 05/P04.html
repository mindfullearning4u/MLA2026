P04 Worked Example

Example 1

Question: What task should happen before export?

Modeled thinking: Export creates the final file. Any accuracy issue must be fixed before the final file is created.

Answer: The team should confirm the student name spelling before export.

Reasoning: This prevents a factual error from being published.

Example 2

Question: Which tasks can happen at the same time?

Modeled thinking: Tasks can happen at the same time if they do not depend on each other.

Answer: The video editor can cut interview clips while the copy editor checks names and captions.

Reasoning: Parallel work saves time without skipping verification.

Example 3

Question: Why does the caption need revision?

Modeled thinking: The caption does not identify the collection table location. Readers need that context.

Answer: The photo editor should revise the caption to identify the collection table location.

Reasoning: Accurate captions help the audience understand visual evidence.

Common Mistake

Incorrect: The producer should export as soon as the video looks complete.

Correct: The producer should export after script, captions, names, clips, and settings are checked.

Teachable explanation: Looking complete is not the same as being publication-ready. Final export comes after quality control.
