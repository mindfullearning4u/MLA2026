P04 Worked Example

Example 1

Question: Which image is most accurate?

Modeled thinking: I match the image to the assignment. The assignment is about the new station outside the gym.

Answer: Image D is strongest because it shows the correct station and includes location and date context.

Reasoning: It gives visual evidence and caption support.

Example 2

Question: Why is Image C incomplete?

Modeled thinking: The close-up shows a student filling a bottle, but the station label is cropped out.

Answer: Image C is partly useful but incomplete because it removes visual context that proves the location and station identity.

Reasoning: Cropping can make an image less accurate.

Example 3

Question: What should the caption include?

Modeled thinking: The caption needs the who, what, where, and when that matter.

Answer: The caption should identify the new refill station outside the gym and note that it opened Monday.

Reasoning: This helps the audience connect the image to the report.

Common Mistake

Incorrect: The best image is always the one with the most dramatic angle.

Correct: The best journalism image is the one that accurately supports the report and gives the audience needed context.

Teachable explanation: Visual drama can support a story, but it cannot replace accuracy.
