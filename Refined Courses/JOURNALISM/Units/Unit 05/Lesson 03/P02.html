P02 Notebook Task Part 1

Notebook Title

Visual Accuracy and Evidence in Journalism

Set up your notebook to compare image choice, source evidence, caption accuracy, and audience effect.

Vocabulary

  • Visual evidence: an image that helps prove or explain a report.
  • Caption: text that identifies and explains an image.
  • Cropping: cutting part of an image out of the frame.
  • Context: information that helps the audience understand what the image shows.
  • Misleading image: a visual that creates an inaccurate impression.

Embedded Source

Embedded Production Scenario: Field Photo Accuracy Check

Assignment: Create accurate visual images for a school news brief about the new water bottle refill station outside the gym.

Available Images: Image A shows the actual refill station outside the gym with the blue installation sign visible. Image B shows an older hallway water fountain near the cafeteria. Image C is a close-up of a student filling a bottle, but the station label is cropped out. Image D shows the refill station after the caption writer added the location and date.

Reporting Notes: The station opened Monday. The facilities manager said it is the first refill station installed near the gym. The student government sponsor said the project was funded by a campus wellness grant.

Accuracy Requirement: The final visual must show the correct station, avoid misleading cropping, and include a caption that identifies what the audience is seeing.

Step-by-Step Teaching

Step 1: Identify the reporting assignment. The image must support a brief about the new refill station outside the gym.

Step 2: Reject inaccurate visuals. Image B shows an older hallway fountain near the cafeteria, so it does not match the report.

Step 3: Check for missing context. Image C shows a student filling a bottle, but the station label is cropped out. That weakens accuracy.

Step 4: Choose the strongest visual evidence. Image A shows the actual station with the installation sign visible. Image D improves that visual by adding location and date in the caption.

Step 5: Connect image to evidence. The caption should identify the gym location and Monday opening so readers understand the visual.

Step 6: Protect ethics. Do not use a more dramatic or convenient image if it does not show the correct subject.

Notebook Directions

Create a chart with four rows: Image A, Image B, Image C, and Image D. For each row, write whether the image is accurate, partly accurate, or misleading, and explain why.

Model Example

Image B: Misleading.

Reason: It shows an older cafeteria-area fountain, not the new refill station outside the gym.
