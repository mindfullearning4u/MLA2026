P03 Notebook Task - Part 2

Putting It All Together: Unit 6 Synthesis

Embedded Source Reminder

Final Journalism Capstone Scenario. Task: The student newsroom is submitting the final course portfolio and publication package. Required evidence: a revised article, a verified reporting note, a media-literacy audience check, a multimedia sequence, a collaborative publication workflow, a final online portfolio page, and a short oral presentation outline. Current Risks: one article transition is weak, one claim needs clearer evidence reasoning, one media headline overstates the audience opinion, one photo caption lacks date context, and the team has not assigned final export and submission roles. Goal: submit one accurate, revised, audience-ready, publication-quality journalism portfolio that demonstrates skills from the full course.

Deeper Learning

The final synthesis asks you to think like a student journalist preparing work for public review. The question is not only, Is this complete? The question is, Is this accurate, responsible, revised, organized, and clear enough for the audience?

Remedial learners can use the source to identify one risk at a time. Standard learners should match risks to course skills. Accelerated learners should evaluate which risks would most damage credibility if left unresolved.

Common Mistake

Incorrect: Treat Lesson 8 as a place to learn new skills for the first time.

Correct: Use Lesson 8 to synthesize already taught reporting, revision, media, multimedia, publication, collaboration, and presentation skills.

Teachable Explanation: Lesson 8 should verify mastery, not hide new instruction. The correct approach is to use familiar course skills together in a final capstone situation.

Notebook Directions

Write one paragraph explaining which final risk should be corrected first and why. Use the embedded source and name the course skill involved.
