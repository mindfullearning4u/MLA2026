Lesson Title

Lesson 5: Multimedia Package Preparation

This lesson teaches how to prepare a multimedia journalism package by checking sequence, presentation choices, and visual accuracy before final portfolio use.

Standards Covered in This Lesson

Primary Standard: MLA.JOUR.DIG.02.

Support Standards: MLA.JOUR.DIG.01, MLA.JOUR.DIG.03.

What You Will Learn

  • How to prepare a multimedia package that uses sequence, visuals, and presentation choices responsibly.
  • How sequential images or motion media help solve a communication problem.
  • How digital presentations and visual accuracy support audience understanding.

What You Will Do

  • Study an embedded multimedia package plan.
  • Identify sequence, visual accuracy, and audience needs.
  • Practice choosing media corrections before final publication.
  • Complete guided practice, independent work, checkpoint, and quiz.

How You Will Show Mastery

  • Organize media in a logical sequence.
  • Explain how visuals and presentation choices support the story.
  • Identify media risks before publication.

Student-Friendly Standard Connection

In student language: I can prepare journalism media for publication by checking sequence, accuracy, teamwork, and audience readiness.
