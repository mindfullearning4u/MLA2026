Instructions

Use the embedded lunch schedule media package to show integrated media literacy. Write in complete sentences and use evidence from more than one part of the package.

Embedded Source

Embedded Media Package: Lunch Schedule Debate

Media Text A: News Brief The school is considering a ten-minute extension to lunch. The proposal would shorten afternoon advisory by ten minutes. The principal says the school is reviewing hallway crowding, lunch line data, and afternoon instructional time before making a decision.

Media Text B: Editorial Excerpt Supporting the Change Students need a longer lunch because current lines leave some students with fewer than ten minutes to eat. A survey from the student newspaper found that 72 percent of respondents support a longer lunch. Supporters argue that a longer lunch would reduce rushing and help students return to class more focused.

Media Text C: Editorial Excerpt Opposing the Change The school should not lengthen lunch if it reduces advisory. Advisory gives students time for grade checks, teacher conferences, and makeup work. Opponents argue that the better solution is to improve line flow instead of removing academic support time.

Media Features: The package includes a comparison chart, a hallway photo caption, and a sidebar titled Questions Still Under Review.

Part A

State the shared issue and the two opposing claims.

Part B

Choose one piece of evidence from each side. Explain how each detail supports its claim.

Part C

Evaluate one media feature from the package. Explain how it helps the audience understand or compare the issue.
