📰 JOURNALISM | Unit 04 | Lesson 07

P02 Notebook Task Part 1

Notebook Title

Integrated Media Package Analysis

Set up your notebook to track central idea, opposing claims, evidence, structure, and audience effect.

Vocabulary

  • Media package: a set of related media texts about the same topic.
  • Central idea: the main message developed by a text or package.
  • Opposing claims: different positions on the same issue.
  • Audience analysis: explaining how choices affect readers or viewers.
  • Validity: whether a claim is logical and supported.

Embedded Source

Embedded Media Package: Lunch Schedule Debate

Media Text A: News Brief The school is considering a ten-minute extension to lunch. The proposal would shorten afternoon advisory by ten minutes. The principal says the school is reviewing hallway crowding, lunch line data, and afternoon instructional time before making a decision.

Media Text B: Editorial Excerpt Supporting the Change Students need a longer lunch because current lines leave some students with fewer than ten minutes to eat. A survey from the student newspaper found that 72 percent of respondents support a longer lunch. Supporters argue that a longer lunch would reduce rushing and help students return to class more focused.

Media Text C: Editorial Excerpt Opposing the Change The school should not lengthen lunch if it reduces advisory. Advisory gives students time for grade checks, teacher conferences, and makeup work. Opponents argue that the better solution is to improve line flow instead of removing academic support time.

Media Features: The package includes a comparison chart, a hallway photo caption, and a sidebar titled Questions Still Under Review.

Step-by-Step Teaching

Step 1: Identify the shared topic. The package is about whether lunch should be extended by ten minutes.

Step 2: Separate neutral information from argument. The news brief explains the proposal. The editorials take sides.

Step 3: Identify opposing claims. One side supports a longer lunch; the other opposes shortening advisory.

Step 4: Compare evidence. The support argument uses survey data and lunch-line time. The opposing argument uses advisory functions.

Step 5: Analyze media features. A comparison chart helps audiences see both sides, while a sidebar shows unresolved questions.

Step 6: Evaluate audience effect. The package is strongest when it helps readers compare claims instead of pushing only one side.

Notebook Directions

Create a chart with five rows: topic, central idea, support claim, opposing claim, and media feature. Complete each row with evidence from the embedded package.

Model Example

Media feature: comparison chart.

Audience effect: The chart helps readers compare the support and opposition arguments quickly, which supports balanced understanding.
