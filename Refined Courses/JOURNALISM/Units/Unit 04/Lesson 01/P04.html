P04 Worked Example

Example 1: Headline Function

Feature: Headline.

Modeled thinking: A headline should tell readers the main news before they read the body.

Function: The headline tells readers a new bike rack area has opened near the east gate.

Reasoning: This prepares readers for the article topic immediately.

Example 2: Sidebar Function

Feature: Sidebar titled Before You Ride.

Modeled thinking: A sidebar can highlight short action steps.

Function: The sidebar separates safety reminders so students can scan them quickly.

Reasoning: The feature makes practical information easier to find.

Example 3: Caption and Map Function

Features: Photo caption and map.

Modeled thinking: Visual features should clarify, not distract.

Function: The caption identifies the east gate entrance, and the map shows the route to the courtyard.

Reasoning: Together, they help students recognize the location and navigate it.

Common Mistake

Incorrect: A feature matters only if it makes the article more colorful.

Correct: A feature matters when it helps the audience understand, locate, remember, or use information.

Teachable explanation: Media literacy asks what a feature does for meaning and audience use.
