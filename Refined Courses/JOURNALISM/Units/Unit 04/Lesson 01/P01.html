📰 JOURNALISM | Unit 04 | Lesson 01

P01 Lesson Overview

Lesson Title

Lesson 1: Media text structures and features

This lesson teaches how media texts use structure and features to guide audience understanding. In journalism, the order of information, headings, sidebars, captions, maps, and other features are not decoration. They help readers find and interpret information.

Standards Covered in This Lesson

Primary Standard: MLA.JOUR.MED.01 - Media Text Structures and Features.

Support Standards: MLA.JOUR.NEWS.03 - Expository News Writing; MLA.JOUR.MED.03 - Author Purpose, Appeals, and Language.

What You Will Learn

  • How structure affects how readers understand a media text.
  • How features such as headlines, subheadings, sidebars, captions, and maps support meaning.
  • How to explain why a feature is useful for the audience.
  • How structure and purpose work together in journalistic media.

What You Will Do

  • Study an embedded school safety web article.
  • Identify the structure and media features.
  • Explain how features help readers understand and act.
  • Complete guided practice, independent work, checkpoint, and quiz.

How You Will Show Mastery

  • Identify text structures and media features.
  • Explain the function of each feature.
  • Connect structure and features to audience needs.
  • Submit checkpoint evidence aligned to MLA.JOUR.MED.01.

Student-Friendly Standard Connection

In student language: I can explain how a media text is organized and how its features help the audience understand the message.
