📰 JOURNALISM | Unit 04 | Lesson 01

P06 Independent Work

Instructions

Use the bike rack media text to analyze how structure and features guide readers.

Part A

Identify the article structure in three stages: what comes first, what comes next, and what comes last.

Part B

Choose three media features. For each one, explain what information it gives and how it helps the audience.

Part C

Write one paragraph explaining which feature is most useful for student readers and why.

Mastery Support Checklist

  • Did I name structures and features accurately?
  • Did I explain each feature function?
  • Did I connect features to audience needs?
  • Did I avoid saying a feature is useful only because it looks good?
  • Did I use evidence from the embedded media text?
