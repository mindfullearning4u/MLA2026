P07 Checkpoint

This checkpoint shows whether you can apply format rules to create quality journalism.

TOR

Ask TOR for help if you cannot explain the difference between a news brief, feature story, opinion column, photo caption, and multimedia post.

Submission Workflow

Submit your notebook evidence using the course submission tool. Make sure your name, unit, lesson, and checkpoint title are visible.

Checkpoint Task

Choose one of the three situations from your independent work. In your notebook, write a response with four labeled parts:

  1. Best format: Name the journalism format.
  2. Purpose: Explain what the format is meant to do for the audience.
  3. Rules: Name two accepted rules for that format.
  4. Quality sentence: Write one sentence that follows those rules.

Mastery Criteria

  • The response names a journalism format that fits the situation.
  • The purpose matches the audience need.
  • The two rules are accurate for the format.
  • The sentence uses factual, format-appropriate language.
