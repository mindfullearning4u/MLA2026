P04 Worked Example

Explain how a media transition changes journalism.

Example 1: Print to Radio

Step 1: Printed newspapers mainly use text, photos, layout, and scheduled publication times.

Step 2: Radio news uses spoken language, sound, and repeated broadcasts.

Step 3: The technique changed because audiences could hear updates without reading a printed page.

Conclusion: Radio made voice, timing, and clear spoken wording more important in journalism.

Example 2: Television to Website

Step 1: Television news can combine images, video, anchors, and sound in scheduled broadcasts.

Step 2: A website can combine text, images, video, links, archives, and updates.

Step 3: The audience can choose what to read, click links, and return for updates.

Conclusion: Websites expanded audience control and made updates easier to publish.

Example 3: Website to Mobile Alert

Step 1: A website requires the audience to visit or search.

Step 2: A mobile alert sends a short update directly to the audience.

Step 3: The technique changes because the message must be brief, clear, and accurate immediately.

Conclusion: Mobile alerts increase speed, but they also require careful wording because there is little space for context.

Common Mistake

Incorrect: New technology means old journalism rules no longer matter.

This is incorrect because accuracy, clarity, and audience awareness still matter across platforms.

Correct: New technology changes tools and techniques, but journalists still need accuracy, clarity, and audience awareness.

This is correct because it explains both change and continuity.
