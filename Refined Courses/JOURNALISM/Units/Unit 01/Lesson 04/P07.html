Checkpoint Task

Write a visual design recommendation for the food drive story. Include:

  1. The main visual you recommend.
  2. How the visual helps the audience understand the story.
  3. One caption or format rule the publication must follow.
  4. One accuracy concern the staff should check before publishing.

Mastery Criteria

  • The recommendation fits the story purpose and audience.
  • The design choice supports accurate understanding.
  • The caption or format rule is specific.
  • The accuracy concern is clear and journalism-focused.
