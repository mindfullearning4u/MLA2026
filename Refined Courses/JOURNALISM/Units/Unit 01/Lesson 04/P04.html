P04 Worked Example

Evaluate whether visual design supports journalism quality.

Example 1: Large Photo

Step 1: A large photo can draw attention to the story.

Step 2: The photo should show the actual event, person, or object being reported.

Step 3: The caption should identify what the audience sees.

Conclusion: A large photo supports journalism when it is relevant and accurately captioned.

Example 2: Chart

Step 1: A chart can help readers compare numbers quickly.

Step 2: The chart must label data clearly.

Step 3: The scale should not exaggerate the difference between numbers.

Conclusion: A chart supports journalism when it clarifies data honestly.

Example 3: Mobile Layout

Step 1: Many readers view journalism on phones.

Step 2: A mobile layout needs readable text, clear spacing, and visuals that fit the screen.

Step 3: The design should not hide captions or source information.

Conclusion: Mobile-friendly design supports audience access when it keeps important information visible.

Common Mistake

Incorrect: A visual is good journalism if it looks exciting.

This is incorrect because excitement alone does not prove accuracy, relevance, or format quality.

Correct: A visual is good journalism when it attracts attention and accurately supports the story purpose.

This is correct because strong design must serve the audience and the facts.
