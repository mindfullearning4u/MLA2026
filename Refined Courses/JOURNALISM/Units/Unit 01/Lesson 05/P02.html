Notebook Title

Interviewing Norms and Active Listening

Use this title for your notes. Your goal is to learn the sequence a journalist uses before, during, and after an interview.

Vocabulary

  • Source: a person, document, or record that provides information for reporting.
  • Interview: a planned conversation used to gather information from a source.
  • Open-ended question: a question that invites explanation instead of a one-word answer.
  • Follow-up question: a question asked after listening to a source response to clarify or deepen information.
  • Active listening: listening carefully, confirming meaning, and responding to what the source actually said.

Step 1: Begin With a Reporting Purpose

A journalist does not interview randomly. Before speaking with a source, identify what the audience needs to understand. The purpose controls the questions. If the story is about a new tutoring program, the reporter may need facts about schedule, location, eligibility, and student need.

Write the reporting purpose first. Then write questions that help gather accurate information for that purpose.

Step 2: Ask Questions That Invite Useful Information

Closed questions can confirm facts: What time does tutoring begin? Open-ended questions invite explanation: What problem is the tutoring program designed to solve? A strong interview usually uses both.

Do not ask loaded questions that push the source toward your opinion. Instead, ask neutral questions that help the source provide accurate information.

Embedded Interview Example

Reporting purpose: Explain how the new tutoring program will help ninth-grade students.

Weak question: Do you agree this program is amazing?

Stronger question: What need led the school to create this tutoring program?

Source response: We noticed that many ninth-grade students wanted help organizing assignments before tests, so the program gives them a place to plan, ask questions, and review skills twice a week.

Model Example

Question: What follow-up should the reporter ask?

Model answer: How will students know when and where tutoring is available? This follow-up is useful because it asks for specific information the audience needs after the source explained the program purpose.

Notebook direction: Copy the model answer and label the audience need and the follow-up question.

Mastery Support: How to Build Interview Questions

Use this thinking path every time:

  1. Name the story topic. Example: a new tutoring program.
  2. Name the audience need. Students need to know when, where, why, and how to attend.
  3. Choose the source. The best source is someone who can verify the information, such as the teacher sponsor or program coordinator.
  4. Write a factual question. Ask for details the audience can use.
  5. Prepare a follow-up. If the source gives a general answer, ask for a specific example, date, number, location, or explanation.

For remedial learners: Start with who, what, when, where, why, and how. For accelerated learners: add a follow-up that asks for impact, cause, or evidence.
