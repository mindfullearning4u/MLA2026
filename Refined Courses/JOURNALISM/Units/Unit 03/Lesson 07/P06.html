📰 JOURNALISM | Unit 03 | Lesson 07

P06 Independent Work

Instructions

Use the library extended-hours source to prepare a one-minute oral briefing plan.

Part A

Write the main news in one clear opening sentence for listeners.

Part B

Create speaker notes with three key details: reason, student action, and review process.

Part C

Write a closing reminder that tells students what to do if they use the extended hours. Then explain how your order helps listeners.

Mastery Support Checklist

  • Did I start with the main news?
  • Did I use verified facts only?
  • Did I include practical listener information?
  • Did I use attribution where needed?
  • Would the briefing be easy to understand aloud?
