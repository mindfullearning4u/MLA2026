P04 Worked Example

Example 1: Choose the Feature Angle

Source detail: Maya noticed classmates walking more than two miles home after practice.

Modeled thinking: This detail shows the reason the project began.

Feature angle: A student repair project grew from noticing a transportation problem.

Reasoning: The angle connects a person, a need, and an action.

Example 2: Use Point of View

Possible point of view: Focus on Maya's careful repair process.

Modeled thinking: The adviser says Maya keeps careful notes and asks for help with safety issues.

Feature sentence: Maya Chen's bike repairs begin with careful notes, safety questions, and a goal of helping classmates get home more easily.

Reasoning: The sentence uses source details to focus the reader on process and purpose.

Example 3: Respect Tone

Weak tone: Maya magically fixes every transportation problem.

Modeled thinking: That wording is exaggerated and not source-based.

Stronger tone: Maya's repair work has helped at least one student stay for tutoring more easily.

Reasoning: This wording is careful because the source gives one student example.

Common Mistake

Incorrect: Add emotional details the source never gave so the story feels powerful.

Correct: Use vivid but verified details from the source to create interest.

Teachable explanation: Feature writing can be engaging, but journalism still requires accuracy. The strongest details are reported, not invented.
