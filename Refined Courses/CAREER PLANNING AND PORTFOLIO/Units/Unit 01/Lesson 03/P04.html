Lifestyle and Workplace Values

Worked Example 1: Name the value

Prompt: A student wants high earnings, a predictable schedule, and outdoor work. The student compares nursing, construction management, and accounting.

Step 1 - Identify the task: This example focuses on name the value.

Step 2 - Find the evidence: Use the values tradeoff matrix and the scenario details before writing the answer.

Step 3 - Explain the reasoning: High earnings is a salary value, predictable schedule is a balance value, and outdoor work is an environment value.

Step 4 - Interpret the answer: This supports MLA.CPP.SELF.3 because it connects a planning decision to evidence.

Incorrect: Do not combine all values into one vague preference.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.
