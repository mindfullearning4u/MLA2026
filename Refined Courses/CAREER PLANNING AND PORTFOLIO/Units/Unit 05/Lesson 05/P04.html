Worked Example 1: Check compliance first

Prompt: A student interested in teaching builds a schedule with core courses, a child development elective, a service activity, and a future dual enrollment goal.

Step 1 - Identify the task: This example focuses on check compliance first.

Step 2 - Find the evidence: Use the academic plan template and the scenario details before writing the answer.

Step 3 - Explain the reasoning: The plan must meet graduation requirements before adding career opportunities.

Step 4 - Interpret the answer: This supports MLA.CPP.ACAD.1, MLA.CPP.ACAD.2, MLA.CPP.ACAD.3 because it connects a planning decision to evidence.

Incorrect: Do not create an exciting plan that misses required credits.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.

Mastery Check: Before moving on, make sure you can explain why each example answer is supported and why the incorrect example is not strong enough.
