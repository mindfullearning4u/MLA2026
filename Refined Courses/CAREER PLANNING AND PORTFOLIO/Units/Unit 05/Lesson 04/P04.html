Extracurricular Activities and Career Alignment

Worked Example 1: Choose for evidence

Prompt: A student lists five activities but cannot explain how any connect to a career goal. The student must choose activities intentionally.

Step 1 - Identify the task: This example focuses on choose for evidence.

Step 2 - Find the evidence: Use the activity alignment matrix and the scenario details before writing the answer.

Step 3 - Explain the reasoning: A coding club supports an IT goal because it builds technical practice and project evidence.

Step 4 - Interpret the answer: This supports MLA.CPP.ACAD.3 because it connects a planning decision to evidence.

Incorrect: Do not join only for resume padding.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.

Mastery Check: Before moving on, make sure you can explain why each example answer is supported and why the incorrect example is not strong enough.
