Synthesis: My Postsecondary Pathway Evidence

Worked Example 1: Connect all parts

Prompt: A student chooses a state college program because it leads to an associate degree, has manageable cost, and reports strong placement in the chosen field.

Step 1 - Identify the task: This example focuses on connect all parts.

Step 2 - Find the evidence: Use the pathway decision organizer and the scenario details before writing the answer.

Step 3 - Explain the reasoning: The pathway is strong only if the provider, credential, and outcomes all support the career goal.

Step 4 - Interpret the answer: This supports MLA.CPP.PATH.1, MLA.CPP.PATH.2, MLA.CPP.PATH.3, MLA.CPP.PATH.4 because it connects a planning decision to evidence.

Incorrect: Do not list details without explaining the connection.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.

Mastery Check: Before moving on, make sure you can explain why each example answer is supported and why the incorrect example is not strong enough.
