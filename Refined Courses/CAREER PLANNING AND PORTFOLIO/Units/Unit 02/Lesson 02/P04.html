P04 Worked Example

Wages, Poverty Thresholds, and Family-Sustaining Income

Worked Example 1: Read the measure

Prompt: Occupation A pays close to the regional poverty threshold. Occupation B pays near the average wage. Occupation C pays above a family-sustaining wage but requires more training.

Step 1 - Identify the task: This example focuses on read the measure.

Step 2 - Find the evidence: Use the wage threshold table and the scenario details before writing the answer.

Step 3 - Explain the reasoning: A wage above the poverty threshold does not automatically mean it supports all household costs.

Step 4 - Interpret the answer: This supports MLA.CPP.LMI.1 because it connects a planning decision to evidence.

Incorrect: Do not treat all thresholds as the same.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.
