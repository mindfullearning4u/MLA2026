P04 Worked Example

Career Clusters, Industries, and Occupations

Worked Example 1: Start broad

Prompt: A student says they want a job in science. The statement is too broad, so the student sorts possible options into clusters, industries, and occupations.

Step 1 - Identify the task: This example focuses on start broad.

Step 2 - Find the evidence: Use the cluster hierarchy chart and the scenario details before writing the answer.

Step 3 - Explain the reasoning: Science may connect to Health Science, Agriculture, STEM, or Manufacturing clusters.

Step 4 - Interpret the answer: This supports MLA.CPP.LMI.1 because it connects a planning decision to evidence.

Incorrect: Do not treat a broad interest as a finished career choice.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.

Mastery Check: Before moving on, make sure you can explain why each example answer is supported and why the incorrect example is not strong enough.
