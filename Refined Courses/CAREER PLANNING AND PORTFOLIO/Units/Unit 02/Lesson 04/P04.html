P04 Worked Example

Comparing Occupations with Personal Fit

Worked Example 1: Use same criteria

Prompt: A student compares dental hygienist, software developer, and elementary teacher using interest, skill, wage, growth, and workplace values.

Step 1 - Identify the task: This example focuses on use same criteria.

Step 2 - Find the evidence: Use the occupation comparison matrix and the scenario details before writing the answer.

Step 3 - Explain the reasoning: Each occupation must be compared with the same factors so the decision is fair.

Step 4 - Interpret the answer: This supports MLA.CPP.LMI.3 because it connects a planning decision to evidence.

Incorrect: Do not use salary for one job and schedule for another only.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.

Mastery Check: Before moving on, make sure you can explain why each example answer is supported and why the incorrect example is not strong enough.
