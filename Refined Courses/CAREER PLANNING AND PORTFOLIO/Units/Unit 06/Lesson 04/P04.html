P04 Worked Example

Readiness Gaps and Next Steps

Worked Example 1: Name the gap

Prompt: A student's plan is promising, but the student has not checked program prerequisites, scholarship requirements, or whether the chosen career includes shift work.

Step 1 - Identify the task: This example focuses on name the gap.

Step 2 - Find the evidence: Use the gap action table and the scenario details before writing the answer.

Step 3 - Explain the reasoning: Program prerequisite unknown is a readiness gap because it could block entry.

Step 4 - Interpret the answer: This supports MLA.CPP.PORT.4 because it connects a planning decision to evidence.

Incorrect: Do not write I need to learn more with no detail.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.

Mastery Check: Before moving on, make sure you can explain why each example answer is supported and why the incorrect example is not strong enough.
