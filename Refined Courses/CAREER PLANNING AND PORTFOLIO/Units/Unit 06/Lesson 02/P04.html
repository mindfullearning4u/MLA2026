P04 Worked Example

Revising Portfolio Artifacts for Quality

Worked Example 1: Revise labels

Prompt: A student's occupation comparison has good data but unclear labels, missing sources, and a conclusion that does not match the table.

Step 1 - Identify the task: This example focuses on revise labels.

Step 2 - Find the evidence: Use the revision rubric and the scenario details before writing the answer.

Step 3 - Explain the reasoning: Changing Salary to Regional median salary makes the table clearer.

Step 4 - Interpret the answer: This supports MLA.CPP.PORT.2 because it connects a planning decision to evidence.

Incorrect: Do not leave vague headings.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.

Mastery Check: Before moving on, make sure you can explain why each example answer is supported and why the incorrect example is not strong enough.
