P04 Worked Example

Paying for Postsecondary Training

Worked Example 1: Start with no-repayment sources

Prompt: A student has a program cost of 8,000 dollars and considers a state scholarship, part-time work, a grant, and a small federal loan.

Step 1 - Identify the task: This example focuses on start with no-repayment sources.

Step 2 - Find the evidence: Use the funding comparison chart and the scenario details before writing the answer.

Step 3 - Explain the reasoning: Scholarships and grants reduce cost without loan repayment.

Step 4 - Interpret the answer: This supports MLA.CPP.PLAN.4 because it connects a planning decision to evidence.

Incorrect: Do not begin with private loans.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.

Mastery Check: Before moving on, make sure you can explain why each example answer is supported and why the incorrect example is not strong enough.
