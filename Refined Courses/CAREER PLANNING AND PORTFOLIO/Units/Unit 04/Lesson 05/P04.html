Synthesis: Career Pathway Plan

Worked Example 1: Link decisions

Prompt: A student chooses cybersecurity analyst, identifies a certification and associate degree path, compares providers, and creates a funding plan using scholarships, work, and limited loans.

Step 1 - Identify the task: This example focuses on link decisions.

Step 2 - Find the evidence: Use the career pathway plan template and the scenario details before writing the answer.

Step 3 - Explain the reasoning: The credential should support the chosen occupation, and the provider should offer that credential.

Step 4 - Interpret the answer: This supports MLA.CPP.PLAN.1, MLA.CPP.PLAN.2, MLA.CPP.PLAN.3, MLA.CPP.PLAN.4 because it connects a planning decision to evidence.

Incorrect: Do not choose unrelated parts.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.

Mastery Check: Before moving on, make sure you can explain why each example answer is supported and why the incorrect example is not strong enough.
