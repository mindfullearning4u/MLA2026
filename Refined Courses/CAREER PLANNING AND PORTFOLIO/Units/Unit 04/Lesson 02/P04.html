P04 Worked Example

Explaining the Career Choice with Evidence

Worked Example 1: Write the claim

Prompt: A student chooses physical therapist assistant because it matches helping interests, uses communication skills, has clear training requirements, and shows regional growth.

Step 1 - Identify the task: This example focuses on write the claim.

Step 2 - Find the evidence: Use the claim-evidence-reasoning frame and the scenario details before writing the answer.

Step 3 - Explain the reasoning: The preferred occupation is physical therapist assistant.

Step 4 - Interpret the answer: This supports MLA.CPP.PLAN.1 because it connects a planning decision to evidence.

Incorrect: Do not start with a vague field like health.

Correct: Name the evidence, explain the connection, and state what the evidence suggests for the plan.

Teachable Explanation

All three worked examples use the same mastery routine: identify the task, locate evidence, explain reasoning, and interpret the decision. That routine matters because career planning can become opinion-based if the student skips evidence.

Mastery Check: Before moving on, make sure you can explain why each example answer is supported and why the incorrect example is not strong enough.
