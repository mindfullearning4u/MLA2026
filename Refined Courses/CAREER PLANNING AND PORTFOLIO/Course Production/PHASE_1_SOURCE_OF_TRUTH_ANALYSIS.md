## Source Conflict Notes

1. CPALMS search did not return an exact course-card title `Career Planning and Portfolio`.
2. CPALMS did return official Career and Education Planning standards embedded in current course records. Those standards directly control career interests, regional labor market exploration, postsecondary pathways, personalized career/academic planning, employability/entrepreneurship skills, graduation requirements, accelerated credit, and student planning.
3. This package therefore treats `Career Planning and Portfolio` as an MLA half-credit elective built from the official Career and Education Planning standard family plus a course-specific portfolio/capstone evidence structure.
4. Portfolio work is not used to introduce off-standard content. It is the evidence vehicle for the official planning standards.
