# Career Planning and Portfolio

## Course Description

Career Planning and Portfolio is a 0.5-credit mastery-based course that helps students identify career interests, skills, values, labor-market evidence, postsecondary pathways, academic planning requirements, and portfolio evidence needed to make informed college, career, and life decisions.

Students use career inventories, occupation research, wage and employment data, pathway comparisons, decision matrices, course-planning tools, and portfolio artifacts to create a personalized academic and career plan.

## Standards Alignment

This course is aligned to CPALMS/FDOE Career and Education Planning standards as the primary content source. Florida B.E.S.T. ELA, Common Core ELA/Literacy, SAT Reading and Writing, ACT College and Career Readiness Standards, and ELD/accessibility supports are embedded as readiness and communication layers.

## Learning Objectives / Outcomes

Students will:

- explain career interests, skills, lifestyle/workplace values, and positive-impact values
- define career clusters, industries, occupations, wage thresholds, and labor-market terms
- interpret regional labor-market data and compare occupations using evidence
- evaluate postsecondary pathways, credentials, training providers, costs, debt, earnings, and placement outcomes
- use decision-making tools to select an occupation, credential, provider, and funding approach
- describe Florida graduation pathways, accelerated credit, CTE, work-based learning, and certification opportunities
- build a freshman-year schedule and activity plan aligned to career goals
- create, revise, present, and reflect on a career planning portfolio

## Prerequisite Knowledge / Skills

Students should be able to read informational text, use basic tables and charts, write short evidence-based explanations, follow multi-step directions, and revise work using a checklist or rubric.

## Course Structure

This 0.5-credit course has 6 units with 5 lessons per unit.

| Unit | Unit Title |
|---|---|
| Unit 01 | Career Self-Knowledge: Interests, Skills, and Values |
| Unit 02 | Occupations, Industries, and Labor-Market Evidence |
| Unit 03 | Postsecondary Pathways, Credentials, and Training Providers |
| Unit 04 | Career Decisions, Skills, Credentials, and Paying for Training |
| Unit 05 | Academic Planning, Graduation Pathways, and Opportunity Alignment |
| Unit 06 | Portfolio Synthesis and Career Readiness Presentation |

## Lesson Workflow

Each lesson uses seven pages: overview, notebook instruction, continued instruction, worked examples, guided practice, independent work, and checkpoint.

Lessons 1-4 in each unit include Guided Practice and a Lesson Quiz. Lesson 5 is the synthesis lesson and includes Guided Practice and the Unit Assessment. Lesson 5 does not include a Lesson Quiz.

## Assessment Structure

Each unit includes:

- Unit Pretest
- Guided Practice for each lesson
- Lesson Quiz banks for Lessons 1-4
- Unit Assessment in Lesson 5

Assessments must be Moodle XML, use four answer choices, include one correct answer, provide teachable feedback for each answer choice, avoid predictable answer patterns, and include any required tables, charts, scenarios, or portfolio stimuli directly in the question.

## Mastery & Progression Criteria

Students demonstrate mastery by completing notebook work, guided practice, quizzes, checkpoint tasks, portfolio artifacts, and unit assessments. Mastery expectations use an 80% benchmark with correction, resubmission, intervention, and retake workflows as directed by the Teacher of Record.

## College / Skill Readiness Integration

The course builds college, career, and life readiness through research, informational reading, labor-market data interpretation, decision-making, financial pathway awareness, academic planning, portfolio development, presentation, revision, and evidence-based reflection.
