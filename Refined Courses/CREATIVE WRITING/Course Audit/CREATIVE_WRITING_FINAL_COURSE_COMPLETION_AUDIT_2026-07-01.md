## Audit Method

Three unit-range audits were completed before correction:

- Units 01-02: lesson structure, TOR cards, assessment self-containment, duplicate stems, answer patterns, and missing standard tags.
- Units 03-04: mapping-source conflict, P03 labels, GIFT standard tags, Unit 04 answer quality, and repeated quiz patterns.
- Units 05-06: metadata counts, TOR headings, P04 worked-example labels, P06 wording, missing assessment tags, and repeated answer patterns.

After corrections, a direct validation pass checked the full course for lesson page structure, Moodle assessment packaging, GIFT formatting, assessment counts, tag presence, answer balance, feedback quality, duplicate stems, duplicate choices, HTML leakage, caret notation, mojibake, hidden backend filenames, empty visible boxes, and required TOR support boxes.

## Corrections Completed

- Normalized P01-P07 structural labels to MLA workflow expectations.
- Corrected P02/P03 notebook task labels to Part 1 and Part 2 format.
- Normalized standards labels to `Standards Covered in This Lesson`.
- Corrected P04 example labels to `Worked Example 1`, `Worked Example 2`, and `Worked Example 3`.
- Added required P05 Moodle Guided Practice references where missing.
- Added or normalized P03 `Teachable Explanation` labels.
- Corrected TOR support heading mojibake to `Need Help?`.
- Removed duplicate nonstandard help-card patterns where they conflicted with the required TOR support structure.
- Corrected P06 `Important Important:` wording to `Important:`.
- Corrected Unit 05 and Unit 06 JSON metadata count mismatches.
- Added missing `[MLA.CW...]` standard tags to GIFT stems using the approved lesson and unit mappings.
- Expanded weak assessment feedback so it teaches the standard being assessed.
- Rebalanced answer choices to avoid predictable answer patterns.
- Disambiguated duplicate stems and duplicate choices.
- Repaired Unit 01 Unit Assessment stems that lacked self-contained context.
- Corrected ambiguous assessment wording so students do not have to search outside the question for the needed passage or scenario.
