# Creative Writing One-Course Re-Audit

**Date:** 2026-07-06  
**Course:** Creative Writing  
**Decision:** PASS - ready for Moodle transfer after repository review.

## Scope

This audit used the current MLA course-production expectations for:

- exact unit and lesson mapping alignment
- standards taught and assessed only within the approved mapped scope
- self-paced lesson rigor with no live-teacher dependency
- TOR-only support language
- Moodle XML assessment readiness
- visible standards in assessment questions
- embedded passages, scenarios, models, or excerpts when assessment items require context
- student-facing lesson structure, workflow, and visual support

## Corrections Made

1. Converted production assessment metadata away from legacy GIFT references.
   - Updated all lesson assessment references to Moodle XML file references.
   - Confirmed quiz and pretest metadata contain no production `.gift` references.

2. Strengthened self-paced lesson rigor.
   - Added Creative Writing rigor/depth support blocks to 148 pages that were below the strict depth threshold.
   - Support blocks tell students how to identify the craft skill, connect evidence to effect, draft or revise with purpose, and use feedback as instruction.

3. Added visual learning support.
   - Added a Creative Writing craft organizer table to every P02 notebook page.
   - The organizer supports Identify, Notice, Explain, and Apply steps for the mapped lesson standard.

4. Corrected teacher-language issues.
   - Removed non-TOR teacher language.
   - Replaced ambiguous teacher-support wording with TOR support language.
   - Confirmed the course does not depend on a live teacher delivering instruction.
