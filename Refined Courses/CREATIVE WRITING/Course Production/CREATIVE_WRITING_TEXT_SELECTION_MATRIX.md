# Creative Writing Text Selection Matrix

## Purpose

This matrix provides production guidance for future Creative Writing lesson development. It is a planning-control document only.

This document does not create lessons, assessments, HTML files, quizzes, GIFT files, quiz JSON files, lesson JSON files, LMS pages, or student-facing instructional content.

## Source Alignment

| Source | Use |
|---|---|
| CPALMS `Creative Writing 1 (#1009320)` | Primary standards source |
| MLA Creative Writing architecture | Unit and lesson production-control framework |
| Course focus | Creative expression, narrative writing, fiction, poetry, author craft, revision, workshop, portfolio development, and publication |

## Production-Control Rules

- Use this matrix to select future mentor texts and product models before lesson writing begins.
- Do not treat the matrix as a lesson sequence.
- Do not treat text categories as required titles.
- Do not create assessments from this matrix during architecture.
- Do not add student-facing instructional content to this matrix.
- Ensure selected future texts support Creative Writing standards through writing craft and production, not literary survey.
