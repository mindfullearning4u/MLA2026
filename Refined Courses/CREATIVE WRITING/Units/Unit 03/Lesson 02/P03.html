P03 Notebook Task - Part 2

Continue by learning how to write a complete comparative theme explanation.

Step 4: Write the Comparison

A complete comparison should include four parts.

First: State the shared or related theme.

Second: Give evidence from Passage A.

Third: Give evidence from Passage B.

Fourth: Explain how the development is similar, different, or both.

Model: Both passages suggest that generosity requires sacrifice. In Passage A, Mara gives away her extra coat before snow arrives. In Passage B, Jin uses nearly all the lantern oil so lost hikers can find the road. Both characters give up comfort to help others, but Mara's sacrifice is an object while Jin's sacrifice is a continued action.

Notebook Task Part 2

Part A: Copy the four-part comparison structure.

Part B: Copy the model comparison.

Part C: Underline or label the shared theme, Passage A evidence, Passage B evidence, and comparison explanation.

Common Mistake

Incorrect: Both passages have characters, so they are the same.

This is incorrect because comparison must focus on a meaningful connection. Almost all stories have characters, so that observation does not explain theme.

Correct: Both passages develop the theme that generosity requires sacrifice, but they use different details to show the sacrifice.

This is correct because it names the shared theme and explains how the passages develop it.
