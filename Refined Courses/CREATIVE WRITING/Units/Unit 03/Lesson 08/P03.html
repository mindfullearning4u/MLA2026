Part C: Write a 5-sentence assessment preparation plan.

Common Mistake

Incorrect: Choosing an answer because it uses a familiar vocabulary word.

This is incorrect because Unit 3 questions require evidence. A familiar word can still be wrong if it does not match the passage.

Correct: Match the answer to the specific passage evidence and the skill being tested.

Teacher-Guided Review Path

Step 4: Choose one Unit 3 skill and write the exact question you would ask yourself before answering. For example: What detail proves the theme? or How does this adaptation change the original meaning?

Step 5: Write one evidence sentence that answers the question. Use a specific word, image, action, or character choice instead of a general memory of the lesson.

Step 6: Explain why the evidence works. A complete review answer should name the skill, point to evidence, and explain the connection in your own words.

Teachable Explanation: The correct example works because it applies the lesson skill deliberately and explains the reasoning instead of only naming an answer.
