Lesson: The Fiction Integration Protocol

The Core Principle

A draft is integrated when every major element earns its place by supporting the same developing effect. Do not ask only, “Is the character interesting?” Ask, “How does this character’s desire activate conflict, shape structure, control what the viewpoint notices, and reveal the theme?”

Seven-Step Integration Protocol

  1. Name the controlling effect: Write the exact feeling, question, or insight the reader should carry.
  2. Trace the throughline: Summarize desire → opposition → escalating choices → irreversible consequence.
  3. Map access: Record what each character and the reader know, misread, or discover.
  4. Test causality: Replace “and then” between scenes with “therefore” or “but.” Repair any break.
  5. Track pattern: Mark repeated image, object, phrase, or setting detail and explain how its meaning changes.
  6. Test the ending: Verify that it pays off earlier choices and transforms—not merely repeats—the opening.
  7. Revise in order: Global structure first; scene purpose second; paragraph and sentence craft last.

Visual Diagnostic: The Story System

DESIRE → PRESSURE → CHOICE → CONSEQUENCE → NEW MEANING
Viewpoint controls what is seen   |   Pattern builds theme   |   Setting changes the cost

If one arrow is weak, diagnose that link instead of polishing random sentences.

Three Learning Routes

  • Visual: Color-code each element and draw arrows showing influence.
  • Verbal/auditory: Explain the story aloud as a chain of “because…therefore…but…”
  • Hands-on: Put scenes on cards; remove or reorder one and observe what meaning changes.

Evidence-Chain Sentence Frame

Because the writer uses [specific detail or pattern], the reader can infer [meaning]; this advances [craft function] and contributes to [controlling effect or theme]. Test a counterreading, then explain why your interpretation accounts for more evidence.
