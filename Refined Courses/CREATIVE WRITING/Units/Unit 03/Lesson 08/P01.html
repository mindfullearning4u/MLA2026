Lesson Overview: Unit 3 Fiction Synthesis

Lesson Focus

Lesson 8: Putting It All Together—Unit 3 Synthesis
Primary standards: MLA.CW.FIC.02, .04, .06, .07, .08; MLA.CW.WR.01, .02, .04.
Supporting skills: theme, adaptation, world building, character change, viewpoint, structure, style, revision, and evidence-based craft reasoning.

What You Will Learn

  • How fiction elements operate as one coordinated system.
  • How to diagnose the weakest link in a draft before revising.
  • How to defend craft decisions with precise evidence.
  • How to transfer Unit 3 skills to unfamiliar passages and original writing.

Why This Matters

Strong fiction is not a pile of separate techniques. Character desire creates conflict; conflict pressures choices; choices shape plot; viewpoint controls access; recurring details develop theme; and revision aligns every part with a controlling effect.

Lesson Workflow

  1. Review the vocabulary system on Page 2.
  2. Use the integration protocol and visual diagnostic on Page 3.
  3. Study three complete synthesis models on Page 4.
  4. Complete the 18-part portfolio synthesis on Page 5 and submit it as Notebook Evidence.
  5. Complete the distinct 12-part Checkpoint on Page 6.
  6. Review feedback, correct errors, and complete the Unit 3 Final Assessment. At least 80% is required.

How You Will Show Mastery

You will analyze how multiple craft choices interact, revise a narrative globally and locally, create an integrated fiction passage, and explain how textual evidence proves the intended reader effect.
