P03 Notebook Task - Part 2

Continue by learning how to test whether an adaptation is purposeful and respectful.

Step 4: Check the Adaptation

Use three questions before drafting.

Question 1: What source element is still recognizable?

Question 2: What has changed for the new version?

Question 3: Does the change create a new meaning, audience connection, or reader effect?

Model: A writer adapts the source pattern of a hero answering a call to adventure. The new version shows a shy student choosing to lead a community cleanup after a storm. The source pattern remains recognizable because the character is called into responsibility. The transformation makes the adventure local and realistic.

Notebook Task Part 2

Part A: Copy the three adaptation check questions.

Part B: Write a 4-5 sentence adaptation plan using one source element.

Part C: Write a rationale explaining why your transformation is purposeful.

Common Mistake

Incorrect: I copied the original story but changed the character names.

This is incorrect because changing names alone does not create a meaningful adaptation.

Correct: I kept the source pattern of a warning before a risky choice, but I changed the setting, conflict, and point of view so the adapted scene explores pride in a modern school competition.

This is correct because it preserves a source element and transforms it for a new purpose.
