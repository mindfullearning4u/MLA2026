P03 Notebook Task - Part 2

Continue by practicing a complete craft explanation.

Step 4: Build the Explanation

Passage: The letter trembled in Mina's hand. She read the first line, folded it shut, and placed it under the heaviest book on the desk.

Purpose: Show that Mina is avoiding a difficult truth.

Craft choice: The writer uses action and object placement instead of directly saying, "Mina is afraid."

Explanation: Folding the letter and hiding it under the heaviest book makes avoidance visible. The reader understands fear through action.

Notebook Task Part 2

Part A: Copy the Mina passage.

Part B: Identify one craft choice and one reader effect.

Part C: Write a 3-4 sentence explanation of how the choice supports purpose.

Common Mistake

Incorrect: The writer uses a letter because letters are in stories.

This is incorrect because it does not explain purpose or reader effect.

Correct: The writer uses the letter as an object Mina hides so readers can infer that she is avoiding a difficult truth.
