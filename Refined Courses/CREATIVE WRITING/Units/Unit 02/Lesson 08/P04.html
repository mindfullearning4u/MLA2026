Worked Example: Three Synthesis Models

Example 1 — Architecture and Viewpoint

A student changes “Lena went to return the key” into a scene where Lena must return it before the owner discovers a copied document.

  1. Objective: return key unnoticed.
  2. Setting pressure: elevator outage and closing office.
  3. Access: Lena sees guards but cannot know what they suspect.
  4. Turn: the key no longer fits.
  5. Consequence: she must ask the owner for help.
  6. Value shift: secrecy → forced honesty.

Example 2 — Motif, Subtext, and Tone

A cracked phone screen appears first as an inconvenience, later hides a message, and finally is replaced after the character chooses to read it aloud.

  1. Literal role remains functional.
  2. Repetition changes meaning from avoidance to disclosure.
  3. Dialogue discusses repair while subtext concerns trust.
  4. Restrained tone prevents sentimentality.
  5. Payoff occurs through action, not explanation.

Example 3 — Pacing and Style Revision

Draft: six paragraphs describe arriving; one sentence contains the confession.

  1. Compress travel into summary.
  2. Begin scene at the last opportunity to leave.
  3. Pause on the listener’s unreadable gesture.
  4. Use a longer sentence to delay the confession.
  5. Use a short consequence sentence after it.
  6. Result: attention matches importance.
