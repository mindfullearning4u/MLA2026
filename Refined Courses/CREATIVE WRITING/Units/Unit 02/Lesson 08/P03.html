Common Mistake

Incorrect: Choosing an answer because it uses a familiar vocabulary word, even when the evidence does not support it.

This is incorrect because Unit 2 mastery requires evidence-based craft reasoning.

Correct: Match the answer to the exact passage evidence. If the question asks about pacing, look for delay, compression, expansion, sentence length, or slowed action.

Teachable Explanation: The correct example works because it applies the lesson skill deliberately and explains the reasoning instead of only naming an answer.
