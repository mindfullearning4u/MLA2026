P07 Checkpoint

TOR Reminder

Ask your TOR for help before submitting if your checkpoint only labels an element and does not explain what the element adds to meaning or style.

Submission Workflow

  1. Review your P02 and P03 notes.
  2. Check that your scene features one intentional key element.
  3. Check that your explanation names the element and explains its craft job.
  4. Submit your checkpoint according to your course directions.

Checkpoint Task

Submit one 6-8 sentence original scene using one key element intentionally. Under the scene, write a 3-4 sentence explanation identifying the element and explaining how it adds meaning or style.

Mastery Criteria

  • The scene is 6-8 sentences and uses one key element intentionally.
  • The element is specific, not generic.
  • The explanation identifies the element accurately.
  • The explanation explains how the element adds meaning or style.
  • The writing follows standard English closely enough that meaning is clear.
