📘 CW | Unit 02 | Lesson 03

P06 Independent Work

Complete the work in your writer's notebook. Focus on intentional details, not on adding as many details as possible.

Instructions

You will create a short scene where one key element does clear craft work. Choose details that help the reader infer meaning.

Part A

Choose one key element to feature: character detail, setting detail, object detail, or conflict detail. Write the element at the top of your notebook page.

Part B

Write a 6-8 sentence scene using that element. The element should appear more than once or be placed where the reader notices it.

Part C

Write 3-4 sentences explaining what the element adds to meaning or style. Use the words element, meaning, and style in your explanation.
