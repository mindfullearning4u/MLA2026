Direct Teaching: The Integrated Scene System

Eight-Step Scene Method

  1. Name the objective.
  2. Choose viewpoint and access limits.
  3. Make setting apply pressure.
  4. Arrange beats: action → reaction → choice.
  5. Plant one motif or setup.
  6. Control time around the turn.
  7. End with consequence and value shift.
  8. Audit every technique for contribution.

Visual Scene Blueprint

OBJECTIVEPRESSUREBEATSTURNCONSEQUENCE
Want → Resistance → Escalation → Choice → Value shift
Learning routes: color-code the blueprint; tell the causal chain aloud; or arrange beat cards physically before drafting.

Common Failure

A scene can contain beautiful description, dialogue, and conflict yet remain inert. If no choice changes pressure or relationship, revise the beat structure before polishing sentences.
