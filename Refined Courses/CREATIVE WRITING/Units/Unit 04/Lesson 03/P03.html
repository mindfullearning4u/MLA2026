P03 Notebook Task - Part 2

This page shows how to support an interpretation without overclaiming.

Step 4: Use Evidence to Limit the Interpretation

A poem can be open, but it cannot mean anything at all. Evidence keeps your interpretation reasonable. In the key poem, an interpretation about memory is reasonable because the key remains after the house is sold. An interpretation about a spaceship is not reasonable because no evidence supports it.

Step 5: Write a Layered Explanation

Strong explanation: Literally, the poem describes a key left under a mat after a house is sold. On a deeper level, the key may symbolize a memory or attachment that remains after someone leaves a place. The detail "no one moved it" suggests that the connection has not been fully released.

Common Mistake - Incorrect

Incorrect: The poem means whatever the reader wants.

This is incorrect because interpretation must be supported by evidence. Ambiguity allows more than one reasonable meaning, but it does not remove the need for proof.

Common Mistake - Correct

Correct: The poem is ambiguous because it never explains why the key remains, but the repeated focus on the sold house and unmoved key supports an interpretation about memory or unfinished attachment.

This is correct because it identifies the ambiguity, names a reasonable meaning, and supports it with details.

Notebook Task Part 2

Part A: Copy the strong explanation.

Part B: Underline the evidence used to support the interpretation.

Part C: Write a second possible interpretation and explain whether the evidence supports it well.

Teachable Explanation: The correct example works because it applies the lesson skill deliberately and explains the reasoning instead of only naming an answer.
