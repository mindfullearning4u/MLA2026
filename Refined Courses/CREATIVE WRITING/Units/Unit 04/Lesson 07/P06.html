Checkpoint: Integrated Poem Development

Directions

Complete all 12 tasks independently and submit separately. At least 80% is required.

Prompt: “The Unclaimed Umbrella”

Create a poem in which an umbrella left near a public doorway changes meaning across time.

Tasks

  1. State the controlling effect.
  2. List literal details.
  3. Plan an image system.
  4. Add counterpressure.
  5. Choose speaker and audience.
  6. Plan a meaningful turn.
  7. Select sound and diction patterns.
  8. Draft 16–22 lines.
  9. Annotate three figurative choices.
  10. Explain the transformed image.
  11. Revise one global and two local choices.
  12. Write a 200–250 word evidence-based rationale.

80% Mastery Requirement

Review TOR feedback, correct mistakes, and resubmit if needed.
