Submission Workflow

  1. Review your P02 and P03 notebook notes.
  2. Complete P06 Parts A, B, and C.

  4. Submit your completed checkpoint work in the LMS.

Checkpoint Task

Choose one poem model from this lesson. Identify one example of figurative language, name the mood, and write a 4-6 sentence explanation of how the language creates that mood. Then write two original lines that use figurative language to create the same mood.

Mastery Criteria

  • Identifies figurative language correctly.
  • Uses a precise mood word.
  • Quotes or names specific evidence from the poem.
  • Explains how the language creates mood.
  • Creates original lines that intentionally use figurative language.
