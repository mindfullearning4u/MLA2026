P03 Notebook Task - Part 2

This page shows how to write a complete style explanation.

Step 4: Compare Word Choices in Context

Line A: The slender branch lifted the moon.

Line B: The scrawny branch lifted the moon.

Both lines describe a thin branch. Line A feels graceful. Line B feels weaker and rougher. That difference is connotation shaping style.

Step 5: Write a Complete Explanation

Use this order: word choice + denotation + connotation + style effect.

Example: The word slender means thin, but its graceful connotation gives the line a delicate style, making the branch seem elegant instead of weak.

Common Mistake - Incorrect

Incorrect: Slender is better because it sounds nicer.

This is incorrect because it gives an opinion without explaining denotation, connotation, or style effect.

Common Mistake - Correct

Correct: Slender is stronger for a delicate style because it means thin while also suggesting grace and lightness.

This is correct because it explains the word's meaning and emotional effect.

Notebook Task Part 2

Part A: Copy Line A and Line B.

Part B: Explain how one word changes the style.

Part C: Write two original lines that use different connotations to create different styles.
