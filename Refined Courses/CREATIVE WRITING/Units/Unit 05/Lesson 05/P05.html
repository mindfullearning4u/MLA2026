Creative Writing | Unit 5 | Lesson 5 | Page 5 of 6

Independent Work: Simulated Digital Publication Packet

Directions

Complete all 18 tasks. Prepare a private staging packet only; do not publish publicly. Submit with Page 2 vocabulary.

Tasks

  1. Select an original work and state audience/purpose.
  2. Create an intake record and version name.
  3. Assign six editorial roles; in solo work, label each review pass.
  4. Write writer boundaries and consent conditions.
  5. Perform developmental review.
  6. Perform copyedit.
  7. Show six tracked before/after decisions.
  8. Record writer acceptance/adaptation/rejection.
  9. Audit privacy and identifying information.
  10. Audit copyright and licenses.
  11. Create complete attribution records.
  12. Write title, byline, summary, and metadata.
  13. Add content warning if justified; explain the choice.
  14. Create alt text and transcript/caption material if applicable.
  15. Build a formatted private mockup or document.
  16. Test links, navigation, contrast, mobile/readability, and file output.
  17. Complete an approval/withdrawal/correction plan.
  18. Write a 300–400 word publication rationale and reflection.
