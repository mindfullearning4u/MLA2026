Creative Writing | Unit 5 | Lesson 4 | Page 5 of 6

Independent Work: Multi-Format Publication Packet

Directions

Complete all 18 tasks using one original creative work. Submit with Page 2 vocabulary.

Tasks

  1. Name genre, audience, platform, and purpose.
  2. List every submission specification.
  3. Separate required conventions from preferences.
  4. Create a visual hierarchy plan.
  5. Format a polished primary version.
  6. Explain paragraph, stanza, or scene divisions.
  7. Explain dialogue or speaker labeling.
  8. Explain white-space decisions.
  9. Audit consistency.
  10. Audit readability and contrast.
  11. Ensure meaning is not color-dependent.
  12. Add descriptive links/transcripts if relevant.
  13. Adapt a 150–250 word section into a second genre.
  14. Explain what meaning changed.
  15. Correct five technical or formatting problems.
  16. Export to an approved file and inspect the rendered version.
  17. Create a before/after quality log.
  18. Write a 300–400 word rationale defending format and accessibility decisions.
