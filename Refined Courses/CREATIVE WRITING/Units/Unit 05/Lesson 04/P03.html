Lesson: The Format-Fit Audit

Six-Step Audit

  1. Name destination: identify genre, audience, platform, and submission specifications.
  2. Separate fixed from flexible: mark required conventions and optional design choices.
  3. Build hierarchy: title, headings, speaker labels, stanza/scene divisions, and page flow.
  4. Control genre movement: line breaks for poetry, paragraphing/dialogue for prose, cues/directions for scripts.
  5. Test access: readable type, contrast, descriptive link text, logical order, and no meaning conveyed by color alone.
  6. Proof technically: file type, name, margins, page numbers, embedded media, and final rendered view.

Learning Routes

Compare rendered examples visually; read layouts aloud as navigation instructions; physically reformat a mixed-up page.

Quality Principle

Formatting should reveal structure, not decorate randomly. A convention may be broken only when the reader can still navigate and the effect is intentional.
