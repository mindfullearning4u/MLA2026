P03 Notebook Task - Part 2

This page shows how to avoid format mistakes and explain format choices.

Step 4: Format Should Support Meaning

A line break, paragraph break, or script cue should help the reader. For example, placing not ready to knock on the final line emphasizes hesitation. That format choice supports meaning because the reader pauses before the action.

Step 5: Explain the Quality Check

A strong format explanation names the format choice and its effect. Example: I used a line break before "not ready to knock" so the reader pauses before the speaker's hesitation.

Common Mistake - Incorrect

Incorrect: I put random line breaks everywhere because poems look like that.

This is incorrect because format choices should support meaning, pacing, or reader understanding.

Common Mistake - Correct

Correct: I placed the final phrase on its own line to slow the pacing and emphasize the speaker's hesitation.

This is correct because it explains the format choice and reader effect.
