Independent Work: Build a Publication-Ready Portfolio Packet

Directions

Create a portfolio packet containing three creative artifacts, a revision trail, and a 600–800-word portfolio reflection. Submit the packet with your Page 2 vocabulary notes as Notebook Evidence.

Part A — Curate

  1. List at least four candidate works and complete a selection matrix for quality, growth, range, and readiness.
  2. Select three artifacts and justify each selection with specific evidence.
  3. Explain how the three works form a coherent collection while still showing range.
  4. If any work uses an unfamiliar or specialized term, define it in context or explain the clues that establish its meaning.

Part B — Document Revision

  1. For one artifact, include a before-and-after passage of 100–200 words.
  2. Identify the feedback or diagnosis that prompted the revision.
  3. Explain how the revision changes meaning, structure, or audience effect.
  4. Name one suggestion you did not adopt and justify that decision.

Part C — Prepare Publication

  1. Proofread all three artifacts and record five corrections or consistency checks.
  2. Create logical file names and metadata for every artifact.
  3. Complete an accessibility audit covering headings, links, images, color, and readability.
  4. Arrange the artifacts in a purposeful order and explain that sequence.

Part D — Reflect

  1. Write a 600–800-word reflection using Claim → Artifact → Evidence → Growth → Next goal.
  2. Identify the strongest craft decision in the portfolio.
  3. Identify one remaining limitation honestly.
  4. Set a precise next writing goal and describe how you will measure progress.

Submission Checklist

  • Vocabulary notes
  • Selection matrix
  • Three polished artifacts
  • Before/after revision trail
  • Publication and accessibility audit
  • 600–800-word reflection
