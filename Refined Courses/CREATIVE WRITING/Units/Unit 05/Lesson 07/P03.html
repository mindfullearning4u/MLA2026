P03 Notebook Task - Part 2

This page teaches the final preparation sequence for a portfolio-ready piece.

Step 4: Revise Before You Polish

Revision changes meaning, organization, craft, or reader effect. Polishing corrects final details. A common mistake is to correct spelling while leaving the ending confusing. First make sure the piece does what it is supposed to do. Then polish.

Step 5: Write the Portfolio Note

A portfolio note explains why the piece is included and how revision improved it. Use this structure: I selected this piece because _____. Feedback or rereading showed _____. I revised _____ so the reader would _____. The final version is ready because _____.

Common Mistake - Incorrect

Incorrect: I chose this draft because it was already typed, and I fixed one comma, so it is portfolio-ready.

This is incorrect because portfolio readiness requires purpose, revision evidence, format, clarity, conventions, and reader readiness.

Common Mistake - Correct

Correct: I selected this story because feedback helped me clarify the ending. I revised the final paragraph so the character's decision is shown through action, then checked dialogue format and conventions.

This is correct because it shows selection, revision, format, and final polish.
