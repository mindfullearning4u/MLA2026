P06 Independent Work

Complete all three parts using a short creative excerpt.

Instructions

Keep your original and revised versions. Label which changes improve clarity, which improve cohesion, and which correct conventions.

Part A: Diagnose

Find one unclear sentence, one weak connection, and one convention issue in a draft excerpt.

Part B: Revise

Revise the excerpt so the meaning is clearer, the parts connect better, and conventions support readability.

Part C: Explain

Write 5-7 sentences explaining one clarity revision, one cohesion revision, and one convention edit.
