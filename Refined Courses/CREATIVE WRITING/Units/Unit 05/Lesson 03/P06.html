📘 CW | Unit 05 | Lesson 03

P06 Independent Work

Complete all three parts using a peer draft excerpt or the provided model excerpt.

Instructions

Write feedback that a writer could actually use. Avoid comments that are only personal preference or general praise.

Part A: Listen

Write the writer's purpose in your own words. If using the model, use this purpose: The writer wants a tense scene that is still clear.

Part B: Respond

Write one craft strength and one clarifying question.

Part C: Suggest

Write one revision suggestion and explain how it supports the writer's purpose.
