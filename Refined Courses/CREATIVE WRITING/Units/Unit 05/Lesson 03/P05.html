Creative Writing | Unit 5 | Lesson 3 | Page 5 of 6

Independent Work: Workshop Casebook

Directions

Complete all 18 tasks. If no peer is available, use the simulated feedback cases on Page 4. Submit with Page 2 vocabulary.

Tasks

  1. State genre, audience, purpose, and boundaries.
  2. Write two workshop questions.
  3. Create four discussion norms.
  4. Identify five exact textual observations.
  5. Describe the reader effect of each.
  6. Write five open craft questions.
  7. Write five criterion-based feedforward comments.
  8. Revise two comments that sound like commands.
  9. Identify one preference disguised as feedback.
  10. Model a writer paraphrase.
  11. Write three clarifying questions.
  12. Cluster repeated concerns.
  13. Resolve conflicting advice.
  14. Create an accept/adapt/test/set-aside chart.
  15. Write a prioritized revision plan.
  16. Revise at least two substantial passages.
  17. Show before/after evidence.
  18. Write a 300–400 word metacognitive reflection on listening, agency, and revision.
