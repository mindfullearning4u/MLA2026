Independent Work: Author Presentation Plan

Directions

Select one substantial creative work from Unit 5. Prepare a written author-presentation script of 500–700 words and a one-page visual presentation map. Answer all tasks in complete sentences. Submit this work with your Page 2 vocabulary notes as Notebook Evidence.

Part A — Frame the Work

  1. Name the title, genre, intended audience, and central creative aim.
  2. Write a two-sentence opening that creates useful context without summarizing the entire work.
  3. Select an excerpt of 80–150 words and explain why it represents the work.
  4. If your excerpt uses an unfamiliar or specialized word, define it in context or explain the contextual clues that establish its meaning.

Part B — Explain Craft

  1. Identify three deliberate craft choices in the excerpt.
  2. Quote or describe exact evidence for each choice.
  3. Explain the intended audience effect of each choice.
  4. For one choice, discuss a plausible alternative and explain why you rejected it.

Part C — Revision and Delivery

  1. Compare one early-version passage or decision with the final version.
  2. Explain which feedback, test, or rereading led to the change.
  3. Mark two pauses, one word for vocal emphasis, and one transition in your script.
  4. Create a visual map with four labeled boxes: Context → Excerpt → Craft Reasoning → Revision Reflection.
  5. Conclude with one unresolved artistic question you would ask an audience.

Submission Check

  • 500–700-word script
  • 80–150-word excerpt
  • Three evidence-based craft explanations
  • One revision comparison
  • One-page visual map
  • Vocabulary notes attached
