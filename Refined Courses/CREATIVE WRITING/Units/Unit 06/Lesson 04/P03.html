P03 Notebook Task - Part 2

This page teaches how to explain poetry and style revisions for a portfolio.

Step 4: Revise with Precision

In poetry and style writing, small changes matter. One stronger verb, one line break, or one removed repetition can change the reader's experience. Do not change language randomly. Name the effect first, then revise.

Step 5: Explain Style Growth

Use this frame: I revised _____ so the reader would _____. This belongs in my portfolio because it shows growth in _____. Name the craft area clearly: imagery, line breaks, sound, figurative language, voice, tone, or rhythm.

Common Mistake - Incorrect

Incorrect: I added random line breaks because poems are supposed to look unusual.

This is incorrect because line breaks should create emphasis, pacing, meaning, or sound. Random breaks can distract readers.

Common Mistake - Correct

Correct: I placed the final phrase on its own line so the reader pauses before the speaker's decision.

This is correct because the line break supports pacing and meaning.
