Independent Work: Complete Author Presentation Plan

Directions

Create a plan and script for a 5–7-minute author presentation of one portfolio work. Submit the 800–1,000-word script, annotated excerpt, visual storyboard, rehearsal evidence, and Page 2 vocabulary notes.

Part A — Design

  1. Name audience, purpose, time limit, and intended audience takeaway.
  2. Compare two possible excerpts using the four selection criteria.
  3. Select a 150–300-word excerpt and justify it.
  4. If the excerpt contains an unfamiliar or specialized term, define it in context or explain the clues listeners need.
  5. Create a five-part presentation arc with exact time allocations.

Part B — Script and Annotate

  1. Write the complete presentation script.
  2. Analyze two craft choices with exact evidence.
  3. Include one meaningful before-and-after revision comparison.
  4. Mark pauses, vocal emphasis, pace changes, and transitions.
  5. End with an authentic question or listening invitation.

Part C — Visual and Rehearsal

  1. Create a 3–5-frame visual storyboard with accessible design.
  2. Complete two timed rehearsals.
  3. Record section times and identify where time was gained or lost.
  4. Collect listener feedback using two targeted questions.
  5. Explain three revisions made after rehearsal.

Required Planning Grid

Include columns for Time | Spoken purpose | Exact evidence/visual | Delivery cue | Revision needed.
