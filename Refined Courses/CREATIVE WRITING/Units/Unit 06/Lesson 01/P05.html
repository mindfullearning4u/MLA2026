Independent Work: Portfolio Selection Defense

Directions

Compare three of your own candidate creative works. Create an evidence matrix and write a 700–900-word selection defense for the one piece that should anchor your Unit 6 portfolio. Submit it with Page 2 vocabulary notes.

Part A — Compare

  1. State the portfolio purpose and intended audience.
  2. For each candidate, identify its strongest controlled craft choice.
  3. For each, cite one exact passage or structural feature.
  4. Score each for craft control, growth, range, and readiness; explain every score.
  5. If a work uses an unfamiliar or specialized term, define it in context or explain the clues that establish its meaning.

Part B — Defend the Selection

  1. Make a defensible selection claim.
  2. Analyze two exact craft choices and their audience effects.
  3. Include a 100–200-word before-and-after revision comparison.
  4. Explain which feedback you adopted, adapted, or rejected and why.
  5. Explain the selected work’s unique contribution to the portfolio.
  6. Identify one tradeoff or remaining limitation.
  7. Set a measurable next revision goal.

Required Visual

Create a four-column comparison table labeled Craft Control | Growth | Range | Readiness. Use brief evidence, not only scores.

Submission Check

  • Vocabulary notes
  • Three-work evidence matrix
  • 700–900-word defense
  • Before/after evidence
  • Feedback reasoning
  • Limitation and measurable next goal
