Independent Work: Author Statement in Three Contexts

Directions

Choose one portfolio anchor piece. Write a 600–750-word full author statement, then adapt it into two shorter formats. Submit all work with Page 2 vocabulary notes.

Part A — Analyze the Situation

  1. Name the work, genre, purpose, intended audience, and publication context.
  2. Describe the voice you want the statement to project using three precise adjectives.
  3. Identify one tone risk and how you will prevent it.
  4. If your work or statement uses an unfamiliar or specialized term, define it in context or explain its contextual clues.

Part B — Write the Full Statement

  1. Explain the work’s central creative question or tension.
  2. Analyze two craft choices with exact evidence.
  3. Compare one meaningful draft-to-final revision.
  4. Explain the intended reader effect without claiming universal control.
  5. Acknowledge one limitation or unresolved question.
  6. End with a reader invitation rather than a summary.

Part C — Adapt

  1. Create a 150–200-word curatorial note for a digital portfolio.
  2. Create a 75–100-word oral introduction and mark two pauses and one emphasized word.
  3. Annotate five changes in register, emphasis, or sentence structure across the versions.

Required Visual Audit

Create a labeled four-row chart: Purpose | Craft | Revision | Invitation. Quote the sentence in each version that fulfills each move, or mark where a move was deliberately omitted for length.
