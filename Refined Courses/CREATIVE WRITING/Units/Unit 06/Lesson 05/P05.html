Independent Work: Digital Publication Package

Directions

Prepare one portfolio piece for digital publication. Submit the final publication file, a readiness report of 700–900 words, a visual preflight checklist, and Page 2 vocabulary notes.

Part A — Plan

  1. Name the genre, audience, platform, and reading context.
  2. Identify three format features essential to meaning.
  3. Create a style specification for title, headings, body text, spacing, and emphasis.
  4. If the work uses an unfamiliar or specialized term, define it in context or explain the clues establishing its meaning.

Part B — Prepare

  1. Format the complete creative work consistently.
  2. Add accurate metadata and a logical file name.
  3. Repair contrast, headings, link text, alternative text, transcript, or caption needs.
  4. Document rights and privacy decisions for every external or personal media element.

Part C — Test and Defend

  1. Test the final file on two screen sizes or in two viewing modes.
  2. Open and test every link and media element.
  3. Record five defects found and how each was corrected.
  4. Explain how three format decisions support genre or reader experience.
  5. Identify one tradeoff and one remaining limitation.
