Worked Example: Three Publication Repairs

Example 1 — Poetry on a Small Screen

Problem: A 42-character line wraps on mobile, creating accidental line breaks.

  1. Identify which line breaks are essential to meaning.
  2. Test a slightly smaller readable font and wider content area.
  3. If wrapping remains, offer a PDF preserving lineation plus an accessible text version.
  4. Do not simply insert arbitrary breaks; that changes poetic pacing.

Example 2 — Image, Contrast, and Rights

Problem: White text overlays a busy copyrighted photograph; no alternative text or permission is recorded.

  1. Replace or license the image; document permission.
  2. Move text to a solid high-contrast panel.
  3. Add alternative text describing the image’s relevant meaning.
  4. If decorative, mark it decorative rather than narrating irrelevant detail.
  5. Test grayscale and enlarged text to ensure access does not depend on color.

Example 3 — File and Link Failure

Draft: “FINAL_final2.docx,” links labeled “here,” tracked changes visible, missing author name.

  1. Accept or reject tracked changes and inspect comments.
  2. Rename the file TideLedger_MayaOrtiz_Final.pdf.
  3. Add title, author, genre, and date metadata.
  4. Replace “here” with “Read the author’s revision reflection.”
  5. Open the PDF in a clean browser and test every link.

Transfer Rule

If a design choice cannot be connected to genre, meaning, navigation, or access, it may be decoration rather than communication.
