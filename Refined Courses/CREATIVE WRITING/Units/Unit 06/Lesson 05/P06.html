New Source: The Almost-Finished File

A digital portfolio has strong writing but inconsistent headings, tiny gray text, missing page numbers, two unlabeled images, a broken table-of-contents link, and a file name that reads “final_FINAL2.” The writer assumes readers will overlook these details.

Accessibility means designing content so people with varied needs and technologies can use it. Document hierarchy uses consistent titles, headings, spacing, and navigation to communicate structure.

Part 1: Analyze the Source

  1. Which problems most directly block access or navigation? Explain why they deserve priority.
  2. Create a logical quality-control sequence that reduces the chance of introducing new formatting errors.

Use this response pattern: Make a precise claim, cite the relevant detail, and explain how the detail proves the claim.

Part 2: Choose A or B

3. Which plan supports professional and accessible digital publication?

A. Decorate each page differently so every piece has a unique visual identity.
B. Use one restrained design system, meaningful headings, readable contrast, descriptive text, consistent navigation, and a final device check.

Record A or B in your submission and explain your choice in 2–3 sentences. The answer is not revealed here because this item is part of your graded written work.

Part 3: Create and Apply

4. Prepare a publication-ready digital portfolio file containing at least three works.

  1. Structure: Include title page, author statement, table of contents, clearly labeled works, and credits or sources.
  2. Consistency: Apply one heading, font, spacing, margin, and page-number system.
  3. Accessibility: Verify readable contrast, meaningful link text, image descriptions where needed, and logical reading order.
  4. Navigation: Test the table of contents and every link.
  5. Export: Use a clear file name and review the final PDF or approved format on more than one screen size.

Submit a completed quality-control checklist with the portfolio.

Plan before drafting: Decide what the audience should understand, how each section will build that understanding, and which details will do the most work.

Part 4: Revise With Purpose

5. Correct one hierarchy or consistency issue and one accessibility or navigation issue. Explain how each change affects the reader.

Do more than correct spelling. Revise organization, meaning, evidence, or craft so the work becomes clearer and more effective.
