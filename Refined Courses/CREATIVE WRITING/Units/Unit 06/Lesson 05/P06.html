Checkpoint: Repair a Digital Publication

Directions

Complete this distinct checkpoint independently. Analyze the new publication case and answer all 12 questions in complete sentences. A score of at least 80% is required.

Case File

A digital literary magazine posts Kareem’s monologue as one unbroken paragraph in 11-point pale-blue text on white. Speaker cues appear only in red. A meaningful photograph has the file name “IMG_4032” but no alternative text or credit. An audio performance begins automatically, has no transcript, and is twice as loud as other media. The download is named “newfinal.docx,” contains unresolved comments, and displays a different ending from the web page.

A monologue is an extended speech by one speaker. Auto-play means media begins without the user choosing to start it.

Diagnosis

  1. Identify two ways the format damages genre readability.
  2. Explain why red-only speaker cues create an accessibility problem.
  3. Write useful alternative text and a credit line for the photograph using plausible details.
  4. Explain two problems with the audio treatment.
  5. Identify the version-control failure.
  6. Explain why unresolved comments create publication risk.

Repair and Preflight

  1. Propose a hierarchy and spacing system for the monologue.
  2. Describe an accessible replacement for color-only cues.
  3. Design a compliant audio presentation with controls and transcript.
  4. Create a logical final file name and metadata record.
  5. Write a six-step preflight sequence in the order it should occur.
  6. Give a final publish/do-not-publish judgment supported by at least five criteria.

80% Mastery Requirement

If you score below 80%, review feedback, correct the identified weaknesses, and resubmit according to your TOR’s directions.
