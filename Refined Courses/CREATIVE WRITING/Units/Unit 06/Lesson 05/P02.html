Vocabulary and Definitions

Notebook Task: Record every core term and its complete meaning in your notebook. Submit these vocabulary notes with your Independent Work as Notebook Evidence. Use the examples to see how each term works in context. Reference glossary terms do not need to be copied.
TermMeaningExample
typographyThe selection and arrangement of type to support readability and visual meaning.A readable font and restrained bolding support the poem.
visual hierarchyDesign cues that show the order and relative importance of information.Title size and section headings guide the reader.
white spaceUnoccupied space that separates and organizes content.Margins and spacing keep the page from feeling crowded.
accessibilityDesign that enables people with differing needs to perceive and use a work.Strong contrast and keyboard navigation improve access.
alternative textA concise written description communicating an image’s purpose or meaning.The description explains the symbolic cracked mirror.
descriptive linkLink text that identifies its destination or purpose.“Read the author statement” is clearer than “click here.”
metadataInformation such as title, author, date, genre, and file description.The file metadata identifies the current revision.
version controlA method for labeling and preserving successive drafts accurately.Numbered filenames prevent an old draft from being published.
preflightA final systematic check of content, files, links, format, rights, and accessibility.The team tests every link and confirms permissions before release.

Make the Vocabulary Work

Which link uses a clear descriptive link?

A. “Click here.”

This does not tell the reader where the link goes or what it does.

B. “Download the accessible poetry portfolio.”

Correct. The wording identifies both the action and the destination.
