Independent Work: Final Portfolio Release Candidate

Directions

Assemble the complete Unit 6 portfolio release candidate and write a 900–1,100-word readiness defense. Submit the portfolio package, audit evidence, and Page 2 vocabulary notes.

Part A — Inventory and Align

  1. Create an inventory of every artifact, file name, version, standard, and status.
  2. Build an artifact map showing where each standard and craft claim is demonstrated.
  3. Cross-reference the author statement, revision trail, presentation excerpt, and final artifacts.
  4. If any component uses an unfamiliar or specialized term, define it in context or explain the clues a reader needs.

Part B — Audit

  1. Run separate craft, revision, coherence, publication, accessibility, and presentation passes.
  2. Record at least eight defects or risks, including any “no issue found” evidence for a category.
  3. Rank defects by impact and correct all high-priority items.
  4. Document provenance and permission for external media.
  5. Export and test the complete release candidate outside the editor.

Part C — Defend

  1. Write a 900–1,100-word defense using Criterion → Evidence → Verification → Limitation → Judgment.
  2. Cite at least five exact locations across different portfolio components.
  3. Explain two tradeoffs made during integration.
  4. Identify one remaining limitation and a responsible plan.
  5. State a final ready/not-ready judgment.

Required Visual Dashboard

Create a table with columns: Component | Standard | Evidence location | Version | Access check | Status | Action.
