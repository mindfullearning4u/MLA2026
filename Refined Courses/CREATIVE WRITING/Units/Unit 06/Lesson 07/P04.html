Worked Example: Three Integration Failures

Example 1 — Statement/Artifact Mismatch

Claim: The author statement praises controlled second-person narration. Artifact: The final story is entirely first person because the writer changed viewpoint after feedback.

  1. Diagnosis: the statement describes an obsolete version.
  2. Verify the revision trail and final file.
  3. Update the statement to analyze first-person distance and explain the viewpoint change.
  4. Cross-reference the exact before/after passage.

Example 2 — Revision Evidence Mismatch

Problem: The portfolio says pacing improved, but the before/after evidence shows only corrected punctuation.

  1. Return to revision history.
  2. Select a passage showing scene expansion, compression, or reordering.
  3. Explain how the change alters reader time and attention.
  4. If no evidence exists, qualify the growth claim rather than manufacturing proof.

Example 3 — Release-Candidate Failure

Problem: The web portfolio works in the editor, but the exported folder contains a broken audio link, an unlabeled image, and “Final3” rather than the approved final poem.

  1. Compare every file to the frozen inventory.
  2. Replace the obsolete poem and update metadata.
  3. Embed or relink the audio using a stable path and provide a transcript.
  4. Add meaningful alternative text.
  5. Re-export and test from a clean browser.

Transfer Principle

A portfolio is a system: a failure of alignment, version, access, or navigation can weaken otherwise excellent writing.
