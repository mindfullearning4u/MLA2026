# English III Instructional Quality and Self-Paced Teaching Audit

## Audit Scope

Course audited: English III

Lessons audited: 48

Audit focus: instructional quality, self-paced teaching clarity, learner support, step-by-step sequencing, vocabulary support, modeling, examples, practice readiness, independent-work clarity, checkpoint mastery criteria, and audit readiness.

## Initial Audit Findings

Initial required correction count: 39 lessons

The audit identified lessons that needed added self-paced instructional support before certification. Findings were concentrated in these categories:

- Explicit learner-level support language for remedial, standard, and accelerated students
- Clearer step-by-step sequencing before independent application
- Common mistake feedback using incorrect and correct examples
- Vocabulary review support in synthesis and assessment-preparation lessons
- Worked example markers for Example 1, Example 2, and Example 3
- Independent work structure using Part A, Part B, and Part C
- Additional teacher-guided thinking support where instruction was too thin for independent learning
- One missing mastery criteria marker

## Corrections Made

The following corrections were made inside English III only:

- Added Learner Support Path boxes to strengthen remedial, standard, and accelerated guidance.
- Added Step-by-Step Learning Path boxes where sequencing needed to be more explicit.
- Added Common Mistake, Incorrect, and Correct feedback blocks where error correction needed to be more teachable.
- Added Vocabulary Review boxes where important terms needed clearer support before use.
- Added Worked Example Review boxes where lessons needed explicit Example 1, Example 2, and Example 3 modeling.
- Added Independent Work Parts boxes to clarify Part A, Part B, and Part C expectations.
- Added Teacher-Guided Thinking Check boxes where students needed stronger support without live teacher instruction.
- Added the missing Mastery Criteria marker to Unit 01 Lesson 08.
