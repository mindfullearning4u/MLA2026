Checkpoint: Presenting “Names on the Bridge”

Source Set

A poem describes names carved into a footbridge, rain filling the letters, and pedestrians adding new marks. A critic argues that inscriptions turn private memory into public text. A preservation report explains that repeated carving weakens the bridge rail and recommends a separate memorial panel.

Questions

  1. Write an interpretive claim.
  2. Identify two important images.
  3. Define inscription in context and verify it with a reputable source.
  4. Analyze one quoted phrase.
  5. Synthesize the critic and preservation report.
  6. State one source limitation.
  7. Develop and answer a counterinterpretation.
  8. Create a five-part speaking outline.
  9. Write a 140–180 word presentation excerpt with oral citations.
  10. Plan one accessible visual.
  11. Add four delivery cues.
  12. Complete a citation and source-integrity check.
