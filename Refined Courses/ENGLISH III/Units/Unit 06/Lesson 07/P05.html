Independent Work: Audit “After the Mill Closed”

Scenario

A multimedia feature includes literary excerpts, worker interviews, economic charts, photographs, ambient audio, and a timeline. The release candidate contains an overstated headline, unidentified quotation, cropped image, misleading chart scale, missing permissions, flawed captions, private contact information, broken links, and no fallback or archive plan.

Questions 1–18

  1. State claim, audience, and publication purpose.
  2. Define ambient and verify it.
  3. Correct the headline.
  4. Repair quotation framing and citation.
  5. Analyze the crop and restore context.
  6. Repair chart scale and source note.
  7. Plan permissions and credit lines.
  8. Correct captions and transcript.
  9. Remove or secure private information.
  10. Repair and label links.
  11. Create alternative text and chart description.
  12. Create low-bandwidth fallback.
  13. Plan content warning if needed.
  14. Create device, network, keyboard, zoom, and screen-reader tests.
  15. Create a release checklist.
  16. Write a 220–280 word audit rationale.
  17. Create an eight-entry change log.
  18. Write sign-off, correction, and archive procedures.
