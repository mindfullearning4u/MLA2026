Lesson: The Final Publication Workflow

1. Freeze the Claim and Audience

Confirm purpose, audience, evidence, and intended action before final polishing. Remove any media or section that does not serve that purpose.

2. Run Editorial and Media Audits

Check reasoning, source representation, tone, conventions, headings, links, visuals, audio, video, interactivity, credits, privacy, licensing, captions, transcripts, alternative text, and fallback content.

3. Build and Test a Release Candidate

Test the exact files on target devices and network conditions. Include keyboard, zoom, screen reader, captions, links, downloads, playback controls, and low-bandwidth use.

4. Document and Approve

Record changes, remaining limitations, reviewer sign-off, release date, version, correction contact, and archive location.

Common Mistakes

  • Adding late media without testing.
  • Publishing drafts with temporary credits.
  • Assuming automated captions are accurate.
  • Hiding known limitations.
  • Failing to preserve an approved archive copy.
