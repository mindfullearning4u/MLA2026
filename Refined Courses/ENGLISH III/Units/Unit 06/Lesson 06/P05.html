Independent Work: Publish “The Community Cooling Guide”

Scenario

A school LAN guide combines heat-safety advice, cooling-center locations, student interviews, a temperature chart, and downloadable checklists. The draft uses long paragraphs, vague links, inconsistent headings, identifiable student information, an unsourced chart, inaccessible PDF scans, and conflicting file versions.

Questions 1–18

  1. State audience, purpose, and tasks.
  2. Define identifiable in context and verify it.
  3. Create an information architecture.
  4. Write a descriptive title and 60-word summary.
  5. Chunk one long section.
  6. Revise four vague links.
  7. Repair heading hierarchy.
  8. Repair chart labels and source.
  9. Plan a text equivalent.
  10. Identify privacy risks and corrections.
  11. Plan interview permissions.
  12. Make scanned checklists accessible.
  13. Create version-control names.
  14. Plan responsive and LAN testing.
  15. Create four usability tasks.
  16. Write a 220–280 word publication rationale.
  17. Create a six-decision revision log.
  18. Complete final content, privacy, source, accessibility, link, and device audit.
