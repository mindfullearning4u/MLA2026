Checkpoint: “A Night Market Pilot”

Source Set

The city is considering a six-week night-market pilot. A pedestrian count found that downtown foot traffic drops 44% after 6 p.m., but the count covered only four weekdays in October. A survey of 51 small businesses found that 34 would consider staying open during a market; participation was voluntary. A police memorandum estimates that traffic control would require 12 officer-hours each week. A neighborhood association supports a pilot if amplified sound ends at 9 p.m.

Questions

  1. Write a focused controlling idea.
  2. Identify one limitation in each quantitative source.
  3. Using context, define pilot in this civic setting; verify it with a reputable source.
  4. Write an accurate oral citation for the pedestrian count.
  5. Create an anaphora that emphasizes measurable testing.
  6. Write an antithesis that distinguishes a pilot from a permanent program.
  7. Create one useful analogy and explain its limit.
  8. Identify a kairos-based reason for speaking now without creating false urgency.
  9. Write a 130–170 word evidence-based speaking excerpt using three devices.
  10. Annotate the function of each device.
  11. Add four delivery cues.
  12. Complete an ethical-rhetoric and source-integrity check.
