Direct Teaching: Constructing an Analytical Response

1. Decode the Prompt

Circle the required task—analyze, compare, explain, or evaluate. Underline the text feature or idea you must address. A response about a related topic still fails if it does not answer the exact question.

2. Write a Focused Claim

A useful claim names the text, makes an interpretation, and indicates the reasoning path. Weak: The story uses imagery. Focused: The story’s recurring winter imagery traces the narrator’s movement from isolation toward cautious trust.

3. Build the Paragraph

  1. Claim/topic sentence
  2. Context for the evidence
  3. Quoted or paraphrased evidence
  4. Reasoning explaining the connection
  5. Elaboration on significance
  6. Concluding insight

4. Balance Evidence and Analysis

Evidence should not dominate the paragraph. After each detail, explain what it reveals, how a word or event creates that meaning, and why the meaning matters to the claim.

5. Create Coherence

Use transitions that name relationships: however signals contrast; because introduces cause; for example introduces evidence; therefore marks a conclusion. Repeat key concepts strategically without repeating entire sentences.

Common Mistakes

  • Retelling events instead of interpreting them.
  • Using a broad claim that could fit any text.
  • Dropping evidence without context.
  • Explaining what happened but not why it matters.
  • Ending by copying the topic sentence.
