P05 Guided Practice

Answer each question by choosing the response that keeps the literary element central to the analysis.

Practice Set

Question 1: Identify the strongest claim about a symbol.

Question 2: Choose the evidence that supports analysis of imagery.

Question 3: Choose the source-supported explanation of figurative language.

Question 4: Identify the revision that improves clarity and style.

Question 5: Choose the analysis that explains allegorical meaning without drifting into plot summary.

Learning Support

Before choosing an answer, ask: Which literary element is being analyzed? If the answer does not name or explain the element, it is probably too general.
