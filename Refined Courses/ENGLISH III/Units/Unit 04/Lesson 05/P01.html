Lesson Overview: Literary Elements in Source-Supported Analysis

Standards Covered in This Lesson

Primary Standard: MLA.ENG3.R.04 — Analyze how literary elements interact to develop meaning, using relevant source evidence to support and complicate interpretation.

Support Standards: MLA.ENG3.R.01 — Cite textual evidence; MLA.ENG3.R.09 — Synthesize sources; MLA.ENG3.W.08 — Evaluate sources; MLA.ENG3.W.09 — Write literary analysis; MLA.ENG3.L.01 — Apply conventions.

Lesson Focus

Analyze interaction among character, setting, conflict, imagery, symbolism, point of view, and structure while using sources for precise contextual or critical support.

Learning Goals

  • Move beyond identifying isolated elements.
  • Trace how elements interact across a text.
  • Select sources appropriate to contextual, critical, or technical subquestions.
  • Use source evidence to support or complicate close reading.
  • Evaluate alternative interpretations.

Workflow and Mastery

Vocabulary → diverse element interactions → worked source-supported model → Independent Work → Checkpoint → five randomized questions at 80%.
