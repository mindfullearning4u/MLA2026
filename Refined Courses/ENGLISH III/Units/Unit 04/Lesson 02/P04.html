P04 Worked Example

Study how to classify and choose sources for literary research.

Worked Example Question

How does the image of the ruined fountain develop the theme of public memory in the poem?

Example 1: Primary Source

The poem itself is the primary source because the research question asks about an image inside the poem.

Example 2: Secondary Source

An article about public monuments and memory in poetry would be a secondary source because it analyzes a related literary idea.

Example 3: Source Choice

The poem should provide direct evidence. The article should help explain how public objects can represent shared memory.

Common Mistake to Avoid

Incorrect: Any source about fountains is the best secondary source.

Why it is weak: A source about building fountains may not help interpret public memory in poetry.

Correct: A secondary source should connect to the research question, such as an article about public monuments and memory in poetry.

Why it is correct: It matches the literary issue, not just one object in the poem.
