P02 Notebook Task Part 1

Set up your notebook to compare shared information and different ends.

Notebook Title

Same Information, Different Ends

Vocabulary

  • Shared information: A fact, detail, example, or piece of evidence used by more than one author.
  • End: The conclusion, purpose, or result an author wants the reader to accept.
  • Claim: The author's position.
  • Reasoning: The explanation that connects information to a claim.
  • Different ends: Different conclusions reached from the same information.

Direct Teaching

When two authors use the same information, do not assume they are making the same argument. First find the information that appears in both texts. Then ask, "What does each author want this information to prove?"

Think of the shared information as a tool. One author may use the tool to build one conclusion. Another author may use the same tool to build a different conclusion.

A strong comparison uses academic vocabulary: Both authors use..., Author A uses the information to..., Author B uses the same information to..., and This difference matters because...

Notebook Setup

Create a four-column chart:

  1. Shared information
  2. Author A's claim or end
  3. Author B's claim or end
  4. How the same information is used differently

Leave at least six lines under the chart for your written explanation.
