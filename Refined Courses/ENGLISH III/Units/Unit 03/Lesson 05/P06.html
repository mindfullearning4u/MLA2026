Independent Work Passage

Argument A: The council should build a new public fountain because last year's summer heat caused long lines at every water stand. A fountain would provide relief and show care for travelers.

Argument B: The council should repair the existing wells because last year's summer heat caused long lines at every water stand. Repairing wells would spread water access across neighborhoods instead of adding one crowded location.

Part A: Identify

Write the shared information used by both authors. Then write each author's claim.

Part B: Explain

Explain how Argument A uses the heat and long-line detail. Then explain how Argument B uses the same detail differently.

Part C: Evaluate

Write two to four sentences explaining which argument uses the shared information more effectively for its purpose. Use evidence from the passage.
