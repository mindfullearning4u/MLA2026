P03 Notebook Task Part 2

Apply your chart to paired arguments.

Paired Arguments

Argument A: The academy should keep public lectures free because last year's free lecture series filled every seat. When citizens can attend without cost, knowledge becomes a common good rather than a privilege.

Argument B: The academy should charge a small fee for public lectures because last year's free lecture series filled every seat. A modest fee would control overcrowding and help pay for better materials.

Notebook Directions

  1. Write the shared information used by both authors.
  2. Write Argument A's end or conclusion.
  3. Write Argument B's end or conclusion.
  4. Explain how the same information supports two different ends.

Use this sentence frame if needed: Both authors use the fact that ____. Argument A uses it to show ____, while Argument B uses it to show ____.

Model Start

Shared information: Last year's free lecture series filled every seat.

Argument A's end: Keep lectures free because free access spreads knowledge.
