P04 Worked Example

Study how the same information can support different ends.

Worked Example Arguments

Argument A: The city should expand the harbor because merchant ships waited three days to unload grain last month. A larger harbor would keep trade moving and protect food supply.

Argument B: The city should limit harbor traffic because merchant ships waited three days to unload grain last month. Too much traffic has already strained the docks, so the city should reduce crowding before expanding.

Example 1: Shared Information

Both authors use the fact that merchant ships waited three days to unload grain last month.

Example 2: Different Ends

Argument A uses the delay to support expansion. Argument B uses the same delay to support limiting traffic.

Example 3: Evaluation

Both arguments are valid if their reasoning fits their purpose. Argument A treats the delay as evidence that capacity is too small. Argument B treats the delay as evidence that traffic is already beyond control.

Common Mistake to Avoid

Incorrect: The authors use different information because they disagree.

Why it is weak: The authors disagree, but they both use the same fact about ships waiting three days.

Correct: Both authors use the same delay, but Argument A uses it to support expansion while Argument B uses it to support traffic limits.

Why it is correct: It identifies the shared information and explains the different ends.
