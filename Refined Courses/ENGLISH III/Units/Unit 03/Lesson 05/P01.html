Lesson 5: Same Information Used to Achieve Different Ends

Standards Covered

Primary Standard: MLA.ENG3.R.08 - Evaluate Multiple Arguments and Reasoning.

Support Standards: MLA.ENG3.R.06 - Analyze Central Ideas in Classical Texts; MLA.ENG3.R.07 - Analyze Author Purpose in Classical Texts; MLA.ENG3.V.01 - Integrate Academic Vocabulary.

What You Will Learn

  • How two authors can use the same fact or detail for different purposes.
  • How to separate shared information from each author's claim.
  • How to explain why the same information supports different ends.
  • How academic vocabulary helps make an argument comparison precise.

Why This Matters

Authors do not always disagree because they have different facts. Sometimes they use the same fact to guide readers toward different conclusions.

This lesson helps you notice how evidence can be shaped by purpose, reasoning, and audience.

What You Will Do

  • Read paired short arguments that share the same information.
  • Identify the shared information in both arguments.
  • Explain each author's different end, purpose, or conclusion.
  • Evaluate how effectively each author uses the shared information.

How You Will Show Mastery

You will compare two arguments, identify the same information used by both authors, and explain how each author uses that information to achieve a different end.

Student-Friendly Standard Connection

This standard asks you to compare arguments and explain how authors can use the same information in different ways to reach different conclusions.

Ask TOR for Help

Ask TOR for help if you can find the shared information but cannot explain how the authors use it for different purposes.
