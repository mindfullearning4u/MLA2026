P07 Checkpoint

Show mastery of comparing how authors use the same information to achieve different ends.

Checkpoint Passage

Argument A: The city should preserve the old walls because visitors still stop to study the stones and inscriptions. These walls teach citizens and travelers about the city's history.

Argument B: The city should create a modern walking path around the old walls because visitors still stop to study the stones and inscriptions. A path would guide visitors safely while protecting the fragile site.

Checkpoint Task

Write one organized paragraph that includes:

  • the shared information used by both authors,
  • Argument A's end or conclusion,
  • Argument B's end or conclusion,
  • an explanation of how the same information is used differently, and
  • a final sentence evaluating which use is more effective for its purpose.

Notebook Evidence Submission

Submit your notebook chart from P02-P03 and your independent work from P06 as evidence of preparation.

Checkpoint Submission

Submit your final paragraph in the checkpoint assignment area.

Ask TOR for help before submitting if your paragraph names the claims but does not explain how the shared information is used differently.

Mastery Criteria

  • Identifies the shared information accurately.
  • Explains each author's different end.
  • Uses academic vocabulary from the lesson.
  • Evaluates effectiveness using evidence, not preference.
