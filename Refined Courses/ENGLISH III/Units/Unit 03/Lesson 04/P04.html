Worked Example: Two Arguments About a School Garden

Argument A

The garden should become parking because afternoon events create congestion. Three recent events filled the existing lot, and nearby streets received complaints. Additional spaces would reduce traffic searching for parking.

Argument B

The garden should remain because science classes use it weekly, produce goes to a food pantry, and shaded soil reduces storm runoff. Event congestion occurs fewer than twelve days each year; shared parking with the library could address those days.

Map and Test

  • A offers relevant congestion evidence but assumes additional parking will reduce traffic rather than attract more cars.
  • B uses several benefits and directly qualifies the frequency of the problem.
  • B’s shared-parking proposal answers A’s concern, but it requires evidence that the library lot has capacity.

Model Evaluation

Using year-round educational and public benefit plus feasibility as criteria, B is currently stronger because it supplies broader evidence and addresses the counterclaim. Its conclusion remains conditional on verifying shared-parking capacity.

Alternative Criterion

If emergency access were the criterion and the existing lot blocked response vehicles, A could become stronger. Evaluation must remain responsive to evidence and decision standards.
