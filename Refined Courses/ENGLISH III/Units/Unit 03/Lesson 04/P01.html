Lesson Overview: Multiple Arguments, Claims, Validity, and Reasoning

Purpose

Evaluate interacting arguments by testing claims, evidence, assumptions, validity, and reasoning—not by selecting the position you already prefer.

Standards Covered in This Lesson

Primary Standard: MLA.ENG3.R.08 — Evaluate arguments by analyzing claims, evidence, assumptions, validity, and reasoning.

Support Standards: MLA.ENG3.R.01 — Cite relevant textual evidence; MLA.ENG3.R.06 — Analyze author purpose and rhetorical choices; MLA.ENG3.V.01 — Apply academic and passage-specific vocabulary; MLA.ENG3.L.01 — Apply standard English conventions.

Learning Goals

  • Separate main, supporting, and opposing claims.
  • Map premises to conclusions.
  • Test relevance, sufficiency, accuracy, and validity.
  • Compare arguments using explicit criteria.

Workflow

Vocabulary → multiple models → worked evaluation → longer Independent Work with targeted passage vocabulary → separate Checkpoint → five-question quiz at 80% mastery.
