Checkpoint: Competing Arguments About School Start Time

Directions

Read the arguments and answer all 12 questions. Submit separately.

Argument A

Start one hour later because adolescent sleep research links adequate sleep with attention. Attendance improved during a two-week delayed-start weather schedule.

Argument B

Keep the schedule because later dismissal conflicts with athletics, jobs, and elementary bus routes. A two-week weather period cannot predict a full year.

Argument C

Pilot a thirty-minute delay for one semester and measure attendance, grades, transportation costs, activities, and student employment before permanent change.

Questions

  1. Infer adolescent from context.
  2. State each conclusion.
  3. Evaluate A’s evidence.
  4. Identify A’s causal assumption.
  5. Evaluate B’s counterclaim.
  6. Explain B’s criticism of the weather example.
  7. Map C’s reasoning.
  8. Identify C’s criteria.
  9. Which argument best addresses uncertainty?
  10. Write an objective synthesis.
  11. Evaluate the strongest argument using two criteria.
  12. Name evidence that could change the judgment.
