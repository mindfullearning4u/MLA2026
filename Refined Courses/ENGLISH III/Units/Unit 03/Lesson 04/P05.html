P05 Guided Practice

Answer each question using the paired arguments. The same questions are in the Guided Practice GIFT file.

Guided Practice Arguments

Argument A: The city should plant trees along the main road because shade will make walking safer during hot months.

Argument B: The city should build covered bus shelters first because many residents wait outside in heat and rain every day.

Questions

  1. What shared topic do the arguments address?
  2. What is Argument A's claim?
  3. What is Argument B's reasoning?
  4. Which argument is more focused on immediate daily need?
  5. Which evaluation is strongest?
