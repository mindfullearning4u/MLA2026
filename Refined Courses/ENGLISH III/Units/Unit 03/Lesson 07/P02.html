P02 Notebook Task - Part 1

Set up your notebook for integrated rhetorical analysis.

Notebook Title

Integrated Classical Argument and Rhetoric Analysis

Vocabulary

  • Integrated analysis: An explanation that connects several parts of a text instead of treating each part separately.
  • Central idea: The main idea developed across the passage.
  • Structure: The way ideas are organized.
  • Rhetorical choice: A deliberate language move used to affect an audience.
  • Effectiveness: How well a choice supports the author's purpose.

Direct Teaching

Integrated analysis answers more than one question at the same time. It does not say, "The author uses repetition." It says, "The author repeats the command to act now, which strengthens the central idea that delay is dangerous."

Use this order: identify the central idea, locate the rhetorical choice, explain the audience effect, and connect the effect to the argument.

A strong sentence often uses this pattern: The author uses ____ to ____, which strengthens the argument that ____.

Notebook Setup

Create a five-part analysis organizer:

  1. Central idea
  2. Structure or feature
  3. Claim or reasoning
  4. Rhetorical choice
  5. Effect and evaluation

Step-by-Step Teaching Support

Lesson focus: Integrated Classical text, argument, and rhetoric analysis

Mapped standard focus: MLA.ENG3.R.12

Use this sequence before you complete the notebook task. It makes the Grade 11 thinking process explicit so you do not have to guess what the skill requires.

  1. Identify the speaker or writer, audience, purpose, and occasion before judging the argument or rhetoric. These details shape what the choices are meant to do.
  2. Separate claim, evidence, reasoning, and rhetorical technique. A strong analysis names the move and explains how it affects the audience.
  3. Evaluate effectiveness, not just presence. Ask whether the structure, appeal, diction, repetition, or contrast actually helps the author achieve the purpose.
  4. Use precise academic language such as claim, validity, reasoning, appeal, effect, audience, and purpose so your analysis sounds mature and defensible.
