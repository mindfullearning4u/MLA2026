Set up your notebook for integrated rhetorical analysis.

Notebook Title

Integrated Classical Argument and Rhetoric Analysis

Vocabulary

  • Integrated analysis: An explanation that connects several parts of a text instead of treating each part separately.
  • Central idea: The main idea developed across the passage.
  • Structure: The way ideas are organized.
  • Rhetorical choice: A deliberate language move used to affect an audience.
  • Effectiveness: How well a choice supports the author's purpose.

Direct Teaching

Integrated analysis answers more than one question at the same time. It does not say, "The author uses repetition." It says, "The author repeats the command to act now, which strengthens the central idea that delay is dangerous."

Use this order: identify the central idea, locate the rhetorical choice, explain the audience effect, and connect the effect to the argument.

A strong sentence often uses this pattern: The author uses ____ to ____, which strengthens the argument that ____.

Notebook Setup

Create a five-part analysis organizer:

  1. Central idea
  2. Structure or feature
  3. Claim or reasoning
  4. Rhetorical choice
  5. Effect and evaluation

Learner Support Path

Remedial support: reread the vocabulary, work with one sentence or passage detail at a time, and use the model before answering independently.

Standard path: complete the full task, cite or name the evidence, and explain how it proves your answer.

Accelerated path: add a second example, compare two interpretations, or explain why a weaker response does not meet mastery.

Step-by-Step Learning Path

  1. Step 1: Review the vocabulary and identify the skill being practiced.
  2. Step 2: Read the model or passage carefully before answering.
  3. Step 3: Find the exact evidence, word, sentence, or structural choice that supports your answer.
  4. Step 4: Explain how that evidence connects to meaning, effect, or purpose.
  5. Step 5: Check the mastery criteria before submitting.

Remedial support: work one step at a time. Standard path: complete the whole task with evidence and explanation. Accelerated path: compare alternatives or add a second evidence-based explanation.
