P03 Notebook Task Part 2

Apply the comparison chart to two contemporaneous authors.

Context

Both passages are written by fictional authors during a period when new machines are changing farm work.

Author A

The new threshing machine should not frighten us. A tool that finishes the day's work before sunset gives families back an hour of light. If we use the machine wisely, it can reduce exhaustion and let workers learn other trades.

Author B

The new threshing machine arrives with promises, but promises do not feed families. When one machine replaces six workers, the saved hour belongs to the owner, not to the people sent home. A tool that removes wages must be judged by more than speed.

Notebook Task

Use your chart from P02. Then answer these prompts:

  1. What shared topic do both authors address?
  2. Paraphrase Author A's main idea.
  3. Paraphrase Author B's main idea.
  4. How does Author A reason about the machine?
  5. How does Author B reason about the machine?
  6. How does the shared time-period context help explain both passages?

Common Mistake

Incorrect: Both authors write about a machine, so they have the same argument.

Why it is weak: Shared topic is not the same as shared reasoning.

Correct: Both authors address farm machinery, but Author A emphasizes reduced exhaustion while Author B emphasizes lost wages.

Why it works: It compares their reasoning instead of only naming the topic.
