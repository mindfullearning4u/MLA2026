P05 Guided Practice

Answer each question using the narrative situation below. The same questions are in the Guided Practice GIFT file.

Narrative Situation

A family restaurant is closing after thirty years. One character, Nia, grew up there and sees the closing as a loss. Another character, Tomas, will open a community kitchen in the same space and sees the change as a new beginning.

Questions

  1. Which detail would best reveal Nia's perspective?
  2. Which detail would best reveal Tomas's perspective?
  3. Which structure would most clearly show both perspectives?
  4. Which sentence uses figurative language to show Nia's view?
  5. Which revision improves clarity in a multiple-perspective narrative?

Learning Support

Choose answers that show perspective through specific details, clear structure, and purposeful contrast.
