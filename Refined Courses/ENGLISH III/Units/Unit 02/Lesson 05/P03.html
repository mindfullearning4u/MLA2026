Direct Teaching: From Image to Allegorical Pattern

Figurative Language in Context

A metaphor is not a code word with one automatic meaning. Interpret it by examining the comparison, connotations, surrounding conflict, repetition, and effect on tone or theme.

Step-by-Step Process

  1. Establish the literal situation.
  2. Identify nonliteral language or recurring concrete elements.
  3. Name the comparison or association.
  4. List supported connotations, avoiding unrelated possibilities.
  5. Trace repetition and development across the text.
  6. Test whether multiple elements form a coherent second level.
  7. Account for details that complicate the interpretation.
  8. Write a claim connecting pattern, evidence, and larger meaning.

Symbol or Allegory?

A locked gate may symbolize exclusion. A complete narrative in which citizens receive keys according to status, guard them, trade them, and eventually discover the walls have no doors may operate allegorically because many coordinated elements develop a sustained commentary on power.

Common Mistakes

  • Declaring that every object symbolizes something.
  • Forcing a rigid one-to-one code.
  • Ignoring the literal story.
  • Choosing a broad message unsupported by the pattern.
  • Treating ambiguity as an error rather than a possible effect.
