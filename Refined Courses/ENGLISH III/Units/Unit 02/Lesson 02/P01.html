Lesson 2: Universal Themes Across Times and Places

Standards Covered

Primary Standard: MLA.ENG3.R.02 - Track and Analyze Universal Themes.

Support Standards: MLA.ENG3.R.01 - Evaluate Literary Elements; MLA.ENG3.R.10 - Paraphrase Grade-Level Texts; MLA.ENG3.V.01 - Integrate Academic Vocabulary.

What You Will Learn

  • How to identify a universal theme in a literary text.
  • How to track the same theme across different times and places.
  • How literary elements help develop a theme.
  • How to explain theme using evidence and academic vocabulary.

Why This Matters

Universal themes help readers see how texts from different cultures, eras, and settings can explore similar human concerns.

This lesson helps you compare meaning without assuming that every text says the exact same thing.

What You Will Do

  • Read short literary passages from different settings.
  • Identify shared themes such as resilience, responsibility, belonging, courage, or memory.
  • Track how each passage develops the theme differently.
  • Write a short comparison using evidence.

How You Will Show Mastery

You will show mastery by explaining how two texts from different times or places develop a shared universal theme.

Student-Friendly Standard Connection

This standard asks you to notice big human ideas that appear across literature and explain how each text develops those ideas in its own way.

Ask TOR for Help

Ask TOR for help if you can identify what happens in both passages but are not sure how to state the shared theme.
