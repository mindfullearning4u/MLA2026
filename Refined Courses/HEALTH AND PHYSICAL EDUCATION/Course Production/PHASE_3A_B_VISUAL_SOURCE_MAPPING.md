# Health & Physical Education Visual and Resource Mapping

Required supports are embedded directly in lesson HTML and Moodle XML when needed. Students must not need to search elsewhere for a visual required to answer a question.

| Support Type | Course Use |
|---|---|
| FITT and activity planning tables | fitness planning, intensity, progression, recovery |
| Heart-rate/intensity charts | effort monitoring and safe activity decisions |
| Nutrition labels | food-choice evidence and comparison |
| Safety decision pathways | injury prevention, weather safety, emergency choices |
| Wellness maps | stress, sleep, communication, and support strategies |
| Portfolio organizers | goals, evidence, revisions, reflections |

External simulations are not required by default for Health & Physical Education. External health resources may be suggested only when directly aligned, student-safe, and non-conflicting with course standards.
