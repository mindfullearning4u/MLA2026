# Course Audit Folder Standard

## Required Course Folder Structure

Every course folder must use this sibling-folder structure:

| Folder | Required Use |
|---|---|
| `Course Production` | Architecture, mapping, course overview, production planning, lesson production artifacts when authorized. |
| `Course Audit` | Audit reports, validation reports, certification checks, workload analyses, and approval/certification audit records. |

## Audit Placement Rule

All course audit documents must be stored in:

`Refined Courses/[COURSE NAME]/Course Audit`

Audit documents must not be stored in `Course Production` unless they are temporary working drafts awaiting relocation during the same task.

## Applies To

This standard applies to:

- English II
- English III
- All future course architecture packages
- All future course production packages

## Production Boundary

This standard does not create lessons, assessments, HTML files, GIFT files, quiz JSON files, lesson JSON files, or student-facing instructional content.
