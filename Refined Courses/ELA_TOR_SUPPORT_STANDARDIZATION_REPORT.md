# ELA TOR Support Standardization Report

## Executive Summary

The ELA Department TOR support implementation was standardized across all reviewed lesson pages. The previous long TOR support box was replaced with the approved compact MLA TOR Support Box. Lesson-specific help callouts were preserved because they provide page-specific instructional support and are not the standardized TOR support box.

Final result: PASS.

## Approved MLA TOR Support Box

The standardized TOR box now uses the approved concise wording:

**🧑‍🏫 Need Help?**

Contact your Teacher of Record (TOR)  
if you need clarification,  
feedback, or support.

Ask for help as soon as you need it.

## Visual Standard Applied

The standardized box uses:

- Compact spacing
- Blue accent border
- Distinct support-box styling
- Same layout across all reviewed ELA pages
- Placement near the bottom of the page
- One standardized TOR Support Box per page
