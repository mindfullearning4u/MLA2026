P04 Concept Development / Worked Examples

Key Concept

Triangle angle problems rely on evidence from the diagram and theorem-based equations: interior angles sum to 180°, and an exterior angle equals the sum of the two remote interior angles.

Worked Example 1

Problem: A triangle has angles 52° and 61°. Find the third angle.

Equation: 52 + 61 + x = 180

Solution: x = 67°.

Worked Example 2

Problem: An exterior angle is 124°. One remote interior angle is 57°. Find the other remote interior angle.

Equation: 57 + x = 124

Solution: x = 67°.

Error Check

Incorrect:

An exterior angle equals the adjacent interior angle.

Correct:

An exterior angle equals the sum of the two remote interior angles.
