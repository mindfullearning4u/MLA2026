Lesson: Circle Constructions

Instructions

Complete Parts A, B, and C in your notebook. Show labels, diagrams, formulas, proof reasons, and units where they apply. This work becomes part of your Notebook Evidence submission.

Part A: Identify the Object

  1. Draw or copy a clear version of the construction diagram with compass arcs, endpoints, and intersection points for Circle Constructions.
  2. Label all given information and write one sentence explaining what the task is asking.

Part B: Work the Skill

  1. Create one lesson-level problem using the same type of object.
  2. Solve it step by step, writing why each step is allowed.
  3. Check notation, units, and conclusion language.

Part C: Explain the Reasoning

  1. Write a short explanation connecting your solution to MLA.GEO.CIR.1, MLA.GEO.CIR.2, MLA.GEO.CIR.3.
  2. Name one mistake a student might make and explain how to avoid it.

Independent Work Success Criteria

Independent work is where you prove mastery, not where you rush. For Circle Constructions, every response must match the mapped lesson target for MLA.GEO.CIR.1, MLA.GEO.CIR.2, MLA.GEO.CIR.3. Use your notebook notes, worked examples, diagrams, constructions, graphs, and tables from the lesson before asking for another attempt.

Part A expectation: show the core skill step by step and label the geometric evidence. Part B expectation: explain the reason behind the step, especially when a diagram, proof, transformation, similarity ratio, trigonometric relationship, circle theorem, coordinate formula, area, volume, or model is involved. Part C expectation: identify the misconception, correct the work, and explain how the correction changes the conclusion.

Before submitting: check that each answer includes units or context when needed, that diagram questions refer to the visual evidence, and that no answer is based on guessing from the appearance of a figure. If you cannot explain the method, return to P02-P04 before submitting.
