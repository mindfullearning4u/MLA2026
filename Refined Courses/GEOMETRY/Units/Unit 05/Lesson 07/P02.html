P02 Notebook Task – Part 1

Notebook Title

Circle Applications

Vocabulary

  • Application: using a learned relationship in a new context.
  • Model: a diagram or equation representing a situation.
  • Justification: a reason that supports a conclusion.
  • Precision: using correct units, notation, and relationships.

Notebook Task

  • Create a two-column organizer for Unit 5 relationships and when to use them.
  • Write one example where a diagram asks for a length, angle, construction, and area.
  • Explain how you know which relationship applies.

Common Mistake to Avoid

Incorrect:

Identify what is being asked, then choose the circle relationship that matches the diagram.

Correct:

The guided practice checks mixed Unit 5 application decisions and calculations.
