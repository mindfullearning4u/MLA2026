P04 Concept Development / Worked Examples

Key Concept

Circle segment problems use specific product relationships. For example, tangent-secant problems use t2 = (external segment)(whole secant), while intersecting chords use product = product.

Worked Example 1

Example: If a tangent has length t and a secant has external segment 4 and whole length 16, then t2 = 4(16) = 64, so t = 8.

Worked Example 2

Example: For a secant, multiply the external segment by only the inside part.

Error Check

Incorrect:

For a secant, multiply the external segment by the whole secant length.

Correct:

The guided practice checks tangent-secant equations, secant-secant equations, intersecting chord products, and tangent-radius right triangles.
