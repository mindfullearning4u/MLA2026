P01 Lesson Overview

Lesson Title

Right-Triangle Applications

Standards Covered in This Lesson

  • MLA.GEO.TRI.5: I can solve right-triangle problems using trigonometric ratios and the Pythagorean Theorem.

What You Will Learn

  • Solve right-triangle problems using the Pythagorean Theorem.
  • Set up trigonometric ratios in application contexts.
  • Interpret right-triangle diagrams with units and labels.

What You Will Do

  • Analyze diagrams and label the useful relationships.
  • Choose equations, ratios, or similarity relationships that match the evidence.
  • Write short explanations that connect calculations to geometric conclusions.

How You Will Show Mastery

  • Complete notebook evidence.
  • Submit the checkpoint response.
  • Complete Guided Practice and the lesson quiz.

Student-Friendly Standard Connection

This lesson connects similarity, right-triangle structure, and trigonometric reasoning in Unit 4.
