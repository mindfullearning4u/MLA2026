P04 Concept Development / Worked Examples

Key Concept

A similarity transformation can include rigid motions and a dilation. Rigid motions preserve size and shape, while dilations change size but preserve shape.

Worked Example 1

Example: A triangle is dilated by scale factor 3 and then translated. The image is similar to the preimage because dilation preserves shape and the translation is a rigid motion.

Worked Example 2

Symmetry example: A figure with a line that creates matching mirror halves has reflection symmetry because reflection maps the figure onto itself.

Error Check

Incorrect:

A dilation with scale factor 2 proves congruence.

Correct:

A dilation with scale factor 2 changes size, so it can support similarity but not congruence.
