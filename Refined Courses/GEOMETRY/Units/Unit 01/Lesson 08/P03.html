Notebook Focus: Reasoning and Proof

Review the reasoning tools from Unit 1.

  • Conditional: If p, then q.
  • Converse: If q, then p.
  • Inverse: If not p, then not q.
  • Contrapositive: If not q, then not p.
  • Counterexample: One example that disproves a false statement.

Connect the Ideas

Use line and angle relationships as reasons in short proof explanations.

  • Vertical angles are congruent.
  • Angles that form a linear pair are supplementary.
  • Supplementary angles have measures that add to 180Â°.

Common Misconception

Incorrect:

One example proves the statement is always true.

Correct:

One example may support a conjecture, but a universal claim needs proof; one counterexample can disprove it.
