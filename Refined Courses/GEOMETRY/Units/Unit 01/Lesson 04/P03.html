Copying an Angle

Goal: Construct an angle congruent to ∠ABC.

  1. Draw a new ray with endpoint D.
  2. Place the compass point on B and draw an arc that crosses both sides of ∠ABC.
  3. Using the same compass opening, draw a matching arc from endpoint D on the new ray.
  4. Set the compass opening to the distance between the two arc intersections on the original angle.
  5. Transfer that distance onto the new arc and draw the second ray through the new intersection point.

m∠EDF = m∠ABC

Reasoning: The arcs transfer the opening of the original angle to the new angle.

How to Check a Construction

A construction copy should match the original because a distance or angle opening was transferred with tools.

  • Segment copy: The copied segment has the same length as the original segment.
  • Angle copy: The copied angle has the same measure as the original angle.
  • Tool evidence: Fixed compass openings and matching arcs support the copy.

Construction Reflection Categories

  • Accurate: I used the correct compass opening and kept the tool setting fixed while transferring.
  • Needs Revision: I used the correct idea but changed the compass opening or missed an arc.
  • Unsupported: I estimated by sight instead of using construction tools.

Common Mistake to Avoid

Do not copy an angle by guessing where the second ray should go.

Incorrect:

Draw the second ray where the angle looks about the same size.

Correct:

Use arcs and compass distances to place the second ray accurately.

Why: A construction uses tool evidence instead of appearance.
