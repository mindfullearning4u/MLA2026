Standards Practiced

Standards Practiced: MLA.GEO.FND.1

Question 1

Which tool is used to transfer the length of a segment?

Answer: Compass

Feedback: A compass holds a fixed opening so a distance can be transferred accurately.

Question 2

After opening the compass to the length of segment AB, what should happen before marking the copy?

Answer: Keep the compass opening fixed.

Feedback: Keeping the compass opening fixed preserves the original segment length.

Question 3

When copying an angle, why are arcs drawn from the original angle and the new vertex?

Answer: They help transfer the original angle opening.

Feedback: Matching arcs and compass distances place the second ray so the copied angle matches the original.

Question 4

Which statement shows a correct segment-copy result?

Answer: CD = AB

Feedback: If segment CD is copied from segment AB, the lengths should be equal.

Question 5

Which mistake would make an angle copy unreliable?

Answer: Placing the second ray by sight instead of using arc intersections

Feedback: An angle copy should be based on arcs and compass distances, not estimation by appearance.
