Notebook Focus: Related Conditionals

Start with a conditional statement:

If p, then q.

  • Converse: If q, then p.
  • Inverse: If not p, then not q.
  • Contrapositive: If not q, then not p.

Example

Conditional: If two angles are vertical angles, then they are congruent.

Converse: If two angles are congruent, then they are vertical angles.

Inverse: If two angles are not vertical angles, then they are not congruent.

Contrapositive: If two angles are not congruent, then they are not vertical angles.

Biconditional Statements

A biconditional statement uses if and only if.

p if and only if q

This combines two directions: if p, then q and if q, then p.

Common Misconception

Do not confuse the inverse with the contrapositive.

Incorrect:

Contrapositive: If not p, then not q.

Correct:

Contrapositive: If not q, then not p.
