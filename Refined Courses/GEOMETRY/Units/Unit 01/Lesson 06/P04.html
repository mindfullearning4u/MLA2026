P04 Concept Development / Worked Examples

Teacher Guided

Example 1: Identify p and q

Statement: If a polygon has three sides, then it is a triangle.

p: A polygon has three sides.

q: It is a triangle.

Reasoning: The hypothesis follows if, and the conclusion follows then.

Example 2: Write Related Statements

Conditional: If a figure is a rectangle, then it has four right angles.

Converse: If a figure has four right angles, then it is a rectangle.

Inverse: If a figure is not a rectangle, then it does not have four right angles.

Contrapositive: If a figure does not have four right angles, then it is not a rectangle.

Example 3: Interpret a Biconditional

Statement: A figure is a triangle if and only if it is a polygon with three sides.

Direction 1: If a figure is a triangle, then it is a polygon with three sides.

Direction 2: If a figure is a polygon with three sides, then it is a triangle.

Example 4: Explain a Correction

A student writes the converse by adding not to both parts.

Incorrect:

Converse: If not p, then not q.

Why it is incomplete: Adding not to both parts creates the inverse, not the converse.

Correct:

Converse: If q, then p.

Error Check

A common mistake is reversing and negating the wrong statement form.

Incorrect:

Inverse: If not q, then not p.

Why it is incomplete: This is the contrapositive because it reverses and negates the original parts.

Correct:

Inverse: If not p, then not q.
