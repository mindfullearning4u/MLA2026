P05 Guided Practice

This practice is not graded. Try each question, then check the feedback to understand the reasoning.

Question 1

Which statement is a conjecture?

Answer: I think these segments are congruent because they have matching tick marks.

Feedback: A conjecture is a claim based on observations that should be supported with evidence.

Question 2

A student claims two angles are congruent. Which evidence supports the claim?

Answer: The angles have matching arc marks.

Feedback: Matching arc marks are relevant evidence that angles are congruent.

Question 3

Which argument is flawed?

Answer: The lines are parallel because they look parallel.

Feedback: The argument is flawed because appearance alone is not enough evidence for parallel lines.

Question 4

What does a valid mathematical argument need?

Answer: A claim, relevant evidence, and reasoning that connects them

Feedback: A valid argument explains why evidence supports a claim.

Question 5

A student says a conjecture is true because one example worked. What is the best correction?

Answer: One example can suggest a conjecture, but more support is needed.

Feedback: A conjecture needs enough evidence or reasoning before it is accepted as a supported conclusion.
