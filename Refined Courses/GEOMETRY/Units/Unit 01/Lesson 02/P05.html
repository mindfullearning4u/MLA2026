P05 Guided Practice

This practice is not graded. Try each question, then check the feedback to understand the reasoning.

Question 1

A figure is a straight path with arrows on both ends. Which description is most precise?

Answer: A line

Feedback: A line is a straight path that extends forever in both directions, which is shown by arrows on both ends.

Question 2

A figure has endpoints A and B. Which description matches the definition?

Answer: Segment AB

Feedback: A segment has two endpoints, so a figure with endpoints A and B is segment AB.

Question 3

Which statement is most precise?

Answer: Rays BA and BC form angle ABC.

Feedback: This statement names the rays and the angle, so it is more precise than saying there is a corner.

Question 4

A student says a figure is a ray because it looks short. What is the best correction?

Answer: Use endpoints and arrows, not appearance, to identify the object.

Feedback: A ray is defined by one endpoint and extension in one direction. How long the drawing looks is not proof.

Question 5

Which phrase best describes evidence in a Geometry explanation?

Answer: Information that supports a conclusion

Feedback: Evidence is the information used to support a conclusion, such as a definition, label, marking, or given statement.
