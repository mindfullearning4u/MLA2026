P04 Concept Development / Worked Examples

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Example 1: Identify the Object by Definition

Problem: A figure has endpoints C and D. Which geometric object is described?

Step 1: Identify the defining feature. The figure has two endpoints.

Step 2: Match the definition. A segment is a part of a line with two endpoints.

segment CD

Answer: The figure is segment CD.

Reasoning: The description matches the definition of a segment.

Example 2: Name a Vertex Precisely

Problem: Rays BA and BC share endpoint B.

Step 1: Identify the shared endpoint.

B

Step 2: Use precise language.

Answer: B is the vertex of angle ABC.

Reasoning: An angle is formed by two rays with a common endpoint, and the common endpoint is the vertex.

Example 3: Explain a Correction

Problem: A student describes a line as "a segment that keeps going forever."

Incorrect:

A line is a segment that keeps going forever.

Why it is wrong: A segment has two endpoints, but a line does not have endpoints.

Correct:

A line is a straight path that extends forever in both directions.

Reasoning: The corrected definition uses the defining features of a line.

Common Mistake

A common readiness mistake is using a vague description when a precise Geometry description is needed.

Problem: A diagram shows rays DE and DF forming an angle.

Incorrect:

There is a corner at D.

Why it is incomplete: The word "corner" is informal and does not name the geometric object.

Correct:

Rays DE and DF form angle EDF with vertex D.
