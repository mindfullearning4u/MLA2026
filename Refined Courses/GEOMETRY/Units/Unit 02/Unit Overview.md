# GEOMETRY - Unit 02 Overview: Reasoning, Proof, and Basic Transformations

This unit follows the approved Geometry Unit 2 mapping. Students build logical reasoning, conditional-statement fluency, counterexample reasoning, introductory proof structure, segment and angle proof skills, basic transformation rules, distance-preservation reasoning, and rigid-motion congruence justification.
