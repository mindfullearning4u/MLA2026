Notebook Focus: Reflection and Rotation Rules

Reflection and rotation rules are exact coordinate descriptions. Each rule explains where every point in the preimage moves.

When you use a rule, keep the order of the coordinates clear. Switching x and y is different from changing signs.

Reflection Rules

  • Reflect across the x-axis: (x, y) -> (x, -y)
  • Reflect across the y-axis: (x, y) -> (-x, y)
  • Reflect across the origin: (x, y) -> (-x, -y)

Rotation Rules About the Origin

  • Rotate 90 degrees counterclockwise: (x, y) -> (-y, x)
  • Rotate 180 degrees: (x, y) -> (-x, -y)
  • Rotate 90 degrees clockwise: (x, y) -> (y, -x)

How to Choose the Correct Rule

  1. Ask whether the point slides, flips, or turns.
  2. Check whether coordinate signs change.
  3. Check whether x and y switch places.
  4. Use one point to verify the rule before applying it to the whole figure.

Common Mistake to Avoid

Incorrect:

Reflecting across the y-axis changes the y-coordinate sign.

Correct:

Reflecting across the y-axis changes the x-coordinate sign.

Why: Points mirror left and right across the y-axis, so x changes sign while y stays the same.
