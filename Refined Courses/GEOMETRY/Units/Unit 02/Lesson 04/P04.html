P04 Concept Development / Worked Examples

Example 1: Draw a Translation Image

A(-1, 2), B(2, 2), C(0, 4) translated by (x, y) → (x + 4, y - 1) gives A'(3, 1), B'(6, 1), C'(4, 3).

Example 2: Draw a Reflection Image

Reflect P(3, -2), Q(5, -2), and R(3, -4) across the y-axis to get P'(-3, -2), Q'(-5, -2), R'(-3, -4).

Example 3: Draw a Rotation Image

Rotate A(2, 1), B(4, 1), and C(2, 3) 90° counterclockwise using (x, y) → (-y, x) to get A'(-1, 2), B'(-1, 4), C'(-3, 2).

Example 4: Draw a Sequence Image

A(1, 1) reflected across the x-axis gives A'(1, -1). Translating 2 units left gives A''(-1, -1).

Error Check

Incorrect:

A'' is (-1, 1).

Correct:

A'' is (-1, -1).
