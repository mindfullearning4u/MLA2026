P02 Notebook Task – Part 1

Notebook Title

Drawing Transformation Images

Notebook Focus: Apply Rules to Every Vertex

To draw the image of a polygon, apply the transformation rule to each vertex. Then plot the new vertices and connect them in the same order.

Vocabulary

  • Vertex: a corner point of a figure.
  • Image: the result after a transformation.
  • Prime notation: labels such as A' and A'' that show transformation steps.
  • Coordinate rule: an algebraic rule that describes how coordinates change.

Example

Translate A(2, 1), B(4, 1), and C(2, 3) by (x, y) → (x + 3, y - 2).

A'(5, -1), B'(7, -1), C'(5, 1)

Common Mistake to Avoid

Incorrect:

Only transform one point.

Correct:

Transform every vertex of the figure.
