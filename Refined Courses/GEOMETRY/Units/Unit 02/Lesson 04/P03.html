P03 Notebook Task – Part 2

Notebook Title

Drawing Images After More Than One Transformation

Notebook Focus: Use Intermediate Images

When a sequence has two transformations, first find the intermediate image. Then use the intermediate image as the starting point for the next transformation.

Sequence Tracking Table

Use columns such as original point, after step 1, and after step 2. This keeps the order clear and reduces graphing errors.

Example

A(1, 2) is reflected across the x-axis and then translated 3 units right.

Step 1: A'(1, -2)

Step 2: A''(4, -2)

Common Mistake to Avoid

Incorrect:

Use the original point again for the second transformation.

Correct:

Use the image from step 1 as the input for step 2.
