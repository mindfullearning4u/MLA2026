P04 Concept Development / Worked Examples

Study each example carefully. Distance preservation is determined by comparing corresponding distances.

Example 1: Translation

Problem: Segment AB has length 7. A translation maps it to A'B'. Does the transformation preserve distance?

Reasoning: A translation slides every point the same distance and direction.

AB = A'B' = 7

Answer: Yes. A translation preserves distance.

Example 2: Dilation

Problem: Segment CD has length 4. A dilation with scale factor 2 maps it to C'D'. Does the transformation preserve distance?

Step: Multiply the original length by the scale factor.

C'D' = 2(4) = 8

Answer: No. The distance changed from 4 to 8.

Common Mistake

Incorrect:

A reflection does not preserve distance because the figure faces the other way.

Correct:

A reflection preserves distance because corresponding lengths stay equal.
