Long Division Structure

Polynomial long division follows the same idea as numerical long division: divide, multiply, subtract, bring down, and repeat.

Always write missing powers with a coefficient of 0 so the columns stay aligned.

Division Identity

If a polynomial is divided by d(x), then the result can be written as:

p(x) = d(x)q(x) + r

The quotient is q(x), and the remainder is r.

Correct Example

Divide: (x3 + 2x2 - 5x - 6) ÷ (x + 1)

The quotient is x2 + x - 6.

Check: (x + 1)(x2 + x - 6) = x3 + 2x2 - 5x - 6.

Correct: The remainder is 0.

Incorrect Example

Divide: (x3 + 0x2 - 4) ÷ (x - 2)

A student skips the missing x2 term and divides x3 - 4 by x - 2.

Incorrect: Missing powers must be included with coefficient 0, or the quotient and remainder can be placed in the wrong columns.

Notebook Task

  1. Copy the division identity p(x) = d(x)q(x) + r.
  2. Divide x3 + 4x2 + x - 6 by x + 2.
  3. Write the result as quotient plus remainder over divisor.
