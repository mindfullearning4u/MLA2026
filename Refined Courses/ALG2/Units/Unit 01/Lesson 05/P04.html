P04 Concept Development and Worked Examples

Synthetic Division

Synthetic division is a shortcut for dividing by a linear expression in the form x - c. Use the value c, not the full divisor.

Worked Example 1

Divide: (x3 - 4x2 + x + 6) ÷ (x - 2)

Use 2 for synthetic division with coefficients 1, -4, 1, 6.

The result gives quotient coefficients 1, -2, -3 and remainder 0.

Quotient: x2 - 2x - 3

Correct: The result is x2 - 2x - 3, and x - 2 is a factor.

Worked Example 2

Divide: (2x3 + 3x2 - 5x + 4) ÷ (x + 2)

Use -2 for synthetic division with coefficients 2, 3, -5, 4.

The quotient is 2x2 - x - 3, and the remainder is 10.

Write the result as 2x2 - x - 3 + 10/(x + 2).

Correct: A nonzero remainder means x + 2 is not a factor.

Common Error

For division by x + 2, a student uses 2 in synthetic division.

Incorrect: x + 2 is x - (-2), so the synthetic value must be -2.

Connection to Factors

If dividing by x - c gives a remainder of 0, then x - c is a factor of the polynomial.
