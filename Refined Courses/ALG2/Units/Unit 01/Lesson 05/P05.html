Question 1

Question ID:
ALG2_U01_L05_GP01

MLA Standard:
MLA.A2.AE.3

Divide (x2 + 5x + 6) ÷ (x + 2).

Answer: x + 3

Feedback: x2 + 5x + 6 factors as (x + 2)(x + 3), so the quotient is x + 3.

Question 2

Question ID:
ALG2_U01_L05_GP02

MLA Standard:
MLA.A2.AE.3

Divide (x3 - 4x2 + x + 6) ÷ (x - 2).

Answer: x2 - 2x - 3

Feedback: Synthetic division with 2 gives quotient coefficients 1, -2, -3 and remainder 0.

Question 3

Question ID:
ALG2_U01_L05_GP03

MLA Standard:
MLA.A2.AE.3

When dividing by x + 4 using synthetic division, what value should be used?

Answer: -4

Feedback: x + 4 is the same as x - (-4), so the synthetic value is -4.

Question 4

Question ID:
ALG2_U01_L05_GP04

MLA Standard:
MLA.A2.AE.3

Divide (2x3 + 3x2 - 5x + 4) ÷ (x + 2).

Answer: 2x2 - x - 3 + 10/(x + 2)

Feedback: Synthetic division with -2 gives quotient 2x2 - x - 3 and remainder 10.

Question 5

Question ID:
ALG2_U01_L05_GP05

MLA Standard:
MLA.A2.AE.3

A polynomial is divided by x - 3 and the remainder is 0. What can you conclude?

Answer: x - 3 is a factor

Feedback: A zero remainder means the divisor divides the polynomial evenly, so it is a factor.
