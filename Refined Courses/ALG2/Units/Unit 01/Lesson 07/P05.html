Question 1

Question ID:
ALG2_U01_L07_GP01

MLA Standard:
MLA.A2.AE.4; MLA.A2.PF.7

A rectangle has width x and length x + 5. Its area is 84. Which equation models the situation?

Answer: x(x + 5) = 84

Feedback: Area is length times width, so x(x + 5) = 84.

Question 2

Question ID:
ALG2_U01_L07_GP02

MLA Standard:
MLA.A2.AE.4; MLA.A2.PF.7

Solve x(x + 5) = 84 and choose the reasonable rectangle width.

Answer: 7

Feedback: The equation becomes x squared plus 5x minus 84 equals 0, so x = 7 or x = -12. The positive width is 7.

Question 3

Question ID:
ALG2_U01_L07_GP03

MLA Standard:
MLA.A2.AE.4; MLA.A2.PF.7

The height model h(t) = -16t2 + 64t equals 0 at t = 0 and t = 4. What does t = 4 represent?

Answer: The object returns to the ground after 4 seconds.

Feedback: h(t) = 0 means height is zero. The later time is when the object returns to the ground.

Question 4

Question ID:
ALG2_U01_L07_GP04

MLA Standard:
MLA.A2.AE.4; MLA.A2.PF.7

A volume model is V(x) = x3 + 2x2 - 8x. Which positive solution makes V(x) = 0?

Answer: x = 2

Feedback: Factoring gives x(x + 4)(x - 2) = 0. The positive solution is x = 2.
