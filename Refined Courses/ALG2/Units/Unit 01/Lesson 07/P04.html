P04 Worked Examples

Work through each example slowly. The goal is not only to get an answer, but to understand why each step is valid and how the idea connects to the lesson standard.

Step-by-step explanation: Each worked example below models the lesson process one step at a time and explains the reasoning before the final answer.

Worked Example 1: Define a Variable

Problem: A gym charges $20 to join and $15 each month. Write a cost model for m months.

Step 1: Let m represent the number of months.

Step 2: Identify the fixed cost and the repeated monthly cost.

Step 3: Write total cost as fixed cost plus monthly cost.

C = 20 + 15m

Reasoning: A clear variable definition makes the model understandable.

Worked Example 2: Interpret a Solution

Problem: If 20 + 15m = 95, what does m mean?

Step 1: Subtract 20 from both sides.

Step 2: Divide by 15.

Step 3: Connect the value back to months.

m = 5 months

Reasoning: A solution must be interpreted in the context, not left as a number alone.

Worked Example 3: Choose a Reasonable Model

Problem: A rectangle has width x and length x + 4. Write an expression for area.

Step 1: Use area = length · width.

Step 2: Substitute x and x + 4.

Step 3: Multiply if expanded form is useful.

A = x(x + 4) = x2 + 4x

Reasoning: The model comes from the structure of the situation.

Common Mistake

Problem: A plan costs $12 per month plus a $30 fee. Write a model.

Incorrect:

C = 12 + 30m

Why it is wrong: The monthly amount and fixed fee were switched.

Correct:

C = 30 + 12m

Fix: Identify what happens once and what repeats each month.

Teachable Explanation: The correct example works because it uses the lesson process accurately and connects the answer back to the mathematical structure or context.
