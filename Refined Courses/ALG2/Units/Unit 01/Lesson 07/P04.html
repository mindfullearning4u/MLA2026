P04 Concept Development and Worked Examples

Interpreting Results

A correct algebraic solution is not always a reasonable contextual answer. Always connect the solution back to the units and restrictions in the problem.

Worked Example 1

Context: A path is modeled by h(t) = -16t2 + 64t. Find when h(t) = 0.

-16t2 + 64t = 0

-16t(t - 4) = 0

Correct: t = 0 seconds and t = 4 seconds. In context, t = 0 is the starting time, and t = 4 is when the object returns to the ground.

Worked Example 2

Context: A product design has area x2 - 2x - 35 square inches. Find x when the area is 0.

x2 - 2x - 35 = 0

(x - 7)(x + 5) = 0

Correct: x = 7 is reasonable for a positive design measurement. x = -5 is rejected.

Common Error

A student rejects t = 0 in the height model because it is not the final answer.

Incorrect: t = 0 is a valid solution and represents the starting time. The question determines whether both times or only the later time should be reported.

Modeling Check

After solving, ask: What does the variable represent? What units are used? Are negative, zero, or complex solutions meaningful in this situation?
