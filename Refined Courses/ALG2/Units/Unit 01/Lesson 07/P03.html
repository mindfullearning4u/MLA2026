P03 Notebook Task Part 2

Choosing a Tool

A useful model depends on the situation. Some contexts use polynomial operations, some use factoring, and some use higher-degree equations.

Modeling Decision Guide

  1. Identify what quantity is unknown.
  2. Write an equation that matches the relationship in the context.
  3. Choose an algebraic tool that fits the equation.
  4. Interpret the solution and check whether it is reasonable.

Correct Example

Context: The volume of a box is modeled by V(x) = x3 + 2x2 - 8x. Find the positive x-value when V(x) = 0.

x3 + 2x2 - 8x = 0

x(x + 4)(x - 2) = 0

Solution Reasonableness Table

Algebraic solution Can it be a positive box dimension?
x = -4 No
x = 0 No
x = 2 Yes

Correct: The positive contextual solution is x = 2.

Incorrect Example

A student lists x = -4, 0, and 2 as all valid box dimensions.

Incorrect: The algebraic equation has three solutions, but only the positive dimension x = 2 is reasonable for the context.

Notebook Task

  1. Copy the modeling decision guide.
  2. Solve x3 + 2x2 - 8x = 0.
  3. Explain why x = 2 is the only reasonable positive dimension in the box context.

Common Mistake

Incorrect: Reporting every algebraic solution as a reasonable answer in a context.

Correct: Solve the equation, then check whether each solution makes sense for the units and situation.

Teachable Explanation: Modeling requires both algebra and interpretation. A negative length, time, or dimension may solve an equation but fail the real-world context.
