Part A: Modeling Practice

  1. Write an equation for a rectangle with width x, length x + 6, and area 91.
  2. Solve the equation from problem 1 and identify the reasonable width.
  3. For h(t) = -16t2 + 80t, solve h(t) = 0 and interpret both solutions.
  4. For V(x) = x3 - 9x, solve V(x) = 0 and identify any positive solution.

Part B: Interpretation and Reasoning

  1. A model has algebraic solutions x = -8 and x = 3. Explain when x = -8 should be rejected.
  2. A quadratic model has no real solutions. Explain what that could mean in a context requiring real measurements.
  3. Describe one situation where t = 0 is a meaningful solution.
  4. Explain how choosing the correct algebraic tool can make a modeling problem easier to solve.
