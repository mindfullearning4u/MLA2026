Modeling Vocabulary

  • Variable: A symbol that represents an unknown or changing quantity.
  • Model: An equation or expression that represents a situation.
  • Constraint: A condition that limits possible values.
  • Interpretation: Explaining what a solution means in context.

Correct Example

Context: A rectangular garden has width x and length x + 5. Its area is 84 square feet.

Model: x(x + 5) = 84

x2 + 5x - 84 = 0, so (x + 12)(x - 7) = 0

Correct: x = 7 is reasonable, so the width is 7 feet and the length is 12 feet.

Incorrect Example

A student gives x = -12 as the garden width because it solves the equation.

Incorrect: A negative width is not reasonable in this context. The solution x = 7 should be used.

Notebook Task

  1. Write the definitions of variable, model, constraint, and interpretation.
  2. Solve the garden model x(x + 5) = 84 and explain why one solution is rejected.
  3. Write one sentence explaining why context matters after solving an equation.
