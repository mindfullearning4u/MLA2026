Question 1

ALG2_U01_L02_GP_Q01

MLA Standard:
MLA.A2.AE.2; MLA.A2.AE.4

Simplify (3x2 + 2x - 5) + (x2 - 7x + 9).

Answer: 4x2 - 5x + 4

Feedback: Combine like terms: 3x2 + x2 = 4x2, 2x - 7x = -5x, and -5 + 9 = 4.

Simplify (5x2 - 3x + 8) - (2x2 + x - 6).

Answer: 3x2 - 4x + 14

Feedback: Distribute the subtraction sign first: -2x2 - x + 6. Then combine like terms.

MLA.A2.AE.2; MLA.A2.AE.4

Simplify (x + 4)(x - 6).

Answer: x2 - 2x - 24

Feedback: Multiply each term: x2 - 6x + 4x - 24. Combine the middle terms to get -2x.

A rectangle has length x + 3 and width x + 5. What polynomial represents the area?

Answer: x2 + 8x + 15

Feedback: Area is length times width, so multiply (x + 3)(x + 5) to get x2 + 8x + 15.
