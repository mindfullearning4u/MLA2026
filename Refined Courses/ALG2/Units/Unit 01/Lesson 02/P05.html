Question 1

Simplify (3x2 + 2x - 5) + (x2 - 7x + 9).

Answer: 4x2 - 5x + 4

Feedback: Combine like terms: 3x2 + x2 = 4x2, 2x - 7x = -5x, and -5 + 9 = 4.

A rectangle has length x + 3 and width x + 5. What polynomial represents the area?

Answer: x2 + 8x + 15

Feedback: Area is length times width, so multiply (x + 3)(x + 5) to get x2 + 8x + 15.
