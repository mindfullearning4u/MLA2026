P04 Concept Instruction and Worked Examples

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Example 1: Add Polynomials

Problem: Simplify (2x3 - x2 + 5x + 4) + (3x3 + 6x2 - 2x - 9).

Step 1: Group like terms.

(2x3 + 3x3) + (-x2 + 6x2) + (5x - 2x) + (4 - 9)

Step 2: Combine like terms.

5x3 + 5x2 + 3x - 5

Answer: 5x3 + 5x2 + 3x - 5

Example 2: Multiply a Monomial and Polynomial

Problem: Simplify 3x(2x2 - 5x + 4).

Step 1: Distribute 3x to each term.

3x(2x2) - 3x(5x) + 3x(4)

Step 2: Multiply coefficients and add exponents when multiplying powers with the same base.

6x3 - 15x2 + 12x

Answer: 6x3 - 15x2 + 12x

Example 3: Apply Polynomial Multiplication

Problem: A rectangle has length x + 8 and width x + 3. Write a polynomial for its area.

Step 1: Area equals length times width.

A = (x + 8)(x + 3)

Step 2: Multiply.

A = x2 + 3x + 8x + 24 = x2 + 11x + 24

Answer: x2 + 11x + 24

Common Mistake

A common multiplication mistake is multiplying only the first terms and the last terms.

Problem: Multiply (x + 5)(x + 2).

Incorrect:

(x + 5)(x + 2) = x2 + 10

Correct:

(x + 5)(x + 2) = x2 + 2x + 5x + 10 = x2 + 7x + 10

Why: Every term in the first binomial must multiply every term in the second binomial.
