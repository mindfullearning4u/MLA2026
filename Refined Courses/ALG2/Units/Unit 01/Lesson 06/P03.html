P03 Notebook Task Part 2

Using a Known Zero

Sometimes a higher-degree equation is easier to solve after one zero is known. Use polynomial division to reduce the degree, then solve the remaining factor.

Strategy

  1. Use the known zero to identify a linear factor.
  2. Divide the polynomial by that factor.
  3. Solve the lower-degree equation that remains.

Correct Example

Solve: x3 - 4x2 + x + 6 = 0, given that x = 2 is a solution.

Divide by x - 2 to get x2 - 2x - 3.

Factor: x2 - 2x - 3 = (x - 3)(x + 1).

Correct: The solutions are x = -1, 2, and 3.

Incorrect Example

Given x = 2 is a solution, a student lists only x = 2 as the answer.

Incorrect: A cubic equation can have more than one solution. The known solution helps you reduce the polynomial and find the remaining solutions.

Notebook Task

  1. Solve x3 + 2x2 - 5x - 6 = 0, given that x = -1 is a solution.
  2. Show the division step and the factored quadratic.
  3. List all real solutions.
