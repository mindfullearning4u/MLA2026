P04 Worked Examples

Work through each example slowly. The goal is not only to get an answer, but to understand why each step is valid and how the idea connects to the lesson standard.

Worked Example 1: Use the Zero Product Property

Problem: Solve x(x - 4)(x + 2) = 0.

Step 1: Set each factor equal to 0.

Step 2: Solve each simple equation.

Step 3: List all solutions.

x = 0, 4, -2

Reasoning: A product equals 0 when at least one factor equals 0.

Worked Example 2: Factor First

Problem: Solve x3 - 9x = 0.

Step 1: Factor out the GCF x.

Step 2: Factor the difference of squares x2 - 9.

Step 3: Set each factor equal to 0.

x = -3, 0, 3

Reasoning: Factoring reveals the roots of the higher-degree equation.

Worked Example 3: Use Structure

Problem: Solve x4 - 16 = 0.

Step 1: Recognize a difference of squares.

Step 2: Rewrite as (x2 - 4)(x2 + 4) = 0.

Step 3: Find real and complex solutions.

x = -2, 2, 2i, -2i

Reasoning: Higher-degree equations may have real and complex solutions.

Common Mistake

Problem: Solve x(x - 5) = 0.

Incorrect:

x - 5 = 0, so x = 5 only

Why it is wrong: The factor x was ignored.

Correct:

x = 0 or x = 5

Fix: Set every factor equal to 0, not just the longest factor.
