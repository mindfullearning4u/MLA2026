P04 Concept Development and Worked Examples

Real and Complex Solutions

Higher-degree equations can have real solutions, complex solutions, or both. After factoring, set each factor equal to 0 and solve.

Worked Example 1

Solve: x4 - 16 = 0

x4 - 16 = (x2 - 4)(x2 + 4)

(x - 2)(x + 2)(x2 + 4) = 0

Correct: The solutions are x = -2, 2, 2i, and -2i.

Worked Example 2

Solve: x3 + x2 + 4x + 4 = 0

Group: x2(x + 1) + 4(x + 1) = 0

(x + 1)(x2 + 4) = 0

Correct: The solutions are x = -1, 2i, and -2i.

Common Error

A student solves x4 - 16 = 0 and lists only x = -2 and x = 2.

Incorrect: The factor x2 + 4 also gives complex solutions x = 2i and x = -2i.

Technology Connection

Technology can help estimate zeros from a graph, but algebraic work is still needed to confirm exact solutions and identify complex solutions that do not appear as x-intercepts.
