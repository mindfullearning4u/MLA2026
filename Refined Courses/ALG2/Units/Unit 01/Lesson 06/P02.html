Notebook Title

Title your notes: Lesson 6: Higher-Degree Equations.

Write the standard: MLA.A2.PF.7.

Key Vocabulary

  • Higher-degree equation: A polynomial equation with degree greater than 2.
  • Zero: An input value that makes a polynomial equal 0.
  • Root or solution: A value that makes an equation true.
  • Multiplicity: The number of times a factor appears in a polynomial.

Teacher Model: Why Factoring Protects Every Solution

A higher-degree equation often has more than one solution. To keep all possible solutions, first move everything to one side so the equation equals 0.

For x3 - 9x = 0, both terms share a factor of x. Factoring gives x(x2 - 9) = 0, then x(x - 3)(x + 3) = 0.

Now each factor can equal 0, so the solutions are x = 0, x = 3, and x = -3. Dividing by x would hide the solution x = 0.

Correct Example

Solve: x3 - 9x = 0

x(x2 - 9) = 0

x(x - 3)(x + 3) = 0

Correct: The solutions are x = -3, 0, and 3.

Incorrect Example

Solve: x3 - 9x = 0

x2 - 9 = 0

x = -3 and x = 3

Incorrect: Dividing by x removed the solution x = 0. Factoring keeps all possible solutions visible.

Notebook Task

  1. Write the definitions of higher-degree equation, zero, root, and multiplicity.
  2. Solve x3 - 16x = 0 by factoring.
  3. Explain why dividing both sides by x can lose the solution x = 0.

Checkpoint Before Moving On

Before continuing, make sure your notes show that every factor set equal to 0 can produce a solution.
