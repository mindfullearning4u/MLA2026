The Discriminant

For a quadratic equation ax2 + bx + c = 0, the discriminant is b2 - 4ac.

The discriminant tells you the type of solutions before you solve the equation.

Discriminant Guide

  • If b2 - 4ac > 0, the equation has two real solutions.
  • If b2 - 4ac = 0, the equation has one repeated real solution.
  • If b2 - 4ac < 0, the equation has two complex solutions.

Correct Example

Classify the solutions: x2 + 4x + 13 = 0

a = 1, b = 4, c = 13

b2 - 4ac = 42 - 4(1)(13) = 16 - 52 = -36

Correct: The discriminant is negative, so the equation has two complex solutions.

Incorrect Example

Classify the solutions: x2 + 4x + 13 = 0

b2 - 4ac = -36

The equation has no solutions.

Incorrect: A negative discriminant means there are no real solutions, but there are two complex solutions.

Notebook Task

  1. Copy the discriminant guide into your notes.
  2. Find the discriminant for x2 - 6x + 10 = 0 and classify the solutions.
  3. Find the discriminant for 2x2 + 3x + 7 = 0 and classify the solutions.
