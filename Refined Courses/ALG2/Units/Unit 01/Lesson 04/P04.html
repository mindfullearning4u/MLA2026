P04 Concept Development and Worked Examples

Solving with Complex Numbers

When the quadratic formula produces the square root of a negative number, rewrite that part using i.

Quadratic formula: x = (-b ± √(b2 - 4ac)) / 2a

Worked Example 1

Solve: x2 + 16 = 0

x2 = -16

x = ±√-16

x = ±4i

Correct: The solutions are 4i and -4i.

Worked Example 2

Solve: x2 - 6x + 13 = 0

a = 1, b = -6, c = 13

x = (6 ± √((-6)2 - 4(1)(13))) / 2

x = (6 ± √-16) / 2

x = (6 ± 4i) / 2

x = 3 ± 2i

Correct: The solutions are 3 + 2i and 3 - 2i.

Common Error

x = (6 ± √-16) / 2

x = (6 ± -4) / 2

Incorrect: √-16 is not -4. It is 4i, so the solutions are complex.

Why Complex Solutions Come in Pairs

For quadratics with real coefficients, non-real solutions appear as conjugates. If 3 + 2i is a solution, then 3 - 2i is also a solution.
