P04 Concept Review and Worked Examples

Cumulative Review

Unit 1 assessment items may combine several skills. Read each problem carefully, identify the goal, and use the most efficient tool.

Worked Example 1

Divide: (x3 - 4x2 + x + 6) ÷ (x - 2)

Synthetic division with 2 gives quotient x2 - 2x - 3 and remainder 0.

Correct: Since the remainder is 0, x - 2 is a factor.

Worked Example 2

Model: A rectangle has width x, length x + 6, and area 91.

x(x + 6) = 91

x2 + 6x - 91 = 0, so (x + 13)(x - 7) = 0

Correct: The reasonable width is 7, and the length is 13.

Common Error

A student keeps x = -13 as the rectangle width because it solves the equation.

Incorrect: A negative width is not reasonable in this context. The algebraic solution must be interpreted.
