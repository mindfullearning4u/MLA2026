  • Represent: Use function notation, expressions, equations, and models.
  • Rewrite: Use operations, factoring, division, and equivalent forms.
  • Solve: Use zero-product reasoning, quadratic methods, and polynomial tools.
  • Interpret: Explain solutions, restrictions, and context.

Correct Example

Task: Solve x3 - 9x = 0 and interpret the solutions as possible zeros.

x(x2 - 9) = 0

x(x - 3)(x + 3) = 0

Correct: The zeros are x = -3, 0, and 3.

Incorrect Example

A student divides both sides of x3 - 9x = 0 by x and lists only x = -3 and x = 3.

Incorrect: Dividing by x removes the possible solution x = 0. Factoring keeps all solutions visible.
