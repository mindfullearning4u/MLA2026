Part A: Cumulative Skill Review

Part B: Synthesis and Modeling

  1. Divide x3 - 4x2 + x + 6 by x - 2.
  2. Solve x3 - 16x = 0.
  3. A rectangle has width x, length x + 6, and area 91. Find the reasonable dimensions.
  4. Explain which Unit 1 skill you feel most confident using and which skill you should review before the assessment.
