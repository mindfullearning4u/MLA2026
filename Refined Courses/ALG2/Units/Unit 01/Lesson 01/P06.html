Part A: Function Notation Practice

  1. If f(x) = 4x + 1, find f(6). Show your substitution step.
  2. If g(x) = x2 - 8, find g(3). Explain what the answer means.
  3. A function has p(2) = 9. Write one complete sentence explaining what this notation means.
  4. If h(x) = 12 - 2x, find the input value when h(x) = 0. Show your work.

Part B: Domain, Range, and Function Rules

Use complete sentences when an explanation is required.

  1. For the relation {(-4, 3), (-1, 0), (2, 5), (7, 5)}, identify the domain and range.
  2. Determine whether {(0, 2), (1, 4), (1, 6), (3, 8)} is a function. Explain your reasoning.
  3. A table has inputs -2, 0, 2, and 4 with outputs 5, 1, 5, and 9. Write the domain and range.
  4. Explain why repeated outputs do not automatically mean a relation is not a function.
