Notebook Title

Lesson 1: Algebra II Readiness and Function Review

Why Function Review Comes First

Algebra II uses functions throughout the course. Polynomial, radical, rational, exponential, logarithmic, and inverse relationships are all studied using function language.

A function assigns each input exactly one output. This rule matters whether the function is shown as an equation, a table, a graph, or a real-world description.

In this lesson, the goal is to use function notation accurately and connect it to meaning.

Core Function Ideas

  • Input: The value placed into the function. On a graph, the input is usually the x-value.
  • Output: The value produced by the function. On a graph, the output is usually the y-value.
  • Function notation: A notation such as f(x) that names the output of a function for input x.
  • Domain: The set of possible input values.
  • Range: The set of possible output values.

Vocabulary

  • Relation: A set of ordered pairs that connects inputs and outputs.
  • Function: A relation in which each input has exactly one output.
  • Evaluate: Substitute an input value into a rule and find the output.
  • x-intercept: A point where the graph crosses or touches the x-axis.
  • y-intercept: A point where the graph crosses the y-axis.

Example 1: Evaluate Function Notation

Problem: If f(x) = 2x + 5, find f(4).

Think: The notation f(4) means the input is 4.

f(4) = 2(4) + 5 = 8 + 5 = 13

Answer: f(4) = 13.

Meaning: When the input is 4, the output is 13.

Example 2: Identify Domain and Range

Problem: A relation contains the ordered pairs (1, 6), (2, 8), (3, 10), and (4, 12).

Domain: The inputs are the x-values.

Domain = {1, 2, 3, 4}

Range: The outputs are the y-values.

Range = {6, 8, 10, 12}

Common Mistake to Avoid

Do not treat two different outputs for the same input as a function.

Relation: (2, 5), (2, 9), (3, 11)

Incorrect:

This relation is a function because it has ordered pairs.

Correct:

This relation is not a function because input 2 has two outputs: 5 and 9.
