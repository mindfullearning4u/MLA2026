Checkpoint Task: Algebra II readiness and function review

Complete all parts. Use organized work and explain your reasoning when asked.

  1. Evaluate f(4) for f(x) = 5x - 7.
  2. Determine whether {(-3, 2), (0, 2), (4, 7), (4, 9)} is a function.
  3. Identify the domain and range of {(-1, 8), (0, 2), (3, 2), (6, 14)}.
  4. Correct the mistake: range = {-1, 0, 3, 6} for the previous relation.

Mastery Criteria

  • Evaluates function notation accurately.
  • Identifies domain and range from ordered pairs.
  • Uses input-output reasoning to determine whether a relation is a function.
  • Explains corrections using lesson vocabulary.
