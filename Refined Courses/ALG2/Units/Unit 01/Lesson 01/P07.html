Checkpoint Task: Function Readiness

Complete all parts. Show work clearly and explain your reasoning in complete sentences where required.

  1. If f(x) = 5x - 7, find f(4). Show the substitution step and final value.
  2. For the relation {(-3, 2), (0, 2), (4, 7), (4, 9)}, determine whether it is a function. Explain your reasoning.
  3. A table has inputs -1, 0, 3, and 6 with outputs 8, 2, 2, and 14. Identify the domain and range.
  4. A student claims that the range of {(-2, 5), (1, 9), (4, 9)} is {-2, 1, 4}.

    Range = {-2, 1, 4}

    Identify the misconception. Correct the range and explain why your correction is accurate.

Mastery Criteria

  • Uses function notation accurately.
  • Substitutes input values correctly and shows organized work.
  • Determines whether a relation is a function using input-output reasoning.
  • Identifies domain and range from ordered pairs or tables.
  • Explains and corrects common function interpretation mistakes.
