How to Work Through a Function Problem

Example: A function is given by g(x) = x2 - 3. Find and interpret g(5).

Step 1: Identify the input.

The notation g(5) means the input is 5.

Step 2: Substitute the input into the rule.

g(5) = 52 - 3 = 25 - 3 = 22

Step 3: Write the answer with meaning.

When the input is 5, the output is 22.

How to Explain a Mistake

When you find a mistake in function notation, explain what the input represents and how to substitute correctly.

Problem: If h(x) = 3x - 4, find h(6).

Incorrect:

h(6) = 3 + 6 - 4 = 5

Misconception: The student added 6 instead of replacing x with 6.

Correct:

h(6) = 3(6) - 4 = 18 - 4 = 14

Correction: The input 6 replaces x everywhere in the rule.

Interpreting Key Features

A graph tells more than individual outputs. In Algebra II, you will use key features to describe function behavior.

  • Increasing: Output values rise as input values move left to right.
  • Decreasing: Output values fall as input values move left to right.
  • Maximum: The greatest output value on a given domain.
  • Minimum: The least output value on a given domain.
  • Zero: An input value where the function output is 0.

Why This Matters Mathematically

Algebra II requires you to move between equations, graphs, tables, and descriptions. Function notation gives a precise way to describe inputs and outputs in every representation.

The skills in this lesson support polynomial functions, rational functions, exponential and logarithmic functions, systems, transformations, composition, and inverse functions.
