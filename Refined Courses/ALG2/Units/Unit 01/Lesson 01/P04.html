P04 Worked Examples

Work through each example slowly. The goal is not only to get an answer, but to understand why each step is valid and how the idea connects to the lesson standard.

Worked Example 1: Evaluate Function Notation

Problem: If f(x) = 3x - 5, find f(4).

Step 1: Replace x with the input value 4.

Step 2: Compute 3(4) - 5.

Step 3: Simplify 12 - 5 to get the output.

f(4) = 7

Reasoning: Function notation asks for the output when the input is 4.

Worked Example 2: Identify Domain and Range

Problem: For {(-2, 5), (0, 1), (3, 1), (6, 8)}, identify the domain and range.

Step 1: The domain is the set of input values.

Step 2: The range is the set of output values.

Step 3: List repeated output values only once.

Domain = {-2, 0, 3, 6}; Range = {1, 5, 8}

Reasoning: Inputs make the domain, and outputs make the range.

Worked Example 3: Connect a Zero to a Graph

Problem: A graph crosses the x-axis at x = -3 and x = 2. Identify the zeros.

Step 1: Zeros happen where the output is 0.

Step 2: On a graph, output 0 occurs at x-intercepts.

Step 3: Read the x-values of the x-intercepts.

Zeros: -3 and 2

Reasoning: The zeros are the input values where the graph meets the x-axis.

Common Mistake

Problem: If f(x) = x + 6, find f(2).

Incorrect:

f(2) = 2f

Why it is wrong: This treats function notation as multiplication.

Correct:

f(2) = 2 + 6 = 8

Fix: Replace x with 2 because f(2) means the output when the input is 2.
