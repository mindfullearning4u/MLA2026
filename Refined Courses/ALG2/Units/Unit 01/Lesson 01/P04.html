P04 Worked Examples

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Example 1: Decide Whether a Relation Is a Function

Problem: Determine whether {(1, 4), (2, 7), (3, 7), (4, 10)} is a function.

Step 1: List the inputs: 1, 2, 3, 4.

Step 2: Check whether any input is paired with more than one output.

Each input appears once.

Answer: The relation is a function.

Reasoning: Repeated outputs are allowed. Repeated inputs with different outputs are not allowed.

Example 2: Interpret a Table

Problem: The table shows values of a function.

x-2035
f(x)91412

Question: What is f(3), and what is the range?

f(3) = 4

Range = {1, 4, 9, 12}

Reasoning: The output paired with input 3 is 4. The range is the set of output values.

Example 3: Explain a Correction

Problem: A function has domain {-1, 0, 2} and outputs 6, 3, and 11 in that order. A student writes the range as {-1, 0, 2}.

Incorrect:

Range = {-1, 0, 2}

Why it is wrong: The student listed the inputs, not the outputs.

Correct:

Range = {3, 6, 11}

Reasoning: The range is the set of output values.

Common Mistake

A common function mistake is confusing f(2) with multiplication by 2.

Problem: If f(x) = x + 9, find f(2).

Incorrect:

f(2) means 2f, so the answer is 2x + 18.

Correct:

f(2) = 2 + 9 = 11

Why: Function notation names the output for an input. It does not mean multiplication.
