Question 1

Question ID:
ALG2_U01_L01_GP_Q01

MLA Standard:
MLA.A2.FN.1

If f(x) = 3x - 2, what is f(5)?

Answer: 13

Feedback: Substitute 5 for x. Since 3(5) - 2 = 15 - 2 = 13, f(5) = 13.

Question 2

Question ID:
ALG2_U01_L01_GP_Q02

MLA Standard:
MLA.A2.FN.1

Which relation is not a function?

Answer: {(1, 4), (1, 6), (2, 8)}

Feedback: Input 1 has two different outputs, 4 and 6. A function cannot assign one input to two different outputs.

Question 3

Question ID:

MLA Standard:
MLA.A2.FN.1

For the relation {(-2, 7), (0, 1), (4, 9)}, what is the domain?

Answer: {-2, 0, 4}

Feedback: The domain is the set of input values, which are the x-values -2, 0, and 4.

Question 4

Question ID:

MLA Standard:
MLA.A2.FN.1

A graph crosses the x-axis at x = -3 and x = 2. Which statement is true?

Answer: The zeros are -3 and 2.

Feedback: Zeros are input values where the function output equals 0, which occur at x-intercepts.

Question 5

MLA Standard:
MLA.A2.FN.1

A table shows that the outputs are 10, 6, 4, and 4 for inputs 0, 1, 2, and 3. What is the range?

Answer: {4, 6, 10}

Feedback: The range lists each output value once. The repeated output 4 is only listed once.
