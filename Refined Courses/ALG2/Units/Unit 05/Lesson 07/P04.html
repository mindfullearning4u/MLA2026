P04 Concept Instruction / Worked Examples

Concept Instruction

Advanced function analysis means using the structure and features of functions to make decisions. A graph may show intercepts and intervals quickly. An equation may make solving exact intersections easier. A table may make comparison over a data set efficient.

Worked Examples

Example 1: If f(x)=x2+1 and g(x)=2x+4, solve f(x)=g(x): x2+1=2x+4, so x2-2x-3=0, giving x=-1 and x=3.

Example 2: For h(x)=3x+2, the average rate of change from x=1 to x=5 is (17-5)/(5-1)=3.

Example 3: If a model describes time, then negative time values may be mathematical solutions but not viable contextual solutions.

Correct Reasoning Check

Correct: When two functions are equal at x=4, their graphs intersect at the point with input x=4.

Common Mistake

Incorrect: Choosing the larger y-intercept as the larger function for all x is incorrect because functions can cross or change at different rates.
