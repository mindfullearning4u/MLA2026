P04 Worked Examples

Study each example carefully. Each step shows the reasoning students should be able to reproduce independently.

Worked Example 1: Compare Representations

Problem: A table and graph both show f(2)=7.

Step 1: Read the input value 2.

Step 2: Find the output in each representation.

Step 3: Compare the outputs.

Both representations agree at x=2.

Reasoning: Function analysis uses multiple representations.

Worked Example 2: Solve from a Graph

Problem: A graph crosses y=0 at x=-1 and x=4.

Step 1: Zeros occur where y=0.

Step 2: Read the x-values.

Step 3: List the solutions.

Solutions: x=-1 and x=4.

Reasoning: Graphical solutions come from intercepts.

Worked Example 3: Interpret a Feature

Problem: A model has a minimum at (3, -5).

Step 1: Identify the input coordinate.

Step 2: Identify the output coordinate.

Step 3: State the lowest output.

The minimum output is -5 when input is 3.

Reasoning: Features describe behavior in context.

Common Mistake

Problem: Compare f(2) from a table and f(3) from a graph.

Incorrect:

They are directly comparable.

Why it is wrong: The inputs are different, so the outputs answer different questions.

Correct:

Compare outputs at the same input.

Fix: Match input values before comparing functions.
