P04 Concept Instruction / Worked Examples

Concept Instruction

Functions can be combined using arithmetic operations or composition. Composition is different from multiplication: f(g(x)) means substitute the entire rule for g(x) into f. Domain restrictions must be checked, especially when division or square roots are involved.

Worked Examples

Example 1: If f(x)=x+4 and g(x)=2x, then (f+g)(x)=3x+4.

Example 2: If f(x)=x2 and g(x)=x-3, then f(g(x))=(x-3)2.

Example 3: If h(x)=10/x, then x=0 is excluded from the domain.

Correct Reasoning Check

Correct: If f(x)=x+2 and g(x)=3x, then f(g(x))=3x+2.

Common Mistake

Incorrect: Writing f(g(x)) as f(x)g(x) is incorrect because composition means substitution, not multiplication.
