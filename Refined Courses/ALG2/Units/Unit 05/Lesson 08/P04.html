P04 Concept Review / Worked Examples

Concept Review

Unit 5 brings together multiple function tools. Systems identify shared solutions. Transformations describe how rules change graphs. Composition chains outputs into new inputs. Inverses reverse a relationship. Advanced analysis uses features and representations to justify conclusions.

Worked Examples

Example 1: Solving y=x+1 and y=5 gives x=4, so the graphs intersect at (4,5).

Example 2: If f(x)=x+3 and g(x)=2x, then f(g(x))=2x+3.

Example 3: If f(x)=2x-6, then f-1(x)=(x+6)/2.

Correct Reasoning Check

Correct: A solution must satisfy the algebra and make sense in the context.

Common Mistake

Incorrect: Treating f-1(x) as 1/f(x) is incorrect; inverse function notation means reversing inputs and outputs.
