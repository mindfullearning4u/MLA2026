P04 Concept Instruction / Worked Examples

Concept Instruction

Transformations describe how a parent function changes. Outside changes affect outputs and usually move graphs vertically or reflect/stretch vertically. Inside changes affect inputs and move graphs horizontally in the opposite direction of the sign shown.

Worked Examples

Example 1: g(x)=f(x)+4 shifts the graph up 4.

Example 2: g(x)=f(x-5) shifts the graph right 5.

Example 3: g(x)=-f(x) reflects the graph across the x-axis.

Example 4: g(x)=2f(x) vertically stretches the graph by factor 2.

Correct Reasoning Check

Correct: The function g(x)=f(x-3)+2 shifts f right 3 units and up 2 units.

Common Mistake

Incorrect: Saying f(x-3) shifts left 3 is incorrect; subtracting inside the input shifts the graph right.
