P02 Notebook Task Part 1

Notebook Title

Title your notes: Lesson 4: Function Transformations.

Write the standard: MLA.A2.FN.4; MLA.A2.FN.5; MLA.A2.FN.6.

Key Vocabulary

  • Parent function: the base function before transformations.
  • Translation: a horizontal or vertical shift.
  • Reflection: a flip across an axis.
  • Stretch/compression: a vertical or horizontal scale change.

Correct Example

Correct: The function g(x)=f(x-3)+2 shifts f right 3 units and up 2 units.

Incorrect Example

Incorrect: Saying f(x-3) shifts left 3 is incorrect; subtracting inside the input shifts the graph right.
