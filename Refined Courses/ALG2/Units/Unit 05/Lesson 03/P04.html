P04 Worked Examples

Step-by-step explanation: Each worked example below models the lesson process one step at a time and explains the reasoning before the final answer.

Study each example carefully. Each step shows the reasoning students should be able to reproduce independently.

Worked Example 1: Use Intersections

Problem: A line and parabola intersect at (-1, 3) and (2, 6).

Step 1: Identify each intersection point.

Step 2: Recognize each point satisfies both relations.

Step 3: List both solutions.

Solutions: (-1, 3) and (2, 6).

Reasoning: Nonlinear systems can have more than one solution.

Visual support: A nonlinear system solution appears where the graphs intersect.

Worked Example 2: Check a Nonlinear Solution

Problem: Check (1, 4) in y = x2 + 3.

Step 1: Substitute x = 1.

Step 2: Compute 12 + 3.

Step 3: Compare to y = 4.

Yes, 4 = 4.

Reasoning: Checking still uses substitution.

Worked Example 3: Interpret Constraints

Problem: A constraint says x ≥ 0 for a design model.

Step 1: Identify x as a quantity.

Step 2: Quantities may not be negative.

Step 3: Restrict the model domain.

Only nonnegative x-values are allowed.

Reasoning: Context determines meaningful solutions.

Common Mistake

Problem: A nonlinear system has two intersections.

Incorrect:

There must be only one solution.

Why it is wrong: Curved graphs can meet more than once.

Correct:

List every intersection point.

Fix: Use the graph or algebra to capture all solutions.

Teachable Explanation: The correct example works because it uses the lesson process accurately and connects the answer back to the mathematical structure or context.
