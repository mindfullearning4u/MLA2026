Notebook Title

Title your notes: Lesson 3: Nonlinear Systems and Constraints.

Write the standard: MLA.A2.SYS.4.

Key Vocabulary

  • Nonlinear system: a system with at least one nonlinear relation.
  • Constraint: a condition that limits possible solutions.
  • Feasible solution: a solution that satisfies all equations, inequalities, and context restrictions.

Correct Example

Correct: For y = x2 and y = x + 2, solving x2 = x + 2 gives intersections (-1, 1) and (2, 4).

Incorrect Example

Incorrect: Keeping x = -3 in a context where x represents time is invalid because time cannot be negative.
