Notebook Setup

Title your notes: Lesson 6: Inverse Functions.

Write the standard: MLA.A2.FN.9; MLA.A2.FN.10.

Key Vocabulary

  • Inverse function: a function that reverses another function.
  • One-to-one: each output comes from exactly one input.
  • Composition check: f(g(x))=x and g(f(x))=x.

Correct Example

Correct: If f(x)=x+5, then f-1(x)=x-5 because it undoes adding 5.

Incorrect Example

Incorrect: Writing f-1(x)=1/f(x) is incorrect because inverse function notation does not mean reciprocal.
