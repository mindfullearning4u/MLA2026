P04 Concept Instruction / Worked Examples

Concept Instruction

A system solution must satisfy every equation in the system. Graphically, solutions are intersection points. Algebraically, substitution and elimination help find those points. Systems can include two lines, a line and a quadratic, or other function families students have studied.

Worked Examples

Example 1: Solve y = x + 4 and y = 3x. Set x + 4 = 3x, so x = 2 and y = 6. Solution: (2, 6).

Example 2: Solve y = x2 and y = x + 2. Set x2 = x + 2, so x2 - x - 2 = 0. Then x = -1 or x = 2. Solutions: (-1, 1) and (2, 4).

Example 3: In a context, a system solution may represent the time and value when two models are equal.

Correct Reasoning Check

Correct: A solution to a line-quadratic system can have zero, one, or two intersection points.

Common Mistake

Incorrect: Assuming every system has exactly one solution ignores nonlinear systems and parallel lines.
