P04 Worked Examples

Study each example carefully. Each step shows the reasoning students should be able to reproduce independently.

Worked Example 1: Solve by Substitution

Problem: Solve y = x + 2 and y = 2x - 1.

Step 1: Set the two expressions for y equal.

Step 2: Solve x + 2 = 2x - 1.

Step 3: Substitute x back to find y.

(3, 5)

Reasoning: The solution is the point where both equations are true.

Worked Example 2: Interpret an Intersection

Problem: Two models meet at (4, 12).

Step 1: Read the x-coordinate.

Step 2: Read the y-coordinate.

Step 3: Connect the ordered pair to both models.

At input 4, both outputs are 12.

Reasoning: An intersection is a shared solution.

Worked Example 3: Check a System Solution

Problem: Check whether (2, 7) solves y = 3x + 1.

Step 1: Substitute x = 2.

Step 2: Compute 3(2) + 1.

Step 3: Compare with y = 7.

Yes, because 7 = 7.

Reasoning: A solution must satisfy the equation.

Common Mistake

Problem: Solve y = x + 4 and y = 2x.

Incorrect:

x = 4 only

Why it is wrong: The x-value alone is not the full system solution.

Correct:

(4, 8)

Fix: Substitute the x-value to find the matching y-value.
