Notebook Setup

Title your notes: Lesson 1: Systems of Equations.

Write the standard: MLA.A2.SYS.1; MLA.A2.SYS.2.

Key Vocabulary

  • System of equations: two or more equations considered together.
  • Solution: an ordered pair that makes every equation true.
  • Intersection: a graph point shared by the equations.
  • Substitution: replacing one expression with an equivalent expression to solve.

Correct Example

Correct: The point (2, 5) solves y = 2x + 1 and y = x + 3 because both equations give y = 5 when x = 2.

Incorrect Example

Incorrect: Using a point that satisfies only one equation is not a system solution.
