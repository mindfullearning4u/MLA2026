P04 Concept Instruction / Worked Examples

Concept Instruction

Logarithms and exponents are inverse operations. To solve a logarithmic equation, rewrite it as an exponential equation. To solve an exponential equation, use matching bases when possible or use logarithms when matching bases is not practical. Always check logarithmic inputs in the original equation.

Worked Examples

Example 1: log4(x) = 3 gives x = 43 = 64.

Example 2: log2(x + 5) = 4 gives x + 5 = 16, so x = 11.

Example 3: 3x = 81 gives x = 4 because 81 = 34.

Example 4: 5x = 12 gives x = log(12)/log(5) by change of base.

Correct Reasoning Check

Correct: A logarithmic candidate is valid only if every logarithm input in the original equation is positive.

Common Mistake

Incorrect: Solving log3(x - 7) = 2 as x = 9 ignores the +7 adjustment; the correct solution is x = 16.
