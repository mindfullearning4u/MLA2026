P04 Concept Instruction / Worked Examples

Concept Instruction

A logarithm answers an exponent question. The statement logb(a) = c is equivalent to bc = a. Logarithmic functions are inverses of exponential functions, so their graphs reverse inputs and outputs. For y = logb(x), the domain is x > 0 and the range is all real numbers.

Worked Examples

Example 1: log3(81) = 4 because 34 = 81.

Example 2: 102 = 100 can be written as log10(100) = 2.

Example 3: y = log2(x) has vertical asymptote x = 0 because its exponential inverse has horizontal asymptote y = 0.

Correct Reasoning Check

Correct: A logarithm output is an exponent, so log4(64) = 3.

Common Mistake

Incorrect: log4(64) = 16 confuses division with exponent reasoning.
