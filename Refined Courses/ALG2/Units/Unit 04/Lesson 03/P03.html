P03 Notebook Task Part 2

Notebook Task

  1. Create a financial-model chart with columns for principal, rate, factor, time, and model.
  2. Write a model for 2000 dollars earning 4% annually.
  3. Write a model for a 18000 dollar car depreciating by 12% annually.
  4. Explain the meaning of each model parameter.

Correct Reasoning

Correct: A 12% depreciation rate uses factor 0.88 because 88% of the value remains each year.

Common Mistake

Incorrect: A depreciation factor of 1.12 models growth, not loss of value.
