P04 Concept Instruction / Worked Examples

Concept Instruction

Logarithmic properties are connected to exponent properties. Multiplication inside a logarithm becomes addition, division becomes subtraction, and powers become coefficients. These properties work only when the logarithms have the same base and when all logarithm inputs are positive.

Worked Examples

Example 1: log2(5x) = log2(5) + log2(x).

Example 2: log3(x4) = 4 log3(x).

Example 3: log5(a) - log5(b) = log5(a/b).

Example 4: log2(7) = log(7)/log(2) by change of base.

Correct Reasoning Check

Correct: log6(m/n) = log6(m) - log6(n).

Common Mistake

Incorrect: log6(m - n) = log6(m) - log6(n) is incorrect because subtraction inside a logarithm does not split.
