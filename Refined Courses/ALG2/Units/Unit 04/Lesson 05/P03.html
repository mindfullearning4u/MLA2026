P03 Notebook Task Part 2

Notebook Task

  1. Make a property chart for product, quotient, and power properties.
  2. Expand log2(8x3).
  3. Condense log5(a) - log5(b).
  4. Write one warning about expressions where properties do not apply.

Correct Reasoning

Correct: 3 log4(x) = log4(x3) by the power property.

Common Mistake

Incorrect: 3 log4(x) = log4(3x) is incorrect because the coefficient becomes an exponent, not a factor.
