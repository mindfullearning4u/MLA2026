P04 Concept Instruction / Worked Examples

Concept Instruction

Application problems require choosing a model, identifying parameters, solving accurately, and interpreting the result. Exponential functions model repeated percent change. Logarithms help answer inverse questions such as how long a process takes to reach a target value.

Worked Examples

Example 1: A population of 1200 grows 4% per year: P(t)=1200(1.04)t.

Example 2: A substance starts at 80 grams and keeps 75% each hour: A(t)=80(0.75)t.

Example 3: To find when 600(1.03)t=900, solve t = log(900/600)/log(1.03).

Correct Reasoning Check

Correct: The final answer should state both the number and what it means in context.

Common Mistake

Incorrect: Reporting t = 13 without units or context does not fully answer an application problem.
