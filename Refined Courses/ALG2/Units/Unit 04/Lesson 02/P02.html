Key Vocabulary

  • Growth factor: 1 + r for a percent increase.
  • Decay factor: 1 - r for a percent decrease.
  • Rate: the percent change written as a decimal.
  • Parameter: a number in a model that has contextual meaning.

Correct Example

Correct: A 12% increase has growth factor 1.12 because 1 + 0.12 = 1.12.

Incorrect Example

Incorrect: Using 0.12 as the whole growth factor is incorrect because it keeps only the increase, not the original amount plus the increase.
