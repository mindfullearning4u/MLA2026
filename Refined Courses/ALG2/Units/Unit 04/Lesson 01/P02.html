Title your notes: Lesson 1: Exponential Functions.

Write the standard: MLA.A2.EX.1.

Key Vocabulary

  • Exponential function: a function with a constant multiplicative rate of change.
  • Initial value: the output when x = 0 in f(x) = a(b)x.
  • Base: the repeated multiplication factor b.
  • Growth factor: a base greater than 1.

Correct Example

Correct: The table 3, 6, 12, 24 has common ratio 2, so it can be modeled by f(x) = 3(2)x.

Incorrect Example

Incorrect: Modeling 3, 6, 12, 24 with f(x) = 3 + 3x is incorrect because the outputs multiply by 2, not add 3 each time.
