P04 Concept Instruction / Worked Examples

Concept Instruction

An exponential function has the form f(x) = a(b)x, where a is the initial value and b is the constant multiplicative factor. If b > 1, the function increases as x increases. Exponential functions model situations where the same factor is applied repeatedly.

Worked Examples

Example 1: A table has outputs 4, 12, 36, 108. The common ratio is 3, so f(x) = 4(3)x.

Example 2: In f(x) = 7(2)x, 7 is the initial value and 2 is the base.

Example 3: A bacteria population begins at 50 and doubles each hour. The model is P(t) = 50(2)t.

Correct Reasoning Check

Correct: When a pattern multiplies by the same factor each step, an exponential model is appropriate.

Common Mistake

Incorrect: Using the difference between outputs as the base is incorrect; the base comes from the ratio between consecutive outputs.
