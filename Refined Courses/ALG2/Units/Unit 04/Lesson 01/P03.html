P03 Notebook Task Part 2

Notebook Task

  1. Create a table for f(x) = 5(3)x for x = 0, 1, 2, 3.
  2. Circle the initial value and underline the base.
  3. Write one sentence explaining the repeated multiplication.

Correct Reasoning

Correct: For f(x) = 5(3)x, each time x increases by 1, the output is multiplied by 3.

Common Mistake

Incorrect: Adding 3 each step treats the pattern as linear instead of exponential.
