P03 Notebook Task Part 2

Strategy Notes

  1. Identify zeros and multiplicities from a factored polynomial.
  2. Use degree and leading coefficient to describe end behavior.
  3. Sketch a reasonable graph using zeros, multiplicities, and end behavior.

Correct Example

f(x) = (x + 2)(x - 1)2

Correct: The graph crosses at x = -2 and touches at x = 1.

Incorrect Example

f(x) = (x + 2)(x - 1)2

Incorrect: Saying the graph crosses at both zeros ignores the even multiplicity at x = 1.

Notebook Task

  1. Redo one worked example independently.
  2. Explain how one feature affects the graph or model.
  3. Write one misconception to avoid.

Common Mistake

Incorrect: Solving the problem by following a procedure without checking what the expression, equation, graph, or model represents.

Correct: Use the procedure and then connect the result back to the meaning of the lesson problem.

Teachable Explanation: Algebra II mastery requires both accurate steps and correct interpretation. A correct answer should make sense in the representation or context given.
