P04 Concept Instruction / Worked Examples

Concept Instruction

Solve and interpret quadratic equations and inequalities graphically and algebraically.

Use equations, graphs, intervals, and function notation together. In Algebra II, a solution is not only a value; it must also be interpreted in relation to a graph, inequality, or context.

Worked Examples

Example 1: Solve x2 - 5x + 6 = 0. Factor to get (x - 2)(x - 3) = 0, so x = 2 or x = 3.

Example 2: For x2 - 4 < 0, the graph is below the x-axis between the zeros -2 and 2, so -2 < x < 2.

Example 3: For y > x2 - 1, the parabola is dashed and the solution region is above the boundary.

Correct Reasoning Check

Correct: For x2 - 4 < 0, use the interval between the x-intercepts because that is where the graph is below the x-axis.

Common Mistake

Incorrect: For x2 - 4 < 0, choosing x < -2 or x > 2 is incorrect because those intervals make the graph positive.
