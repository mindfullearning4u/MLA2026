Key Vocabulary

  • Quadratic equation: an equation that can be written with a degree 2 expression.
  • Quadratic inequality: a quadratic comparison using <, >, <=, or >=.
  • Boundary: the graph or value where equality occurs.
  • Solution set: all values or points that make an equation or inequality true.

Correct Example

Correct: For x2 - 4 < 0, use the interval between the x-intercepts because that is where the graph is below the x-axis.

Incorrect Example

Incorrect: For x2 - 4 < 0, choosing x < -2 or x > 2 is incorrect because those intervals make the graph positive.
