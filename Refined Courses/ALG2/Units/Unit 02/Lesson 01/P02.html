Notebook Setup

Title your notes: Lesson 1: Quadratic-to-Polynomial Function Bridge.

Write the standard: MLA.A2.PF.3.

Key Vocabulary

  • Polynomial function: A function built from nonnegative integer powers of x.
  • Quadratic function: A degree 2 polynomial function.
  • Zero: An input that makes the output 0.

Correct Example

f(x) = x2 - 5x + 6

f(x) = (x - 2)(x - 3)

Correct: The zeros are x = 2 and x = 3.

Incorrect Example

f(x) = x2 - 5x + 6

The zeros are x = -2 and x = -3.

Incorrect: The signs are reversed. x - 2 = 0 gives x = 2.
