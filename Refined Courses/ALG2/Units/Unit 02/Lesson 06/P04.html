P04 Concept Development and Worked Examples

Polynomial Models and Applications

Polynomial models connect algebraic features to real-world meaning. A solution must be checked against the context.

Worked Example 1

If A(x) = x(20 - 2x), then x represents a length. Values x < 0 are not meaningful, and values that make 20 - 2x negative are not meaningful.

Worked Example 2

If h(t) = -16t2 + 48t, zeros t = 0 and t = 3 represent launch and landing times.

Common Mistake

Do not report every algebraic solution as viable. Check units, signs, and context restrictions.
