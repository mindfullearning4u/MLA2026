Notebook Setup

Title your notes: Lesson 4: Zeros, Roots, and Multiplicity.

Write the standard: Support-only review; no new primary MLA standard.

Key Vocabulary

  • Zero: An input where f(x) = 0.
  • Root: A solution of a polynomial equation.
  • Multiplicity: How many times a factor repeats.

Correct Example

f(x) = (x - 2)2(x + 3)

Correct: x = 2 has multiplicity 2 and x = -3 has multiplicity 1.

Incorrect Example

f(x) = (x - 2)2(x + 3)

Incorrect: x = -2 is not a zero; x - 2 = 0 gives x = 2.

Notebook Task

  1. Identify zeros from a factored polynomial.
  2. State the multiplicity of each zero.
  3. Explain whether the graph crosses or touches at each zero.
