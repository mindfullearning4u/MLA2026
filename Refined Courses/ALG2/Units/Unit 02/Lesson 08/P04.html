P04 Concept Instruction / Worked Examples

Concept Instruction

Synthesize polynomial and quadratic function analysis across Unit 2.

Use equations, graphs, intervals, and function notation together. In Algebra II, a solution is not only a value; it must also be interpreted in relation to a graph, inequality, or context.

Worked Examples

Example 1: f(x) = -2(x + 1)2(x - 3) has zeros -1 and 3, odd degree, and negative leading coefficient, so the graph rises left and falls right.

Example 2: The inequality x2 - 9 <= 0 has solution -3 <= x <= 3 because the graph is on or below the x-axis between the zeros.

Example 3: A polynomial height model can be interpreted by using intercepts, maximum or minimum values, and the practical domain.

Correct Reasoning Check

Correct: A complete analysis names the feature, connects it to the equation or graph, and explains its meaning.

Common Mistake

Incorrect: A partial analysis that lists numbers without identifying zeros, intervals, or context meaning is incomplete.
