Key Vocabulary

  • End behavior: what a polynomial graph does as x moves far left or far right.
  • Zero: an input where the function value is 0.
  • Multiplicity: the number of times a factor repeats.
  • Solution region: the set of points satisfying an inequality.

Correct Example

Correct: A complete analysis names the feature, connects it to the equation or graph, and explains its meaning.

Incorrect Example

Incorrect: A partial analysis that lists numbers without identifying zeros, intervals, or context meaning is incomplete.
