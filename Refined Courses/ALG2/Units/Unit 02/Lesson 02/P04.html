P04 Worked Examples

Work through each example slowly. The goal is not only to get an answer, but to understand why each step is valid and how the idea connects to the lesson standard.

Step-by-step explanation: Each worked example below models the lesson process one step at a time and explains the reasoning before the final answer.

Worked Example 1: Identify Vertex and Intercepts

Problem: For a parabola with vertex (2, -3) and x-intercepts 1 and 3, name the key features.

Step 1: State the vertex.

Step 2: State the x-intercepts as ordered pairs.

Step 3: Use the vertex to describe the minimum if the graph opens upward.

Vertex (2, -3); x-intercepts (1, 0) and (3, 0).

Reasoning: Key features summarize the graph behavior.

Visual support: The vertex (2, 3) is the lowest point, and the axis of symmetry is x = 2.

Worked Example 2: Interpret a Context

Problem: A ball reaches a maximum height of 18 feet at 2 seconds. What does the vertex mean?

Step 1: Identify the input coordinate as time.

Step 2: Identify the output coordinate as height.

Step 3: Interpret both together.

At 2 seconds, the ball is 18 feet high, its maximum height.

Reasoning: Context gives meaning to coordinates.

Worked Example 3: Use Domain and Range

Problem: A quadratic height model is valid from t = 0 to t = 5 and reaches a maximum of 20 feet.

Step 1: Use the time interval for domain.

Step 2: Use possible heights for range.

Step 3: Include realistic lower and upper values.

Domain: 0 ≤ t ≤ 5; Range: 0 ≤ h ≤ 20

Reasoning: Context can restrict a quadratic model.

Common Mistake

Problem: A height graph has vertex (3, 25).

Incorrect:

The maximum time is 25 seconds.

Why it is wrong: The x-coordinate gives time, and the y-coordinate gives height.

Correct:

The maximum height is 25 at 3 seconds.

Fix: Always match coordinates to the variables in the context.
