Quadratic Key Features

Quadratic functions are analyzed using vertex, axis of symmetry, intercepts, intervals, domain, range, and constraints.

Worked Example 1

f(x) = (x + 3)2 - 5 has vertex (-3, -5), axis x = -3, minimum -5, and range y ≥ -5.

Worked Example 2

h(t) = -16t2 + 64t factors as -16t(t - 4), so the meaningful flight interval is 0 ≤ t ≤ 4.

Correct Reasoning Check

Correct: The worked examples identify the relevant polynomial feature first, then connect that feature to the equation, graph, or context.

Common Mistake

A projectile domain is not all real numbers; context restricts time.
