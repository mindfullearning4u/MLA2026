P03 Notebook Task Part 2

Strategy Notes

  1. Find vertex, axis, intercepts, domain, and range from a quadratic.
  2. Interpret maximum or minimum values in context.
  3. Explain contextual restrictions.

Correct Example

h(t) = -16(t - 2)2 + 64

Correct: The maximum height is 64 feet at 2 seconds.

Incorrect Example

h(t) = -16(t - 2)2 + 64

Incorrect: The maximum height is not 2 feet. The input 2 is time; the output 64 is height.

Notebook Task

  1. Redo one worked example without looking.
  2. Explain one feature in a complete sentence.
  3. Write one mistake to avoid.
