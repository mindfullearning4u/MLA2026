P04 Concept Instruction / Worked Examples

Concept Instruction

Analyze graphs, domains, ranges, and key features of radical functions.

Use structure first. Decide whether the task is asking for an equivalent expression, a domain or range, or a graph feature before simplifying or interpreting.

Worked Examples

Example 1: For f(x) = √(x - 4), the domain is x >= 4 and the range is y >= 0.

Example 2: For g(x) = √x + 3, the graph shifts up 3 units and the range is y >= 3.

Example 3: For h(x) = -√(x + 2), the endpoint is (-2, 0), the domain is x >= -2, and the range is y <= 0.

Correct Reasoning Check

Correct: For f(x) = √(x - 5) + 2, the domain is x >= 5 because the radicand x - 5 must be nonnegative.

Common Mistake

Incorrect: For f(x) = √(x - 5) + 2, saying the domain is x >= 2 is incorrect because the vertical shift does not control the radicand.
