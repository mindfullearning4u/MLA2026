P01 Lesson Overview

Lesson Title

Lesson 2: Radical Functions

Analyze graphs, domains, ranges, and key features of radical functions.

Standards Covered in This Lesson

MLA.A2.RR.2

Florida B.E.S.T. Benchmark: MA.912.AR.7.2

Analyze graphs, domains, ranges, and key features of radical functions.

What You Will Learn

  • Identify the domain and range of square root and cube root functions.
  • Describe translations and reflections of radical parent functions.
  • Connect the starting point of a square root graph to domain and range.
  • Interpret key features from radical equations and graph descriptions.

What You Will Do

  • Take notebook notes on radical function families.
  • Study worked examples involving domain, range, and transformations.
  • Complete guided practice, independent work, checkpoint, notebook evidence, and a lesson quiz.

How You Will Show Mastery

  • Analyze radical function graphs and key features.
  • Use domain and range notation accurately.
  • Explain transformations from a parent radical function.

Student-Friendly Standard Connection

MLA.A2.RR.2: Analyze graphs, domains, ranges, and key features of radical functions.

In student language: I can analyze radical functions by identifying domain, range, transformations, endpoints, and graph behavior.
