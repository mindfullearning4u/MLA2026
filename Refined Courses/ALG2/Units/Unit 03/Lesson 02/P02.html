Notebook Title

Title your notes: Lesson 2: Radical Functions.

Write the standard: MLA.A2.RR.2.

Key Vocabulary

  • Square root function: a function based on f(x) = √x.
  • Cube root function: a function based on f(x) = √3x.
  • Domain: the set of input values for a function.
  • Range: the set of output values for a function.
  • Endpoint: the starting point of a square root graph.

Correct Example

Correct: For f(x) = √(x - 5) + 2, the domain is x ≥ 5 because the radicand x - 5 must be nonnegative.

Incorrect Example

Incorrect: For f(x) = √(x - 5) + 2, saying the domain is x ≥ 2 is incorrect because the vertical shift does not control the radicand.
