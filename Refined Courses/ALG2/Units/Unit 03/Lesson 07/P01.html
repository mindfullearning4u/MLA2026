P01 Lesson Overview

Lesson Title

Lesson 7: Rational Functions and Applications

Analyze rational function behavior and model contexts involving rational relationships.

Standards Covered in This Lesson

MLA.A2.RR.5; MLA.A2.RR.6

Florida B.E.S.T. Benchmark: MA.912.AR.8.2; MA.912.AR.8.3

Analyze rational function graphs, restrictions, asymptotes, and contextual meaning.

What You Will Learn

  • Identify domain restrictions and vertical asymptotes of rational functions.
  • Interpret horizontal asymptotes and end behavior.
  • Connect rational function features to real-world contexts.
  • Use graph features to describe rational relationships.

What You Will Do

  • Take notes on rational function features.
  • Study worked examples with asymptotes, intercepts, and context restrictions.
  • Complete guided practice, independent work, checkpoint, notebook evidence, and a lesson quiz.

How You Will Show Mastery

  • Identify rational function domain restrictions.
  • Describe asymptotes and graph behavior accurately.
  • Interpret rational model features in context.

Student-Friendly Standard Connection

MLA.A2.RR.5; MLA.A2.RR.6: Analyze rational functions and applications.

In student language: I can read a rational function graph or model and explain its restrictions, asymptotes, and meaning.
