P04 Worked Examples

Study each example carefully. Each one shows a different way the lesson idea appears in Algebra II work.

Worked Example 1: Identify a Vertical Asymptote

Problem: For f(x)=1/(x - 4), identify the vertical asymptote.

Step 1: Set the denominator equal to 0.

Step 2: Solve x - 4 = 0.

Step 3: State the vertical asymptote.

x = 4

Reasoning: The function is undefined at the vertical asymptote.

Worked Example 2: Interpret a Rational Model

Problem: A cost per person model decreases as more people share a fixed cost.

Step 1: Identify the fixed total cost.

Step 2: Recognize division by number of people.

Step 3: Interpret why the output decreases.

Cost per person decreases as group size increases.

Reasoning: Rational models often describe sharing, rates, or inverse relationships.

Worked Example 3: Find Domain Restriction

Problem: Find the domain restriction for R(x)=100/x.

Step 1: The denominator cannot be 0.

Step 2: Set x = 0 as restricted.

Step 3: Interpret in context if x is number of items.

x != 0

Reasoning: A zero denominator is not meaningful mathematically or contextually.

Common Mistake

Problem: For f(x)=1/(x+2), identify the vertical asymptote.

Incorrect:

x = 2

Why it is wrong: Solving x + 2 = 0 gives -2, not 2.

Correct:

x = -2

Fix: Set the denominator equal to zero and solve carefully.
