P04 Concept Instruction / Worked Examples

Concept Instruction

Rational functions often have restrictions and asymptotes. The denominator identifies values that are not allowed. A non-canceled denominator factor usually creates a vertical asymptote. Horizontal asymptotes describe long-run behavior.

Worked Examples

Example 1: f(x) = 3/(x - 2) has domain x ≠ 2 and vertical asymptote x = 2.

Example 2: f(x) = (2x + 1)/(x - 4) has vertical asymptote x = 4 and horizontal asymptote y = 2 because the leading coefficient ratio is 2/1.

Example 3: If T(n) = 120/n gives time per worker for a fixed job, n = 0 is not allowed because zero workers cannot complete the job.

Correct Reasoning Check

Correct: In a model, restrictions must make sense algebraically and contextually.

Common Mistake

Incorrect: Using x = 0 in f(x) = 5/x is incorrect because division by zero is undefined.
