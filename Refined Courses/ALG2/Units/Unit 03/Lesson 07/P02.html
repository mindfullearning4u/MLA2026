Key Vocabulary

  • Vertical asymptote: a vertical line the graph approaches near a restricted input.
  • Horizontal asymptote: a horizontal line the graph approaches as x becomes very large or very small.
  • Hole: a removable discontinuity caused by a canceled factor.
  • Rational model: a context modeled by a ratio of expressions.

Correct Example

Correct: f(x) = 1/(x - 3) has vertical asymptote x = 3 because the denominator is zero there.

Incorrect Example

Incorrect: Saying f(x) = 1/(x - 3) has vertical asymptote x = -3 is incorrect because x - 3 = 0 gives x = 3.
