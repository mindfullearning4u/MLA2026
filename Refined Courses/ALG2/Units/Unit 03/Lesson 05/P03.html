P03 Notebook Task Part 2

Notebook Task

  1. List the denominator factors before combining expressions.
  2. Show how each numerator is adjusted to match the LCD.
  3. Explain why restrictions come from the original denominators.

Correct Reasoning

Correct: 1/x + 2/(x + 1) = (x + 1)/(x(x + 1)) + 2x/(x(x + 1)) = (3x + 1)/(x(x + 1)), with x ≠ 0 and x ≠ -1.

Common Mistake

Incorrect: Adding denominators is incorrect. Rational expressions need a common denominator before adding or subtracting numerators.
