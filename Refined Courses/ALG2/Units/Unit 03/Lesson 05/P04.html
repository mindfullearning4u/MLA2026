P04 Concept Instruction / Worked Examples

Concept Instruction

To add or subtract rational expressions, factor denominators, identify the least common denominator, rewrite each fraction with that denominator, combine numerators, simplify, and keep restrictions.

Worked Examples

Example 1: 4/(x + 2) + 3/(x + 2) = 7/(x + 2), with x ≠ -2.

Example 2: 1/x + 2/(x + 3) = (x + 3 + 2x)/(x(x + 3)) = (3x + 3)/(x(x + 3)), with x ≠ 0 and x ≠ -3.

Example 3: 5/(x - 1) - 2/(x + 1) = [5(x + 1) - 2(x - 1)]/[(x - 1)(x + 1)] = (3x + 7)/[(x - 1)(x + 1)], with x ≠ 1 and x ≠ -1.

Correct Reasoning Check

Correct: When subtracting rational expressions, distribute the subtraction across the entire second numerator.

Common Mistake

Incorrect: 5/(x - 1) - 2/(x + 1) = (5x + 5 - 2x - 2)/... is incorrect if the subtraction was not distributed to every term of 2(x - 1).
