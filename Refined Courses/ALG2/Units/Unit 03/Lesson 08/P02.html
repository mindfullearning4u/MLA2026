Key Vocabulary Review

  • Radical expression, radical function, radical equation, and extraneous solution.
  • Rational expression, restriction, rational equation, vertical asymptote, and horizontal asymptote.
  • Context validity: whether a solution makes sense in a real situation.

Correct Example

Correct: For √(x + 4) = 6, x = 32 because x + 4 = 36 and the check works.

Incorrect Example

Incorrect: Reporting x = 0 for a rational equation with denominator x is invalid because x = 0 is restricted.
