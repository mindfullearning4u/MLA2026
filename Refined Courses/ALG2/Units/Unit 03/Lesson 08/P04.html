P04 Worked Examples

Study each example carefully. Each one shows a different way the lesson idea appears in Algebra II work.

Worked Example 1: Simplify a Radical

Problem: Simplify √45.

Step 1: Factor 45 as 9 · 5.

Step 2: Simplify √9.

Step 3: Write the simplified radical.

3√5

Reasoning: Unit 3 combines radical fluency with function and equation work.

Worked Example 2: Solve a Rational Equation

Problem: Solve 2/x = 5.

Step 1: Multiply both sides by x.

Step 2: Solve 2 = 5x.

Step 3: Check x is not 0.

x = 2/5

Reasoning: Rational equations require restrictions and checking.

Worked Example 3: Analyze a Rational Feature

Problem: For f(x)=1/(x + 3), find the vertical asymptote.

Step 1: Set x + 3 = 0.

Step 2: Solve for x.

Step 3: State the asymptote.

x = -3

Reasoning: The denominator controls where the function is undefined.

Common Mistake

Problem: Solve √x= -6.

Incorrect:

x = 36

Why it is wrong: A principal square root cannot be negative.

Correct:

No solution

Fix: Always check whether the original equation is possible.
