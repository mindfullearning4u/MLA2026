P04 Worked Examples

Study each example carefully. Each one shows a different way the lesson idea appears in Algebra II work.

Worked Example 1: Identify Restrictions

Problem: Find restrictions for (x + 2)/(x - 5).

Step 1: The denominator cannot equal 0.

Step 2: Set x - 5 = 0.

Step 3: Solve for the restricted value.

x != 5

Reasoning: Restrictions come from denominator values that make division by zero.

Worked Example 2: Simplify a Rational Expression

Problem: Simplify (x2 - 9)/(x - 3).

Step 1: Factor the numerator.

Step 2: Cancel common factors only after factoring.

Step 3: State the restriction.

x + 3, x != 3

Reasoning: The simplified form is equivalent only where the original expression is defined.

Worked Example 3: Multiply Rational Expressions

Problem: Simplify (2x/5)(15/x).

Step 1: Multiply numerators and denominators.

Step 2: Cancel common factors.

Step 3: Keep restrictions from original denominators.

6, x != 0

Reasoning: Multiplying rational expressions uses fraction structure.

Common Mistake

Problem: Simplify (x2 - 16)/(x - 4).

Incorrect:

x + 4 with no restriction

Why it is wrong: The simplified expression hides the original excluded value.

Correct:

x + 4, x != 4

Fix: Always state restrictions from original denominators.
