Title your notes: Lesson 6: Rational Equations.

Write the standard: MLA.A2.RR.4.

Key Vocabulary

  • Rational equation: an equation containing rational expressions.
  • Least common denominator: a denominator used to clear fractions.
  • Restriction: a value that makes any original denominator zero.
  • Extraneous solution: a candidate that is not valid in the original equation.

Correct Example

Correct: 3/x = 6 gives x ≠ 0 and 3 = 6x after multiplying by x, so x = 1/2.

Incorrect Example

Incorrect: Solving 1/(x - 2) = 3 and reporting x = 2 is incorrect because x = 2 makes the original denominator zero.
