P04 Worked Examples

Step-by-step explanation: Each worked example below models the lesson process one step at a time and explains the reasoning before the final answer.

Study each example carefully. Each one shows a different way the lesson idea appears in Algebra II work.

Worked Example 1: Solve with a Denominator

Problem: Solve 3/x = 6.

Step 1: Multiply both sides by x.

Step 2: Solve 3 = 6x.

Step 3: Check x is not 0.

x = 1/2

Reasoning: Restrictions must be considered in rational equations.

Worked Example 2: Clear Denominators

Problem: Solve 1/x + 2 = 5.

Step 1: Subtract 2 from both sides.

Step 2: Solve 1/x = 3.

Step 3: Invert to find x.

x = 1/3

Reasoning: Clearing denominators can simplify rational equations.

Worked Example 3: Check an Extraneous Solution

Problem: Solve (x + 1)/(x - 2) = 3.

Step 1: Multiply by x - 2.

Step 2: Solve x + 1 = 3x - 6.

Step 3: Check x is not 2.

x = 7/2

Reasoning: A denominator restriction can make a candidate invalid.

Common Mistake

Problem: Solve 4/(x - 1) = 2.

Incorrect:

x = 1

Why it is wrong: x = 1 makes the denominator 0 and cannot be used.

Correct:

x = 3

Fix: Multiply by x - 1, solve, and check the restriction.
