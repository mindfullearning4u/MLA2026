P04 Concept Instruction / Worked Examples

Concept Instruction

To solve a rational equation, write restrictions, multiply every term by the least common denominator, solve the resulting equation, and check solutions against restrictions and the original equation.

Worked Examples

Example 1: 4/x = 2. Restriction: x ≠ 0. Multiply by x: 4 = 2x, so x = 2.

Example 2: 1/(x - 1) = 3. Restriction: x ≠ 1. Multiply by x - 1: 1 = 3x - 3, so x = 4/3.

Example 3: 2/(x - 3) = 1. Restriction: x ≠ 3. Multiply by x - 3: 2 = x - 3, so x = 5.

Correct Reasoning Check

Correct: A value that makes any original denominator zero must be rejected even if it appears after clearing denominators.

Common Mistake

Incorrect: Multiplying only one side by the LCD is incorrect. Every term on both sides must be multiplied by the same LCD.
