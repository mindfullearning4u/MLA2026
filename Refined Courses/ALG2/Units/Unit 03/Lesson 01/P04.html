P04 Concept Instruction / Worked Examples

Concept Instruction

Rewrite and simplify expressions involving radicals and rational exponents.

Use structure first. Decide whether the task is asking for an equivalent expression, a domain or range, or a graph feature before simplifying or interpreting.

Worked Examples

Example 1: √72 = √(36 · 2) = 6√2.

Example 2: 272/3 = (√327)2 = 32 = 9.

Example 3: √(x6) = x3 when x is nonnegative in this lesson context.

Correct Reasoning Check

Correct: √75 = 5√3 because 75 = 25 · 3 and 25 is a perfect square.

Common Mistake

Incorrect: √75 = 25√3 is incorrect because the square root of 25 is 5, not 25.
