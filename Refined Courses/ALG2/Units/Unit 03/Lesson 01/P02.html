Key Vocabulary

  • Radical expression: an expression containing a root, such as √50.
  • Index: the root being taken, such as 3 in a cube root.
  • Rational exponent: an exponent written as a fraction, such as x1/2.
  • Perfect power: a number or expression that can be rooted exactly.

Correct Example

Correct: √75 = 5√3 because 75 = 25 · 3 and 25 is a perfect square.

Incorrect Example

Incorrect: √75 = 25√3 is incorrect because the square root of 25 is 5, not 25.
