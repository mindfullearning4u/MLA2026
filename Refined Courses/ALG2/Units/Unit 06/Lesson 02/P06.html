P06 Independent Work + Checkpoint + Notebook Evidence

Independent Work

  1. Classify 8, 12, 16, 20, ... and find the 12th term.
  2. Classify 3, 9, 27, 81, ... and find the 7th term.
  3. Write an explicit rule for an arithmetic sequence with a1=11 and d=-2.
  4. Write a recursive rule for a geometric sequence with a1=5 and r=4.

Checkpoint Submission

Submit one arithmetic sequence and one geometric sequence. For each, identify the pattern and write a rule.

Notebook Evidence Submission

Submit your comparison chart, two worked examples, and one corrected mistake about choosing arithmetic versus geometric rules.
