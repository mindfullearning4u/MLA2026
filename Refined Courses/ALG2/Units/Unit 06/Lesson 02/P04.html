P04 Worked Examples

Study each example carefully. Each step shows the reasoning students should be able to reproduce independently.

Worked Example 1: Arithmetic Sequence

Problem: Find the next term: 4, 9, 14, 19.

Step 1: Find the common difference.

Step 2: Add 5 to the last term.

Step 3: State the next term.

24

Reasoning: Arithmetic sequences add the same amount each step.

Worked Example 2: Geometric Sequence

Problem: Find the next term: 3, 6, 12, 24.

Step 1: Find the common ratio.

Step 2: Multiply by 2.

Step 3: State the next term.

48

Reasoning: Geometric sequences multiply by the same factor.

Worked Example 3: Recursive Thinking

Problem: A pattern starts at 10 and adds 3 each step.

Step 1: Identify the starting value.

Step 2: Identify the repeated change.

Step 3: Describe how to get the next term.

Add 3 each time.

Reasoning: Recursive rules explain how a sequence continues.

Common Mistake

Problem: Classify 2, 4, 8, 16.

Incorrect:

Arithmetic because it increases.

Why it is wrong: The differences are not constant; the ratios are constant.

Correct:

Geometric with ratio 2.

Fix: Check differences and ratios before classifying.
