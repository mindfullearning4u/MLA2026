P01 Lesson Overview

Lesson Title

Lesson 5: Comparing Models

Compare function models and determine which model best fits a context or data set.

Standards Covered in This Lesson

MLA.A2.FN.2

Florida B.E.S.T. Benchmark: MA.912.F.1.7

Compare function models and determine which model best fits a context or data set.

What You Will Learn

  • Compare linear, quadratic, exponential, logarithmic, rational, and regression models.
  • Use tables, graphs, equations, residuals, and context to judge fit.
  • Decide which model best answers a question.
  • Explain why a model is reasonable or limited.

What You Will Do

  • Review model behaviors and compare representations.
  • Work through examples involving competing models.
  • Complete guided practice, independent work, checkpoint, notebook evidence, and a lesson quiz.

How You Will Show Mastery

  • Choose a model based on evidence.
  • Support model choices with mathematical reasoning.
  • Interpret model strengths and limitations in context.

Student-Friendly Standard Connection

MLA.A2.FN.2: Compare function models and decide which best fits a context or data set.

In student language: I can compare models and justify which one best represents a situation.
