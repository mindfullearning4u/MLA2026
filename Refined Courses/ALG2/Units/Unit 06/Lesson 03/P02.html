P02 Notebook Task Part 1

Set Up Your Notes

Title your notes: Lesson 3: Data Modeling.

Write the standard: MLA.A2.FM.1.

Write the learning target: I can choose a model that fits data and explain what its predictions mean.

Vocabulary

  • Scatterplot: a graph of paired numerical data.
  • Model: an equation used to represent a data relationship.
  • Residual: actual value minus predicted value.
  • Interpolation: predicting inside the data range.
  • Extrapolation: predicting outside the data range.

Notebook Prompt

Sketch four small scatterplots: one linear, one quadratic, one exponential, and one with no clear pattern. Under each sketch, write the clue that helped you identify the model type.
