P01 Lesson Overview

Lesson Title

Lesson 3: Data Modeling

Interpret data relationships and use technology to create appropriate models.

Standards Covered in This Lesson

MLA.A2.FM.1

Florida B.E.S.T. Benchmark: MA.912.DP.2.8

Interpret data relationships and use technology to create appropriate models.

What You Will Learn

  • Read tables and scatterplots to describe data relationships.
  • Identify whether a linear, quadratic, exponential, or other model may fit data.
  • Use technology outputs such as equations and residuals to judge model fit.
  • Interpret model predictions in context.

What You Will Do

  • Analyze data displays and choose reasonable model types.
  • Study worked examples that connect scatterplot shape to model choice.
  • Complete guided practice, independent work, checkpoint, notebook evidence, and a lesson quiz.

How You Will Show Mastery

  • Select model types that match data behavior.
  • Use model equations to make predictions.
  • Explain limits and reasonableness of predictions.

Student-Friendly Standard Connection

MLA.A2.FM.1: Interpret data relationships and use technology to create appropriate models.

In student language: I can choose a model that fits data and explain what its predictions mean.
