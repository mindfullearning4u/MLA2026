P01 Lesson Overview

Lesson Title

Lesson 4: Regression Models

Use regression to model exponential and other function relationships in data.

Standards Covered in This Lesson

MLA.A2.EX.4

Florida B.E.S.T. Benchmark: MA.912.DP.2.9

Use regression to model exponential and other function relationships in data.

What You Will Learn

  • Use regression equations to model data.
  • Interpret linear and exponential regression parameters.
  • Use correlation, residuals, and context to compare model fit.
  • Make and evaluate predictions from regression models.

What You Will Do

  • Read regression output from technology.
  • Connect coefficients and growth factors to context.
  • Complete guided practice, independent work, checkpoint, notebook evidence, and a lesson quiz.

How You Will Show Mastery

  • Choose a regression model that fits the data and context.
  • Interpret model parameters accurately.
  • Use residuals and reasonableness to evaluate predictions.

Student-Friendly Standard Connection

MLA.A2.EX.4: Use regression to model exponential and other function relationships in data.

In student language: I can use regression equations to model data and judge whether the model is reasonable.
