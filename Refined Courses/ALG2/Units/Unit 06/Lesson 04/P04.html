P04 Concept Development / Worked Examples

Worked Example 1: Linear Regression

A regression model for cost is C=18x+45.

The slope 18 means the cost increases by $18 for each additional unit. The intercept 45 means the starting cost is $45.

For x=6, C=18(6)+45=153.

Correct: The predicted cost is $153.

Worked Example 2: Exponential Regression

A regression model is y=80(0.92)x.

The initial value is 80. The factor 0.92 means the value keeps 92% each period, so it decreases by 8% each period.

Correct: This is an exponential decay model.

Incorrect Example

Incorrect: A residual near 0 means the model is wrong.

Correct: A residual near 0 means the prediction is close to the actual data value.
