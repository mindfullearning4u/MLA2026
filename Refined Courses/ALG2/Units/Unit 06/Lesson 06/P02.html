Set Up Your Notes

Title your notes: Lesson 6: Multi-Step Modeling.

Write the standard: Support-only synthesis; no new primary MLA standard.

Write the learning target: I can solve a real problem by building, checking, and improving a model.

Vocabulary

  • Assumption: a condition accepted to make a model possible.
  • Constraint: a required limit on variables or answers.
  • Revision: a change made to improve a model.
  • Validation: checking whether a model works for the context.

Notebook Prompt

Write the modeling cycle: understand, define variables, build a model, solve, interpret, check constraints, and revise.
