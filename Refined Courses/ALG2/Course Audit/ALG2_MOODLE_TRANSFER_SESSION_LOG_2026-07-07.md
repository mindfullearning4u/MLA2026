### Moodle Navigation Notes Captured During Lesson Transfer

- TinyMCE sometimes reports the source editor container as zero-height through the DOM even when the visible source-code box is usable. Use the visible source-code box, paste the full repo HTML, save the source dialog, then verify the editor iframe text before clicking Moodle `Save page`.
- If Moodle opens a lesson entry URL after several page views and shows `You have left during a timed lesson`, audit by explicit `pageid` instead of the activity entry URL.
- Unit 1 Lesson 7 briefly loaded an edit page before the TinyMCE toolbar finished rendering. Waiting/reopening the explicit page view and re-running the normal source paste/save recovered the page without saving incomplete content.
- Unit 1 Lesson 8 `P01` uses the heading `P01 Putting It All Together Overview`; marker audits should check the course/unit/lesson marker and page number, not assume every `P01` heading is exactly `P01 Lesson Overview`.
- Keep lesson-transfer browser batches small. A six-page lesson may take 2-3 minutes in MoodleCloud; if a browser-control timeout occurs mid-lesson, audit the explicit page IDs for that lesson before continuing to avoid duplicate or skipped saves.
