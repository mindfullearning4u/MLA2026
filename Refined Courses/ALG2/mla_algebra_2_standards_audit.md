# MLA Algebra II Standards Crosswalk Audit

**Audited File:** `mla_algebra_2_standards_crosswalk.xlsx`  
**Audit Date:** June 11, 2026  
**Audit Scope:** Independent review of Florida B.E.S.T. coverage, MLA standards architecture, Common Core alignment, SAT readiness alignment, ACT readiness alignment, and workbook suitability for curriculum audit/accreditation review.

---

## Executive Summary

The MLA Algebra II Standards Crosswalk workbook includes all 50 Florida Algebra II benchmarks identified from the official CPALMS Algebra 2 course record (#1200330, CPALMS internal course id 23353). No required Florida benchmark was missing, duplicated, or orphaned in the crosswalk.

The workbook is structurally complete and includes the required tabs:

• README  
• MLA Standards Crosswalk  
• Embedded Standards  
• Coverage Audit  
• MLA Inventory  
• Sources  
• Corrections Log  

The workbook passes the core Florida coverage requirement. However, the audit identified several revisions needed before the workbook should be treated as final for accreditation review:

• ACT alignment uses broad current-style readiness labels rather than the requested ACT reporting categories.  
• Several Common Core alignments are reasonable but should be strengthened or marked as support alignments.  
• Complex-number Common Core alignments are underrepresented.  
• Some benchmark placements within MLA domains should be reconsidered, especially radical and rational expression standards currently placed in Advanced Expressions.  
• SAT Geometry and Trigonometry is not represented, which is acceptable only if explicitly noted as not applicable to the Florida Algebra II benchmark set.

**Final Determination: PASS WITH REVISIONS**

• The workbook includes all 50 Florida Algebra II benchmarks from CPALMS.

## Findings

### Finding 1: Florida Benchmark Coverage Is Complete

The official CPALMS Algebra 2 course benchmark set contains 50 unique Florida benchmark codes. The workbook contains 50 rows in the MLA Standards Crosswalk tab and 50 unique Florida benchmark codes.

No missing benchmarks were identified.

No duplicate benchmark ownership was identified.

No orphaned Florida benchmarks were identified.

No orphaned MLA standards were identified.

### Finding 2: ACT Alignment Does Not Use the Requested ACT Reporting Categories

The audit prompt requires representation of:

• Pre-Algebra  
• Elementary Algebra  
• Intermediate Algebra  
• Coordinate Geometry  
• Plane Geometry  
• Trigonometry  
• Statistics and Probability  
• Functions  

The workbook instead uses labels such as:

• Preparing for Higher Math - Algebra  
• Preparing for Higher Math - Functions  
• Preparing for Higher Math - Modeling  
• Integrating Essential Skills / Modeling  
• Preparing for Higher Math - Statistics and Probability / Modeling  

These are useful readiness labels, but they do not directly match the requested ACT category structure. This makes the ACT audit trail weaker than it should be.

### Finding 3: Common Core Complex Number Alignments Are Underrepresented

Several Florida Algebra II benchmarks explicitly include real and complex number systems or complex roots:

• MA.912.AR.1.8  
• MA.912.AR.3.2  
• MA.912.AR.6.1  

Current Common Core alignments emphasize factoring, quadratic solving, and polynomial zeros, but they do not clearly reference the High School Number and Quantity complex number standards.

Recommended additions include:

• HSN-CN.A.1  
• HSN-CN.A.2  
• HSN-CN.C.7  
• HSN-CN.C.9, where appropriate

### Finding 4: Some Common Core Alignments Are Supportive Rather Than Direct

Some Common Core cross-references are reasonable but should be marked as support alignments because Common Core does not always contain an exact one-to-one standard for the Florida benchmark.

Examples:

• MA.912.AR.3.3, one-variable quadratic inequalities, is aligned to HSA-REI.D.11 and HSA-CED.A.1-style modeling ideas, but Common Core does not provide a clean direct match for solving one-variable quadratic inequalities.

• MA.912.AR.4.2, absolute value inequalities, is aligned to HSA-REI.B.3 / HSA-CED.A.1-style work, but the match should be identified as a support alignment rather than a precise direct equivalent.

• MA.912.AR.3.10, two-variable quadratic inequalities, is reasonably supported by HSA-REI.D.12, but the workbook should clarify that the Florida benchmark is more specific than the Common Core reference.

### Finding 5: MLA Domain Placement Should Be Refined

The overall MLA domain structure is usable, but some placements should be reconsidered.

Current concern:

• MA.912.AR.1.9, rational algebraic expression operations, is placed in `MLA.A2.AE` Advanced Expressions.

• MA.912.NSO.1.3 and MA.912.NSO.1.5, radical and rational exponent expression work, are also placed in `MLA.A2.AE`.

Because the approved suggested domain architecture includes `MLA.A2.RR` for Radical and Rational Relationships, these standards may fit better in `MLA.A2.RR` or should be clearly labeled as expression-readiness standards supporting the RR domain.

### Finding 6: SAT Alignment Is Strong but Geometry/Trigonometry Is Absent

The workbook represents:

• Algebra  
• Advanced Math  
• Problem-Solving and Data Analysis  

The workbook does not represent:

• Geometry and Trigonometry

This is not necessarily an error because the Florida Algebra II benchmark set does not include substantial Geometry/Trigonometry standards. However, the workbook should explicitly state that Geometry and Trigonometry is not a primary Algebra II readiness domain in this course and is addressed in Geometry or Precalculus where appropriate.

### Finding 7: MLA Standards Are Clear but Mostly One-to-One

The workbook uses one MLA standard per Florida benchmark. This is clean for audit purposes and eliminates orphaned benchmarks, but it may not always reflect instructional complexity.

Some standards may need to be split later during instructional mapping, especially:

• Rational functions: equation solving, graphing, restrictions, and modeling may require separate instructional targets.

• Function transformations: identifying transformations, parameter values, and generating transformed representations may require careful sequencing.

• Systems and constraints: graphing systems, interpreting feasible solutions, and modeling constraints may require separate lesson-level competencies.

This does not require changing the crosswalk immediately, but it should be considered during unit mapping.

---

## Required Corrections

1. **Revise ACT alignment labels.**  
Add or replace ACT alignment language so the workbook explicitly references the requested ACT categories: Intermediate Algebra, Functions, Statistics and Probability, and relevant Algebra readiness categories. For categories not applicable to Algebra II, mark them as not primary rather than omitting them silently.

2. **Add complex-number Common Core references.**  
Add HSN-CN alignments where Florida benchmarks reference complex roots or complex solutions.

3. **Mark weak Common Core alignments as support alignments.**  
For benchmarks without a direct Common Core equivalent, update notes to clarify that the Common Core reference is a supporting alignment.

4. **Clarify SAT Geometry and Trigonometry status.**  
Add a note in Coverage Audit or Sources explaining that SAT Geometry and Trigonometry is not a primary Algebra II alignment area for this benchmark set.

5. **Review domain placement for radical and rational expression standards.**  
Consider moving rational expression and radical expression standards from `MLA.A2.AE` into `MLA.A2.RR`, or add notes explaining why they remain in Advanced Expressions.

---

## Recommended Improvements

• Add an alignment-strength field, such as `Direct`, `Supporting`, or `Related`, for Common Core, SAT, and ACT references.

• Add a note distinguishing CPALMS benchmark text from MLA student-facing standard statements.

• Add a separate ACT legacy category column if the Academy wants both current ACT readiness language and older reporting categories.

• Add a domain rationale section in the README explaining why each MLA domain exists.

• During unit mapping, avoid treating one-to-one benchmark rows as lesson-level pacing. Some standards will require more instructional time than others.

## Final Determination

**PASS WITH REVISIONS**

The workbook passes the Florida B.E.S.T. coverage audit: every official Algebra II benchmark is represented once, and no benchmark is omitted or orphaned.

The workbook should be revised before final accreditation use because external alignment details need strengthening, especially ACT category labeling, Common Core complex-number references, and notes for support-only Common Core alignments.
