Worked Example 1

Prompt: An investment table compares risk, expected return, liquidity, fees, and time horizon.

Step 1: Match time. This identifies the decision before solving.

Step 2: Longer goals can accept different risk. This ties the answer to the table, chart, or scenario evidence.

Step 3: Time horizon matters. This is the teachable conclusion for MLA.PFLE.INV.1.

Common Mistake

Correct: using the financial evidence to choose the best-supported decision.

Incorrect: choosing a familiar money word without checking the evidence.

Teachable Explanation

Each example uses the same mastery path: define the decision, read the evidence, compare cost and benefit, account for risk, and explain the final choice.
