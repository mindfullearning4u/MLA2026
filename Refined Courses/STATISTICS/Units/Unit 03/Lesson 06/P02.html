Notebook Title: Two-Way Frequency Tables and Categorical Association

A two-way frequency table organizes counts for two categorical variables at the same time.

Vocabulary

  • Categorical variable: a variable that places data into groups.
  • Bivariate categorical data: data with two categorical variables.
  • Two-way frequency table: a table that shows counts for two categorical variables.
  • Joint frequency: a count inside the table for one row category and one column category.
  • Marginal frequency: a row total or column total.

Reading the Table

Suppose a table compares grade level and preferred study method. A cell might show that 18 juniors prefer flashcards. That cell is a joint frequency because it belongs to one row category and one column category.

A row total tells how many students are in that row category. A column total tells how many students are in that column category.

Notebook Task

Write a definition for joint frequency and marginal frequency. Then create a small two-way table with two row categories and two column categories.
