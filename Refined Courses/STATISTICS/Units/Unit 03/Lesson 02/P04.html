📘 STATISTICS | Unit 03 | Lesson 02

P04 Worked Examples

Step-by-step explanation: Read each model in order. Notice how the example identifies the statistical situation, selects the correct method, completes the work, and explains the conclusion in context.

Each example shows how to interpret or use a linear model in context.

Worked Example 1

Model: y = 3x + 20, where x is hours studied and y is predicted quiz score.

  1. Slope: 3.
  2. Meaning: each additional hour studied is associated with about 3 more quiz points.
  3. y-intercept: 20.
  4. Meaning: when x = 0, the predicted quiz score is 20 points.

Worked Example 2

Model: y = 8x + 12, where x is weeks of training and y is predicted endurance score.

  1. Predict for 5 weeks: y = 8(5) + 12.
  2. y = 40 + 12.
  3. y = 52.
  4. The predicted endurance score after 5 weeks is 52.

Worked Example 3

Model: y = 2x + 45, where x is minutes of daily practice and y is predicted performance score. The data used practice times from 10 to 40 minutes.

  1. A prediction for 25 minutes is reasonable because 25 is inside the data range.
  2. A prediction for 120 minutes is risky because 120 is far outside the data range.
  3. Using the model far outside the data range is extrapolation.

Common Mistake

Incorrect: A linear model can always predict accurately for any x-value.
Correct: A linear model is most reliable near the data used to build it. Predictions far outside the data range may be unreasonable.

Teachable Explanation: A statistic is only useful when it answers the question being asked and is interpreted in the context of the data.
