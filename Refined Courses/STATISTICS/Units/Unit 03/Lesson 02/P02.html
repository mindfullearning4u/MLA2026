Notebook Title: Linear Models for Bivariate Numerical Data

A linear model is an equation of a line used to summarize and predict a relationship between two numerical variables.

Vocabulary

  • Linear model: a line used to approximate a relationship in bivariate numerical data.
  • Slope: the predicted change in y for each 1-unit increase in x.
  • y-intercept: the predicted y-value when x = 0.
  • Prediction: an estimated value from a model.
  • Extrapolation: making a prediction outside the range of the data.

Reading a Linear Model

Suppose a model for quiz score is y = 4x + 62, where x is hours studied and y is predicted quiz score.

  1. The slope is 4.
  2. This means each additional hour studied is connected with about 4 more quiz points.
  3. The y-intercept is 62.
  4. This means the predicted score is 62 when study time is 0 hours, if that value is reasonable in context.

Notebook Task

For the model y = 5x + 40, where x is weeks of practice and y is predicted performance score, write:

  1. The slope.
  2. The y-intercept.
  3. A sentence explaining the slope in context.
  4. A sentence explaining the y-intercept in context.
