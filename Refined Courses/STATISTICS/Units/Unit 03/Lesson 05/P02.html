Notebook Title: Exponential Models for Bivariate Numerical Data

An exponential pattern grows or decays by multiplying by the same factor over equal intervals.

Vocabulary

  • Exponential model: a model where values change by repeated multiplication.
  • Starting value: the value when x = 0.
  • Growth factor: the number multiplied each step when values increase.
  • Decay factor: the number multiplied each step when values decrease.
  • Exponential association: a curved pattern that grows or decays by factors.

Linear or Exponential?

A linear pattern adds the same amount each step. An exponential pattern multiplies by the same factor each step.

Example: 10, 20, 40, 80 is exponential because each value is multiplied by 2.

Notebook Task

For each sequence, decide whether it is linear or exponential and explain why: 5, 8, 11, 14 and 5, 10, 20, 40.
