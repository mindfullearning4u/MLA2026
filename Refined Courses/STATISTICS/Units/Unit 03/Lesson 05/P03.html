P03 Notebook Task Part 2

Now interpret the parts of an exponential model.

Reading the Model

For y = 100(1.25)x, the starting value is 100 and the growth factor is 1.25. This means the predicted value increases by 25% each step.

For y = 80(0.90)x, the starting value is 80 and the decay factor is 0.90. This means the predicted value keeps 90% each step, so it decreases by 10% each step.

Notebook Task

For y = 60(1.10)x, identify the starting value, growth factor, and percent increase each step.

Common Mistake

Incorrect: y = 60(1.10)x adds 10 every step.
Correct: The model multiplies by 1.10 each step, which means a 10% increase each step. Exponential change uses repeated multiplication, not repeated addition.

Teachable Explanation: When working with statistics, always connect the answer to the context, data type, and question being asked.
