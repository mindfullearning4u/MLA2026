Lesson Title

Lesson 5: Exponential Models for Bivariate Numerical Data

Learn when an exponential model is useful and how to interpret repeated percent growth or decay in context.

Standards Covered in This Lesson

  • MLA.STAT.BVM.6 - I can fit and use an exponential model when bivariate data show exponential association.

What You Will Learn

  • Recognize growth or decay patterns that are not linear.
  • Identify an exponential model from repeated multiplication.
  • Use a model such as y = 50(1.2)x for contextual predictions.
  • Explain limits of exponential predictions.

What You Will Do

  • Compare linear and exponential patterns.
  • Interpret starting value and growth factor.
  • Use exponential models to estimate future values.
  • Decide whether a prediction is reasonable in context.

How You Will Show Mastery

  • Complete notebook tasks interpreting exponential models.
  • Submit a checkpoint using an exponential model in context.
  • Demonstrate at least 80% mastery on the lesson quiz.

Student-Friendly Standard Connection

MLA.STAT.BVM.6: I can use an exponential model when data change by repeated multiplication instead of by adding the same amount each time.
