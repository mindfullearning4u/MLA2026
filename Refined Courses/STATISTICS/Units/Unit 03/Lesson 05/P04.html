P04 Worked Examples

Use each example to identify and use exponential models.

Worked Example 1

Data: 4, 8, 16, 32.

  1. Each value is multiplied by 2.
  2. The pattern is exponential growth.
  3. The growth factor is 2.

Worked Example 2

Model: y = 200(0.80)x.

  1. Starting value: 200.
  2. Decay factor: 0.80.
  3. The predicted value keeps 80% each step, so it decreases by 20% each step.

Worked Example 3

Model: y = 50(1.2)x. Predict when x = 3.

  1. y = 50(1.2)3
  2. 1.23 = 1.728
  3. y = 50(1.728) = 86.4
  4. The predicted value is about 86.4.

Common Mistake

Incorrect: A growth factor of 1.2 means add 1.2 each step.
Correct: A growth factor of 1.2 means multiply by 1.2 each step. That is a 20% increase each step.
