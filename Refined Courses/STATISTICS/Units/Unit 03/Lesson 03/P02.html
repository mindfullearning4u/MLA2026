Notebook Title: Residuals and Model Fit

A residual measures prediction error. It tells how far the actual value is from the model's predicted value.

Vocabulary

  • Predicted value: the value estimated by the model.
  • Actual value: the observed value in the data.
  • Residual: actual value - predicted value.
  • Positive residual: actual value is above the prediction.
  • Negative residual: actual value is below the prediction.
  • Model fit: how well a model matches the data.

How to Calculate a Residual

Use the formula residual = actual value - predicted value.

  1. Find the actual value from the data.
  2. Find the predicted value from the model.
  3. Subtract: actual - predicted.
  4. Interpret the sign and size of the residual.

Notebook Task

Copy this example and complete the interpretation: If the actual score is 84 and the predicted score is 80, then residual = 84 - 80 = 4. The model underpredicted by 4 points because the actual value was above the predicted value.
