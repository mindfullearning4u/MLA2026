Lesson Title

Lesson 3: Residuals and Model Fit

Learn how residuals show the difference between actual data values and predicted values from a linear model.

Standards Covered in This Lesson

  • MLA.STAT.BVM.3 - I can use residuals to judge how well a linear model fits bivariate data.

What You Will Learn

  • Calculate a residual using actual value - predicted value.
  • Interpret positive, negative, and zero residuals.
  • Use residual size to judge prediction error.
  • Use residual patterns to decide whether a linear model is appropriate.

What You Will Do

  • Compare actual and predicted values.
  • Calculate residuals step by step.
  • Decide whether residuals are small or large in context.
  • Explain whether residuals show a good model fit.

How You Will Show Mastery

  • Complete notebook tasks about residuals.
  • Submit a checkpoint interpreting model fit from residuals.
  • Demonstrate at least 80% mastery on the lesson quiz.

Student-Friendly Standard Connection

MLA.STAT.BVM.3: I can check how far predictions are from real data values and use those differences to decide if a line fits well.
