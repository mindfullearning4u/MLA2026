P03 Notebook Task Part 2

Residuals help you decide whether the model misses by a little or a lot.

Interpreting Residuals

If residuals are close to 0, the model predictions are close to the actual values. If residuals are large, the model predictions are farther away from the actual values.

A residual plot with points randomly scattered around 0 supports a linear model. A curved pattern in the residuals suggests a line may not be the best model.

Notebook Task

For each pair, calculate and interpret the residual.

  1. Actual = 72, predicted = 75
  2. Actual = 91, predicted = 88
  3. Actual = 60, predicted = 60

Common Mistake

Incorrect: residual = predicted value - actual value.
Correct: residual = actual value - predicted value. The sign matters because it tells whether the actual point is above or below the prediction.

Teachable Explanation: When working with statistics, always connect the answer to the context, data type, and question being asked.
