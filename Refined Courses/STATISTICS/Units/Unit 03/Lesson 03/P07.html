This checkpoint shows whether you can calculate and interpret residuals to judge model fit.

TOR Information

Submission Workflow

Submit your checkpoint response in the assigned Moodle location.

Checkpoint Task

A model predicts a value of 68, but the actual value is 75. Calculate the residual and explain what it means. Then explain what it means if most residuals in a residual plot are randomly scattered around 0.

Mastery Criteria

  • Uses residual = actual - predicted.
  • Calculates 75 - 68 = 7 correctly.
  • Explains that the model underpredicted by 7.
  • Explains that random scatter around 0 supports a linear model.
