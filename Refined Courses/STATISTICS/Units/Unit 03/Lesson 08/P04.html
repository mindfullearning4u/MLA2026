P04 Worked Examples

These examples review the major Unit 3 tools.

Worked Example 1

For y = 4x + 30, the slope is 4. Each 1-unit increase in x is associated with a predicted increase of 4 in y.

Worked Example 2

If actual = 86 and predicted = 80, residual = 86 - 80 = 6. The model underpredicted by 6.

Worked Example 3

If 18 of 45 Group A students choose tutoring, the conditional relative frequency is 18/45 = 40%.

Common Mistake

Incorrect: Use the same method for every Unit 3 problem.
Correct: Choose the method based on the data type and question. Numerical relationships use models and correlation; categorical relationships use two-way tables and relative frequencies.
