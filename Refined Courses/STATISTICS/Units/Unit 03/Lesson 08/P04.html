P04 Worked Examples

Step-by-step explanation: Read each model in order. Notice how the example identifies the statistical situation, selects the correct method, completes the work, and explains the conclusion in context.

These examples review the major Unit 3 tools.

Worked Example 1

For y = 4x + 30, the slope is 4. Each 1-unit increase in x is associated with a predicted increase of 4 in y.

Worked Example 2

If actual = 86 and predicted = 80, residual = 86 - 80 = 6. The model underpredicted by 6.

Worked Example 3

If 18 of 45 Group A students choose tutoring, the conditional relative frequency is 18/45 = 40%.

Common Mistake

Incorrect: Use the same method for every Unit 3 problem.
Correct: Choose the method based on the data type and question. Numerical relationships use models and correlation; categorical relationships use two-way tables and relative frequencies.

Teachable Explanation: A statistic is only useful when it answers the question being asked and is interpreted in the context of the data.

Worked Example Verification

Use each worked example as a model for your own reasoning. First, locate the given information and mark what is being asked. Second, follow the setup exactly: table entries stay in their row and column, graph features are read from the correct axis, and statistics are calculated from the correct values. Third, interpret the result using the context of Putting It All Together. A correct numerical answer is incomplete if it does not explain what the number means. Before you continue, compare your notebook work to the example and check that every step has a reason, not just a final answer.
