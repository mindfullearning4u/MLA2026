Notebook Title: Empirical Expected Value

Once empirical probabilities are in a distribution, expected value is calculated the same way as before: multiply each value by its probability and add.

Use the Empirical Distribution

For the prize wheel example, the empirical distribution is:

Value$0$2$5
Probability0.500.300.20

Calculate the Expected Value

Expected value = 0(0.50) + 2(0.30) + 5(0.20)

Expected value = 0 + 0.60 + 1.00 = 1.60

The empirical expected value is $1.60. Based on the observed spins, the average payout is about $1.60 per spin.

Common Mistake

Incorrect: "The expected value is the outcome that happened most often."

Correct: "The expected value is the weighted average of all outcomes using their observed probabilities."

The most common outcome is called the most frequent or most likely observed value. Expected value uses every value, not only the most common one.
