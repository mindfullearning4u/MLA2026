📘 STATISTICS | Unit 06 | Lesson 03

P04 Worked Example

Step-by-step explanation: Read each model in order. Notice how the example identifies the statistical situation, selects the correct method, completes the work, and explains the conclusion in context.

Study each example step by step. The goal is to use observed data to build an empirical distribution and expected value.

Example 1: Convert Counts

A survey records how many streaming services students use. Out of 40 students, 10 use 0 services, 18 use 1 service, and 12 use 2 services.

  1. Total observations: 40.
  2. P(X = 0) = 10/40 = 0.25.
  3. P(X = 1) = 18/40 = 0.45.
  4. P(X = 2) = 12/40 = 0.30.

Example 2: Expected Value From Data

Using the streaming services distribution:

  1. Set up: 0(0.25) + 1(0.45) + 2(0.30).
  2. Multiply: 0 + 0.45 + 0.60.
  3. Add: 1.05.
  4. The empirical expected value is 1.05 streaming services per student.

Example 3: Interpret the Result

An expected value of 1.05 does not mean a student can use exactly 1.05 services. It means that if this observed pattern represents the group, the average number of services per student is about 1.05.

The expected value summarizes the center of the empirical distribution.

Common Mistake

Incorrect: "Use theoretical probabilities even though observed counts are given."

Correct: "Use count / total trials to build empirical probabilities from the observed data."

When the problem gives observed counts, those counts are the evidence. Use them to estimate probability.

Teachable Explanation: A statistic is only useful when it answers the question being asked and is interpreted in the context of the data.
