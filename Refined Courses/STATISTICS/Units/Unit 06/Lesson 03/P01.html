Lesson Title

Lesson 3: Empirical Probability Distributions and Expected Value

Learn how observed data from repeated trials can create an empirical probability distribution and how expected value describes the average result from that data.

Standards Covered in This Lesson

  • MLA.STAT.PSU.13 - I can build an empirical probability distribution and interpret expected value as the mean.

What You Will Learn

  • Distinguish empirical probability from theoretical probability.
  • Build a probability distribution from observed frequencies.
  • Convert counts to relative frequencies.
  • Calculate expected value from empirical probabilities.
  • Interpret expected value as an average based on observed data.

What You Will Do

  • Read observed trial results.
  • Calculate empirical probabilities using count / total trials.
  • Organize empirical distributions in tables.
  • Use value Ã— probability to find expected value.

How You Will Show Mastery

  • Complete notebook work that turns observed counts into probabilities.
  • Answer guided practice questions about empirical distributions.
  • Submit a checkpoint explaining empirical expected value in context.
  • Demonstrate at least 80% mastery on the lesson quiz.

Student-Friendly Standard Connection

MLA.STAT.PSU.13: I can use real trial results to estimate probabilities, organize them in a distribution, and find the average result the data suggest over time.
