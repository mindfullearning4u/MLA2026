P04 Worked Example

Study each example step by step. The goal is to recognize binomial contexts and calculate expected successes.

Example 1: Identify Binomial Features

A quality checker inspects 50 items. Each item is classified as defective or not defective. The probability an item is defective is 0.04.

  1. Fixed trials: n = 50 items.
  2. Success: item is defective.
  3. Failure: item is not defective.
  4. Probability of success: p = 0.04.

Example 2: Expected Defective Items

Use expected successes = n × p.

  1. n = 50.
  2. p = 0.04.
  3. Expected successes = 50 × 0.04 = 2.
  4. The checker expects about 2 defective items per 50 inspected items over many inspections.

Example 3: Interpret a Non-Whole Expected Value

A website expects 12% of 30 visitors to click a link.

  1. n = 30 and p = 0.12.
  2. Expected clicks = 30 × 0.12 = 3.6.
  3. The result does not mean exactly 3.6 people click. It means the average number of clicks should be about 3.6 per 30 visitors over many similar groups.

Common Mistake

Incorrect: "Use p by itself as the expected number of successes."

Correct: "Use n × p because expected successes depends on both the number of trials and the probability of success."

A probability is a chance for one trial. Expected successes is a count across all trials.
