Notebook Title: Random Variables

This page builds the foundation. A random variable is not just any variable. It is a number assigned to the result of a chance process.

Vocabulary

  • Random experiment: an action or process with an outcome that is not known before it happens.
  • Outcome: one possible result of a random experiment.
  • Random variable: a variable that assigns a numerical value to each outcome.
  • Value of a random variable: one number the random variable can equal.
  • Probability distribution: a table or graph that shows each possible value of a random variable and its probability.

Step 1: Start With a Chance Situation

A chance situation has outcomes that can vary. For example, suppose a student shoots two free throws. Each shot can be made or missed, so the final result is not known ahead of time.

The possible outcomes are: miss both, make one, or make both. Statistics often turns those outcomes into numbers so the situation can be analyzed.

Step 2: Name the Random Variable

A random variable should clearly state what number is being measured. In the free-throw example, define X = the number of free throws made.

The letter is not the important part. The definition is the important part. If you only write X without explaining what X means, the reader does not know what is being counted or measured.

Step 3: List the Possible Values

If X is the number of free throws made out of two shots, then X can equal 0, 1, or 2.

These are values of the random variable, not separate variables. The random variable is the rule, and the values are the numbers the rule can produce.
