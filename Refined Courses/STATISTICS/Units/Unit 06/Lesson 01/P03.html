Notebook Title: Probability Distributions

Now that you can define a random variable, you will connect each value to a probability.

What a Probability Distribution Shows

A probability distribution shows the possible values of a random variable and the probability of each value. For a complete distribution, every possible value must be included.

For example, if X = the number of heads when two coins are tossed, then X can be 0, 1, or 2. A distribution might show P(X = 0), P(X = 1), and P(X = 2).

Two Rules for a Valid Distribution

  1. Each probability must be from 0 to 1, including 0 and 1.
  2. All probabilities in the complete distribution must add to 1.

These rules make sense because probability measures the chance of an outcome. A probability cannot be negative, cannot be greater than 1, and the full set of all possible outcomes must represent 100% of what can happen.

Reading a Distribution Table

X012
P(X)0.250.500.25

This table says the probability of 0 heads is 0.25, the probability of 1 head is 0.50, and the probability of 2 heads is 0.25. The probabilities add to 1, so the table is valid.

Common Mistake

Incorrect: "The distribution is valid because every value of X is listed."

Correct: "The distribution is valid only if every probability is between 0 and 1 and the probabilities add to 1."

Listing the values is necessary, but it is not enough. You must check the probabilities too.
