P04 Worked Example

Step-by-step explanation: Read each model in order. Notice how the example identifies the statistical situation, selects the correct method, completes the work, and explains the conclusion in context.

Study each example step by step. The goal is to define the random variable, list its values, and interpret the distribution.

Example 1: Define the Random Variable

A family has three pets. Each pet is either a cat or a dog. Let X be the number of dogs.

  1. The chance situation is the type of each pet.
  2. The random variable is X = number of dogs.
  3. The possible values are 0, 1, 2, and 3.
  4. X = 0 means no pets are dogs. X = 3 means all three pets are dogs.

Example 2: Check a Distribution

A distribution lists probabilities 0.20, 0.30, and 0.50.

  1. Check each probability: all are between 0 and 1.
  2. Add them: 0.20 + 0.30 + 0.50 = 1.00.
  3. The distribution is valid because both rules are satisfied.

Example 3: Interpret a Graph

A graph shows P(X = 0) = 0.10, P(X = 1) = 0.60, and P(X = 2) = 0.30 for the number of rainy days in a two-day forecast.

  1. The tallest bar is at X = 1.
  2. That means one rainy day is the most likely value.
  3. The probabilities add to 0.10 + 0.60 + 0.30 = 1.00, so the graph represents a complete distribution.

Common Mistake

Incorrect: "X is the experiment."

Correct: "X is the numerical value assigned to the result of the experiment."

The experiment is what happens, such as tossing coins or selecting a card. The random variable is the number you record from that experiment.

Teachable Explanation: A statistic is only useful when it answers the question being asked and is interpreted in the context of the data.
