Lesson Title

Lesson 2: Theoretical Probability Distributions and Expected Value

Learn how theoretical probabilities create a probability distribution and how expected value describes the long-run average outcome.

Standards Covered in This Lesson

  • MLA.STAT.PSU.12 - I can build a theoretical probability distribution and interpret expected value as the mean.

What You Will Learn

  • Build a theoretical probability distribution from equally likely outcomes.
  • Multiply each value by its probability.
  • Add the products to find expected value.
  • Interpret expected value as a long-run average, not a guaranteed single outcome.

What You Will Do

  • Create theoretical probability tables.
  • Calculate expected value using value Ã— probability.
  • Explain what the expected value means in context.
  • Identify mistakes that treat expected value as a prediction for one trial.

How You Will Show Mastery

  • Complete notebook tasks that build theoretical probability distributions.
  • Calculate expected value accurately.
  • Submit a checkpoint explaining expected value in context.
  • Demonstrate at least 80% mastery on the lesson quiz.

Student-Friendly Standard Connection

MLA.STAT.PSU.12: I can use theoretical probabilities to build a distribution, calculate its expected value, and explain what that value means over many repeated trials.
