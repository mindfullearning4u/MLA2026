P04 Worked Example

Study each example step by step. The goal is to calculate expected value and explain what it means.

Example 1: Fair Coin Game

A game pays $2 for heads and $0 for tails. Each outcome has probability 0.50.

  1. Multiply each value by its probability: 2(0.50) and 0(0.50).
  2. Add the products: 1.00 + 0 = 1.00.
  3. The expected value is $1. Over many plays, the average payout is $1 per play.

Example 2: Unequal Probabilities

A prize wheel pays $0 with probability 0.60, $5 with probability 0.30, and $10 with probability 0.10.

  1. Set up: 0(0.60) + 5(0.30) + 10(0.10).
  2. Multiply: 0 + 1.50 + 1.00.
  3. Add: 2.50.
  4. The expected value is $2.50 per spin over many spins.

Example 3: Number Cube

For a fair number cube, X can be 1, 2, 3, 4, 5, or 6, and each probability is 1/6.

  1. Expected value = 1(1/6) + 2(1/6) + 3(1/6) + 4(1/6) + 5(1/6) + 6(1/6).
  2. Add the values first: 1 + 2 + 3 + 4 + 5 + 6 = 21.
  3. Divide by 6: 21/6 = 3.5.
  4. The expected value is 3.5, meaning the long-run average roll is 3.5.

Common Mistake

Incorrect: "Add the outcomes and divide by the number of outcomes every time."

Correct: "Multiply each value by its probability, then add the products."

Dividing by the number of outcomes only works when the outcomes are equally likely. Expected value must account for probability.
