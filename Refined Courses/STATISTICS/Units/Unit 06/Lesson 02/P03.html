Notebook Title: Expected Value

Expected value is the mean of a probability distribution. It tells the long-run average if the chance process repeats many times.

How to Calculate Expected Value

To find expected value, multiply each value by its probability, then add the products.

Expected value = value Ã— probability + value Ã— probability + ...

This is a weighted average because values with larger probabilities have more influence on the average.

Example Calculation

A fair spinner has values 1, 2, 3, and 4, each with probability 0.25.

Expected value = 1(0.25) + 2(0.25) + 3(0.25) + 4(0.25)

Expected value = 0.25 + 0.50 + 0.75 + 1.00 = 2.50

The expected value is 2.5. The spinner can never land on 2.5, but over many spins, the average result should be close to 2.5.

Common Mistake

Incorrect: "The expected value is 2.5, so the next spin will be 2.5."

Correct: "The expected value is 2.5, so the average of many spins should be close to 2.5."

Expected value is not a promise about one trial. It describes long-run behavior.
