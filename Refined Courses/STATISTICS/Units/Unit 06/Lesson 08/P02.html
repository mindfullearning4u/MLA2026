Notebook Title: Probability Model Review

Begin by organizing the major probability models from this unit. The goal is to know which tool fits which situation.

Vocabulary

  • Random variable: a numerical value assigned to each outcome.
  • Probability distribution: a table or graph showing values and probabilities.
  • Expected value: the long-run average outcome.
  • Binomial distribution: a model for a fixed number of success/failure trials.
  • Geometric distribution: a model for the number of trials until the first success.
  • Fair decision: a decision method with probabilities that match the intended chances.

Step 1: Identify the Situation

Ask what the problem is tracking. If it tracks a numerical outcome, define a random variable. If it tracks repeated success/failure trials, decide whether the number of trials is fixed or whether the process stops at the first success.

Step 2: Choose the Tool

Use a probability distribution when all outcomes and probabilities are listed. Use expected value when you need a long-run average. Use payoff and risk reasoning when a decision has gains, losses, and uncertainty.
