Lesson Title

Lesson 8: Putting It All Together

Review random variables, probability distributions, expected value, binomial and geometric settings, payoff decisions, risk, and fair probability-based decisions.

Standards Covered in This Lesson

  • MLA.STAT.PSU.11: Define random variables and graph probability distributions.
  • MLA.STAT.PSU.12: Develop theoretical probability distributions and expected value.
  • MLA.STAT.PSU.13: Develop empirical probability distributions and expected value.
  • MLA.STAT.PSU.14: Calculate and interpret expected value for binomial distributions.
  • MLA.STAT.PSU.15: Solve real-world problems involving geometric distributions.
  • MLA.STAT.DMC.2: Compare payoff strategies using expected value and risk.
  • MLA.STAT.DMC.3: Apply probabilities to make fair decisions.

What You Will Learn

  • Choose the correct probability model for a situation.
  • Calculate expected value and interpret it as a long-run average.
  • Compare decision strategies using payoffs, risk, and fairness.
  • Explain statistical conclusions clearly in context.

What You Will Do

  • Review the major ideas from Lessons 1-7.
  • Complete guided practice that previews Unit Assessment expectations.
  • Submit notebook evidence and a checkpoint reflection.
  • Complete the Unit Assessment.

How You Will Show Mastery

  • Use probability vocabulary correctly.
  • Show calculations clearly.
  • Interpret answers in the context of the problem.
  • Demonstrate mastery on the Unit Assessment.

Student-Friendly Standard Connection

This lesson asks you to use the whole unit together: model uncertainty, calculate long-run averages, compare strategies, and explain fair decisions using probability.
