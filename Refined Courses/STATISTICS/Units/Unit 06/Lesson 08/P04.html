P04 Worked Example

Step-by-step explanation: Read each model in order. Notice how the example identifies the statistical situation, selects the correct method, completes the work, and explains the conclusion in context.

Study each example step by step. These examples review the types of reasoning needed for the Unit Assessment.

Worked Example 1: Expected Value from a Distribution

A game pays 0 points with probability 0.50, 2 points with probability 0.30, and 5 points with probability 0.20.

Step 1: Multiply each value by its probability.

Step 2: 0(0.50) + 2(0.30) + 5(0.20) = 0 + 0.60 + 1 = 1.60.

Conclusion: The expected value is 1.6 points per play in the long run.

Worked Example 2: Choose Binomial or Geometric

A student takes 6 free throws and counts how many are made. The number of trials is fixed, and each shot is success/failure.

Conclusion: This is binomial. If the question were how many shots until the first make, it would be geometric.

Worked Example 3: Fair Decision

A random number from 1 to 40 chooses one of four groups. Each group receives 10 numbers.

Step 1: Each group has probability 10/40 = 1/4.

Conclusion: The method is fair because each group has the same probability.

Common Mistake

Incorrect: "Use the same formula for every probability question."

Correct: "First identify the situation, then choose the model or reasoning tool that matches it."

The Unit Assessment will expect you to choose methods, not just calculate.

Teachable Explanation: A statistic is only useful when it answers the question being asked and is interpreted in the context of the data.
