Instructions

Show the probability for each outcome and explain whether the method is fair.

Part A

Six students each place one identical slip into a box. One slip is drawn. State each student's probability and decide whether the method is fair.

Part B

A random number from 1 to 50 chooses one of five groups. Create a fair number assignment for the five groups.

Part C

A teacher chooses the student sitting closest to the door to go first. Explain why this is not a fair random method for equal selection.
