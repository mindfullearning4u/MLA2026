Notebook Title: Random Number Assignments

Random number generators can make fair decisions when each outcome receives the same number of possible numbers.

Equal Ranges

If five teams need equal chances, a random number generator from 1 to 100 can assign 20 numbers to each team: 1-20, 21-40, 41-60, 61-80, and 81-100. Each team has 20/100 = 20%.

Unequal Ranges

If Team A receives numbers 1-50 and each other team receives only 10 numbers, the method is not fair for equal selection. Team A has a larger probability because it has more assigned numbers.

Common Mistake

Incorrect: "The method is fair because every team has at least one number."

Correct: "The method is fair only if teams that should be equal receive the same number of possible outcomes."

Having a chance is not the same as having an equal chance.

Notebook Task Part 2

Create a fair random number assignment for six students using numbers 1-60. Show the number range for each student and explain why the method is fair.

Teachable Explanation: When working with statistics, always connect the answer to the context, data type, and question being asked.
