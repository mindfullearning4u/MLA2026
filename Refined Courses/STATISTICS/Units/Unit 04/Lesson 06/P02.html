Notebook Title: Multiplication Rule for Probability

Build the foundation first. Read each explanation slowly and write the key ideas in your notebook.

Vocabulary

  • Multiplication rule: a rule for finding the probability of event A and event B.
  • A and B: both events occur.
  • Independent events: the first event does not change the probability of the second.
  • Conditional probability: the probability of the second event after the first is known.

What "And" Means

When a probability question asks for A and B, both events must happen. The multiplication rule connects the probability of the first event with the probability of the second event after the first event is considered.

If the events are independent, multiply the two regular probabilities. If the events are dependent, multiply by the conditional probability for the second event.
