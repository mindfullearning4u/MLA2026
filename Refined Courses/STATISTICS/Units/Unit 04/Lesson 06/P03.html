Independent vs. Dependent Multiplication

For independent events, use P(A and B) = P(A) times P(B). For dependent events, use the probability of A times the probability of B after A has happened.

The key question is: does the first event change the probability of the second event?

Common Mistake

Incorrect: Use the same second probability even when the first event changes the situation.
Correct: If the events are dependent, update the second probability after the first event occurs.
