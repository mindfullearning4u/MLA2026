Instructions

Use the sample space before deciding which outcomes belong in each event.

Part A

List the sample space for spinning a spinner labeled A, B, C, and D.

Part B

For S = {1, 2, 3, 4, 5, 6}, A = {1, 2, 3}, and B = {3, 4, 5}, list A and B and A or B.

Part C

For S = {red, blue, green, yellow} and A = {red, yellow}, list not A.
