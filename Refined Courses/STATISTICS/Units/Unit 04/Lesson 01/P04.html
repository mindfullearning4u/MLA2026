P04 Worked Examples

Use the examples to practice event language.

Worked Example 1

Rolling one number cube has sample space {1, 2, 3, 4, 5, 6}. The event "odd" is {1, 3, 5}.

Worked Example 2

If A = {red, blue} and B = {blue, green}, then A and B = {blue}. The intersection is the overlap.

Worked Example 3

If the sample space is {1, 2, 3, 4, 5, 6} and A = {2, 4, 6}, then not A = {1, 3, 5}. The complement includes outcomes outside A.

Common Mistake

Incorrect: The complement of even numbers is all numbers not listed anywhere.
Correct: The complement must come from the sample space. For one number cube, not even is {1, 3, 5}.
