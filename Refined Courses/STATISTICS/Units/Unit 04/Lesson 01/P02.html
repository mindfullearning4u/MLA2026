Notebook Title: Sample Spaces and Events

A sample space is the complete list of possible outcomes. An event is a selected group of outcomes from that sample space.

Vocabulary

  • Outcome: one possible result.
  • Sample space: all possible outcomes.
  • Event: a subset of the sample space.
  • Subset: a group chosen from a larger set.

Building a Sample Space

If one number cube is rolled, the sample space is {1, 2, 3, 4, 5, 6}. The event "roll an even number" is {2, 4, 6}. The event is smaller than the sample space because it only includes outcomes that match the description.

Notebook Task

Write the sample space for rolling one number cube. Then list the event "roll a number greater than 4."
