P05 Guided Practice

This practice is not graded. Try each question, then check the feedback to understand the reasoning.

Question 1

Set A has median 12 and range 4. Set B has median 12 and range 20. Which set is more consistent?

Answer: A. Set A

Feedback: Correct. The same median with smaller range means Set A has less spread.

Question 2

Which summary is usually less affected by a high outlier?

Answer: B. Median

Feedback: Correct. The median depends on position, so one high value has less effect.

Question 3

Store A wait times are 3, 4, 4, 5, 18. What value is the likely outlier?

Answer: C. 18

Feedback: Correct. 18 is far from the cluster of values between 3 and 5.

Question 4

Two classes have similar means, but Class B has much larger standard deviation. What is true?

Answer: D. Class B scores are more spread out

Feedback: Correct. Larger standard deviation means values are typically farther from the mean.

Question 5

Why should outliers be considered when comparing data sets?

Answer: A. They can affect summaries and conclusions

Feedback: Correct. Outliers can change measures such as mean and range and influence interpretation.
