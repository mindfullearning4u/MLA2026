P04 Worked Examples

Study each example carefully. Statistics is not just calculation; each answer must be interpreted in the context of the data.

Worked Example 1: Compare Centers

Problem: Class A has median 78. Class B has median 85. Which class has the higher typical score?

Step 1: Use median as the typical value.

Step 2: Compare 78 and 85.

Step 3: State the conclusion in context.

Class B has the higher typical score.

Reasoning: Center helps compare typical values.

Worked Example 2: Account for an Outlier

Problem: A data set is 6, 7, 8, 9, 100. How does 100 affect the data?

Step 1: Notice 100 is far from the other values.

Step 2: Recognize it pulls the mean upward.

Step 3: Use median to describe typical value more fairly.

The outlier increases the mean.

Reasoning: Outliers can distort measures of center and spread.

Worked Example 3: Compare Center and Spread

Problem: Set A has median 20 and IQR 4. Set B has median 20 and IQR 12.

Step 1: Centers are equal because both medians are 20.

Step 2: Compare IQR values.

Step 3: State which set is more variable.

Set B is more variable.

Reasoning: Data sets can have the same center but different spread.

Common Mistake

Problem: Compare two data sets using only the mean.

Incorrect:

The higher mean always tells the full story.

Why it is wrong: Outliers and variability can change the interpretation.

Correct:

Compare center, spread, shape, and outliers.

Fix: Use more than one feature when comparing data sets.
