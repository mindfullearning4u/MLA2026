Notebook Task Part 2

For each data set, calculate the mean, median, and mode.

  1. 4, 6, 6, 7, 9, 10
  2. 12, 14, 15, 15, 16, 38
  3. 20, 21, 21, 23, 25

Then write one sentence explaining which measure best represents each data set.

Common Mistakes

  • Forgetting to order values before finding the median.
  • Dividing by the wrong number of values when finding the mean.
  • Assuming every data set has exactly one mode.
  • Ignoring how an outlier can pull the mean.
