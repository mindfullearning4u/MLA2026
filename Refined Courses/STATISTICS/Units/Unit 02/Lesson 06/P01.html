STATISTICS | Unit 02 | Lesson 06

Lesson Title

Lesson 06: Estimating Population Percentages from Normal Models

This lesson builds the Statistics skills needed to describe distributions, make reasonable estimates, and explain what data values mean in context.

Standards Covered in This Lesson

  • MLA.STAT.DVD.5 - I can decide when a normal model is appropriate and use mean and standard deviation to estimate percentages.
    MA.912.DP.2.2
  • MLA.STAT.DVD.6 - I can estimate population percentages using a data set that has been fit to a normal distribution.
    MA.912.DP.2.3

What You Will Learn

  • How to estimate percentages using a normal model.
  • How to use the empirical rule to estimate intervals and tails.
  • How to connect a model percentage to a population statement.

What You Will Do

  • Identify how many standard deviations a value is from the mean.
  • Estimate percentages within intervals and beyond cutoffs.
  • Write conclusions that include context and model limitations.

How You Will Show Mastery

  • Complete notebook evidence and independent work.
  • Use Guided Practice and quiz feedback to correct misconceptions.
  • Submit a checkpoint estimating percentages from a normal model.

Student-Friendly Standard Connection

These standards ask you to use a fitted normal model to make population estimates. The goal is to turn mean and standard deviation into reasonable percentage statements, while remembering that the estimate depends on the model being appropriate.
