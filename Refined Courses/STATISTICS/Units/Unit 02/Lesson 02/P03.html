Notebook Task Part 2

For each pair of data sets, compare the spread.

  1. Set A: 8, 9, 10, 11, 12 and Set B: 2, 6, 10, 14, 18
  2. Set C: 20, 21, 21, 22, 23 and Set D: 10, 15, 20, 25, 30

Use range and one other variability idea in your explanation.

Common Mistakes

  • Using only the mean to compare data sets.
  • Confusing range with interquartile range.
  • Thinking a larger standard deviation means a larger center.
  • Ignoring units when interpreting spread.

Common Mistake Example

Incorrect: Choosing a statistical measure or display without checking what the data values represent.

Correct: First identify the statistical question, the variable, and the data type; then choose the measure, display, or interpretation that fits that context.

Teachable Explanation: Statistics decisions depend on context. A correct answer must connect the calculation or graph to what the data actually describe.
