STATISTICS | Unit 02 | Lesson 02

P04 Worked Examples

Step-by-step explanation: Read each model in order. Notice how the example identifies the statistical situation, selects the correct method, completes the work, and explains the conclusion in context.

Study each example carefully. Statistics is not just calculation; each answer must be interpreted in the context of the data.

Worked Example 1: Find the Range

Problem: Find the range of 4, 9, 12, 18, 20.

Step 1: Identify the maximum value: 20.

Step 2: Identify the minimum value: 4.

Step 3: Subtract minimum from maximum.

Range = 16

Reasoning: Range describes the total spread from least to greatest.

Worked Example 2: Find the IQR

Problem: Find the IQR of 2, 4, 6, 8, 10, 12, 14.

Step 1: Find the lower half: 2, 4, 6. Q1 = 4.

Step 2: Find the upper half: 10, 12, 14. Q3 = 12.

Step 3: Subtract Q1 from Q3.

IQR = 8

Reasoning: IQR measures the spread of the middle half of the data.

Worked Example 3: Compare Variability

Problem: Data Set A has range 6. Data Set B has range 20. Which is more spread out?

Step 1: Compare the range values.

Step 2: The larger range means greater total spread.

Step 3: State the comparison.

Data Set B is more spread out.

Reasoning: Variability describes how much data values differ from each other.

Common Mistake

Problem: Find the range of 5, 8, 12, 19.

Incorrect:

Range = 19

Why it is wrong: The range is not the maximum value by itself.

Correct:

Range = 19 - 5 = 14

Fix: Subtract the minimum from the maximum.

Teachable Explanation: A statistic is only useful when it answers the question being asked and is interpreted in the context of the data.
