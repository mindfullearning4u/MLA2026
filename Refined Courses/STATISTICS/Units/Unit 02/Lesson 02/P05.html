P05 Guided Practice

This practice is not graded. Try each question, then check the feedback to understand the reasoning.

Question 1

What is the range of 5, 7, 12, 15?

Answer: A. 10

Feedback: Correct. The range is 15 minus 5, which equals 10.

Question 2

Two data sets have the same mean. Set A has smaller standard deviation than Set B. What does that mean?

Answer: B. Set A is less spread out

Feedback: Correct. A smaller standard deviation means values are typically closer to the mean.

Question 3

What does interquartile range measure?

Answer: C. Spread of the middle half of the data

Feedback: Correct. IQR is Q3 minus Q1, describing the middle 50%.

Question 4

Set A has values close together, and Set B has values far apart. Which set has greater variability?

Answer: D. Set B

Feedback: Correct. Values that are farther apart show greater spread.

Question 5

Why is variability important when comparing two data sets with the same median?

Answer: A. It shows whether values are clustered or spread out

Feedback: Correct. Center alone does not show consistency or spread.
