Lesson Title

Lesson 2: Measures of Variability for Numerical Data

Learn how range, interquartile range, mean absolute deviation, and standard deviation describe how spread out numerical data values are.

Standards Covered in This Lesson

  • MLA.STAT.DVD.4 - I can compare numerical data sets using center, variability, shape, and outliers.

What You Will Learn

  • Calculate and interpret range and interquartile range.
  • Interpret mean absolute deviation and standard deviation as measures of spread.
  • Compare data sets using variability.
  • Explain why center alone is not enough to describe a distribution.

What You Will Do

  • Find variability measures from numerical data.
  • Compare data sets with the same center but different spread.
  • Interpret variability in context.
  • Justify which data set is more consistent.

How You Will Show Mastery

  • Complete notebook tasks.
  • Submit a checkpoint comparing variability.
  • Demonstrate at least 80% mastery on the lesson quiz.

Student-Friendly Standard Connection

MLA.STAT.DVD.4: I can use variability to describe and compare how spread out numerical data sets are.
