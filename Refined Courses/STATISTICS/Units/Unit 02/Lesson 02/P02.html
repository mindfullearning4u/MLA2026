Notebook Task Part 1

Notebook Title: Measures of Variability for Numerical Data

Create a reference table for measures of variability.

  • Range: maximum minus minimum.
  • Interquartile range: third quartile minus first quartile.
  • Mean absolute deviation: average distance from the mean.
  • Standard deviation: typical distance from the mean, with larger values showing more spread.

Key Idea

Variability tells whether data values are tightly clustered or spread far apart.
