P05 Guided Practice

Try each question before looking at the answer. Then read the feedback so you understand the reasoning, not just the final choice.

Question 1

A survey asks students how many minutes they studied last night. What type of data is collected?

Answer: B. Numerical, because minutes measure an amount of time

Feedback: Correct. Minutes can be compared, ordered, and averaged because they measure time.

Question 2

A class records each student's favorite movie genre. What type of data is collected?

Answer: D. Categorical, because genre is a label or group

Feedback: Correct. Movie genre names groups rather than measured amounts.

Question 3

A data table lists student ID numbers. How should the ID numbers be classified?

Answer: A. Categorical, because the numbers are labels

Feedback: Correct. Student ID numbers identify people; arithmetic with the IDs is not meaningful.

Question 4

Which display is usually appropriate for counts of students in each favorite app category?

Answer: C. Bar chart

Feedback: Correct. A bar chart compares counts across categories.

Question 5

A display shows the number of pets owned by each student. Why is this numerical data?

Answer: B. Because the values are counts that can be compared and summarized

Feedback: Correct. Number of pets is a count, so comparing or finding a mean is meaningful.
