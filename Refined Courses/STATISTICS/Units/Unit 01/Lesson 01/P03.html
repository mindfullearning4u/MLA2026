P03 Notebook Task - Part 2

Continue your lesson notes. This page shows how to use context to classify data correctly.

Notebook Task Part 2

For each situation, write three things in your notebook:

  1. The variable being recorded.
  2. Whether the data are numerical or categorical.
  3. A sentence explaining your reasoning.

This three-part process helps you avoid guessing from the wording or from whether a value contains digits.

Model Reasoning

Situation: A school records each student's bus route number.

Variable: bus route number.

Classification: categorical.

Reason: The number names the bus route. It is a label, not an amount that should be averaged or measured.

Situation: A class records each student's free-throw percentage.

Variable: free-throw percentage.

Classification: numerical.

Reason: The percentage measures performance. It can be compared, ordered, and summarized.

Practice in Your Notebook

Classify each variable. For each one, write the variable, data type, and reason.

  1. Hours slept last night.
  2. Type of music listened to most often.
  3. ZIP code of a home address.
  4. Number of notifications received yesterday.

Common Mistake

Incorrect: "A ZIP code is numerical data because it is written with numbers."

Why this is wrong: This reasoning looks only at the symbols. It does not ask what the number means.

Teachable Explanation: When working with statistics, always connect the answer to the context, data type, and question being asked.
