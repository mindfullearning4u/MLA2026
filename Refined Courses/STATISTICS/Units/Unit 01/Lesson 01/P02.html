Notebook Title

Numerical Data and Categorical Data

Vocabulary

  • Data: information collected to answer a question.
  • Variable: the characteristic or value being recorded for each person, object, or situation.
  • Numerical data: data that use numbers as amounts, counts, or measurements.
  • Categorical data: data that use names, labels, groups, or choices.
  • Context: the real situation that explains what the data mean.

Step 1: Identify the Variable

Before deciding whether data are numerical or categorical, first ask: What exactly is being recorded? That recorded idea is the variable.

Situation: A survey asks students how many minutes they studied last night.

Variable: minutes studied last night.

The variable is not "students" and it is not "survey." The variable is the thing being measured or recorded for each student.

Step 2: Decide Whether the Variable Measures an Amount or Names a Group

Use this decision rule:

  • If the values are amounts, counts, or measurements, the data are numerical.
  • If the values are names, labels, groups, types, or choices, the data are categorical.

Numerical

minutes studied, number of pets, quiz score, height, temperature

Categorical

favorite app, grade level, lunch choice, eye color, music genre

Important Idea: Not Every Number Is Numerical Data

Some values look like numbers but are really labels. A label identifies something; it does not measure an amount.

Example: A student ID number is categorical because it identifies a student. Adding or averaging student ID numbers would not tell you something meaningful about the students.

Notebook note: Always use the context to decide what the number means.
