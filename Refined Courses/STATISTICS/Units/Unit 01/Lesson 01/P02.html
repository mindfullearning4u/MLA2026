P02 Notebook Task Part 1

Notebook Task Part 1

Create a two-column chart titled Numerical Data and Categorical Data. Write a definition for each type in your own words.

  • Numerical data answer questions about amount, count, or measurement.
  • Categorical data answer questions about group, type, label, or choice.
  • Numbers used as labels, such as jersey numbers or ZIP codes, are categorical.

Notebook Examples

  • Number of text messages sent in one day: numerical.
  • Favorite school lunch option: categorical.
  • Student ID number: categorical label.
  • Time in minutes to finish homework: numerical.
