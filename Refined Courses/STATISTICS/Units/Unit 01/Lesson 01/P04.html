📘 STATISTICS | Unit 01 | Lesson 01

P04 Worked Example

Step-by-step explanation: Read each model in order. Notice how the example identifies the statistical situation, selects the correct method, completes the work, and explains the conclusion in context.

Study all three examples. Each one shows the same reasoning process: identify the variable, classify the data, and explain why.

Worked Example 1: Numerical Data

Situation: A teacher records each student's score on a 20-point quiz.

  1. Identify the variable: quiz score.
  2. Ask what the values mean: each score is a count of points earned.
  3. Classify the data: numerical.
  4. Explain: scores can be compared, ordered, and summarized because they represent amounts.

Appropriate display: A dot plot or histogram can show how the numerical scores are distributed.

Worked Example 2: Categorical Data

Situation: A class records each student's favorite school lunch option.

  1. Identify the variable: favorite school lunch option.
  2. Ask what the values mean: each answer names a choice, such as pizza, salad, or sandwich.
  3. Classify the data: categorical.
  4. Explain: lunch options are groups or labels, not measured amounts.

Appropriate display: A bar chart can compare how many students chose each lunch option.

Worked Example 3: A Number Used as a Label

Situation: A school records each student's locker number.

  1. Identify the variable: locker number.
  2. Ask what the values mean: each number identifies a locker.
  3. Classify the data: categorical.
  4. Explain: the number is a label. Adding locker numbers or finding their average would not describe a useful quantity.

Appropriate display: Usually, a locker number itself is an identifier. If the question groups lockers by hallway or floor, a bar chart could compare those categories.

Common Mistake

Incorrect: "Locker number is numerical data because it is a number."

Problem: This answer ignores the purpose of the value. The locker number identifies a locker; it does not measure an amount.

Teachable Explanation: A statistic is only useful when it answers the question being asked and is interpreted in the context of the data.
