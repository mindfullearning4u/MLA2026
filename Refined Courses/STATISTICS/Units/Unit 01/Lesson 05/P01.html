P01 Lesson Overview

Lesson Title

Lesson 5: Interpreting Components and Quantities in Data Displays

In this lesson, you will learn how to read titles, labels, scales, quantities, and context so you can interpret a data display accurately.

Standards Covered in This Lesson

  • MLA.STAT.STQ.2 - I can interpret a data display by explaining the variables, data type, quantities, context, and what can reasonably be concluded.

What You Will Learn

  • Identify the parts of a data display.
  • Read quantities using labels and scales.
  • Explain what a display shows in context.
  • Avoid conclusions that go beyond the data.

What You Will Do

  • Examine titles, labels, scales, and units.
  • Use quantities from displays to answer questions.
  • Write conclusions supported by the display.
  • Identify claims that are too strong.

How You Will Show Mastery

  • Complete notebook notes about display components.
  • Interpret data displays using context.
  • Submit a checkpoint with supported conclusions.
  • Demonstrate at least 80% mastery on the lesson quiz.

Student-Friendly Standard Connection

MLA.STAT.STQ.2: I can read a data display carefully, explain what the quantities mean, and make only conclusions that the display supports.
