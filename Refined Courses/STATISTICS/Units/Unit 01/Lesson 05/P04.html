📘 STATISTICS | Unit 01 | Lesson 05

P04 Worked Example

Step-by-step explanation: Read each model in order. Notice how the example identifies the statistical situation, selects the correct method, completes the work, and explains the conclusion in context.

Study all three examples. Each one shows the thinking process you should use before answering independently.

Worked Example 1: Reading a Bar Chart

Situation: A bar chart shows favorite study methods.

  1. Read the title.
  2. Identify categories on the axis.
  3. Use the scale to read counts.
  4. State a conclusion supported by the counts.

Worked Example 2: Reading a Histogram

Situation: A histogram shows homework times.

  1. Read the interval labels.
  2. Identify the tallest interval.
  3. Describe where most values fall.
  4. Avoid naming exact individual values if they are grouped.

Worked Example 3: Reading a Scatterplot

Situation: A scatterplot shows study time and score.

  1. Read both axes.
  2. Look for an overall pattern.
  3. Describe the association cautiously.
  4. Do not claim cause unless the study supports it.

Common Mistake

Incorrect: "The graph shows tutoring causes better grades."

Problem: The display may show a relationship, but cause requires more evidence.

Teachable Explanation: A statistic is only useful when it answers the question being asked and is interpreted in the context of the data.
