P03 Notebook Task - Part 2

Continue your lesson notes. This page shows how to reason carefully before choosing or interpreting a data display.

Notebook Task Part 2

When you read a statistical question, underline each variable. Then decide whether the question asks about a distribution of one variable or a relationship between two variables.

  1. If there is one variable, write univariate.
  2. If there are two variables measured for the same individuals, write bivariate.
  3. Choose a display that matches the data types.

Model Reasoning

Question: Is there a relationship between hours studied and quiz score?

Variables: hours studied and quiz score.

Classification: bivariate.

Display: scatterplot, because both variables are numerical.

Practice in Your Notebook

Classify each as univariate or bivariate and name an appropriate display.

  1. Favorite sport for each student.
  2. Height and arm span for each student.
  3. Phone type and preferred streaming app for each student.

Common Mistake

Incorrect: "A data set is bivariate because it has many students in it."

Why this is wrong: The number of people or rows does not decide whether data are bivariate. The number of variables decides it.

Teachable Explanation: When working with statistics, always connect the answer to the context, data type, and question being asked.
