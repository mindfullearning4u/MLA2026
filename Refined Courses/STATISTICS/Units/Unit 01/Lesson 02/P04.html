P04 Worked Example

Study all three examples. Each one shows the thinking process you should use before answering independently.

Worked Example 1: One Categorical Variable

Situation: Students report their favorite after-school activity.

  1. Variable: favorite activity.
  2. Number of variables: one.
  3. Classification: univariate categorical data.
  4. Display: bar chart.

A bar chart compares the number of students in each activity category.

Worked Example 2: One Numerical Variable

Situation: A teacher records each student's commute time in minutes.

  1. Variable: commute time.
  2. Number of variables: one.
  3. Classification: univariate numerical data.
  4. Display: dot plot or histogram.

The display shows how commute times are distributed.

Worked Example 3: Two Numerical Variables

Situation: A class records hours studied and quiz score for each student.

  1. Variables: hours studied and quiz score.
  2. Number of variables: two.
  3. Classification: bivariate numerical data.
  4. Display: scatterplot.

A scatterplot can show whether larger study times tend to connect with larger quiz scores.

Common Mistake

Incorrect: "A scatterplot should be used for favorite app category because there are many students."

Problem: A scatterplot requires two numerical variables. Favorite app category is categorical.
