Notebook Task Part 1

Create a chart with two headings: Univariate and Bivariate.

  • Univariate data involve one variable for each case.
  • Bivariate data involve two variables for each case.
  • The display should match both the number of variables and the data type.

Examples

  • Heights of students: univariate numerical.
  • Favorite transportation method: univariate categorical.
  • Hours studied and quiz score: bivariate numerical.
  • Grade level and preferred lunch option: bivariate categorical.
