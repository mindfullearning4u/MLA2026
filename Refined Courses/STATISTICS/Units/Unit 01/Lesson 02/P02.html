Notebook Title

Univariate and Bivariate Data Displays

Vocabulary

  • Univariate data: data collected about one variable.
  • Bivariate data: data collected about two variables for the same individuals or items.
  • Association: a relationship or pattern between two variables.
  • Scatterplot: a display used for two numerical variables.
  • Two-way table: a table that organizes two categorical variables.

Step 1: Count the Variables

A variable is the characteristic being recorded. To decide whether data are univariate or bivariate, count how many variables are being studied.

One variable: number of minutes each student studied.

Two variables: number of minutes studied and quiz score for each student.

The same group can be used in both cases. The difference is how many characteristics are recorded.

Step 2: Match the Display to the Question

A display should match the kind of data and the number of variables.

  • One categorical variable can use a bar chart.
  • One numerical variable can use a dot plot or histogram.
  • Two numerical variables can use a scatterplot.
  • Two categorical variables can use a two-way table or segmented bar graph.
