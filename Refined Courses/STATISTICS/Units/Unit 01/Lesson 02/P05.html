P05 Guided Practice

This practice is not graded. Try each question, then check the feedback to understand the reasoning.

Question 1

A dataset records only the number of books each student read last month. What type of data structure is this?

Answer: B. Univariate, because one variable is recorded for each student

Feedback: Correct. The one variable is number of books read.

Question 2

A study records each student's hours of sleep and reaction time. What display is most appropriate for exploring the relationship?

Answer: D. Scatterplot

Feedback: Correct. A scatterplot shows the relationship between two numerical variables.

Question 3

A table records grade level and preferred lunch option for each student. What kind of data relationship can be studied?

Answer: A. A relationship between two categorical variables

Feedback: Correct. Grade level and lunch option are both categories.

Question 4

Which display best fits one numerical variable such as commute time in minutes?

Answer: C. Dot plot

Feedback: Correct. A dot plot can show the distribution of one numerical variable.

Question 5

Why is favorite sport and number of hours practiced per week a bivariate dataset?

Answer: B. Because two variables are recorded for each person

Feedback: Correct. Each person has a sport category and a numerical practice-time value.
