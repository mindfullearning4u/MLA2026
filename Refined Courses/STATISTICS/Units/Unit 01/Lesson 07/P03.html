Notebook Task Part 2

For each context, choose a display and justify the choice.

  1. Daily reading minutes for students in one class.
  2. Hours studied and test score for each student.
  3. Favorite club by grade level.
  4. Relative frequency table showing transportation method by grade.

Common Mistakes

  • Choosing a display based only on how it looks.
  • Using a scatterplot for categorical variables.
  • Using raw counts when percentages are needed for fair group comparisons.
  • Making conclusions beyond what the display supports.
