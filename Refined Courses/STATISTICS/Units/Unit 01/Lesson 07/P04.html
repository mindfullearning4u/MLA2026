📘 STATISTICS | Unit 01 | Lesson 07

P04 Worked Example

Step-by-step explanation: Read each model in order. Notice how the example identifies the statistical situation, selects the correct method, completes the work, and explains the conclusion in context.

Study all three examples. Each one shows the thinking process you should use before answering independently.

Worked Example 1: Numerical Display Choice

Situation: Compare homework times for two classes.

  1. Variable: homework time.
  2. Type: numerical.
  3. Purpose: compare groups.
  4. Display: side-by-side box plots.

Worked Example 2: Categorical Display Choice

Situation: Show favorite elective for one school.

  1. Variable: favorite elective.
  2. Type: categorical.
  3. Purpose: compare counts.
  4. Display: bar chart.

Worked Example 3: Relative Frequency Choice

Situation: Compare transportation choices for two grade levels with different totals.

  1. Variables: grade and transportation choice.
  2. Type: categorical.
  3. Purpose: compare proportions.
  4. Display: segmented bar graph.

Common Mistake

Incorrect: "Use raw counts to compare two groups even if one group is much larger."

Problem: The larger group may have larger counts simply because it has more people.

Teachable Explanation: A statistic is only useful when it answers the question being asked and is interpreted in the context of the data.
