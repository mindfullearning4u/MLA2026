P03 Notebook Task Part 2

Notebook Task Part 2

For each context, identify the categorical variable or variables and choose a display.

  1. Favorite cafeteria entree for each student.
  2. Preferred study location by grade level.
  3. Transportation method used to get to school.
  4. Club membership status by after-school job status.

Common Mistakes

  • Using a histogram for category names.
  • Using a scatterplot for two categorical variables.
  • Comparing groups with counts when percentages would be fairer.
