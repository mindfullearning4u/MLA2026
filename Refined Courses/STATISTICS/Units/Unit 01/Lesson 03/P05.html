P05 Guided Practice

Try each question before looking at the answer. Then read the feedback so you understand the reasoning, not just the final choice.

Question 1

A class records the number of minutes each student spends reading in one night. Which display is appropriate for showing the distribution?

Answer: A. Dot plot

Feedback: Correct. A dot plot shows individual values for one numerical variable.

Question 2

A data set records study hours and test scores for each student. Which display fits the question about relationship?

Answer: B. Scatterplot

Feedback: Correct. A scatterplot shows the relationship between two numerical variables.

Question 3

Which display groups one numerical variable into intervals?

Answer: C. Histogram

Feedback: Correct. Histograms group numerical values into intervals to show distribution.

Question 4

A coach wants a quick summary of median, quartiles, and range for player heights. Which display fits best?

Answer: D. Box plot

Feedback: Correct. A box plot summarizes center and spread using quartiles and extremes.

Question 5

Why would a bar chart be a weak choice for raw times in seconds?

Answer: A. Times are numerical values, so a distribution display such as a dot plot or histogram fits better

Feedback: Correct. A bar chart is for categories; numerical times need a display that shows distribution.
