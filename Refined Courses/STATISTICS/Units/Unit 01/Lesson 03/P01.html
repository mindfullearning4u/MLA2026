P01 Lesson Overview

Lesson Title

Lesson 3: Representing Numerical Data

In this lesson, you will learn how to choose displays for numerical data so the shape, center, spread, and unusual values can be seen more clearly.

Standards Covered in This Lesson

  • MLA.STAT.STQ.1 - I can identify the type of data, the statistical question being investigated, and the most appropriate display for the context.

What You Will Learn

  • Identify numerical data that can be counted or measured.
  • Choose dot plots, histograms, or box plots for numerical data.
  • Explain what each display helps you see.
  • Avoid using category displays for numerical distributions.

What You Will Do

  • Read numerical data contexts.
  • Choose a display that fits the purpose.
  • Explain what the display would show.
  • Practice matching data questions to displays.

How You Will Show Mastery

  • Complete notebook notes about numerical displays.
  • Classify numerical situations and choose displays.
  • Submit a checkpoint with display choices and explanations.
  • Demonstrate at least 80% mastery on the lesson quiz.

Student-Friendly Standard Connection

MLA.STAT.STQ.1: I can choose a display for numerical data and explain why the display helps show how the values are distributed.
