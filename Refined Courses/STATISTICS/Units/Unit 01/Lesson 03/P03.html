STATISTICS | Unit 01 | Lesson 03

P03 Notebook Task Part 2

Notebook Task Part 2

For each context, identify the numerical variable or variables and choose a display.

  1. Times in seconds for students to run 100 meters.
  2. Daily high temperatures for one month.
  3. Study time and test score for each student.
  4. Heights of players on two basketball teams.

Common Mistakes

  • Using a scatterplot for only one numerical variable.
  • Using a bar chart when the goal is to show a numerical distribution.
  • Ignoring whether the question asks about distribution or relationship.
