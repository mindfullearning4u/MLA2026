P03 Notebook Task - Part 2

Continue your lesson notes. This page shows how to reason carefully before choosing or interpreting a data display.

Notebook Task Part 2

When selecting a numerical display, think about the question being asked. If you need to see each value, choose a dot plot. If you need to see the overall shape, choose a histogram. If you need a summary or comparison, choose a box plot.

Model Reasoning

Question: What are the quiz scores for a class of 15 students?

Data type: numerical.

Display: dot plot.

Reason: A dot plot shows each score and repeated scores clearly.

Practice in Your Notebook

Choose dot plot, histogram, or box plot and explain why.

  1. Heights of 12 students.
  2. Ages of 500 customers.
  3. Comparing test scores from two classes.

Common Mistake

Incorrect: "A bar chart is best for quiz scores because each score can be listed."

Why this is wrong: A bar chart is mainly for categories. Quiz scores are numerical values.

Correct: "A dot plot or histogram is better for quiz scores because scores are numerical data."

Why this is correct: Use a numerical display when values are counts or measurements.
