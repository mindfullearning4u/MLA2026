P04 Worked Example

Step-by-step explanation: Read each model in order. Notice how the example identifies the statistical situation, selects the correct method, completes the work, and explains the conclusion in context.

Study all three examples. Each one shows the thinking process you should use before answering independently.

Worked Example 1: Dot Plot

Situation: A teacher records the number of books read by 12 students.

  1. Variable: number of books.
  2. Data type: numerical count.
  3. Display: dot plot.
  4. Reason: the data set is small and each value can be shown.

Worked Example 2: Histogram

Situation: A website records the ages of 400 users.

  1. Variable: age.
  2. Data type: numerical measurement.
  3. Display: histogram.
  4. Reason: intervals help show the overall age pattern.

Worked Example 3: Box Plot

Situation: Two classes compare times to complete an assignment.

  1. Variable: completion time.
  2. Data type: numerical measurement.
  3. Display: box plots.
  4. Reason: box plots make it easier to compare center and spread.

Common Mistake

Incorrect: "Use a pie chart for homework times because time can be divided into pieces."

Problem: Pie charts show parts of a whole for categories, not numerical distributions.

Teachable Explanation: A statistic is only useful when it answers the question being asked and is interpreted in the context of the data.

Worked Example Verification

Use each worked example as a model for your own reasoning. First, locate the given information and mark what is being asked. Second, follow the setup exactly: table entries stay in their row and column, graph features are read from the correct axis, and statistics are calculated from the correct values. Third, interpret the result using the context of Representing Numerical Data. A correct numerical answer is incomplete if it does not explain what the number means. Before you continue, compare your notebook work to the example and check that every step has a reason, not just a final answer.
