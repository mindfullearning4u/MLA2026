P04 Worked Example

Study all three examples. Each one shows the thinking process you should use before answering independently.

Worked Example 1: Dot Plot

Situation: A teacher records the number of books read by 12 students.

  1. Variable: number of books.
  2. Data type: numerical count.
  3. Display: dot plot.
  4. Reason: the data set is small and each value can be shown.

Worked Example 2: Histogram

Situation: A website records the ages of 400 users.

  1. Variable: age.
  2. Data type: numerical measurement.
  3. Display: histogram.
  4. Reason: intervals help show the overall age pattern.

Worked Example 3: Box Plot

Situation: Two classes compare times to complete an assignment.

  1. Variable: completion time.
  2. Data type: numerical measurement.
  3. Display: box plots.
  4. Reason: box plots make it easier to compare center and spread.

Common Mistake

Incorrect: "Use a pie chart for homework times because time can be divided into pieces."

Problem: Pie charts show parts of a whole for categories, not numerical distributions.

Correct: "Use a dot plot, histogram, or box plot for homework times."

Correction: Choose based on whether you need individual values, shape, or summary comparisons.
