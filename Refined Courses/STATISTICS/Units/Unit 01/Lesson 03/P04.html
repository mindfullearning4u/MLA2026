Worked Example

Question: A teacher records the number of minutes each student spent reading last night. Which display fits?

Data: one numerical variable, minutes read.

Display choice: a dot plot or histogram.

Reasoning: both displays show the distribution of one numerical variable; a dot plot preserves individual values, while a histogram groups values into intervals.
