# STATISTICS - Statistics: How This Course Works

---

## Welcome to Mastery-Based Learning

At Mindful Learning Academy, learning is based on demonstrated mastery rather than time spent in a course.

Students learn, practice, apply, receive feedback, revise when needed, and demonstrate mastery before advancing.

This approach helps ensure that learning gaps are addressed and understanding is built on a strong foundation.

---

## Lesson Workflow

Most lessons follow the same sequence:

1. Notebook Task - Part 1
2. Notebook Task - Part 2
3. Guided Practice
4. Independent Work
5. Checkpoint
6. Notebook Evidence Submission
7. Checkpoint Submission
8. Lesson Quiz

This structure provides multiple opportunities to learn, practice, apply, and demonstrate understanding before advancing.
