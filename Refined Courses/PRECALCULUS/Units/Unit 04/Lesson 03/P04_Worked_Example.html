P04 Worked Example

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Step-by-step explanation: Each worked example models the Precalculus process one step at a time and explains how the reasoning supports the final answer.

Worked Example 1: Identify Parabola Features From Standard Form

Problem: For x² = 12y, identify the vertex, p-value, focus, directrix, and axis of symmetry.

  1. Step 1: Match the equation to x² = 4py. This form opens up or down because x is squared.
  2. Step 2: Compare 4p to 12. Since 4p = 12, divide by 4 to get p = 3.
  3. Step 3: The vertex is (0, 0) because the equation is not shifted.
  4. Step 4: For x² = 4py, the focus is (0, p), so the focus is (0, 3).
  5. Step 5: The directrix is y = -p, so the directrix is y = -3. The axis of symmetry is x = 0.

Worked Example 2: Use the Focus to Write an Equation

Problem: A parabola has vertex (0, 0) and focus (0, 5). Write its equation.

  1. Step 1: The focus is above the vertex, so the parabola opens upward and uses x² = 4py.
  2. Step 2: The distance from the vertex to the focus is p = 5.
  3. Step 3: Substitute p = 5 into x² = 4py to get x² = 20y.
  4. Step 4: The matching directrix would be y = -5, which checks the focus-directrix relationship.

Worked Example 3: Interpret the Result

Problem: Explain what p = 3 means for x² = 12y.

  1. Step 1: p is the directed distance from the vertex to the focus.
  2. Step 2: Since p is positive, the focus is 3 units above the vertex and the directrix is 3 units below the vertex.
  3. Step 3: The graph opens upward because the focus is above the vertex.
  4. Step 4: The point-by-point definition still holds: every point on the parabola is the same distance from (0, 3) and the line y = -3.

Common Mistake

Incorrect: Calling the graph a circle or ellipse because it is a conic section.

Correct: Check which variable is squared, match the equation to x² = 4py or y² = 4px, and use p to identify the focus and directrix.

Most errors happen when a student memorizes a shape name without using the equation structure. A parabola has exactly one squared variable in standard conic form, and its focus/directrix relationship confirms the classification.

Teachable Explanation: The correct approach works because the value of p links the algebraic equation to the geometric features: vertex, focus, directrix, opening direction, and axis of symmetry.

Mathematical Visual: Parabola Focus and Directrix

A parabola is the set of points the same distance from the focus and the directrix. Use the vertex to locate the axis of symmetry, then use p to place the focus and directrix.
