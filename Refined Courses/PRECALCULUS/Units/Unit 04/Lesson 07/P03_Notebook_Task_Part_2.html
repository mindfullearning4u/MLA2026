Deepening the Concept

The main idea in this lesson is integrating Pythagorean identities, angle formulas, expression simplification, and one-variable trigonometric ratio problems.

A complete solution must connect the method to the problem. Formula selection, identity selection, and context checks are part of the reasoning.

Notebook Task

Create a four-column organizer labeled Problem Type, Given Information, Method, and Reason.

Use the organizer to decide whether a problem needs a triangle theorem, an area formula, an identity, an angle formula, simplification, or a trigonometric ratio equation.

Common Mistake

Incorrect: Use the first formula you remember, even if it does not match the problem type.

Correct: Identify the problem type first, then choose the identity, formula, theorem, or ratio that matches the structure.

Integrated Unit 4 problems require method selection. A correct answer depends on matching the given information to the right tool.
