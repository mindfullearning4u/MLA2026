Worked Example 1

Problem: Simplify tan(x)cos(x), then explain which identity makes the simplification possible.

  1. Identify the problem type and the requested result.
  2. Choose the identity, formula, theorem, or ratio.

  4. Solve or simplify and state the result.

Worked Example 2

Problem: Use sin(2x)=2sin(x)cos(x) when sin(x)=3/5 and cos(x)=4/5.

  1. Identify the known information.
  2. Choose the method that matches the structure.
  3. Carry out each algebraic or trigonometric step carefully.
  4. Check signs, restrictions, and context.

Worked Example 3

Problem: Solve sin(theta)=1/2 on 0 degrees <= theta < 360 degrees, then explain why there are two solutions.

  1. Translate the problem into trigonometric language.
  2. Use the matching identity, formula, theorem, or ratio.
  3. Keep each step equivalent to the previous step.
  4. Explain why the final answer fits the original problem.

Common Mistake

Incorrect: Use the first formula you remember, even if it does not match the problem type.

Correct: Identify the problem type first, then choose the identity, formula, theorem, or ratio that matches the structure.
