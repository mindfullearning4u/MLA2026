Notebook Title

Systems and Piecewise Function Modeling

Begin a new notebook page with this title. Leave space under the vocabulary because you will use these words while solving and explaining problems.

Vocabulary

  • System of equations: two or more equations considered together.
  • Solution to a system: a point that makes all equations true.
  • Intersection: a point where graphs meet.
  • Piecewise function: a function defined by different rules on different intervals.
  • Interval: a section of input values.
  • Constraint: a condition that limits which rule or value can be used.
  • Model: a mathematical representation of a situation.

Lesson Foundation

This lesson focuses on systems, intersections, piecewise rules, intervals, and constraints.
