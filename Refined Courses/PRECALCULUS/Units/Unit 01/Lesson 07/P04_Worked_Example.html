Common Mistake

Incorrect: For a piecewise function, use the first rule listed every time because it comes first.

Correct: Use the rule whose interval contains the input value.

The interval condition controls which rule applies. If x = 5 and the first rule is only for x < 2, that rule cannot be used for x = 5.

Teachable Explanation: The correct approach works because it connects the computation, function behavior, representation, or model back to the lesson standard.
