Notebook Title

Radical and Rational Function Models

Begin a new notebook page with this title. Leave space under the vocabulary because you will use these words while solving and explaining problems.

Vocabulary

  • Radical function: a function that includes a root, such as vx.
  • Rational function: a function written as one polynomial divided by another polynomial.
  • Domain restriction: an input value that is not allowed.
  • Radicand: the expression inside a radical symbol.
  • Asymptote: a line a graph approaches but does not cross in the expected model behavior.
  • Extraneous solution: a solution that appears during solving but does not work in the original equation.

Lesson Foundation

This lesson focuses on radical domains, rational restrictions, intercepts, holes, and asymptotic behavior.

Read each representation slowly. Before calculating, identify what the question is asking you to find or compare.

Step-by-Step Process

  2. Name the feature, restriction, operation, or model that matters.
