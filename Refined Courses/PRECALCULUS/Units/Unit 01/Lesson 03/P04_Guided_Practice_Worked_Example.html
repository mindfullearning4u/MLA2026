Worked Example

Analyze f(x) = sqrt(x - 5). The radicand must be nonnegative, so x - 5 >= 0 and x >= 5. The graph begins at x = 5, and the range is y >= 0.

Analyze g(x) = 1 / (x - 3). The denominator cannot equal 0, so x cannot equal 3. The graph has a vertical asymptote at x = 3.
