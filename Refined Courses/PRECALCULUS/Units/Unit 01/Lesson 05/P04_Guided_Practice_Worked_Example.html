Worked Example

Find the inverse of f(x) = 2x + 5. Write y = 2x + 5, switch x and y to get x = 2y + 5, then solve for y: y = (x - 5) / 2.

The inverse is f^-1(x) = (x - 5) / 2. Verify by composition: f(f^-1(x)) = 2((x - 5) / 2) + 5 = x.
