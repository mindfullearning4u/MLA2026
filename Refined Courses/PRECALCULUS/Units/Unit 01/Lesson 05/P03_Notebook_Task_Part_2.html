Common Mistake

Incorrect: The inverse of f(x) = x2 is always f-1(x) = vx with no restriction.

Correct: f(x) = x2 needs a domain restriction, such as x = 0, before its inverse can be f-1(x) = vx.

Without a domain restriction, both 2 and -2 produce the output 4. The inverse would send 4 to two outputs, which is not a function. Restricting the domain to x = 0 keeps only one branch.
