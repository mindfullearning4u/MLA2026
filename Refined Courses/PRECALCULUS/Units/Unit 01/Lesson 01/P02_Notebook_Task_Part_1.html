Notebook Title

Comparing Function Features Across Representations

Begin a new notebook page with this title. Leave space under each vocabulary word because you will use these ideas throughout the lesson.

Vocabulary

  • Function: a rule that gives exactly one output for each input.
  • Input: the value placed into the function, usually represented by x.
  • Output: the value produced by the function, usually represented by y or f(x).
  • Domain: all input values that make sense for the function.
  • Range: all output values that the function can produce.
  • Intercept: a point where a graph crosses an axis.
  • Extremum: a highest or lowest point on a section of a graph, such as a maximum or minimum.
  • Transformation: a change to a graph, such as shifting, reflecting, stretching, or compressing.

What It Means To Compare Functions

Comparing functions means deciding how two functions are alike or different. You should not compare functions by only saying that one graph looks higher or lower. Instead, compare specific features and use evidence.

A function may be shown as an equation, a graph, a table, or a written description. The representation may change, but the function features can still be identified. Your job is to read the representation carefully and pull out the information that can be compared.

Step-by-Step: Reading Key Features

  1. Identify the representation. Decide whether the function is shown as an equation, graph, table, or description.
  2. Find the inputs and outputs. Inputs are x-values. Outputs are y-values or f(x)-values.
  3. Look for intercepts. A y-intercept happens when x = 0. An x-intercept happens when the output is 0.
  4. Look for increasing and decreasing behavior. A function is increasing when the outputs rise as x moves left to right. It is decreasing when the outputs fall as x moves left to right.
  5. Look for a maximum or minimum. A maximum is a highest output. A minimum is a lowest output.
  6. Use evidence in your comparison. State the feature and the value or behavior that proves your answer.
