Notebook Task Part 1

Function Feature Review

Record the key features that can be used to compare functions: domain, range, intercepts, increasing intervals, decreasing intervals, extrema, end behavior, and rate of change when appropriate.

Task

Create a two-column notebook organizer. In the first column, list each key feature. In the second column, describe how that feature can appear in an equation, graph, table, or written description.

Evidence

Your notes should show how the same function feature can be identified from more than one representation.
