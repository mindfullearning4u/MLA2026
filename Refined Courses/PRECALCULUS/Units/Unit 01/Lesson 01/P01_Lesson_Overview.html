📘 PRECALCULUS | Unit 01 | Lesson 01

P01 Lesson Overview

Lesson Title

Lesson 1: Precalculus Readiness, Function Review, and Transformations

Standards Covered in This Lesson

  • MLA.PC.FA.7
  • MA.912.F.1.7: Compare key features of two functions each represented algebraically, graphically, in tables, or written descriptions.

What You Will Learn

  • How to identify key features of a function from an equation, graph, table, or written description.
  • How to compare two functions by using evidence such as intercepts, domain, range, increasing and decreasing intervals, extrema, and end behavior.
  • How transformations change a function's graph and key features.

What You Will Do

  • Build a notebook reference for the major features used to describe and compare functions.
  • Practice reading function information from different representations.
  • Write comparison statements that use mathematical evidence instead of guessing from appearance.

How You Will Show Mastery

  • Submit notebook evidence showing function features and transformation reasoning.
  • Complete independent work that compares functions using clear evidence.
  • Submit a checkpoint response and complete the lesson quiz.

Student-Friendly Standard Connection

You will show that you can compare functions even when they are shown in different ways. You will learn to name the important features, find evidence, and explain which function has a greater value, smaller value, different interval, or different behavior.
