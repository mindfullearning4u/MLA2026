Precalculus Readiness, Function Review, and Transformations

Standards Covered in This Lesson

  • MLA.PC.FA.7
  • MA.912.F.1.7: Compare key features of two functions each represented algebraically, graphically, in tables, or written descriptions.

What You Will Learn

  • How to compare functions across equations, graphs, tables, and descriptions.
  • How transformations affect key features such as intercepts, intervals, domain, range, and extrema.

What You Will Do

  • Identify key features of functions from multiple representations.
  • Compare two functions using evidence from their representations.
  • Use transformation language to explain how a graph changes.

How You Will Show Mastery

  • Complete notebook tasks showing feature comparisons.
  • Submit checkpoint reasoning about two represented functions.
  • Complete the lesson quiz.

Student-Friendly Standard Connection

You will show that you can compare functions even when they are shown in different ways, and you will explain which features support your comparison.
