Checkpoint Task

Compare two functions shown in different ways. Function A is f(x) = (x - 1)² + 2. Function B is a quadratic function with vertex (-3, -1) that opens upward.

In your response, identify the vertex and minimum value of each function. Then explain which function has the smaller minimum value and which function has a vertex farther left on the coordinate plane.

Mastery Criteria

  • You correctly identify the vertex of each function.
  • You correctly identify the minimum value of each function.
  • You compare the functions using mathematical evidence, not guessing.
  • Your explanation uses clear function language connected to the lesson standard.
