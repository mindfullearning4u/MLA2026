Worked Example

Function A is represented by f(x) = (x - 2)^2 + 1. Function B is described as the graph of y = x^2 shifted left 3 units and down 4 units.

Function A has vertex (2, 1), opens upward, and has range y >= 1. Function B can be written as g(x) = (x + 3)^2 - 4, so it has vertex (-3, -4), opens upward, and has range y >= -4.

Function B has the smaller minimum value because -4 is less than 1.
