P04 Worked Example

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Worked Example 1: Compare Minimum Values

Problem: Function A is f(x) = (x - 2)2 + 1. Function B is described as the graph of y = x2 shifted left 3 units and down 4 units. Which function has the smaller minimum value?

  1. Function A is in vertex form. The vertex is (2, 1), so the minimum value is 1.
  2. Function B starts with y = x2, which has vertex (0, 0).
  3. Shifting left 3 and down 4 moves the vertex to (-3, -4).
  4. The minimum value for Function B is -4.
  5. Compare the minimum values: -4 is less than 1, so Function B has the smaller minimum value.

Worked Example 2: Compare From a Table and an Equation

Problem: Function A is f(x) = 2x + 1. Function B is shown by the table: when x = 0, y = 4; when x = 1, y = 6; when x = 2, y = 8. Which function has the greater y-intercept?

  1. The y-intercept happens when x = 0.
  2. For Function A, substitute x = 0: f(0) = 2(0) + 1 = 1. The y-intercept is 1.
  3. For Function B, use the table row where x = 0. The output is y = 4. The y-intercept is 4.
  4. Compare 1 and 4. Function B has the greater y-intercept.

Worked Example 3: Compare Intervals of Increase

Problem: Function A is f(x) = |x - 1|. Function B is described as a V-shaped absolute value graph with vertex at (-2, 3). Which function begins increasing at the smaller x-value?

  1. An absolute value graph decreases until its vertex and increases after its vertex.
  2. For Function A, f(x) = |x - 1| has vertex (1, 0), so it begins increasing when x = 1.
  3. For Function B, the vertex is (-2, 3), so it begins increasing when x = -2.
  4. Compare the x-values -2 and 1. Since -2 is smaller, Function B begins increasing at the smaller x-value.

Common Mistake

Incorrect: Function A begins increasing first in Example 3 because 1 is farther to the right and the graph rises there.

Correct: Function B begins increasing first because -2 is less than 1.

The question asks for the smaller x-value, not the point that appears farther right. On a number line, values increase from left to right. Since -2 is to the left of 1, Function B begins increasing at the smaller x-value.
