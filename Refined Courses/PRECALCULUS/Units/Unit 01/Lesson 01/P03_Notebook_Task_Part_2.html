Transformation Connections

A transformation changes a parent function. A parent function is the basic function shape before changes are made. For example, y = x2 is the parent quadratic function.

When a graph is transformed, its key features may change. A vertical shift changes output values. A horizontal shift changes input values. A reflection flips the graph. A stretch or compression changes how steep or wide the graph appears.

Step-by-Step: Describing a Transformation

  1. Start with the parent function. Identify the basic graph, such as y = x, y = x2, or y = |x|.
  2. Look inside the grouping symbols. In f(x) = (x - 2)2, the x - 2 tells you the graph shifts right 2 units.
  3. Look outside the function. In f(x) = (x - 2)2 + 1, the + 1 tells you the graph shifts up 1 unit.
  4. Connect the transformation to a feature. For a quadratic in vertex form, the shift changes the vertex, which also changes the minimum or maximum location.

For example, if f(x) = (x - 2)2 + 1, the parent function is y = x2. The graph shifts right 2 and up 1, so the vertex changes from (0, 0) to (2, 1). The minimum value changes from 0 to 1.

Common Mistake

Incorrect: f(x) = (x - 2)2 + 1 shifts left 2 and up 1 because subtracting 2 means move left.

Correct: f(x) = (x - 2)2 + 1 shifts right 2 and up 1.

The value inside the parentheses works opposite of what many students expect. The expression x - 2 means the input must be 2 to make the inside equal 0, so the vertex moves from x = 0 to x = 2. The + 1 outside the square changes the output directly, so the graph moves up 1.
