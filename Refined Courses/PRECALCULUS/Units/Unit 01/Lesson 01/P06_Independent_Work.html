📘 PRECALCULUS | Unit 01 | Lesson 01

P06 Independent Work

Complete the independent work in your notebook. This work helps your Teacher of Record see whether you are ready to move forward or need more support with comparing functions.

Instructions

Show your thinking for each part. A complete answer names the feature being compared, identifies the value or behavior for each function, and explains the comparison in a sentence.

Part A: Identify Features

For f(x) = (x + 4)2 - 3, identify the parent function, vertex, minimum value, and direction the graph opens.

Then explain how the vertex helps you find the range of the function.

Part B: Compare Representations

Function A is f(x) = 3x - 2. Function B is shown by the table: when x = 0, y = 5; when x = 1, y = 8; when x = 2, y = 11.

Compare the y-intercepts and rates of change. State which features are the same and which are different.

Part C: Explain With Evidence

Function A is an absolute value graph with vertex (3, -1). Function B is an absolute value graph with vertex (-2, 4).

Which function has the smaller minimum value? Which function begins increasing at the smaller x-value? Explain both answers using the vertices.
