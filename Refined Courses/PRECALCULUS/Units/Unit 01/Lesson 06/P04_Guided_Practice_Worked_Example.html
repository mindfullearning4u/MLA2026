Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Worked Example

Evaluate 3^x = 81. Since 81 = 3^4, x = 4.

Rewrite log base 2 of 32 = 5 in exponential form. This means 2^5 = 32.

The logarithmic input must be positive because it represents an exponential output.
