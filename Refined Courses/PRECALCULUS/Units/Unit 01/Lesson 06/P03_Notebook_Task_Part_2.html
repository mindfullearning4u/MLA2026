Common Mistake

Incorrect: In f(x) = 5(2x), the initial value is 2 because 2 is the base.

Correct: In f(x) = 5(2x), the initial value is 5.

The initial value occurs when x = 0. Since 20 = 1, f(0) = 5(1) = 5. The base 2 is the growth factor, not the initial value.
