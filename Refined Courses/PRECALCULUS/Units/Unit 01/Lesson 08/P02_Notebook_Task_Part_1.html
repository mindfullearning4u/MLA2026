Notebook Title

Putting It All Together

Begin a new notebook page with this title. Leave space under the vocabulary because you will use these words while solving and explaining problems.

Vocabulary

  • Synthesis: using several ideas together to solve a larger problem.
  • Function feature: a property such as intercept, domain, range, extremum, rate of change, or end behavior.
  • Model selection: choosing the type of function that fits a situation.
  • Constraint: a restriction that limits possible inputs or outputs.
  • Justification: a mathematical explanation supported by evidence.

Lesson Foundation

This lesson focuses on Unit 1 synthesis across function analysis, restrictions, operations, inverse reasoning, exponential and logarithmic models, systems, and piecewise modeling.

Read each representation slowly. Before calculating, identify what the question is asking you to find or compare.

Step-by-Step Process

  1. Identify the function type or representation.
  2. Name the feature, restriction, operation, or model that matters.
  3. Carry out the correct procedure one step at a time.
  4. Write a sentence explaining what your result means.
