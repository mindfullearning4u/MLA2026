Worked Example

Analyze p(x) = (x + 2)(x - 1)^2(x - 4).

The zeros are x = -2, x = 1, and x = 4. The zero x = 1 has even multiplicity, so the graph touches the x-axis there. The zeros x = -2 and x = 4 have odd multiplicity, so the graph crosses the x-axis there.

The degree is 4 and the leading coefficient is positive, so both ends of the graph rise.
