Notebook Title

Function Operations and Composition

Begin a new notebook page with this title. Leave space under the vocabulary because you will use these words while solving and explaining problems.

Vocabulary

  • Function operation: adding, subtracting, multiplying, or dividing two functions.
  • Composition: using the output of one function as the input of another function.
  • Input: the value placed into a function.
  • Output: the value produced by a function.
  • Domain: all allowed inputs.
  • Composite function: a function such as f(g(x)) formed by applying one function inside another.

Lesson Foundation

This lesson focuses on function arithmetic, composition, domain, range, and inside-out evaluation.

Read each representation slowly. Before calculating, identify what the question is asking you to find or compare.

Step-by-Step Process

  1. Identify the function type or representation.
  2. Name the feature, restriction, operation, or model that matters.
  3. Carry out the correct procedure one step at a time.
  4. Write a sentence explaining what your result means.
