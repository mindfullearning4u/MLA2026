Common Mistake

Incorrect: If f(x) = x + 2 and g(x) = 3x, then f(g(x)) = (x + 2)(3x).

Correct: f(g(x)) = 3x + 2.

The notation f(g(x)) means substitute g(x) into f. Since f(input) adds 2 to the input, replace the input with 3x to get 3x + 2.
