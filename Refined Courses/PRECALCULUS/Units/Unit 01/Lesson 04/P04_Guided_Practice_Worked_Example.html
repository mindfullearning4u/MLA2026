Worked Example

Let f(x) = x + 3 and g(x) = 2x. Then (f + g)(x) = (x + 3) + 2x = 3x + 3.

The composite function f(g(x)) is f(2x) = 2x + 3. The composite function g(f(x)) is g(x + 3) = 2(x + 3) = 2x + 6.

The two compositions are not the same, which shows that order matters.
