Step-by-Step Method

  1. Identify whether the series is finite or infinite.
  2. Identify a1, r, and n if the series is finite.
  3. Use Sn = a1(1 - rn) / (1 - r) for a finite geometric series.
  4. For an infinite series, first check whether |r| < 1.
  5. If it converges, use S = a1 / (1 - r).

How To Decide What The Problem Gives You

If the problem gives a number of terms, use the finite formula. If the problem says the pattern continues forever, check the common ratio. Infinite geometric series only have a finite sum when the terms shrink toward 0.

Common Mistake

Incorrect: Using the infinite formula for 4 + 8 + 16 + 32 + ....

Correct: Since r = 2, |r| is not less than 1, so the infinite series does not have a finite sum.

The infinite formula only works when the terms get smaller in magnitude. If the terms grow, the sum keeps growing.
