Step-by-Step Method

  1. List the terms in order and subtract to check the pattern: next term - previous term.
  2. If the same difference repeats, identify the sequence as arithmetic.
  3. Name the first term a1 and the common difference d.
  4. Substitute into an = a1 + (n - 1)d.
  5. Simplify carefully and write the answer as a term value with an explanation.

How To Decide What The Problem Gives You

If the problem gives a list of terms, check the difference between consecutive terms. If the problem gives a term number, use the explicit rule. If the problem gives a real-world pattern such as a starting value and a repeated increase or decrease, the starting value is usually a1 and the repeated change is d.

Common Mistake

Incorrect: For 3, 8, 13, 18, use an = 3 + 5n because the sequence adds 5.

Correct: Use an = 3 + (n - 1)5.

The first term is already 3, so you do not add the common difference for the first term. The expression n - 1 counts the number of jumps after the first term. If you use 5n, the first term would become 8 instead of 3.
