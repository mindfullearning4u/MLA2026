Notebook Title

Arithmetic Sequences

Vocabulary

  • Sequence: An ordered list of numbers. Each number is called a term.
  • Term: One number in a sequence. The first term is written as a1.
  • Arithmetic Sequence: A sequence where the same number is added each time.
  • Common Difference: The repeated amount added from one term to the next. It is written as d.
  • Explicit Rule: A formula that finds a term directly when you know the term number.

Core Lesson Notes

An arithmetic sequence is built by repeated addition. The addition can be positive or negative. If the terms are 6, 10, 14, 18, the pattern is add 4 each time, so the common difference is 4. If the terms are 25, 20, 15, 10, the pattern is add -5 each time, so the common difference is -5.

The explicit rule is an = a1 + (n - 1)d. In this rule, an is the term you want, a1 is the first term, n is the term number, and d is the common difference.

The expression n - 1 appears because the first term has not moved yet. To get to the second term, you add the difference once. To get to the third term, you add the difference twice. That is why the number of jumps is always one less than the term number.
