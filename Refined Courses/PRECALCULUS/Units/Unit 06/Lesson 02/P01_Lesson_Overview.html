📘 PRECALCULUS | Unit 06 | Lesson 02

P01 Lesson Overview

Lesson Title

Lesson 2: Geometric Sequences

Standards Covered in This Lesson

  • MLA.PC.SEQ.2
  • MA.912.AR.10.2: Write and solve problems involving geometric sequences.

What You Will Learn

  • How to recognize a geometric sequence by checking for a constant ratio.
  • How to write explicit rules using an = a1rn - 1.
  • How to use geometric patterns in growth and decay contexts.

What You Will Do

  • Build notebook notes that explain the sequence vocabulary and formulas.
  • Study three worked examples with every step shown.
  • Complete guided practice, independent work, a checkpoint submission, and a lesson quiz.

How You Will Show Mastery

  • Submit notebook evidence showing definitions, formulas, worked steps, and explanations.
  • Complete independent work that shows whether you can identify and use the sequence pattern.
  • Submit a checkpoint response and complete the lesson quiz.

Student-Friendly Standard Connection

You will show that you can recognize a pattern that multiplies by the same factor each step, write a rule for the pattern, and use the rule to find a term.
