P04 Worked Example

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Step-by-step explanation: Each worked example models the Precalculus process one step at a time and explains how the reasoning supports the final answer.

Worked Example 1: Identify the Common Ratio

Problem: Determine whether 3, 15, 75, 375 is geometric. If it is, name the common ratio.

  1. Divide consecutive terms: 15 / 3 = 5.
  2. Continue checking: 75 / 15 = 5 and 375 / 75 = 5.
  3. The same ratio appears every time.
  4. The sequence is geometric with common ratio r = 5.

Worked Example 2: Find a Later Term

Problem: Find the 7th term of the geometric sequence 2, 6, 18, 54, ...

  1. The first term is a1 = 2.
  2. The common ratio is r = 3 because 6 / 2 = 3.
  3. Use an = a1rn - 1.
  4. Substitute n = 7: a7 = 2(3)7 - 1.
  5. Simplify: a7 = 2(3)6 = 2(729) = 1458.
  6. The 7th term is 1458.

Worked Example 3: Use a Decay Context

Problem: A medicine amount starts at 160 mg and halves each hour. How much remains after hour 5 if hour 1 is 160 mg?

  1. The first term is a1 = 160.
  2. Halves means multiply by r = 1/2.
  3. Use an = 160(1/2)n - 1.
  4. For hour 5, substitute n = 5: a5 = 160(1/2)4.
  5. Since (1/2)4 = 1/16, a5 = 160(1/16) = 10.
  6. After hour 5, 10 mg remains.

Common Mistake

Incorrect: For 4, 12, 36, 108, use an = 4(3)n.

Correct: Use an = 4(3)n - 1.

The first term is already 4, so the ratio has not been applied yet. If you use exponent n, the first term becomes 12 instead of 4.
