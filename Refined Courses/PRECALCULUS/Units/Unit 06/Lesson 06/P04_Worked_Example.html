P04 Worked Example

Example 1

Problem: Expand the sum from k = 1 to 4 of 2k.

  1. Use k = 1, 2, 3, 4.
  2. Substitute: 2(1) + 2(2) + 2(3) + 2(4).
  3. Add: 2 + 4 + 6 + 8 = 20.

Example 2

Problem: Expand the sum from k = 0 to 3 of 3(2k).

  1. Use k = 0, 1, 2, 3.
  2. Substitute: 3(20) + 3(21) + 3(22) + 3(23).
  3. Add: 3 + 6 + 12 + 24 = 45.

Example 3

Problem: Identify whether 5 + 8 + 11 + 14 is arithmetic or geometric.

  1. Check differences: 3, 3, 3.
  2. The repeated change is addition by 3.
  3. This is an arithmetic series.

Common Mistake

Incorrect: Skip k = 0 because it looks unusual.

Correct: If the lower bound is 0, substitute 0 as the first index value.
