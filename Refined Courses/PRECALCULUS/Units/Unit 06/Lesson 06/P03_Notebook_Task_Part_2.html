Expanding a Sum

  1. Find the lower bound.
  2. Find the upper bound.
  3. Substitute each index value into the rule.
  4. Add the results.

Common Mistake

Incorrect: Use only the first and last terms.

Correct: Use every integer index value from the lower bound through the upper bound.
