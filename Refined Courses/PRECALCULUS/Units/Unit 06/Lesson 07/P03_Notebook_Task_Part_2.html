P03 Notebook Task Part 2

This page organizes the method into a repeatable sequence of steps.

Step-by-Step Method

  1. Identify the two input values or the expression x + h.
  2. Evaluate the function at each input.
  3. Subtract outputs in the numerator.
  4. Subtract inputs or divide by h in the denominator.
  5. Simplify and explain what the rate means.

How To Decide What The Problem Gives You

If a problem gives two x-values, use average rate of change. If it asks for (f(x + h) - f(x)) / h, substitute and simplify algebraically. If a graph or table asks what values approach, use informal limit language without treating this as a full Calculus course.

Common Mistake

Incorrect: For average rate of change, subtracting inputs over outputs.

Correct: Use output change over input change: (f(b) - f(a)) / (b - a).

Rate of change compares how the output changes for each input change. Reversing the ratio changes the meaning.
