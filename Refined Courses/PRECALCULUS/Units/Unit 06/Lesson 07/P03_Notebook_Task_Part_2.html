P03 Notebook Task Part 2

Reading Tables and Graphs

To describe behavior near a point, look from both sides when possible. One side means input values less than the target value. The other side means input values greater than the target value.

  1. If two input values are given, compute output change divided by input change.
  2. If a difference quotient is given, substitute and simplify.
  3. Identify the input value the problem is asking about.
  4. Look at output values as the inputs get closer from the left.
  5. Look at output values as the inputs get closer from the right.
  6. If both sides approach the same output, write a clear approach statement.

Common Mistake

Incorrect: If the table has no value exactly at x = 3, then there is nothing to say.

Correct: You can still describe what the y-values approach as x gets close to 3. Approach language is about nearby behavior, not only the exact listed value.
