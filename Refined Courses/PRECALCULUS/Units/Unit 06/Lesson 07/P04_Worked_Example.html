P04 Worked Example

Example 1: Describe Behavior From a Table

Problem: As x gets closer to 4 from both sides, the y-values get closer to 9. What statement describes the behavior?

  1. The input value is 4.
  2. The output values get close to 9.
  3. Write the approach statement: as x approaches 4, f(x) approaches 9.

Example 2: Describe End Behavior

Problem: A graph rises on the right side as x-values become very large. What does this mean?

  1. Focus on the far right side of the graph.
  2. The graph rises, so the output values increase.
  3. A clear statement is: as x increases without bound, f(x) increases without bound.

Example 3: Describe an Asymptote

Problem: A graph gets closer and closer to y = 2 as x moves to the right. What behavior is shown?

  1. Identify the horizontal line the graph approaches: y = 2.
  2. Notice that the graph gets close to that output value.
  3. State the behavior: the graph approaches the horizontal asymptote y = 2.

Common Mistake

Incorrect: The graph approaches y = 2, so x approaches 2.

Correct: y = 2 is an output value. The correct idea is that f(x), or the y-value, approaches 2.
