P04 Worked Example

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Worked Example 1: Average Rate of Change

Problem: For f(x) = x2 + 1, find the average rate of change from x = 1 to x = 4.

  1. Find f(1) = 12 + 1 = 2.
  2. Find f(4) = 42 + 1 = 17.
  3. Use (f(4) - f(1)) / (4 - 1).
  4. Calculate (17 - 2) / 3 = 5.
  5. The average rate of change is 5.

Worked Example 2: Difference Quotient

Problem: Simplify (f(x + h) - f(x)) / h for f(x) = x2.

  1. Find f(x + h) = (x + h)2.
  2. Find f(x) = x2.
  3. Substitute: ((x + h)2 - x2) / h.
  4. Expand: (x2 + 2xh + h2 - x2) / h.
  5. Simplify: (2xh + h2) / h = 2x + h.

Worked Example 3: Informal Limit Language

Problem: A table shows values of f(x) getting closer to 8 as x gets closer to 3 from both sides. What can you say informally?

  1. Look at values from the left of 3 and right of 3.
  2. Both sides approach the same output value, 8.
  3. Use readiness language: as x approaches 3, f(x) approaches 8.
  4. This supports future Calculus but does not create a new Precalculus benchmark.

Common Mistake

Incorrect: For average rate of change, subtracting inputs over outputs.

Correct: Use output change over input change: (f(b) - f(a)) / (b - a).

Rate of change compares how the output changes for each input change. Reversing the ratio changes the meaning.
