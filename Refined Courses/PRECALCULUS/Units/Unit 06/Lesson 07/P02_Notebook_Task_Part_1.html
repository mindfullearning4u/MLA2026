Notebook Title

Rates of Change, Difference Quotients, and Limit Foundations

Vocabulary

  • Average Rate of Change: Output change divided by input change.
  • Difference Quotient: An expression such as (f(x+h)-f(x))/h that measures function change.
  • Approaches: Gets closer to a value.
  • Behavior Near a Point: What the output values do when input values get close to a selected input.
  • End Behavior: What a graph does as input values move far left or far right.
  • Asymptote: A line a graph gets close to but may not touch in the viewed region.
  • Informal Limit: A readiness idea that describes what output values approach.

What Function Behavior Means

In this lesson, you are not learning a full Calculus unit. You are learning how to describe function change using average rate of change and difference quotients, then how to describe function behavior in a careful Precalculus way. The key question is: When x-values get close to a certain number, what do the y-values appear to get close to?

A table can show this behavior. If x-values move closer and closer to 2, and the y-values move closer and closer to 5, you can say: as x approaches 2, f(x) approaches 5.
