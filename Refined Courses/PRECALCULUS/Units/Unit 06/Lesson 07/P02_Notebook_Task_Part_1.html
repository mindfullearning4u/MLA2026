Notebook Title

Rates of Change, Difference Quotients, and Limit Foundations

Vocabulary

  • Average Rate of Change: The change in output divided by the change in input.
  • Difference Quotient: An expression such as (f(x + h) - f(x)) / h that measures function change.
  • Interval: A set of input values between two endpoints.
  • Informal Limit: A value a function approaches, used here only as readiness support.

Core Lesson Notes

Average rate of change is the slope between two points on a function. It answers: how much did the output change for each 1-unit change in input?

The formula is (f(b) - f(a)) / (b - a). The difference quotient (f(x + h) - f(x)) / h uses the same idea with a general interval from x to x + h.
