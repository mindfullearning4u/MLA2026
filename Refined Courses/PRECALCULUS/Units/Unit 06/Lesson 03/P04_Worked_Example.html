P04 Worked Example

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Worked Example 1: Write a Recursive Rule

Problem: Write a recursive rule for 6, 10, 14, 18, ...

  1. The first term is a1 = 6.
  2. The sequence adds 4 each time.
  3. A recursive rule uses the previous term, so write an = an - 1 + 4.
  4. Complete rule: a1 = 6; an = an - 1 + 4 for n > 1.

Worked Example 2: Write an Explicit Rule

Problem: Write an explicit rule for 3, 9, 27, 81, ...

  1. The first term is a1 = 3.
  2. The common ratio is r = 3.
  3. Use the geometric explicit form an = a1rn - 1.
  4. Substitute: an = 3(3)n - 1.

Worked Example 3: Compare Rule Types

Problem: For 12, 17, 22, 27, should you use an explicit rule or recursive rule to find the 40th term quickly?

  1. The sequence is arithmetic with first term 12 and common difference 5.
  2. A recursive rule would require building many terms one at a time.
  3. An explicit rule finds the term directly.
  4. Use an = 12 + (n - 1)5 for a far-away term like the 40th term.

Common Mistake

Incorrect: Writing only an = an - 1 + 6 as a recursive rule.

Correct: Include the initial term, such as a1 = 10, and then write an = an - 1 + 6.

A recursive rule needs a starting value. Without the first term, the rule tells how to move but not where to start.
