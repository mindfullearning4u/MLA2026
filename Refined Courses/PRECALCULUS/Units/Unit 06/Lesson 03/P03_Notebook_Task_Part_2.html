This page organizes the method into a repeatable sequence of steps.

Step-by-Step Method

  1. Identify the first term and pattern.
  2. For an explicit rule, connect the term number directly to the term value.
  3. For a recursive rule, write the first term first.
  4. Then write how an depends on an - 1.
  5. Check the rule by generating the next two terms.

How To Decide What The Problem Gives You

Use an explicit rule when the question asks for a far-away term such as the 50th term. Use a recursive rule when the problem describes a process that depends on what happened immediately before. Recursive rules must include the starting value; without it, the pattern has no place to begin.

Common Mistake

Incorrect: Writing only an = an - 1 + 6 as a recursive rule.

Correct: Include the initial term, such as a1 = 10, and then write an = an - 1 + 6.

A recursive rule needs a starting value. Without the first term, the rule tells how to move but not where to start.

Teachable Explanation

The correct method works because it connects the given representation to the lesson relationship, checks the relevant restrictions or features, and explains the conclusion instead of relying on appearance or memorized steps.
