Notebook Title

Recursive and Explicit Models

Vocabulary

  • Explicit Rule: A rule that finds a term directly from the term number.
  • Recursive Rule: A rule that uses one or more previous terms to find the next term.
  • Initial Term: The starting term needed before a recursive rule can begin.
  • an - 1: The term immediately before an.

Core Lesson Notes

A sequence can be described with an explicit rule or a recursive rule. An explicit rule is direct. If you want the 20th term, you substitute n = 20 and calculate once. A recursive rule builds term by term. It must tell you the starting value and how to get each next value.

For the sequence 5, 8, 11, 14, ..., an explicit rule is an = 5 + (n - 1)3. A recursive rule is a1 = 5 and an = an - 1 + 3 for n > 1. Both describe the same pattern, but they answer questions in different ways.
