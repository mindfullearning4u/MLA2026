P04 Worked Example

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Worked Example 1: Expand Sigma Notation

Problem: Expand and evaluate Î£i = 14 3i.

  1. The index is i.
  2. The lower limit is 1 and the upper limit is 4.
  3. Substitute i = 1, 2, 3, 4.
  4. Expand: 3(1) + 3(2) + 3(3) + 3(4).
  5. Add: 3 + 6 + 9 + 12 = 30.

Worked Example 2: Connect Sigma to an Arithmetic Series

Problem: Evaluate Î£k = 15 (2k + 1).

  1. Substitute k = 1, 2, 3, 4, 5.
  2. The terms are 3, 5, 7, 9, 11.
  3. This is an arithmetic series with 5 terms.
  4. Add directly: 3 + 5 + 7 + 9 + 11 = 35.

Worked Example 3: Connect Sigma to a Geometric Series

Problem: Evaluate Î£j = 03 2(3)j.

  1. Substitute j = 0, 1, 2, 3.
  2. Expand: 2(3)0 + 2(3)1 + 2(3)2 + 2(3)3.
  3. Evaluate the terms: 2 + 6 + 18 + 54.
  4. Add: 80.

Common Mistake

Incorrect: For Î£i = 14 3i, substituting only i = 4.

Correct: Substitute every integer value from 1 through 4: 3(1) + 3(2) + 3(3) + 3(4).

Sigma notation represents repeated addition, not one substitution. The lower and upper limits tell all values that must be used.
