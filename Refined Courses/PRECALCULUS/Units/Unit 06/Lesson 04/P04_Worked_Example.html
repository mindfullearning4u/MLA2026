Worked Example 1: Add a Short Arithmetic Series

Problem: Find the sum of 5 + 9 + 13 + 17 + 21.

  1. Step 1: The first term is a1 = 5.
  2. Step 2: The last term is an = 21.
  3. Step 3: There are n = 5 terms.
  4. Step 4: Use Sn = n(a1 + an) / 2.
  5. Step 5: Substitute: S5 = 5(5 + 21) / 2 = 5(26) / 2 = 65.

Worked Example 2: Find the Last Term First

Problem: Find the sum of the first 12 terms of 3, 7, 11, 15, ...

  1. Step 1: The first term is a1 = 3 and the common difference is d = 4.
  2. Step 2: Find the 12th term: a12 = 3 + (12 - 1)4 = 47.
  3. Step 3: Now use the series formula with n = 12, a1 = 3, and a12 = 47.
  4. Step 4: Calculate: S12 = 12(3 + 47) / 2 = 12(50) / 2 = 300.

Worked Example 3: Use a Context

Problem: A runner jogs 2 miles on day 1 and increases by 1 mile each day for 10 days. How many total miles are jogged

  1. Step 1: This asks for a total, so use a series.
  2. Step 2: The first term is a1 = 2, the common difference is d = 1, and n = 10.
  3. Step 3: Find day 10: a10 = 2 + (10 - 1)1 = 11.
  4. Step 4: Find the total: S10 = 10(2 + 11) / 2 = 65.
  5. Step 5: The runner jogs 65 miles total.

Common Mistake

Incorrect: Using Sn = a1 + an and forgetting the number of terms.

Correct: Use Sn = n(a1 + an) / 2.

The first and last terms only give one pair. The formula must account for every term in the series, so the number of terms n is required.
