P03 Notebook Task Part 2

This page organizes the method into a repeatable sequence of steps.

Step-by-Step Method

  1. Identify the first term a1.
  2. Identify the number of terms n.
  3. Identify or calculate the last term an.
  4. Substitute into Sn = n(a1 + an) / 2.
  5. Simplify and label the sum.

How To Decide What The Problem Gives You

If the problem asks for a total, sum, or combined amount over several terms, it is asking for a series. If the last term is not given, find it first using the arithmetic sequence formula. Then use the series formula to add all the terms efficiently.

Common Mistake

Incorrect: Using Sn = a1 + an and forgetting the number of terms.

Correct: Use Sn = n(a1 + an) / 2.

The first and last terms only give one pair. The formula must account for every term in the series, so the number of terms n is required.
