Vocabulary

  • Unit synthesis: using several Unit 5 ideas together.
  • Complex plane: the coordinate-plane representation of complex numbers.
  • Polar form: a representation using distance and direction.
  • Conic section: a curve formed from slicing cones.
  • Circle, parabola, ellipse, and hyperbola: conic types with different defining features.
  • Key features: the values that determine graph shape, location, and meaning.

Lesson Foundation

This lesson focuses on all Unit 5 complex-number and conic-section standards.

Start by identifying the equation form, representation, graph shape, and key features. Then connect each feature to its meaning.

Step-by-Step Process

  1. Identify the problem type and given information.
  2. Name the key features, coordinates, or representation.
  3. Choose the correct formula, equation form, or interpretation rule.
  4. Complete the calculation or graph analysis one step at a time.
  5. Check that the result answers the original question.
