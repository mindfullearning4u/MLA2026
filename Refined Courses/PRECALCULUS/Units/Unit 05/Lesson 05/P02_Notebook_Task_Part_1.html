Notebook Title

Parabolas: Equations, Graphs, and Key Features

Begin a new notebook page with this title. Leave space under the vocabulary because you will use these words while solving and explaining problems.

Vocabulary

  • Parabola: the set of all points equidistant from a fixed point called the focus and a fixed line called the directrix.
  • Vertex: the turning point of a parabola.
  • Focus: the fixed point used to define a parabola.
  • Directrix: the fixed line used to define a parabola.
  • Axis of symmetry: the line through the vertex and focus that divides the parabola into two matching halves.
  • Key features: vertex, focus, directrix, axis of symmetry, opening direction, and contextual meaning.

Lesson Foundation

This lesson focuses on deriving, graphing, solving, and interpreting equations of parabolas using key features.

Start by identifying the equation form, graph shape, and key features. Then connect each feature to its meaning.

Step-by-Step Process

  1. Identify the conic section and equation form.
  2. Find the key features from the equation or graph.
  3. Use the key features to sketch, write, or interpret the equation.
  4. Check that the graph and equation describe the same relationship.
  5. Explain what the answer means in the original context.
