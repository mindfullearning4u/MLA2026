P04 Worked Example

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Worked Example 1

Problem: Identify the vertex and opening direction of y = (x - 2)^2 + 3.

  1. Identify the conic and equation form.
  2. Locate the key feature values.
  3. State the feature clearly.
  4. Explain what the feature means on the graph.

Worked Example 2

Problem: Write an equation for a parabola with vertex (1, -4) that opens upward with a stretch factor of 2.

  1. Identify the given key features.
  2. Choose the matching equation or graph structure.
  3. Substitute the key values carefully.
  4. Check that the result matches the requested feature.

Worked Example 3

Problem: A satellite dish is modeled by a parabola. Explain why the focus is important in the context.

  1. Translate the context into conic-section language.
  2. Identify the feature that matters in the situation.
  3. Connect the feature to the graph or equation.
  4. Explain the answer in words.

Common Mistake

Incorrect: Treat every parabola as if it opens upward.

Correct: Use the equation form and key features to determine whether the parabola opens up, down, left, or right.

A parabola can open vertically or horizontally. The equation structure and key features determine the direction.
