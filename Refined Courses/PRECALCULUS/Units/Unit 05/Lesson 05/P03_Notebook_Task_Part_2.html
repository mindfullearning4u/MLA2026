Deepening the Concept

The main idea in this lesson is deriving, graphing, solving, and interpreting equations of parabolas using key features.

A correct solution connects equation structure, graph features, and context. The graph is not separate from the equation; each feature has a reason.

Notebook Task

Create a four-column organizer labeled Equation Form, Key Feature, Graph Meaning, and Context Meaning.

Use the organizer to show how each part of the equation affects the graph and interpretation.

Common Mistake

Incorrect: Treat every parabola as if it opens upward.

Correct: Use the equation form and key features to determine whether the parabola opens up, down, left, or right.

A parabola can open vertically or horizontally. The equation structure and key features determine the direction.
