P04 Worked Example

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Worked Example 1

Problem: Convert an angle, identify its coterminal measure, and explain the full rotation used.

  1. Identify the context and the trigonometric function.
  2. Find the requested parameter or feature.
  3. Connect the value to graph behavior.
  4. State the answer with context.

Worked Example 2

Problem: Find a unit circle value and use a symmetry relationship to explain the sign.

  1. Identify the equation or graph feature.
  2. Use the correct trigonometric model relationship.
  3. Check the period, midline, shift, or constraint.
  4. Explain why the result fits the model.

Worked Example 3

Problem: Analyze a sinusoidal model by identifying amplitude, period, midline, and context meaning.

  1. Compare the feature to the real-world situation.
  2. Determine which values are allowed.
  3. Use evidence from the graph or equation.
  4. Write the conclusion in a complete sentence.

Common Mistake

Incorrect: Prepare for the Unit Assessment by memorizing isolated values without checking angle units, quadrant, graph features, or context.

Correct: Prepare by identifying angle units, unit circle relationships, graph features, and context restrictions.

The Unit Assessment requires interpretation. A correct answer must match the angle unit, function, quadrant, graph behavior, and context.
