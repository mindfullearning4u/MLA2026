Notebook Title

Calculating Trigonometric Function Values

Begin a new notebook page with this title. Leave space under the vocabulary because you will use these words while solving and explaining problems.

Vocabulary

  • Trigonometric function value: the output of sine, cosine, tangent, cosecant, secant, or cotangent for a given angle.
  • Reference angle: the acute angle used to connect an angle to known unit circle values.
  • Quadrantal angle: an angle whose terminal side lies on an axis.
  • Undefined value: a value that does not exist because division by 0 would be required.
  • Technology value: an approximate value found with a calculator or graphing tool.
  • Exact value: a value written using fractions and radicals.
  • Identity: a true relationship that can be used to calculate or simplify trigonometric values.

Lesson Foundation

This lesson focuses on calculating sine, cosine, tangent, cosecant, secant, and cotangent for angles in degrees or radians.

Trigonometric reasoning depends on matching a value, graph feature, or restriction to the correct function.

Step-by-Step Process

  1. Identify the given angle, equation, table, or graph feature.
  2. Choose the correct unit circle value, reciprocal relationship, or graph rule.
  3. Check signs, restrictions, and key features carefully.
  4. Write a sentence explaining what the result means.
