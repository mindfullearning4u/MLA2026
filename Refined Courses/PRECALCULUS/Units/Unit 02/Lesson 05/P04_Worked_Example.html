Common Mistake

Incorrect: In f(x) = 8(1.25x), the initial value is 1.25 because it is next to x.

Correct: In f(x) = 8(1.25x), the initial value is 8 and the growth factor is 1.25.

The initial value is the output when x = 0. Since 1.250 = 1, f(0) = 8(1) = 8. The base 1.25 tells how the output is multiplied each step.
