P04 Worked Example

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Worked Example 1

Problem: A polynomial model h(t) = -t³ + 6t² gives the height of an object for t between 0 and 6 seconds. Identify the domain constraint.

  1. Identify the variables and the model type.
  2. Find the feature or restriction named in the question.
  3. Apply the context before interpreting the answer.
  4. State the answer with a clear explanation.

Worked Example 2

Problem: A revenue model R(x) = -2x² + 40x represents revenue for 0 ≤ x ≤ 20 items. Find the zeros and explain what they mean.

  1. Identify the model feature being requested.
  2. Calculate or describe the feature using the model.
  3. Connect the result to the real-world meaning.
  4. Check that the answer fits the stated context.

Worked Example 3

Problem: A volume model V(x) = x³ - 9x² + 20x represents a box design. Explain why only positive x-values that create positive volume make sense.

  1. Identify the possible mathematical values.
  2. Remove values that do not make sense in context.
  3. Use the remaining values to interpret the model.
  4. Write the conclusion in a complete sentence.

Common Mistake

Incorrect: If a polynomial formula works algebraically, every x-value must make sense in the real-world model.

Correct: A real-world polynomial model may have a restricted domain based on the context.

The equation can often accept many x-values, but the situation may not. Time, length, number of items, and distance usually cannot be negative, so the domain must match the context.
