Common Mistake

Incorrect: log base 2 of x is defined for x = 0 because 0 is a common starting value.

Correct: log base 2 of x is defined only for x > 0.

A logarithm asks for an exponent that produces the argument. No power of a positive base such as 2 gives 0, so the argument must be positive.
