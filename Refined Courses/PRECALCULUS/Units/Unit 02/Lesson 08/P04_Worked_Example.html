P04 Worked Example

Study each example carefully. Every step is shown because the reasoning matters as much as the final answer.

Worked Example 1

Problem: Compare a polynomial model and a rational model by identifying a zero and a denominator restriction.

  1. Identify the function family.
  2. Find the key feature or restriction being requested.
  3. Connect the feature to the model or graph.
  4. State the answer with context.

Worked Example 2

Problem: Compare an exponential model and a logarithmic model by explaining inverse reasoning and domain constraints.

  1. Identify the representation.
  2. Choose the correct unit strategy.
  3. Apply the method carefully.
  4. Explain why the answer fits the model.

Worked Example 3

Problem: Choose the best model type for a situation with repeated percent growth and explain the choice.

  1. Compare the models by the same type of feature.
  2. Check restrictions before interpreting.
  3. Use evidence to make the decision.
  4. Write the conclusion in a complete sentence.

Common Mistake

Incorrect: Prepare for the Unit Assessment by memorizing formulas without checking context or restrictions.

Correct: Prepare by identifying the function family, key features, restrictions, and context meaning for each model.

The Unit Assessment asks for interpretation, not only calculation. Context and restrictions determine whether an algebraic answer is meaningful.
