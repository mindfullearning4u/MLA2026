Common Mistake

Incorrect: Prepare for the Unit Assessment by memorizing formulas without checking context or restrictions.

Correct: Prepare by identifying the function family, key features, restrictions, and context meaning for each model.

The Unit Assessment asks for interpretation, not only calculation. Context and restrictions determine whether an algebraic answer is meaningful.
