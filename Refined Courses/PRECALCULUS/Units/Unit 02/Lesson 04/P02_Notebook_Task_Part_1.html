Notebook Title

Rational Function Models and Constraints

Begin a new notebook page with this title. Leave space under the vocabulary because you will use these words while solving and explaining problems.

Vocabulary

  • Rational function: a function written as one polynomial divided by another polynomial.
  • Denominator: the expression below the fraction bar.
  • Restriction: an input value that is not allowed.
  • Vertical asymptote: a vertical line the graph approaches when the denominator is 0 and the behavior is not removable.
  • Horizontal asymptote: a horizontal line the graph approaches for very large or very small inputs.
  • Hole: a missing point caused by a removable factor.
  • Rate model: a model that compares quantities using division.

Lesson Foundation

This lesson focuses on rational models, restrictions, vertical asymptotes, horizontal behavior, intercepts, and contextual constraints.

A model must be read in two ways: algebraically and contextually. Algebra shows possible behavior, but the situation tells which inputs and outputs actually make sense.

Step-by-Step Process

  1. Identify the function type and what the variables represent.
  2. Find the key features or restrictions that matter.
  3. Apply any context limits before interpreting the answer.
  4. Write a sentence explaining the meaning of the result.
