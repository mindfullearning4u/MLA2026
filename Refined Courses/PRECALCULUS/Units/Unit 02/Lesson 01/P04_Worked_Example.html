Worked Example 3

Problem: A polynomial has zeros -1, 2, and 4. Write three matching linear factors.

  1. Compare the same type of feature in each polynomial.
  2. Record the value or behavior for each polynomial.
  3. Use the evidence to decide which polynomial meets the condition.
  4. Write the final comparison in a complete sentence.

Common Mistake

Incorrect: If f(3) = 0, then x + 3 is a factor.

Correct: If f(3) = 0, then x - 3 is a factor.

The factor uses the opposite sign of the zero. A zero at x = 3 means the input 3 makes the polynomial equal 0, so the matching factor is x - 3.
