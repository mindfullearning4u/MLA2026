P04 Worked Example

Worked Example 1

Prompt: A student reads a sociology scenario and must explain a social pattern using evidence rather than opinion.

Step 1: Name the social pattern. This identifies the sociology object before reasoning.

Step 2: Identify what is happening across people, groups, or institutions. This ties the answer to the embedded model, source, chart, or scenario evidence.

Step 3: Sociology begins with patterns, not isolated guesses. This is the teachable conclusion for MLA.SOC.FND.2.

Worked Example 2

Prompt: A student reads a sociology scenario and must explain a social pattern using evidence rather than opinion.

Step 1: Use the evidence. This identifies the sociology object before reasoning.

Step 2: Read the model, table, source, or scenario details. This ties the answer to the embedded model, source, chart, or scenario evidence.

Step 3: Evidence protects against stereotypes. This is the teachable conclusion for MLA.SOC.FND.2.

Worked Example 3

Prompt: A student reads a sociology scenario and must explain a social pattern using evidence rather than opinion.

Step 1: Apply the concept. This identifies the sociology object before reasoning.

Step 2: Connect the evidence to MLA.SOC.FND.2. This ties the answer to the embedded model, source, chart, or scenario evidence.

Step 3: A sociological explanation must stay inside the mapped standard. This is the teachable conclusion for MLA.SOC.FND.2.

Common Mistake

Correct: using sociological evidence to explain the social pattern within the mapped standard.

Incorrect: making a stereotype, personal opinion, or unsupported claim without evidence.

Teachable Explanation

Each example uses the same mastery path: define the social pattern or institution, read the evidence, apply the correct concept, and state a careful conclusion.

Student Clarity and Mastery Check
