P04 Worked Example

Worked Example 1

Prompt: A life-course case shows how family, peers, school, media, or work shape behavior.

Step 1: Find the agent. This identifies the sociology object before reasoning.

Step 2: Identify who or what teaches expectations. This ties the answer to the embedded model, source, chart, or scenario evidence.

Step 3: Socialization has sources. This is the teachable conclusion for MLA.SOC.CUL.2.

Worked Example 2

Prompt: A life-course case shows how family, peers, school, media, or work shape behavior.

Step 1: Separate status and role. This identifies the sociology object before reasoning.

Step 2: Status is position; role is behavior. This ties the answer to the embedded model, source, chart, or scenario evidence.

Step 3: This prevents confusion. This is the teachable conclusion for MLA.SOC.CUL.2.

Worked Example 3

Common Mistake

Correct: using sociological evidence to explain the social pattern within the mapped standard.

Incorrect: making a stereotype, personal opinion, or unsupported claim without evidence.

Teachable Explanation

Each example uses the same mastery path: define the social pattern or institution, read the evidence, apply the correct concept, and state a careful conclusion.
