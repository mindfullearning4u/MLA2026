P04 Worked Example

Worked Example 1

Prompt: An institution case shows how family, education, religion, economy, government, or health systems affect behavior.

Step 1: Name the institution. This identifies the sociology object before reasoning.

Step 2: Identify which system is involved. This ties the answer to the embedded model, source, chart, or scenario evidence.

Step 3: Institutions organize social life. This is the teachable conclusion for MLA.SOC.INST.2.

Worked Example 2

Prompt: An institution case shows how family, education, religion, economy, government, or health systems affect behavior.

Step 1: Find function and impact. This identifies the sociology object before reasoning.

Step 2: Use the chart or scenario evidence. This ties the answer to the embedded model, source, chart, or scenario evidence.

Step 3: Institutions can help and limit people. This is the teachable conclusion for MLA.SOC.INST.2.

Worked Example 3

Prompt: An institution case shows how family, education, religion, economy, government, or health systems affect behavior.

Step 1: Explain change. This identifies the sociology object before reasoning.

Step 2: Connect stability, conflict, or reform. This ties the answer to the embedded model, source, chart, or scenario evidence.

Step 3: Institutions are not static. This is the teachable conclusion for MLA.SOC.INST.2.

Embedded Sociology Support: institution change analysis matrix

Student check: Use this support before answering. Your explanation should name the social pattern, cite one piece of evidence, and connect it to the mapped standard without stereotyping or guessing.

Common Mistake

Correct: using sociological evidence to explain the social pattern within the mapped standard.

Incorrect: making a stereotype, personal opinion, or unsupported claim without evidence.

Teachable Explanation

Each example uses the same mastery path: define the social pattern or institution, read the evidence, apply the correct concept, and state a careful conclusion.
