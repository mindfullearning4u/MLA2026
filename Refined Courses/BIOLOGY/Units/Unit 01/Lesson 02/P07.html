Teacher of Record Graded

This checkpoint is submitted for Teacher of Record review. It shows whether you can design a fair, safe investigation plan from a biological question.

Checkpoint Task

Scenario: A student wants to know how light duration affects radish seedling height using provided class data.

  1. Write the testable question.
  2. Identify the independent variable, dependent variable, and at least four controls.
  3. Write a five-step safe data-based procedure.
  4. Create a blank data table with correct headings.
  5. Write one sentence explaining how the evidence would answer the question.
