Vocabulary You Will Use

TermStudent-Friendly Meaning
independent variablethe factor deliberately changed
dependent variablethe outcome measured
control variablea condition kept the same
control groupa comparison group without the tested treatment
trialone complete repetition of a procedure
confounding variablean uncontrolled difference that could explain the result

First, Read the Biology

How to read this visual: Name each labeled part or condition. Follow arrows only in their stated direction. Then connect the visible feature to a biological function or process.

Step-by-Step Teaching Sequence

  1. Step 1: Start with one measurable cause-and-effect question.
  2. Step 2: Name the independent variable, dependent variable, comparison group, and constants before writing the procedure.
  3. Step 3: Use repeated trials and one change at a time so differences can be attributed to the tested factor.
  4. Step 4: Write numbered, safe steps and prepare a data table with units before collecting data.
