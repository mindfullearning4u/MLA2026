P04 Worked Example

Worked Example 1: Identify Variables

Problem: A student asks, "How does temperature affect yeast bubble production in a virtual data set?" Identify the variables.

  1. Step 1: Find what is changed on purpose: temperature. Why: This is the condition being compared.
  2. Step 2: Find what is measured: number of bubbles produced in 5 minutes. Why: This is the outcome that provides evidence.
  3. Step 3: List controls: yeast amount, sugar amount, container size, time, and measurement method. Why: These must stay the same for a fair comparison.

Interpretation: The plan can test temperature only if temperature is the main changed factor.

Worked Example 2: Improve a Question

Problem: Improve this question: "Do seeds like water?"

  1. Step 1: Replace "like" with a measurable outcome. Why: Preference is not directly measured in seeds.
  2. Step 2: Name the changed factor. Why: The investigation needs an independent variable.
  3. Step 3: Add a time frame. Why: Measurements need a consistent endpoint.

Improved question: How does the amount of water affect the percent of bean seeds that germinate after 7 days?

Interpretation: The improved question can be answered with a data table.

Worked Example 3: Build an Investigation Plan

Problem: Plan a safe data-based investigation for this question: How does light color affect the growth of algae in a provided virtual data set?

Plan PartCompleted Plan
Independent variableLight color
Dependent variableAlgae growth measured as cell density
ControlsSame starting algae amount, container, nutrients, temperature, and time
  1. Step 1: Use provided virtual data only. Why: This avoids unsafe or unapproved wet lab materials.
  2. Step 2: Record cell density for each light color. Why: The dependent variable must be measured consistently.
  3. Step 3: Compare averages and write a CER conclusion. Why: The conclusion must use evidence, not a guess.

Interpretation: A complete plan makes the question, variables, controls, data, and conclusion fit together.

Common Mistake

Incorrect: "The dependent variable is light color because it depends on what color I choose."

Correct: "The independent variable is light color because it is changed on purpose. The dependent variable is algae growth because it is measured."

Teachable explanation: The word dependent means the result may depend on the changed condition; it does not mean the choice the investigator makes.
