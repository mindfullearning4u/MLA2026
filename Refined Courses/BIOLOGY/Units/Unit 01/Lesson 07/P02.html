Investigation Notebook Title

Biology Foundations Data Investigation: Question, Purpose, and Evidence Setup

Copy this title into your notebook. Under it, create four labeled sections: Investigation Question, Variables or Comparison Groups, Data/Model Evidence, and CER Draft.

Vocabulary

  • Investigation question: the testable question the evidence is being used to answer.
  • Variable: a factor that changes or is measured in an investigation.
  • Control or controlled condition: what stays the same so the comparison is fair.
  • Evidence: specific data, observation, model detail, or source information that supports a claim.
  • CER: claim, evidence, and reasoning.

Step-by-Step Setup

  1. Step 1: Read the investigation purpose: Students analyze a simulated investigation comparing microscope observations, cell-theory evidence, water-property evidence, and macromolecule data to decide which evidence best supports a biological claim.
  2. Step 2: Write one focused question the data can answer. Do not write a question that requires outside research.
  3. Step 3: Identify the comparison groups or variables from the table below.
  4. Step 4: Mark which evidence will be numerical data, which will be a model, and which will be a source or scenario.
