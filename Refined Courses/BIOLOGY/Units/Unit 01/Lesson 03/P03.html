Common Mistake

Incorrect: "The 11.9 cm value proves Plant B grew much more, so I will use it without question."

Correct: "The 11.9 cm value does not match the nearby Plant B trials, so I should flag it as a possible outlier and check the procedure or recording notes before using it in a conclusion."

Teachable Explanation: Strong data analysis notices patterns and possible errors. A conclusion should not depend on one suspicious value without explanation.
