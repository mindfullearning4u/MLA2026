Notebook Title: Classification and Evolutionary Relationships

Vocabulary

  • Classification: grouping organisms based on evidence.
  • Cladogram: diagram showing hypothesized evolutionary relationships.
  • Common ancestor: ancestral population shared by later groups.
  • Derived trait: trait that appears in a lineage and helps define a group.
  • Phylogeny: evolutionary history and relationships.

Detailed Teaching Sequence

Modern classification uses evolutionary relationships, not just appearance. Cladograms show hypotheses about common ancestry. Branch points represent common ancestors. Traits shown on branches help explain which groups share derived traits. Classification can change when new evidence, especially molecular evidence, improves the relationship model.

Cladogram FeatureMeaning
Branch pointCommon ancestor
Shared derived traitEvidence for grouping
Closer branchesMore recent common ancestry
New DNA evidenceMay revise classification
