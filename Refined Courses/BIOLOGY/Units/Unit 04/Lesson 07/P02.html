Investigation Notebook Setup

Genetics, Cell Division, and Biotechnology Investigation: Question, Purpose, and Evidence Setup

Copy this title into your notebook. Under it, create these six labeled sections: Investigation Question, Claim Being Tested, Variables or Comparison Groups, Controlled Conditions, Data/Model Evidence, and CER Draft.

Vocabulary

  • Investigation question: the testable question the evidence is being used to answer.
  • Variable: a factor that changes or is measured in an investigation.
  • Control or controlled condition: what stays the same so the comparison is fair.
  • Evidence: specific data, observation, model detail, or source information that supports a claim.
  • CER: claim, evidence, and reasoning.

Step-by-Step Setup

  1. Step 1: Copy this investigation question: How can DNA, mutation, inheritance, and biotechnology evidence explain variation in a fictional genetics case?
  2. Step 2: Copy this claim being tested: Genetic information can be copied, expressed, changed, inherited, and analyzed using evidence from DNA and inheritance models.
  3. Step 3: Copy the variable or comparison focus: Evidence source being compared: DNA sequence, codon effect, Punnett square, cell division model, and biotechnology case data.
  4. Step 4: Copy the controlled conditions: Use the same fictional trait and the same parent genotypes for all inheritance comparisons.
  5. Step 5: Read the evidence table below. Put a star next to the two evidence rows that most directly answer the investigation question.
