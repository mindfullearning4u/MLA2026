P04 Worked Example

Worked Example 1: Classify a mutation

Problem: Original DNA: A T G. Mutated DNA: A C G. What type is shown?

  1. Step 1: Compare each position. Why: mutation type comes from sequence change.
  2. Step 2: Notice T changed to C. Why: one base was replaced.
  3. Step 3: Name substitution. Why: replacement of one base is substitution.

Interpretation: This is a substitution mutation.

Worked Example 2: Predict possible phenotype impact

Problem: A mutation changes an enzyme active site. Why might phenotype change?

  1. Step 1: Identify the affected product: enzyme. Why: proteins perform cell work.
  2. Step 2: Connect active site to function. Why: shape affects substrate binding.
  3. Step 3: Explain phenotype effect if cell process changes. Why: altered function can affect traits.

Interpretation: Protein function can link mutation to phenotype.

Worked Example 3: Separate inherited and non-inherited mutations

Problem: A mutation occurs in a skin cell. Is it automatically passed to offspring?

  1. Step 1: Identify the cell type. Why: skin cells are body cells.
  2. Step 2: Recall inheritance requires reproductive cells. Why: offspring inherit from gametes.
  3. Step 3: State it is not automatically inherited. Why: body-cell mutations usually affect only that organism.

Interpretation: Cell type matters when discussing inheritance.

Common Mistake

Incorrect: "All mutations are harmful and always passed to offspring."

Correct: "Mutations can be harmful, neutral, or beneficial, and only inherited mutations can be passed to offspring."

Teachable explanation: Mutation effects must be evaluated from sequence, protein, cell type, and phenotype evidence.
