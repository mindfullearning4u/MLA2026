P04 Worked Example

Worked Example 1: Match function to organelle

Problem: A cell needs to build many proteins. Which organelle is most directly involved?

  1. Step 1: Identify the function: protein building. Why: the function tells you what job is needed.
  2. Step 2: Match the function to the table. Ribosomes build proteins. Why: ribosomes assemble amino acids into proteins.
  3. Step 3: Choose ribosomes. Why: they directly perform the needed function.

Interpretation: The answer comes from matching the job to the structure.

Worked Example 2: Use a structure clue

Problem: An organelle has folded inner membranes and releases usable energy. Identify it.

  1. Step 1: Read the structure clue. Folded inner membranes are given. Why: structure clues help identify organelles.
  2. Step 2: Read the function clue. It releases usable energy. Why: function confirms the structure clue.
  3. Step 3: Identify the mitochondrion. Why: mitochondria match both clues.

Interpretation: Two clues make the identification stronger.

Worked Example 3: Explain structure-function

Problem: Why does a chloroplast's structure support photosynthesis?

  1. Step 1: Name the function. Photosynthesis uses light to make sugars. Why: function frames the explanation.
  2. Step 2: Name the structure. Chloroplasts contain pigments and internal membranes. Why: those structures help capture light and organize reactions.
  3. Step 3: Connect structure to function. Why: a strong answer explains how the parts support the job.

Interpretation: Structure-function explanations must include both the structure and the job.

Common Mistake

Incorrect: "Mitochondria store DNA because they are large organelles."

Correct: "The nucleus stores most cell DNA; mitochondria release usable energy for cell work."

Teachable explanation: Size is not the best clue. Match each organelle to the job it is specialized to perform.
