# Biology Phase 3A-A: Mapping Framework

## Purpose

This framework governs how Biology standards are distributed across the approved MLA six-unit, eight-lesson structure. It establishes coursewide mapping rules before unit-level and lesson-level mapping are finalized.

This is architecture only. It does not create lessons, assessments, HTML content, JSON content, GIFT content, or LMS pages.

## Required Mapping Structure

| Item | Required Control |
|---|---|
| Course | Biology |
| Units | 6 |
| Lessons per unit | 8 |

| Unit assessment location | Lesson 8 |
| Unit diagnostic | Unit Pretest |

## Mapping Principles

1. Florida Biology 1 science benchmarks drive primary content alignment.
2. MLA Biology standards provide the mastery framework for production.
3. Scientific inquiry, lab safety, data analysis, evidence, and technical communication are embedded across all units.
4. Embedded ELA Expectations, MTRs, ELD standards, and health support benchmarks are used as support standards unless the lesson focus requires a direct biological health connection.
5. Adjacent science content is limited to what Biology 1 standards require.
6. Lesson 8 in every unit synthesizes standards taught in Lessons 1-7 and contains the Unit Assessment.
7. No Lesson 8 introduces a new primary standard.

## Unit Sequencing Rationale

| Unit | Title | Sequencing Rationale |
|---|---|---|
| Unit 1 | Scientific Thinking and Biology Foundations | Establishes the lab, evidence, nature-of-science, microscopy, cell theory, and molecule foundations needed before deeper biological systems work. |
| Unit 2 | Cells, Homeostasis, and Transport | Builds from cell theory into cell types, structure/function, transport, homeostasis, and selected biological systems. |
| Unit 3 | Cellular Energy and Life Processes | Uses cell structure knowledge to explain water, enzymes, ATP, photosynthesis, respiration, matter cycling, and plant physiology. |
| Unit 4 | DNA, Genetics, and Heredity | Moves from cellular processes into DNA, gene expression, inheritance, mutation, cell division, biotechnology, and reproduction. |
| Unit 5 | Evolution, Classification, and Diversity of Life | Uses genetics and variation as a foundation for evolution, natural selection, classification, diversity, and origin-of-life explanations. |
| Unit 6 | Ecology, Interdependence, and Human Impact | Culminates with organism-environment relationships, populations, ecosystems, biodiversity, sustainability, resources, and human impact. |

## Assessment Evidence Rules

| Assessment Evidence Type | Mapping Use |
|---|---|
| Unit Pretest | Diagnostic evidence for unit readiness and prior knowledge. |
| Notebook Evidence | Process evidence: notes, observations, data tables, models, explanations, vocabulary, and reasoning. |
| Guided Practice | Scaffolded evidence of the lesson's primary standard. |
| Checkpoint | Independent application evidence for the lesson's primary and support standards. |
| Lesson Quiz | Standards-aligned verification for Lessons 1-7. |
| Unit Assessment | Synthesis evidence in Lesson 8 using standards already taught in Lessons 1-7. |

## Laboratory and Virtual Lab Controls

Biology is a laboratory science course. Each unit must include architecture support for lab or virtual lab experiences, including:

- safety expectations
- measurable variables
- data collection or use of authentic data
- tables, graphs, or model interpretation
- evidence-based explanation
- technical communication

Virtual labs may use simulations, data sets, models, microscopy images, case data, or field-observation data when physical lab access is not available. Virtual lab expectations must preserve inquiry, data analysis, and safety reasoning.

## Lesson 8 Control

Every Unit Lesson 8 must:

- be titled Putting It All Together
- contain the Unit Assessment
- synthesize standards already taught in Lessons 1-7
- introduce no new primary standard
- use support standards only to reinforce evidence, reading, data, communication, or synthesis expectations

## Mapping Validation Rules

| Rule | Validation Method |
|---|---|
| 48 lesson rows required | Count lesson-level mapping rows. |
| 6 units required | Count unit mapping sections. |
| 8 lessons per unit required | Verify lesson numbers 01-08 in every unit. |
| Lesson 8 no-new-primary-standard rule | Compare Lesson 8 primary standards to Lessons 1-7 in same unit. |
| Florida alignment complete | Verify each MLA standard maps to Florida benchmark codes. |
| Lab and data expectations represented | Verify SCI/LAB standards and lab evidence appear across units. |
| Biology identity preserved | Verify adjacent science content remains benchmark-bound. |
