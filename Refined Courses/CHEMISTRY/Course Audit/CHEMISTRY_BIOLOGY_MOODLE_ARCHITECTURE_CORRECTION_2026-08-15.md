# Chemistry Biology-Matched Moodle Architecture Correction — 2026-08-15

## Required architecture

Chemistry must follow the live Biology Moodle pattern:

1. A unit is one Moodle course section.
2. Each lesson is one Moodle Lesson activity.
3. Each Moodle Lesson activity contains these eight ordered content pages:
   1. Lesson Overview and Notebook-Evidence Checklist
   2. Notebook Task 1 — Vocabulary
   3. Notebook Task 2 — Savvas eText Lesson
   4. Model, Worked Example, or Guided Exploration
   5. Lesson Review
   6. Independent Application
   7. Checkpoint
   8. Help and TOR Support
4. Each lesson is followed by Notebook Evidence Submission and Checkpoint Submission assignments.
5. Each assignment is restricted until its Moodle Lesson is marked complete.
6. Lesson completion requires viewing the Lesson and reaching the end.
