## Embedded Stimuli and Data

Every question includes an embedded HTML stimulus table, model, or data set before the answer choices. The stimuli support no-teacher, self-contained assessment by placing the needed reference information directly inside the item.

Included stimulus families:

- atomic theory evidence table
- subatomic particle charge, mass, and location table
- isotope abundance and weighted-average mass table
- electron arrangement and periodic-position table
- periodic trend comparison table
- quantized energy event table
- electromagnetic spectrum application table
- Unit 2 synthesis table combining atomic structure, periodic trends, and spectrum evidence
