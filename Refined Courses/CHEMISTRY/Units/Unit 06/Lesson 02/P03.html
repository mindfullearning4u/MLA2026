pH and Quantitative Acid-Base Reasoning: Misconception Repair

Common Incorrect Idea

A pH difference of 2 units is not a difference of 2 times. It represents a 100-fold difference because the pH scale is logarithmic.

Step-by-Step Correction

  1. Identify the claim.
  2. Find the relevant pH data, ion model, rate graph, equilibrium model, or source evidence.
  3. Check whether the claim uses the correct chemistry relationship.
  4. Write the corrected claim.
  5. Explain why the evidence supports the correction.
Practice: Correct the misconception using one specific detail from Page 2.
