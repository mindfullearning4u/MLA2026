P05 Guided Practice

Purpose of Guided Practice

Guided Practice checks whether you can apply this lesson before the independent checkpoint. Use the model, data, or diagram from the lesson and show reasoning before choosing an answer.

Practice Focus: Use periodic patterns to reason about atomic properties.

How to Prepare

  1. Review vocabulary on P02.
  2. Review the misconception correction on P03.
  3. Review all three worked examples on P04.
  4. For each practice item, write the evidence first, then the conclusion.

Standards Reminder

Primary Standards: MLA.CHEM.ATO.03
