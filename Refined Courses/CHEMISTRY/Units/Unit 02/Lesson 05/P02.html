Notebook Title: Unit 2 Lesson 05 - Periodic Trends and Chemical Properties

Vocabulary

  • Periodic trend: a repeating pattern in element properties across the periodic table.
  • Atomic radius: a measure of atom size.
  • Ionization energy: energy needed to remove an electron.
  • Electronegativity: attraction for shared electrons.
  • Shielding: inner electrons reducing attraction between nucleus and outer electrons.

Start With the Big Idea

Use periodic patterns to reason about atomic properties. This lesson is hard if you try to memorize words without connecting them to evidence. Read each model or table slowly and ask what the evidence proves.

Step-by-Step Teaching Sequence

  1. Step 1: Identify whether elements are compared across a period or down a group.
  2. Step 2: Choose the trend being asked about.
  3. Step 3: Use structure reasoning, not memorization alone.
  4. Step 4: Across a period, increasing nuclear charge often pulls electrons closer.
  5. Step 5: Down a group, added energy levels and shielding often make atoms larger.

How to Read the Visual

  1. Read the column headings before using any numbers or labels.
  2. Identify the evidence the table or model provides.
  3. Connect each row to the lesson vocabulary.
  4. Write one conclusion that the evidence supports and one conclusion it does not support.

Notebook Evidence

Copy the visual or data display in your notebook. Under it, write three evidence statements using the sentence frame: The evidence shows ___ because ___.
