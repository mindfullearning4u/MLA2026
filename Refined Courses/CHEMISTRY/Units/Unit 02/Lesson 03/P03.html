Continue the Teaching

Isotopes do not change the element identity because the proton number stays the same. Chlorine-35 and chlorine-37 are both chlorine because both have 17 protons. They differ because chlorine-37 has two more neutrons.

Average atomic mass is usually not a whole number because it is a weighted average. If one isotope is more common, the average will be closer to that isotope's mass.

Common Mistake: Averaging isotope masses without using abundance, or thinking different neutrons create a different element.
Incorrect: Chlorine-35 and chlorine-37 are different elements because they have different mass numbers.
Correct: Chlorine-35 and chlorine-37 are isotopes of the same element because both have 17 protons; they differ in neutrons.
