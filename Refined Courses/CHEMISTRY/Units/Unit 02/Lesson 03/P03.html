P03 Notebook Task - Part 2

Continue the Teaching

Isotopes do not change the element identity because the proton number stays the same. Chlorine-35 and chlorine-37 are both chlorine because both have 17 protons. They differ because chlorine-37 has two more neutrons.

Average atomic mass is usually not a whole number because it is a weighted average. If one isotope is more common, the average will be closer to that isotope's mass.

Reasoning Steps for This Lesson

  1. Identify the specific atomic evidence, particle count, periodic pattern, energy change, or spectrum information.
  2. Name the Chemistry concept that matches that evidence.
  3. Apply the correct rule or model one step at a time.
  4. Check that the conclusion does not claim more than the evidence supports.
  5. Write the final explanation using lesson vocabulary.
Common Mistake: Averaging isotope masses without using abundance, or thinking different neutrons create a different element.
Incorrect example: Chlorine-35 and chlorine-37 are different elements because they have different mass numbers.
Correct example: Chlorine-35 and chlorine-37 are isotopes of the same element because both have 17 protons; they differ in neutrons.

Teachable Explanation

The correct example is stronger because it uses evidence and the specific Unit 2 concept. Atomic structure and periodic patterns are not guessed; they are reasoned from models, data, and particle relationships.
