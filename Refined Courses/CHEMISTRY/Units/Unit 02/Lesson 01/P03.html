P03 Notebook Task - Part 2

Continue the Teaching

Atomic theory did not change because scientists guessed randomly. It changed because evidence created problems for older models. Rutherford expected alpha particles to pass through if positive charge was spread out. Most did pass through, but a few bounced back sharply. That tiny number mattered because it showed positive charge and mass were concentrated in a small nucleus.

When a model changes, the older model is not simply thrown away as useless. It may still explain some observations, but the newer model explains more evidence.

Reasoning Steps for This Lesson

  1. Identify the specific atomic evidence, particle count, periodic pattern, energy change, or spectrum information.
  2. Name the Chemistry concept that matches that evidence.
  3. Apply the correct rule or model one step at a time.
  4. Check that the conclusion does not claim more than the evidence supports.
  5. Write the final explanation using lesson vocabulary.
Common Mistake: Thinking that newer models prove older scientists were careless, instead of understanding that models improve when better evidence becomes available.
Incorrect example: Rutherford's model replaced Thomson's model because Rutherford liked a different picture of the atom.
Correct example: Rutherford's model replaced Thomson's model because scattering evidence showed that positive charge and most mass are concentrated in a tiny nucleus.

Teachable Explanation

The correct example is stronger because it uses evidence and the specific Unit 2 concept. Atomic structure and periodic patterns are not guessed; they are reasoned from models, data, and particle relationships.
