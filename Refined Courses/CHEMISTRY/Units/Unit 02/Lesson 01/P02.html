P02 Notebook Task - Part 1

Notebook Title: Unit 2 Lesson 01 - Atomic Theory and Experimental Evidence

Vocabulary

  • Atomic theory: the evidence-based explanation that matter is made of atoms.
  • Model: a representation used to explain observations and make predictions.
  • Evidence: observations or data that support or challenge a model.
  • Revision: a change to a model when new evidence shows the old model is incomplete.
  • Limitation: something a model cannot explain well.

Start With the Big Idea

Explain how evidence changed atomic models over time. This lesson is hard if you try to memorize words without connecting them to evidence. Read each model or table slowly and ask what the evidence proves.

Step-by-Step Teaching Sequence

  1. Step 1: Start with the observation or experiment.
  2. Step 2: Ask what the older model predicted.
  3. Step 3: Compare the prediction to the evidence.
  4. Step 4: Identify what the old model could not explain.
  5. Step 5: Explain how the new model fixed that limitation without claiming it is perfect.

How to Read the Visual

  1. Read the column headings before using any numbers or labels.
  2. Identify the evidence the table or model provides.
  3. Connect each row to the lesson vocabulary.
  4. Write one conclusion that the evidence supports and one conclusion it does not support.

Notebook Evidence

Copy the visual or data display in your notebook. Under it, write three evidence statements using the sentence frame: The evidence shows ___ because ___.
