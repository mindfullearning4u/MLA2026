Three Worked Examples

Study how each answer is built. You are not required to submit this page.

Example 1 — Rank regions

Question: Compare infrared, visible, and ultraviolet.

Reasoning: In the spectrum order, infrared comes before visible, and ultraviolet comes after visible. Therefore wavelength: infrared > visible > ultraviolet. Frequency and energy reverse: ultraviolet > visible > infrared.

Example 2 — Calculate frequency

Given: λ = 486 nm. First convert: 486 nm × (1 m / 109 nm) = 4.86 × 10−7 m.

Use: ν = c/λ = (3.00 × 108 m/s)/(4.86 × 10−7 m) = 6.17 × 1014 s−1. The meter units cancel.

Example 3 — Interpret a line spectrum

Evidence: A reference element has bright lines at 410, 434, 486, and 656 nm. An unknown has the same four lines.

Conclusion: The unknown contains the reference element because all line positions match. The pattern—not color alone—is the atomic fingerprint. If a line were missing or extra, more evidence would be needed.

Problem-solving routine: identify the relationship → convert units → substitute values → calculate with units → connect the result to atomic evidence.
