From atomic number to arrangement

For a neutral atom, electrons equal the atomic number. In the simplified model used for the first 20 elements, place 2 electrons in the first level, up to 8 in the second, and then continue to the next level.

How arrangement reveals position

Period: count occupied energy levels.

Valence pattern: count electrons in the outer occupied level.

Main-group elements with the same valence-electron count often appear in the same group and show related chemical behavior.

Neutral atoms and ions

Changing electrons changes charge, not element identity. Element identity still depends on protons.

Common error: Do not call all electrons valence electrons. Only electrons in the outer occupied level are valence electrons.
