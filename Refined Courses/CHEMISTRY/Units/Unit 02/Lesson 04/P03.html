From atomic number to arrangement

For a neutral atom, electrons equal the atomic number. In the simplified model used for the first 20 elements, place 2 electrons in the first level, up to 8 in the second, and then continue to the next level.

Read Electron Arrangement on the Periodic Table

The periodic table is organized in horizontal periods and vertical groups. For main-group elements, the simplified electron arrangement gives two useful location clues.

Number of occupied energy levels = period number.

Number of outer-level electrons = main-group valence pattern.

Example: aluminum has the arrangement 2, 8, 3

  1. Total electrons: 2 + 8 + 3 = 13, so a neutral atom is aluminum, atomic number 13.
  2. Period: three occupied energy levels place aluminum in Period 3.
  3. Group pattern: three electrons in the outer level place aluminum in the Group 13 main-group pattern.
  4. Meaning: aluminum is in the same period as sodium and chlorine but has a different outer-electron pattern, so their chemical behavior differs.

How arrangement reveals position

Period: count occupied energy levels.

Valence pattern: count electrons in the outer occupied level.

Main-group elements with the same valence-electron count often appear in the same group and show related chemical behavior.

Neutral atoms and ions

Changing electrons changes charge, not element identity. Element identity still depends on protons.

Common error: Do not call all electrons valence electrons. Only electrons in the outer occupied level are valence electrons.
