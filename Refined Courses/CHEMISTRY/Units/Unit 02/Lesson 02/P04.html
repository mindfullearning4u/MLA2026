P04 Worked Example

Worked Example 1

Problem: A neutral carbon atom has atomic number 6 and mass number 12. Find protons, neutrons, and electrons.

  1. Atomic number is 6, so protons = 6.
  2. Neutral atom means electrons = protons = 6.
  3. Neutrons = mass number - atomic number = 12 - 6 = 6.
  4. Answer: 6 protons, 6 neutrons, 6 electrons.

Worked Example 2

Problem: Which particle determines the element?

  1. Element identity depends on atomic number.
  2. Atomic number counts protons.
  3. Changing protons changes the element.
  4. Answer: proton.

Worked Example 3

Problem: Why does an electron contribute little to mass number?

  1. Electrons have much smaller mass than protons or neutrons.
  2. Mass number counts protons plus neutrons.
  3. Electron mass is usually ignored for mass number.
Common Mistake: Using mass number as the number of protons or thinking neutrons determine the element identity.
Incorrect example: An atom with mass number 14 must have 14 protons.
Correct example: Mass number is protons plus neutrons. The atomic number gives the number of protons.
