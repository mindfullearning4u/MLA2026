Continue the Teaching

The most important particle for element identity is the proton. Carbon has 6 protons. If the atom has 7 protons, it is not carbon anymore; it is nitrogen. Neutrons can change without changing the element, which creates isotopes. Electrons can change when ions form, but that does not change the element identity.

Common Mistake: Using mass number as the number of protons or thinking neutrons determine the element identity.
Incorrect: An atom with mass number 14 must have 14 protons.
Correct: Mass number is protons plus neutrons. The atomic number gives the number of protons.
