2. Three rules

Protons = atomic number

Neutrons = mass number - atomic number

Charge = protons - electrons

3. What changes what?

  • Changing protons changes the element.
  • Changing neutrons changes the isotope and mass number.
  • Changing electrons changes the charge, not the element.
Common error: Mass number is not the number of protons. Mass number equals protons plus neutrons.
