Worked Example 1

Problem: Convert 3500 g to scientific notation with two significant figures.

  1. Step 1: Identify the meaningful digits: two significant figures means keep 3 and 5.
  2. Move the decimal so the number is from 1 to less than 10: 3500 becomes 3.5.
  3. Count the decimal moves: 3500. to 3.5 is three places left.
  4. Choose exponent sign: the original number is larger than 1, so the exponent is positive.
  5. Answer: 3.5 x 10^3 g.
  6. Check: 3.5 x 1000 = 3500, so the size is reasonable.
  7. Interpretation: Explain what the chemistry evidence shows and why it supports the conclusion.

Worked Example 2

Problem: A graduated cylinder reads 42.6 mL. What does the digit 6 communicate?

  1. Read the unit: mL means volume.
  2. Read the decimal: 42.6 is measured to the tenths place.
  3. The 6 is the estimated or finest reported digit.
  4. Reporting 43 mL would lose precision; reporting 42.6000 mL would invent precision.

Worked Example 3

Problem: Add 12.4 g and 3.15 g and report the answer correctly.

  1. Add the values: 12.4 + 3.15 = 15.55 g.
  2. Check decimal places: 12.4 is measured to tenths; 3.15 is measured to hundredths.
  3. For addition, report to the least precise decimal place, which is tenths.
  4. Round 15.55 g to the tenths place: 15.6 g.
  5. Answer: 15.6 g.
Common Mistake: Confusing precision with accuracy, dropping units, or adding extra zeros that the measuring tool did not show.
Incorrect: The balance reads 12.36 g, so reporting 12.360000 g is better because it has more digits.
Correct: The balance reads 12.36 g, so 12.36 g is the supported measurement. Extra zeros would claim precision the tool did not show.

Teachable Explanation

The examples slow down the measurement reasoning. Always identify the unit first, then precision, then the rule for reporting the answer.
