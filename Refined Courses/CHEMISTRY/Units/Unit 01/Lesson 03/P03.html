P03 Notebook Task - Part 2

Continue the Teaching

Significant figures are not decoration. They tell the reader how precise the measurement is. The value 25 mL and 25.0 mL do not communicate the same precision. The zero in 25.0 mL means the tenths place was measured or intentionally reported.

Scientific notation also preserves meaning. The value 4.5 x 10^-4 g is small because the exponent is negative. It means 0.00045 g, not 45,000 g. The exponent tells how far the decimal moves.

Reasoning Steps for This Lesson

  1. Identify the unit and quantity.
  2. Identify the measured digits shown by the tool or problem.
  3. For scientific notation, move the decimal and count moves.
  4. Use a positive exponent for large values and a negative exponent for small values.
  5. Check whether the reported answer has reasonable precision.
Common Mistake: Confusing precision with accuracy, dropping units, or adding extra zeros that the measuring tool did not show.
Incorrect example: The balance reads 12.36 g, so reporting 12.360000 g is better because it has more digits.
Correct example: The balance reads 12.36 g, so 12.36 g is the supported measurement. Extra zeros would claim precision the tool did not show.

Teachable Explanation

More digits are not always better. Correct Chemistry measurement means reporting what the tool and procedure actually support.
