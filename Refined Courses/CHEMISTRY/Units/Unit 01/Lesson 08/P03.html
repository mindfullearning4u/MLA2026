P03 Notebook Task - Part 2

Continue the Teaching

Synthesis means more than review. It means deciding which skill is needed and then applying it correctly. For example, if a problem includes a safety procedure and a data table, you may need to critique the procedure and interpret the data.

A strong synthesis answer is organized. It begins with the evidence, uses the correct Unit 1 concept, and explains why the conclusion follows.

Reasoning Steps for This Lesson

  1. Identify all stimulus types in the task.
  2. Match each stimulus to a Unit 1 lesson skill.
  3. Underline numbers, units, hazard words, model features, and source details.
  4. Write one conclusion for each stimulus.
  5. Combine the conclusions into one explanation.
Common Mistake: Answering from memory without first identifying which Unit 1 skill the stimulus requires.
Incorrect example: The answer is chemical because the scenario looks like a lab.
Correct example: The classification depends on evidence. If a new substance forms, the change is chemical; if only state, shape, or size changes, it is physical.

Teachable Explanation

Synthesis problems can feel hard because they combine skills. Slow the task down by naming the stimulus type and matching it to the correct Unit 1 reasoning tool.
