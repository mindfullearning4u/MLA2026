P03 Notebook Task - Part 2

Continue the Teaching

A graph is not just a picture. It is a way to show the relationship between variables. If time is chosen by the investigator and temperature is measured in response, time belongs on the x-axis and temperature belongs on the y-axis.

Uncertainty is not failure. It is honest reporting. A thermometer, balance, or graduated cylinder has limits. Repeated trials help show whether the data are consistent.

Reasoning Steps for This Lesson

  1. Identify the independent variable.
  2. Identify the dependent variable.
  3. Write axis labels with units.
  4. Describe the data pattern using increase, decrease, constant, or irregular.
  5. Check for outliers and explain how they should be investigated.
Common Mistake: Putting variables on the wrong axes or deleting an outlier without explaining why it may be error.
Incorrect example: The point 1.95 g/mL does not fit, so delete it and do not mention it.
Correct example: The point 1.95 g/mL is far from 1.02 and 1.03 g/mL, so it should be investigated as a possible outlier before deciding whether to exclude it.

Teachable Explanation

Chemistry data decisions must be documented. If a value is strange, the scientific response is to investigate the procedure, tool, units, and recording before changing the data set.
