Worked Example 1

Problem: Choose graph axes for the temperature table.

  1. Step 1: Identify the variable chosen by the investigation: time.
  2. Place time on the x-axis because it is the independent variable.
  3. Identify the measured response: temperature.
  4. Place temperature on the y-axis because it depends on time in this data set.
  5. Include units: x-axis is Time (min), y-axis is Temperature (deg C).

Worked Example 2

Problem: Describe the trend in the table.

  1. Read the first and last temperature: 22.0 deg C to 35.5 deg C.
  2. Check the middle values: 26.5 deg C and 31.0 deg C also increase.
  3. Write the trend: as time increases from 0 to 6 minutes, temperature increases from 22.0 deg C to 35.5 deg C.
  4. Interpretation: the sample became warmer over the recorded time.

Worked Example 3

Problem: Density trials are 1.02, 1.03, and 1.95 g/mL. What should a student do?

  1. Compare the values: 1.02 and 1.03 are close; 1.95 is far away.
  2. Label 1.95 as a possible outlier, not automatically wrong.
  3. Investigate possible causes: wrong unit, recording error, contaminated sample, or tool problem.
  4. Conclusion: report the concern and explain the investigation before excluding the value.
Common Mistake: Putting variables on the wrong axes or deleting an outlier without explaining why it may be error.
Incorrect: The point 1.95 g/mL does not fit, so delete it and do not mention it.
Correct: The point 1.95 g/mL is far from 1.02 and 1.03 g/mL, so it should be investigated as a possible outlier before deciding whether to exclude it.

Teachable Explanation

The examples show the full path from data to interpretation. In Chemistry, a graph or table does not speak for itself; the student must explain what the pattern means and how certain the evidence is.
