Notebook Title: Unit 1 Lesson 04 - Data Tables, Graphs, Precision, and Uncertainty

Vocabulary

  • Data table: organized rows and columns of values or observations.
  • Independent variable: the variable selected or changed in an investigation.
  • Dependent variable: the measured response.
  • Accuracy: closeness to an accepted value.
  • Uncertainty: the reasonable limit of confidence in a measurement.
  • Outlier: a data value far from the pattern that should be investigated.

Start With the Big Idea

Chemistry data must be organized before it can support a claim. Tables show exact values. Graphs make patterns visible. Uncertainty reminds us that every measurement has limits.

Step-by-Step Teaching Sequence

  1. Step 1: Read the title or scenario. Identify what the investigation is measuring.
  2. Step 2: Identify variables. The independent variable usually goes on the x-axis. The dependent variable usually goes on the y-axis.
  3. Step 3: Check headings and units. A table column must say both the quantity and the unit, such as Time (min) or Temperature (deg C).
  4. Step 4: Describe the pattern. Say whether values increase, decrease, stay constant, or change irregularly.
  5. Step 5: Treat outliers carefully. Do not erase a value just because it is inconvenient. Investigate possible measurement or recording error.

Graph setup: Time (min) belongs on the x-axis. Temperature (deg C) belongs on the y-axis. The points would rise from left to right.

How to Read the Visual

  1. Read column headings before reading numbers.
  2. Notice that time increases by 2 minutes each row.
  3. Notice that temperature also increases each row.
  4. State the trend in words: as time increases, temperature increases.
  5. Use units in the trend statement so the reader knows what was measured.

Notebook Evidence

Copy the table. Then write the graph title, x-axis label, y-axis label, and one trend sentence using units.
