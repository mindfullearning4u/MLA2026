Unit 4 Lesson 06: Chemical and Nuclear Reactions

Standard(s): MLA.CHEM.REA.03

Florida alignment: SC.912.P.10.12; ELA.K12.EE.2.1

Learning target: I can differentiate chemical and nuclear reactions using particle-level evidence.

Start Here

This lesson teaches the process step by step. Read the vocabulary, model, and examples in order before answering practice questions.

Vocabulary Before Use

TermMeaning
chemical reactiona reaction that rearranges electrons and chemical bonds without changing nuclei
nuclear reactiona reaction that changes atomic nuclei
isotopeatoms of the same element with different numbers of neutrons
radiationenergy or particles emitted during nuclear changes
Safety boundary: Chemical vs nuclear comparison analysis using charts and equation models. No radioactive materials or demonstrations are required. Physical reactions, heating, mixing, chemicals, pressure, or nuclear/radiation materials are not part of this independent lesson and require separate Teacher of Record assignment and safety controls.

Required Direct Simulation Link

Open this exact simulation/resource: PhET Build an Atom

Click the link above. After the page opens, follow these steps exactly:

  1. After the simulation opens, use the atom-building workspace with protons, neutrons, and electrons.
  2. Change one particle type at a time: first protons, then neutrons, then electrons.
  3. After each change, read the element name, charge, and mass number shown by the simulation.
  4. Record a table with protons, neutrons, electrons, element identity, mass number, charge, and the lesson connection for Chemical and Nuclear Reactions.
