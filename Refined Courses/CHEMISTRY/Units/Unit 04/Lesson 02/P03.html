Reaction Types: Misconception Repair

Common Incorrect Idea

A reaction is not classified by memorizing one chemical name. Classification comes from the whole equation pattern.

Step-by-Step Correction

  1. Identify the exact claim.
  2. Find evidence in the Page 2 model.
  3. Check whether the claim uses observations, equations, units, or particle changes correctly.
  4. Write the corrected claim.
  5. Explain why the evidence supports the correction.

The corrected explanation is ___ because the evidence shows ___.

Practice: Correct the misconception using one detail from the model.

How to use PhET Balancing Chemical Equations

  1. After the simulation opens, start with the introduction or balance-equation screen.
  2. Select one equation from the lesson activity and change coefficients only, not subscripts.
  3. Turn on atom counts, bar charts, or balance indicators if those tools are available.
  4. Record the unbalanced equation, final coefficients, atom counts on both sides, and the conservation rule shown by the model.
