Vocabulary

Write each term and definition in your notebook. These definitions are provided so every student uses the same chemistry meaning.

  1. law of definite proportions: a compound always contains the same elements in the same fixed ratio by mass.
  2. percent composition: the percent by mass contributed by each element in a compound.
  3. empirical formula: the smallest whole-number ratio of atoms in a compound.
  4. molecular formula: the actual number of each type of atom in one molecule.
  5. mole ratio: a comparison of amounts expressed in moles.
  6. subscript: the small whole number in a formula that shows how many atoms of an element are present.
