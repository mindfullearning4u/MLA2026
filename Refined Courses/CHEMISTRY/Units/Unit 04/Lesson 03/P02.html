How to Reason Through This Lesson

  1. Write the unbalanced equation.
  2. Count atoms of each element on both sides.
  3. Change coefficients only; do not change subscripts.
  4. Recount atoms after each coefficient change.
  5. Confirm that every element has the same count on both sides.
Checkpoint: Cover the conclusion column. Use the evidence and reasoning columns to predict the conclusion, then compare.
