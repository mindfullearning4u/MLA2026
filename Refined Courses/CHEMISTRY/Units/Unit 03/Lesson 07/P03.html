P03 Notebook Task - Part 2

Common Incorrect Idea

Common Mistake: Treating a memorized chemistry phrase as an explanation without using evidence from the model, table, formula, diagram, or source.
Incorrect: The answer is correct because it sounds like the vocabulary word from the lesson.
Correct: The answer is supported when the claim uses the lesson vocabulary and points to specific chemistry evidence.

Teachable Explanation

A chemistry explanation must connect a claim to evidence. If the evidence is missing, the answer is not yet complete even if the vocabulary word is familiar.

Do not use prefixes for ordinary ionic compounds like NaCl. Sodium chloride is not monosodium monochloride.

Step-by-Step Correction

  1. Identify the exact chemistry claim being made.
  2. Find the evidence in the model or table from Page 2.
  3. Decide whether the evidence describes particles, charges, formulas, names, or properties.
  4. Use one sentence to state the corrected claim.
  5. Use a second sentence to explain why the corrected claim is better.

Correction Frame

The correct explanation is ___ because the evidence shows ___.

Practice: Rewrite the misconception in your own words, then correct it using one detail from the model.
