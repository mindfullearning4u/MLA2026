Nomenclature and Chemical Communication: Worked Examples

Study each worked example before attempting independent work. Each example shows the claim, evidence, and reasoning sequence.

Worked Example: MgCl2

Mg is a metal and Cl is a nonmetal, so this is ionic. Mg has a fixed 2+ charge. The name is magnesium chloride.

Worked Example: CuO

O is oxide with a 2- charge. One Cu balances one O, so Cu must be 2+. The name is copper(II) oxide.
