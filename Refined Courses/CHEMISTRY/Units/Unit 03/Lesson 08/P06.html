Possible-answer guide

  • Adding solute while volume stays about the same should increase concentration.
  • Adding water while solute amount stays the same should decrease concentration.
  • Evaporating water while solute remains should increase concentration.
  • 12.0 g ÷ 200 mL = 0.060 g/mL.
  • 8.0 g ÷ 100 mL = 0.080 g/mL, so that solution is more concentrated.
Correction rule: If an answer differs, draw one line through it. Write the corrected answer beside it and add one sentence explaining the chemistry. Do not erase your original work.
