Putting It All Together: Guided Practice

Use This Answer Process

  1. Read the question and identify whether it asks about bonding, formula, composition, property, or naming.
  2. Return to the model table and select the row that is most similar.
  3. Write the evidence before writing the answer.
  4. Write the answer using chemistry vocabulary from Page 1.
  5. Check that the explanation contains both a claim and a reason.

Guided Item

Compare NaCl, CO2, and Cu using one sentence for bonding model, one sentence for formula/composition, and one sentence for property evidence.

Answer Quality Checklist

  • The answer uses the correct lesson vocabulary.
  • The answer includes evidence from a model, formula, table, or property statement.
  • The answer explains why the evidence supports the conclusion.
