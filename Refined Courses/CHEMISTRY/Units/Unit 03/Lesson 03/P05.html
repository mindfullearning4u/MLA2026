Follow these steps exactly

  1. Download the PDF and enter your name and date.
  2. Open PhET and select Make Molecules.
  3. Drag atoms from the displayed kit into the workspace until they connect.
  4. Build water; record H2O, two H atoms, one O atom, and model evidence in row 1.
  5. Build carbon dioxide; record CO2, one C atom, two O atoms, and model evidence in row 2.
  6. Build ammonia; record NH3, one N atom, three H atoms, and model evidence in row 3.
  7. If a target is unavailable, select Larger Molecules; if still unavailable, draw and label it using the formula as the atom-count guide.
  8. Complete all three Part B explanations using lesson vocabulary.
  9. Save the PDF and correct it on the next page.
