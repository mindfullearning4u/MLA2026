Chemical Formulas and Compound Composition: Worked Examples

Study each worked example before attempting independent work. Each example shows the claim, evidence, and reasoning sequence.

Worked Example: Na2SO4

Na has subscript 2, so there are 2 Na atoms. S has no subscript, so there is 1 S. O has subscript 4, so there are 4 O atoms.

  2. Apply the lesson rule.
  3. State the chemistry conclusion with evidence.

Worked Example: Al2(SO4)3

Al: 2. The SO4 group is multiplied by 3, so S: 3 and O: 12.

  2. Apply the lesson rule.
  3. State the chemistry conclusion with evidence.

Worked Example: 4NH3

The coefficient 4 multiplies N and H. N: 4 and H: 12.
