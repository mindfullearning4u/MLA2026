# Chemistry Phase 3A-A: Mapping Framework

## Purpose

This framework governs how Chemistry standards are distributed across the approved MLA six-unit, eight-lesson structure. It establishes coursewide mapping rules before unit-level and lesson-level mapping are finalized.

This is architecture only. It does not create lessons, assessments, HTML content, JSON content, GIFT content, or LMS pages.

## Required Mapping Structure

| Item | Required Control |
|---|---|
| Course | Chemistry |
| Units | 6 |
| Lessons per unit | 8 |

| Unit assessment location | Lesson 8 |
| Unit diagnostic | Unit Pretest |

## Mapping Principles

1. Florida Chemistry 1 science benchmarks drive primary content alignment.
2. MLA Chemistry standards provide the mastery framework for production.
3. Scientific inquiry, lab safety, measurement, significant figures, quantitative reasoning, data analysis, evidence, and technical communication are embedded across all units.
4. Embedded ELA Expectations, MTRs, and ELD standards are used as support standards unless the lesson focus requires direct quantitative or communication evidence.
5. Adjacent science content is limited to what Chemistry 1 standards require.
6. Lesson 8 in every unit synthesizes standards taught in Lessons 1-7 and contains the Unit Assessment.
7. No Lesson 8 introduces a new primary standard.

## Unit Sequencing Rationale

| Unit | Title | Sequencing Rationale |
|---|---|---|
| Unit 1 | Scientific Thinking, Measurement, and Matter | Establishes lab, evidence, measurement, significant figures, states of matter, properties, and change before atomic and quantitative chemistry. |
| Unit 2 | Atomic Structure and the Periodic Table | Builds from matter into atomic theory, particles, evidence, energy levels, periodic position, and spectrum applications. |
| Unit 3 | Chemical Bonding and Compounds | Uses atomic structure and periodicity as the foundation for bonding, molecular structure, formulas, compounds, and nomenclature. |
| Unit 4 | Chemical Reactions and Quantitative Chemistry | Uses compound/formula knowledge to classify reactions, balance chemical ideas, apply mole reasoning, and calculate reaction quantities. |
| Unit 5 | Energy, Gases, and Solutions | Builds from particles and reactions into energy transformations, temperature, phase behavior, gases, solutions, and thermochemistry. |
| Unit 6 | Acids, Bases, Equilibrium, and Real-World Chemistry | Culminates with pH, acids/bases, rates, catalysts, dynamic equilibrium, and chemistry-informed societal applications. |

## Assessment Evidence Rules

| Assessment Evidence Type | Mapping Use |
|---|---|
| Unit Pretest | Diagnostic evidence for unit readiness and prior knowledge. |
| Notebook Evidence | Process evidence: measurements, observations, data tables, graphs, models, calculations, explanations, and vocabulary. |
| Guided Practice | Scaffolded evidence of the lesson's primary standard. |
| Checkpoint | Independent application evidence for the lesson's primary and support standards. |
| Lesson Quiz | Standards-aligned verification for Lessons 1-7. |
| Unit Assessment | Synthesis evidence in Lesson 8 using standards already taught in Lessons 1-7. |

## Laboratory and Virtual Lab Controls

Chemistry is a laboratory science course. Each unit must include architecture support for lab or virtual lab experiences, including:

- safety expectations
- measurable variables
- measurement precision and significant figures
- data collection or use of authentic data
- tables, graphs, equations, or model interpretation
- quantitative reasoning
- evidence-based explanation
- technical communication

Virtual labs may use simulations, data sets, particle models, reaction data, graph-based investigations, or case data when physical lab access is not available. Virtual lab expectations must preserve inquiry, data analysis, quantitative reasoning, and safety reasoning.

The controlling Chemistry lab, visual, simulation, and resource matrix is:

- `PHASE_3A_B_3_LAB_VISUAL_SIMULATION_MAPPING.md`

Lesson development, assessment development, Moodle XML production, and Moodle transfer must use that file before production begins. If the matrix identifies a required visual, graph, model, data table, equation, particle diagram, lab, investigation, simulation review, safety note, candidate resource location, or assessment stimulus, the responsible agent must include it or document a standards-based reason for not including it.

Candidate resources are suggestions for approval only. External resources must not be embedded into lessons until approved.

## Lesson 8 Control

Every Unit Lesson 8 must:

- be titled Putting It All Together
- contain the Unit Assessment
- synthesize standards already taught in Lessons 1-7
- introduce no new primary standard
- use support standards only to reinforce evidence, reading, data, communication, quantitative reasoning, or synthesis expectations
