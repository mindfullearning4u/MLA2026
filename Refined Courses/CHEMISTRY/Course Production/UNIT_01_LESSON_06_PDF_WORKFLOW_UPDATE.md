## Standard established for future chemistry lessons

Every Independent Application and Checkpoint that requires student work should provide one consistent answer-sheet PDF containing all questions and any required blank tables, graphs, organizers, CER fields, and correction records. Moodle must tell students exactly which file to download, how to complete it, where corrections are recorded, and which submission activity receives the final file.
