# Chemistry Unit 1 Gradebook and Rubric Configuration

## Assessment attempt policy

The following activities are configured for exactly one attempt:

- U1 PRETEST
- U1 L1 Quiz
- U1 L2 Quiz
- U1 L3 Quiz
- U1 L4 Quiz
- U1 L5 Quiz
- U1 L6 Quiz
- U1 L7 Quiz
- U1 Unit Assessment

If a student does not demonstrate 80% mastery, the Teacher of Record provides an intervention and manually releases another attempt when the student is ready.

- U1 Pretest: 0%
- U1 Notebook Evidence: 20%
- U1 Checkpoints: 20%

All Unit 1 activities are placed in the corresponding Unit 1 gradebook group.
