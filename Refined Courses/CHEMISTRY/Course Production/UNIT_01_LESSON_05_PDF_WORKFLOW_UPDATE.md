# Chemistry Unit 1 Lesson 5 PDF Workflow Update

## Purpose

Lesson 5 now uses standardized fillable PDF answer sheets for the Independent Application and Checkpoint. This keeps submissions consistent and makes grading easier for the Teacher of Record.

## Files

- Independent Application: `CHEM_U1_L5_PHASE_CHANGE_CER_ORGANIZER.pdf`
- Checkpoint: `CHEM_U1_L5_CHANGE_CLASSIFICATION_CHECKPOINT.pdf`
- GitHub folder: `Refined Courses/CHEMISTRY/Worksheets/Unit 01/`

## Independent Application workflow

1. Student opens the Savvas Phase Change resource and reads page 1 only.
2. Student downloads the MLA Question 1 CER Organizer PDF.
3. Student completes Claim, Evidence 1, Evidence 2, and Reasoning in the PDF.
4. After Lesson Review, the student returns to the same PDF and completes the Correction Record.
5. Student submits the single completed and corrected PDF in `U1 L5 Notebook Evidence Submission`.

## Checkpoint workflow

1. Student downloads the two-page U1 L5 Checkpoint Answer Sheet PDF.
2. Student completes the six-row Observation / Classification / Best Evidence table.
3. Student completes the physical-change and chemical-change justifications.
4. Student completes the self-check and Correction Record.
5. Student submits the single completed PDF in `U1 L5 Checkpoint Submission`.
