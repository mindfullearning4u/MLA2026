# Standards Gap and Redundancy Analysis

## Verified result

All 46 required Florida Algebra 1 benchmark codes in the MLA inventory appear in at least one of the 50 audited Savvas core lesson standards panels. Required code-level gaps: **0**.

Savvas additionally lists `MA.912.AR.4.2`, `MA.912.F.2.3`, `MA.912.F.3.1`, `MA.912.DP.2.5`, `MA.912.DP.3.2`, and `MA.912.DP.3.3`. They remain supporting/enrichment and are not added to the required inventory.

Financial-literacy benchmarks `MA.912.FL.3.2` and `MA.912.FL.3.4` are directly visible in the audited Savvas metadata for linear-function and exponential-growth contexts. Polynomial division `MA.912.AR.1.4` is directly visible in Savvas Lesson 6-4.

Code presence is not the same as mastery evidence. Blueprint approval must verify an aligned objective, practice, and named evidence source. Topic 2 metadata inconsistencies and assessment licensing are production risks, not standards-code gaps.

## Redundancy controls

- Linear relationships recur across Topics 2, 3, 4, and 7; each recurrence must progress from representation to comparison, modeling, and synthesis.
- Function analysis recurs across Topics 3, 7, 9, and 10; lesson records must identify whether a benchmark is introduced, practiced, or assessed.
- Polynomial operations and factoring belong in the Unit 5 core sequence, not as a detached duplicate readiness unit.
- Six Savvas-only codes must not be counted as required course benchmarks.
