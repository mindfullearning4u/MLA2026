# ALG1 Benchmark Master Tracker

## Purpose

This tracker establishes a single standards source of truth for `ALG1` using the official Florida Algebra 1 B.E.S.T. benchmark set. It is designed so that:

- every Algebra 1 benchmark has one primary unit placement;
- benchmark wording stays aligned to the official state language;
- unit sequencing reflects prerequisite knowledge and course progression;
- supporting and prerequisite connections can repeat, but primary ownership does not.

## Coursewide Sequence Notes

- Unit 01 establishes symbolic structure, equivalent forms, and polynomial foundations.
- Unit 02 moves into linear equations, linear functions, and function notation.
- Unit 03 extends linear reasoning into inequalities, systems, and feasibility constraints.
- Unit 04 develops quadratic and absolute value reasoning, including graphing, features, and transformations.
- Unit 05 focuses on exponential models, family comparison, and financial literacy applications.
- Unit 06 closes the course with data representation, inference, linear fit, residuals, and categorical association.

## Compliance Notes

- Every official Algebra 1 benchmark in the FDOE Algebra 1 guide is assigned one primary unit in this tracker.
- Primary benchmark ownership is not duplicated across units.
- Supporting and prerequisite references may recur in later units, but primary placement remains fixed here.
