# Algebra 1 Course Structure Analysis

Savvas organizes the course into ten instructional topics, with readiness material before the course, topic-level readiness and assessment ecosystems, and cumulative assessments after Topics 2, 4, 6, 8, and 10.

| Savvas topic | Core lessons |
|---|---:|
| 1. Solving Equations and Inequalities | 6 |
| 2. Linear Equations | 4 |
| 3. Linear and Absolute Value Functions | 5 |
| 4. Systems of Linear Equations and Inequalities | 5 |
| 5. Exponents and Exponential Functions | 4 |
| 6. Polynomials and Factoring | 7 |
| 7. Quadratic Functions | 5 |
| 8. Solving Quadratic Equations | 5 |
| 9. Working With Functions | 4 |
| 10. Analyzing Data | 5 |

Total publisher core lessons: 50. Each topic also includes teacher/student editions, readiness assessment, STEM project, modeling task, MathXL review, performance tasks, and assessments.

## Instructional conclusion

The fixed six-unit/eight-lesson MLA baseline is not traceable one-to-one to the publisher. An eight-unit structure is proposed: one diagnostic foundation unit followed by seven coherent units that preserve Savvas prerequisite order while avoiding an oversized nonlinear-functions unit.

The publisher sequence is instructionally sound overall. The only structural changes proposed are: insert a readiness unit; combine closely related Topics 2-3; combine Topics 5-6; combine Topics 7-8; and retain Topics 4, 9, and 10 as distinct units.
