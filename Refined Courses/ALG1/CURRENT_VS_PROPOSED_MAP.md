# Current vs. Proposed Algebra 1 Map

| Dimension | Current v3 | Proposed architecture |
|---|---|---|
| Units | Fixed 6 | Evidence-based 8 |
| Lessons | Fixed 8 per unit; 48 total | 56 core lessons including 6 readiness lessons |
| Savvas traceability | Mostly synthesized MLA titles | Direct topic/lesson references required |
| Unit 1 | Eight broad foundation lessons | Six targeted prerequisite lessons with diagnostic acceleration |
| Systems | Combined with data and financial literacy | Standalone coherent unit from Topic 4 |
| Nonlinear content | One large quadratics/exponentials unit | Exponent/polynomial, quadratic, and extended-function units separated |
| Data | Combined with systems/financial literacy | Standalone Topic 10 unit |

Major change rationale: the current map asserts complete standards coverage but forces equal unit size and lacks direct traceability to the 2023 Savvas lesson sequence. The proposal preserves publisher progression while adding only the prerequisite foundation and necessary MLA supplements.

No existing file is deleted or overwritten. Approval and standards validation are required before replacement.
