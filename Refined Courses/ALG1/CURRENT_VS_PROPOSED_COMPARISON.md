# Current vs. Approved Algebra 1 Architecture Comparison

Status: Approved replacement baseline (2026-08-03).

| Dimension | Superseded six-unit baseline | Approved eight-unit baseline |
|---|---|---|
| Units | 6 | 8 |
| Lessons | 48, forced to 8 per unit | 64, with content-driven unit lengths |
| Unit pretests | Present but embedded in old production | One separate ungraded pretest per unit; zero grade weight; 90% acceleration-eligibility rule |
| Savvas traceability | Mostly synthesized MLA titles | Direct Savvas topic/lesson, source, standards-panel, and URL traceability |
| Unit 1 | Eight broad foundation lessons | Six targeted readiness lessons plus final synthesis lesson |
| Linear content | Distributed across broad units | Equations/inequalities, linear/absolute-value functions, and systems organized coherently |
| Nonlinear content | Large combined quadratic/exponential unit | Exponents/polynomials, quadratics, and extended functions separated by conceptual sequence |
| Data | Combined with systems and financial literacy | Standalone Savvas Topic 10-aligned data unit |
| Quizzes | Quiz expected in every lesson | Lesson-level or clustered quizzes based on approved Savvas sources |
| Unit ending | Assessment-centered final slot | True synthesis lesson containing the unit assessment |
| Standards evidence | Workbook asserted complete coverage | 46/46 required codes verified against 50 Savvas lesson panels; six extras classified supporting/enrichment |

## Replacement decision

The approved architecture replaces the old fixed six-unit map because the old organization forced equal unit lengths, obscured direct publisher traceability, and required a lesson quiz everywhere. The approved baseline follows the 2023 Savvas sequence, uses content-driven unit lengths, and implements the approved diagnostic, quiz-clustering, and synthesis rules.

## Repository disposition

The superseded `Units/` production tree, v2/v3 maps, proposed duplicates, and old audit records were removed after approval. Git history preserves them. `COURSE_MAP.md`, `UNIT_AND_LESSON_MAPPING.md`, `LESSON_BLUEPRINT.md`, the verified standards workbook, and the approved assessment and implementation requirements are the active architecture inputs.
