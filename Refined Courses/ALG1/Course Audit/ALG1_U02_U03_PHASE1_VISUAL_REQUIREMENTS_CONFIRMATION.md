# ALG1 Units 2-3 Phase 1 Mathematical Visual Requirements Confirmation

**Course:** Algebra 1  
**Units:** Unit 02 and Unit 03  
**Phase:** Phase 1 - Planning Confirmation  
**Production Status:** No implementation began until after this confirmation was recorded.

## Audit Standard

A mathematical visual is required only when it directly supports the learning objective or student task on that specific page or assessment item. A visual is not required simply because a page exists.

P06 and P07 pages require visuals only when students must actively use the representation to complete the independent work or checkpoint task. Workflow directions, notebook reminders, mastery language, and general submission instructions do not require visuals.
