# ALG1 Unit 1 Phase 1 Refined Mathematical Visual Requirements Audit

**Course:** Algebra 1  
**Unit:** Unit 01  
**Scope:** Lessons 2-8, P01-P07, Guided Practice, Lesson Quiz, Unit Pretest, Unit Assessment  
**Phase:** Phase 1 - Planning Only  
**File Modification Status:** No lesson files, assessment files, HTML files, GIFT files, JSON files, or production files were modified.

## Audit Standard

A mathematical visual is required only when it directly supports the learning objective or student task on that specific page or assessment item. A visual is not required simply because a page exists.

## P06 and P07 Refinement Standard

P06 and P07 pages were re-evaluated separately from the direct-instruction pages. A visual is required on P06 or P07 only when the student must actively use that visual to complete the independent work or checkpoint task on that page.

Workflow directions, notebook submission reminders, mastery language, reflection prompts, and general study reminders do not require mathematical visuals. Checkpoint pages require visuals only when the checkpoint task itself asks students to analyze, interpret, complete, compare, or justify a mathematical representation.
