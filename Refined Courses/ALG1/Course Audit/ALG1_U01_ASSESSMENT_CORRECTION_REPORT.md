### Mathematical Visual Requirement Cleanup

Generic `Visual reference:` lines were removed from Unit 1 assessment GIFT files because they were not item-specific mathematical representations and did not meet the minimal sufficient visual principle.

No assessment item currently requires an embedded graph, diagram, or table to be answerable. Items that benefit from a simple representation include the representation directly in the question stem, such as a number-line reference for signed-number comparison.

### Mathematical Notation

Exponent notation was checked for consistency. New exponent items use true superscript notation where applicable, including:

- `2³`
- `2⁴`
- `2⁷`
- `(x²)³`
- `x⁶`
- `5⁰`
- `y⁻³`
- `y³`

No caret notation remains in Unit 1 assessment files.
