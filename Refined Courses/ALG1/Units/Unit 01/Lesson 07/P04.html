P04 Worked Example

Study each example. Notice whether the expression needs combining like terms, distribution, or both.

Worked Example 1: Combine Like Terms

Problem: Simplify 6x + 2x + 5.

6x + 2x + 5 = 8x + 5

Reasoning: Combine 6x and 2x. The constant 5 stays separate.

Worked Example 2: Use the Distributive Property

Problem: Rewrite 5(a + 2).

5(a + 2) = 5a + 10

Reasoning: Multiply 5 by a and multiply 5 by 2.

Worked Example 3: Distribute and Combine

Problem: Simplify 3(x + 4) + 2x.

3(x + 4) + 2x = 3x + 12 + 2x = 5x + 12

Reasoning: Distribute first, then combine like terms.

Common Mistake

Incorrect:

4(y + 6) = 4y + 6

This is incorrect because 4 was not distributed to the 6.

Correct:

4(y + 6) = 4y + 24
