The Distributive Property

The distributive property lets you multiply a factor by every term inside parentheses.

a(b + c) = ab + ac

The outside factor must be distributed to each term inside the parentheses.

Example 3: Distribute to Add

Problem: Rewrite 4(x + 3).

4(x + 3) = 4x + 12

Reasoning: Multiply 4 by x and multiply 4 by 3.

Example 4: Distribute to Subtract

Problem: Rewrite 2(3y - 5).

2(3y - 5) = 6y - 10

Reasoning: Multiply 2 by 3y and multiply 2 by -5.

Distribute, Then Combine

Problem: Simplify 3(x + 4) + 2x.

3(x + 4) + 2x = 3x + 12 + 2x = 5x + 12

Reasoning: First distribute 3. Then combine the like terms 3x and 2x.

Common Mistake

Incorrect example:

3(x + 4) = 3x + 4

This is incorrect because the 3 was only multiplied by x. It must also be multiplied by 4.

Correct example:

3(x + 4) = 3x + 12
