Notebook Title

Lesson 6: Properties of Exponents

Why Exponent Properties Matter

Exponents are a shorthand way to show repeated multiplication. Exponent properties help rewrite expressions without expanding every factor.

Equivalent expressions have the same value, even if they look different.

This lesson prepares you for radicals, exponential models, polynomial structure, and financial formulas later in Algebra 1.

Key Vocabulary

  • Base: The repeated factor in a power.
  • Exponent: The number that tells how many times the base is used as a factor.
  • Power: An expression made of a base and an exponent.
  • Equivalent expressions: Expressions that have the same value.
  • Rational exponent: An exponent written as a fraction.

Core Exponent Laws

  • Product of powers: xm · xn = xm+n
  • Quotient of powers: xm ÷ xn = xm-n, when x is not 0
  • Power of a power: (xm)n = xmn
  • Zero exponent: x0 = 1, when x is not 0
  • Negative exponent: x-n = 1⁄xn, when x is not 0

Example 1: Product of Powers

Problem: Rewrite x3 · x4.

x3 · x4 = x3+4 = x7

Reasoning: The bases are the same, so add the exponents.
