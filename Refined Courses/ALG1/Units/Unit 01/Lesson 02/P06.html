Independent Work Visual Reference

Operation Sign Reasoning
addition with same signs add absolute values and keep the shared sign
addition with different signs subtract absolute values and keep the sign of the number farther from zero
multiplication or division same signs make positive; different signs make negative

Part A: Signed Number Practice

  1. Order the numbers from least to greatest: -6, 2, -9, 0.
  2. Evaluate: -8 + 13.
  3. Evaluate: -5 + (-7).
  4. Evaluate: 10 - (-4).

Part B: Rational Number Practice

  1. Evaluate: (-3)(8).
  2. Evaluate: -24 ÷ (-6).
  3. Evaluate: -3⁄4 + 1⁄4.
  4. Evaluate: 2⁄3 - 5⁄3.

Part C: Error Analysis

These questions require correction and explanation.

  1. A student says -10 is greater than -3 because 10 is greater than 3. Explain the mistake using number line reasoning.
  2. A student evaluates 7 - (-5) as 2. Explain the mistake and show the correct work.
