P03 Concept Instruction

Learn how exponent properties generate equivalent algebraic expressions.

Prerequisite Review: What You Need First

Variable: A letter that represents a number.

Coefficient: The number factor multiplied by a variable expression.

Base: The repeated factor in a power.

Exponent: The number that tells how many times the base is used as a factor.

For example, in 5x to the power of 3, the coefficient is 5, the base is x, and the exponent is 3.

5x3

New Concept: Equivalent Forms

Equivalent algebraic expressions may look different, but they have the same value for every allowed value of the variable.

Exponent properties allow you to rewrite expressions in simpler or more useful forms.

Vocabulary

  • Like bases: Powers with the same base.
  • Product of powers: Multiplying powers with the same base.
  • Quotient of powers: Dividing powers with the same base.
  • Power of a power: Raising a power to another power.
  • Equivalent expression: An expression with the same value as another expression.

How to Generate an Equivalent Algebraic Expression

Example: x to the power of 4 times x to the power of 3

x4 × x3

Step 1: Identify the base. Both powers have base x.

base: x

Step 2: Identify the operation. The powers are being multiplied.

Step 3: Use the product of powers property. Multiplying powers with the same base means add the exponents.

x4 × x3 = x4+3

Step 4: Add the exponents.

4 + 3 = 7

Final Answer:

x4 × x3 = x7

General Process

  1. Identify the base or bases.
  2. Identify the operation: multiply, divide, or raise to a power.
  3. Choose the matching exponent property.
  4. Combine exponents using the operation required by the property.
  5. Simplify coefficients if the expression has them.
  6. Check that the final expression is equivalent to the original expression.

Connecting Exponent Form and Radical Form

Some algebraic expressions use rational exponents. Exponent properties can help rewrite those expressions into equivalent radical forms.

6x to the power of 3/2 means:

6x3/2

Step 1: Separate the exponent 3/2 into 1 and 1/2.

x3/2 = x1x1/2

Step 2: Rewrite x to the power of 1/2 as the square root of x.

x1/2 = √x

Final equivalent form:

6x3/2 = 6x√x

Why This Matters

Equivalent forms make algebra easier to use. They help you simplify expressions, compare expressions, solve equations, and work with formulas more efficiently.
