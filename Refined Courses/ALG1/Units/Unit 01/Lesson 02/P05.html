P05 Guided Practice

This practice is not graded. Try each question, then check the feedback to understand the reasoning.

Mathematical Visual Reference

Operation Sign Pattern Result
same signs positive for multiplication/division; add and keep the sign for addition
different signs negative for multiplication/division; subtract absolute values for addition

Question 1

Which number is less?

-8 or -3

Answer: -8

Feedback: On a number line, -8 is farther left than -3, so -8 is less.

Question 2

Evaluate.

-6 + 14

Answer: 8

Feedback: The signs are different, so subtract the absolute values: 14 - 6 = 8. The positive value has the larger absolute value, so the answer is positive.

Question 3

Evaluate.

5 - (-9)

Answer: 14

Feedback: Subtracting a negative means adding its opposite: 5 - (-9) = 5 + 9 = 14.

Question 4

Evaluate.

(-4)(-7)

Answer: 28

Feedback: The factors have the same sign, so the product is positive. Since 4 × 7 = 28, (-4)(-7) = 28.

Question 5

Evaluate.

-1⁄2 + 3⁄4

Answer: 1⁄4

Feedback: Use fourths: -1⁄2 = -2⁄4. Then -2⁄4 + 3⁄4 = 1⁄4.
