Evaluating Algebraic Expressions

To evaluate an algebraic expression, replace each variable with the given value. Then use the order of operations.

  1. Write the expression.
  2. Substitute the given value for the variable.
  3. Use order of operations to simplify.
  4. Check whether the answer is reasonable.

Example: Substitute and Simplify

Evaluate 4x + 6 when x = 5.

4x + 6

4(5) + 6

20 + 6

26

The value 5 replaces x. Then multiplication is completed before addition.

Common Mistake

Incorrect: 6 + 22 = 82 = 64

Correct: 6 + 22 = 6 + 4 = 10

Exponents are evaluated before addition. Do not add first unless grouping symbols require it.
