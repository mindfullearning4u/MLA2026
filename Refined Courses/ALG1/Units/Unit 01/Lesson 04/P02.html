Lesson 4: Order of Operations and Evaluating Expressions

Why Order Matters

An expression can contain several operations. The order of operations tells us which operation to complete first so everyone gets the same value.

Order matters because changing the order can change the answer.

In this lesson, the goal is to simplify expressions carefully, show each step, and use grouping symbols and exponents correctly.

Order of Operations

  1. Grouping symbols: Simplify inside parentheses or other grouping symbols first.
  2. Exponents: Evaluate powers such as 23 or 52.
  3. Multiplication and division: Work from left to right.
  4. Addition and subtraction: Work from left to right.

Vocabulary

  • Expression: A mathematical phrase that can contain numbers, variables, and operations.
  • Grouping symbols: Symbols such as parentheses that show which part of an expression should be simplified first.
  • Exponent: A number that tells how many times the base is used as a factor.
  • Substitution: Replacing a variable with a given value.
  • Evaluate: Find the value of an expression.

Example 1: Numerical Expression

Problem: Evaluate 7 + 3 × 4.

Think: Multiplication is completed before addition.

7 + 3 × 4

7 + 12 = 19

Answer: 19
