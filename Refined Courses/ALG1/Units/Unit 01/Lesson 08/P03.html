P03 Unit Review - Part 2

Use this page to review expression structure, exponent rules, and simplifying expressions.

Review Focus 3: Algebraic Language

  • A variable represents an unknown or changing quantity.
  • A coefficient is the number multiplying a variable.
  • A constant is a term with no variable.
  • Like terms have the same variable part and the same exponent.

Review Example 3

Problem: In 6x + 9, identify the coefficient and the constant.

Answer: The coefficient is 6. The constant is 9.

Reasoning: The coefficient multiplies the variable. The constant has no variable.

Review Focus 4: Exponents and Equivalent Expressions

  • Use exponent laws to rewrite powers with the same base.
  • Use rational exponents to connect powers and roots.
  • Use the distributive property to rewrite expressions.
  • Combine like terms only when the variable parts match.

Review Example 4

Problem: Simplify 3(x + 4) + 2x.

3(x + 4) + 2x = 3x + 12 + 2x = 5x + 12

Reasoning: Distribute first, then combine like terms.

Common Mistake

Incorrect example:

2x + 5x = 7x2

This is incorrect because combining like terms does not change the variable part.

Correct example:

2x + 5x = 7x

Teachable Explanation: Algebra errors usually happen when a step is skipped or a rule is used without checking the expression, equation, graph, or context first.
