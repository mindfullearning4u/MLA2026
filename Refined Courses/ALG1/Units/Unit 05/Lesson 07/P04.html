P04 Worked Example

Worked Example

Classify the table: \(x: 0, 1, 2, 3\); \(y: 6, 12, 24, 48\)

The first differences are \(6, 12, 24\), so the model is not linear.

The ratios are \(2, 2, 2\), so the table shows exponential growth.

A matching model is \(y=6(2)^x\). The initial value is 6 and the multiplier is 2.
