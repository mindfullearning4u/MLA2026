P04 Worked Example

How to Use These Examples

Read each example slowly. The goal is not just to get an answer; the goal is to understand how each step connects to comparing linear, quadratic, and exponential models.

Worked Example 1: Recognize a linear model

  1. Look for a constant first difference.
  2. A graph is a straight line.
  3. The model changes by adding the same amount each step.

Worked Example 2: Recognize a quadratic model

  1. Look for constant second differences or a parabola.
  2. The rule usually includes x2.
  3. The model can increase then decrease, or decrease then increase.

Worked Example 3: Recognize an exponential model

  1. Look for repeated multiplication by the same factor.
  2. The graph often grows or decays quickly.
  3. Use ratios or percent change to justify the model choice.

Common Mistake

Incorrect: Choose the model with the largest output for one input.

Correct: Model selection depends on the pattern of change across the data, not one output value.

When you check your own work, ask whether your reasoning matches the definition, feature, or model type being used in the lesson.
