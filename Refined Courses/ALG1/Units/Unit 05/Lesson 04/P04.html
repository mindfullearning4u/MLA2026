P04 Worked Example

Step-by-step explanation: Follow each example in order. Notice how the work identifies the structure, applies the correct algebraic process, and checks the result.

How to Use These Examples

Read each example slowly. The goal is not just to get an answer; the goal is to understand how each step connects to graphing quadratics and interpreting key features.

Worked Example 1: Identify the vertex

  1. Find the lowest or highest point of the parabola.
  2. This point is the vertex.
  3. Use the vertex to describe the maximum or minimum output.

Worked Example 2: Find the axis of symmetry

  1. The axis of symmetry passes through the vertex.
  2. It is a vertical line.
  3. Write it in the form x = value.

Worked Example 3: Interpret zeros

  1. Zeros are where the graph crosses the x-axis.
  2. At a zero, the output is 0.
  3. Use zeros to connect a graph to solutions of a quadratic equation.

Common Mistake

Incorrect: The vertex and y-intercept are always the same point.

Correct: The y-intercept is where x = 0. The vertex is the turning point, so they are only the same in some quadratics.
