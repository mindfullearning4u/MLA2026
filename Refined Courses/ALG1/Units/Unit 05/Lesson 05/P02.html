Notebook Title: Lesson 5: Solving and Modeling Quadratics

Notebook Task

Create a heading titled Solving Quadratics. Define root, zero, x-intercept, factor, and zero-product property.

Then solve x2 - 7x + 12 = 0 by factoring. Show how each factor produces one solution.

Key Reminder

The zero-product property says that if two factors multiply to 0, then at least one factor must equal 0.
