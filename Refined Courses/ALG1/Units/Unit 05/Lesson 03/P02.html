P02 Notebook Task - Part 1

Notebook Task

Create a heading titled Recognizing Quadratic Functions. Define quadratic function, parabola, first differences, and second differences.

Then compare the tables \(0, 2, 4, 6, 8\) and \(1, 4, 9, 16, 25\). Identify which table has constant first differences and which table has constant second differences.

Key Reminder

A quadratic table with evenly spaced input values has constant second differences. A linear table has constant first differences.
