P04 Worked Example

Worked Example

Determine whether the table can represent a quadratic function: \(x: 0, 1, 2, 3, 4\); \(y: 2, 5, 10, 17, 26\)

First differences: \(3, 5, 7, 9\).

Second differences: \(2, 2, 2\).

The second differences are constant, so the table can represent a quadratic function.

Context connection: If a function includes a product such as \(x(x+6)\), expanding gives \(x^2+6x\), which is quadratic because the highest power of \(x\) is 2.
