Notebook Title: Lesson 1: Polynomial Operations and Radical Readiness

Notebook Task

Create a heading titled Polynomial Operations. Define monomial, binomial, trinomial, coefficient, term, like terms, and degree.

Then simplify (3x2 + 5x - 4) + (2x2 - x + 7) and explain how you matched like terms.

Key Reminder

Only like terms can be combined. Terms are like terms when they have the same variable part with the same exponent.
