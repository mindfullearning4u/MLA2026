P04 Worked Example

Step-by-step explanation: Follow each example in order. Notice how the work identifies the structure, applies the correct algebraic process, and checks the result.

How to Use These Examples

Read each example slowly. The goal is not just to get an answer; the goal is to understand how each step connects to polynomial operations and radical readiness.

Worked Example 1: Combine polynomial terms

  1. Group like terms with the same variable part.
  2. Add or subtract the coefficients.
  3. Keep the variable part the same, such as x2.

Worked Example 2: Multiply a monomial and binomial

  1. Distribute the monomial to each term.
  2. Multiply coefficients.
  3. Use exponent rules for matching bases, such as x · x = x2.

Worked Example 3: Simplify a square root

  1. Recognize the perfect square under the radical.
  2. √49 = 7 because 72 = 49.
  3. Use perfect squares to prepare for quadratic solving.

Common Mistake

Incorrect: Combine 3x2 + 4x as 7x2.

Correct: Only like terms can be combined. 3x2 and 4x have different variable parts, so they are not like terms.
