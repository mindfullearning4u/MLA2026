Independent Work

Complete each task independently. Include substitution work and context interpretation when needed.

Problems

  1. If f(x) = 7x - 1, find f(3).
  2. If q(x) = x^2 + 5, find q(4).
  3. If r(x) = 30 - 2x, find r(9).
  4. If M(n) = 15n + 40 gives money raised, interpret M(6).
  5. From the table x: 1, 3, 5 and f(x): 8, 14, 20, find f(5).
