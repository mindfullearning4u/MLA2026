P04 Worked Example

Step-by-step explanation: Follow each example in order. Notice how the work identifies the structure, applies the correct algebraic process, and checks the result.

How to Use These Examples

Read each example slowly. The goal is not just to get an answer; the goal is to understand how each step connects to evaluating functions and interpreting outputs.

Worked Example 1: Evaluate a linear function

  1. Use f(x) = 3x - 2.
  2. Substitute 5 for x: f(5) = 3(5) - 2.
  3. Simplify: f(5) = 13.

Worked Example 2: Evaluate from a table

  1. Find the row where the input is 6.
  2. Read the output in the same row.
  3. State the output as the function value for that input.

Worked Example 3: Interpret the output

  1. If d(t) is distance after t seconds, d(8) is distance after 8 seconds.
  2. Evaluate the expression or table entry.
  3. Explain the answer using the context units.

Common Mistake

Incorrect: When evaluating f(5), replace only one x and leave the other x unchanged.

Correct: Every x in the rule must be replaced with the same input value before simplifying.
