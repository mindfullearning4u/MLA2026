P04 Worked Example

Worked Example 1: Evaluate With Order of Operations

Given: p(x) = 2x^2 + 1

Find: p(3)

p(3) = 2(3^2) + 1 = 2(9) + 1 = 19

Answer: p(3) = 19.

Worked Example 2: Interpret an Output

A parking cost function is C(h) = 5h + 8, where h is the number of hours.

C(4) = 5(4) + 8 = 28.

Meaning: Parking for 4 hours costs $28.

Common Mistakes

  • Forgetting to substitute the input for every x in the rule.
  • Squaring after multiplying instead of following order of operations.
  • Reporting the input instead of the output.
  • Leaving off units or context when interpreting an output.
