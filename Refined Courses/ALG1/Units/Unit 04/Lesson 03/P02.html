Notebook Title: Lesson 3: Evaluating Functions

Notebook Setup

Title your notes Evaluating Functions. Create sections for substitution, tables, graphs, and context interpretation.

Vocabulary

  • Evaluate: Substitute an input and simplify to find the output.
  • Input: The value used in the function rule.
  • Output: The result produced by the function.
  • Function value: The output for a specific input, such as f(4).
  • Reasonable input: An input that makes sense in the situation.

Key Idea

Evaluating a function means finding the output for a specific input. The input may come from notation, a table, a graph, or a real-world context.

Teacher-Guided Thinking for Notebook Part 1

Read this as your teacher modeling the first layer of the lesson. In Evaluating Functions, do not begin by guessing a procedure. First name what the problem is asking, identify the quantities or expression parts you can see, and connect the task to MLA.A1.FN.2. Step 1: Copy the vocabulary and underline the words that tell you what operation, relationship, graph feature, or model is being used. Step 2: Write what each number, variable, point, table entry, or expression part represents before calculating. Step 3: Choose the rule only after the structure is clear. A veteran teacher would pause here because many mistakes happen when students compute before they understand the representation.
