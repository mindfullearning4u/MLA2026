P03 Notebook Task - Part 2

Evaluate From Different Representations

Function values can be found from a rule, table, graph, or description.

Example A: Rule

Given: f(x) = 4x - 3

Find: f(5)

f(5) = 4(5) - 3 = 17

Example B: Table

If the table shows x: 1, 2, 3, 4 and f(x): 6, 8, 10, 12, then f(3) = 10.

The input 3 is paired with output 10.

Notebook Task

Evaluate each function value.

  1. f(x) = 2x + 9; find f(6)
  2. g(x) = x^2 - 4; find g(5)
  3. h(x) = 18 - 3x; find h(4)
