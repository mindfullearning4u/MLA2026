P04 Worked Example

Step-by-step explanation: Follow each example in order. Each example names the mathematical object, shows the work, and explains the decision a careful teacher would make.

Study all three worked examples before working independently.

Worked Example 1: Classify and evaluate

Problem: The relation {(0, 2), (1, 5), (2, 8)} follows f(x) = 3x + 2. Classify it and find f(4).

Step 1: Each input appears once, so the relation is a function.

Step 2: Substitute 4 into f(x) = 3x + 2.

Step 3: f(4) = 3(4) + 2 = 14.

Worked Example 2: Interpret key features

Problem: A graph has y-intercept (0, 6) and increases by 2 for each step right. Explain both features.

Step 1: The y-intercept (0, 6) means the starting output is 6.

Step 2: Increasing by 2 each step means the rate of change is 2.

Step 3: The function can be represented by y = 2x + 6.

Worked Example 3: Compare functions

Problem: Compare Function A: y = 2x + 6 and Function B: y = 3x + 1 at x = 5.

Step 1: Function A: y = 2(5) + 6 = 16.

Step 2: Function B: y = 3(5) + 1 = 16.

Step 3: At x = 5, both functions have the same output.

Common Mistake

Incorrect: Using only one skill on a synthesis problem.

Correct: A synthesis task may require classification, evaluation, interpretation, and comparison together.

Teachable Explanation: Match the method to the exact function representation: ordered pairs, notation, equation, graph, table, or context.
