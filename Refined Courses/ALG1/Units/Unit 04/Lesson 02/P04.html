P04 Worked Example

Worked Example 1: Function Rule

Given: f(x) = -4x + 9

Find: f(2)

f(2) = -4(2) + 9 = 1

Answer: f(2) = 1.

Worked Example 2: Context

A cost function is C(x) = 8x + 20, where x is the number of tickets.

C(4) = 8(4) + 20 = 52.

Meaning: Four tickets cost $52.

Common Mistakes

  • Reading f(3) as multiplication instead of as a function value.
  • Substituting the input in only one place when the variable appears more than once.
  • Forgetting order of operations after substitution.
  • Giving an output without explaining its meaning in context.
