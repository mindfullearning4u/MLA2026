P01 Lesson Overview

Lesson Title

Lesson 2: Function Notation

In this lesson, you will interpret function notation as a rule connecting inputs and outputs.

Standards Covered in This Lesson

MLA Standards Covered: No new primary MLA standard; bridge support.

Florida B.E.S.T. Benchmarks Covered: No new primary benchmark.

Common Core Alignment: HSF.IF.A.2 support.

SAT Domain Connection: Algebra / Advanced Math.

ACT Domain Connection: Preparing for Higher Math - Functions / Modeling.

What You Will Learn

  • What function notation means.
  • How to read f(x) as the output of function f for input x.
  • How to evaluate functions using substitution.
  • How to interpret function outputs in context.

What You Will Do

  • Evaluate function rules for given inputs.
  • Connect function notation to ordered pairs.
  • Read values from function tables.
  • Explain what a function value means in context.

How You Will Show Mastery

  • Complete notebook evidence evaluating and interpreting function notation.
  • Submit checkpoint responses that connect notation, inputs, and outputs.
  • Complete the Lesson Quiz with at least 80% mastery.
