Evaluating Function Notation

To evaluate a function, replace the input variable with the given input value and simplify.

Example A

Given: f(x) = 2x + 5

Find: f(3)

f(3) = 2(3) + 5 = 11

Meaning: When the input is 3, the output is 11.

Example B

Given: g(x) = x² - 1

Find: g(4)

g(4) = 4² - 1 = 15

Meaning: When the input is 4, the output is 15.

Notebook Task

Evaluate each function value.

  1. f(x) = 3x - 2; find f(5)
  2. h(x) = x + 7; find h(10)
  3. p(x) = x² + 2; find p(3)
