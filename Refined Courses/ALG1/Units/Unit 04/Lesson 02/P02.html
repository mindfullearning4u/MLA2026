P02 Notebook Task - Part 1

Notebook Setup

Title your notes Function Notation. Create sections for notation, substitution, tables, and contextual interpretation.

Vocabulary

  • Function notation: A way to name a function and show its input, such as f(x).
  • f(x): The output of function f when the input is x.
  • Evaluate: Substitute a value for the input and simplify.
  • Function value: The output produced for a specific input.

Key Idea

The notation f(3) does not mean f times 3. It means the output of function f when the input is 3.
