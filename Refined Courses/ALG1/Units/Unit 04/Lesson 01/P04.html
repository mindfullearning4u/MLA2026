P04 Worked Example

Step-by-step explanation: Follow each example in order. Each example names the mathematical object, shows the work, and explains the decision a careful teacher would make.

Study all three worked examples before working independently.

Worked Example 1: Check ordered pairs

Problem: Decide whether {(0, 3), (1, 5), (2, 7), (3, 9)} represents a function.

Step 1: List the inputs: 0, 1, 2, and 3.

Step 2: No input repeats with a different output.

Step 3: Every input has exactly one output, so the relationship is a function.

Worked Example 2: Find a repeated input

Problem: Decide whether {(2, 5), (4, 7), (2, 9)} represents a function.

Step 1: List the inputs: 2, 4, and 2.

Step 2: The input 2 is paired with both 5 and 9.

Step 3: One input has two different outputs, so the relationship is not a function.

Worked Example 3: Use the vertical line test

Problem: A graph has points (1, 2) and (1, 6). Explain whether it can represent a function.

Step 1: Both points have the same x-value, 1.

Step 2: A vertical line at x = 1 would touch both points.

Step 3: One input has two outputs, so the graph does not represent a function.

Common Mistake

Incorrect: Thinking repeated outputs make a relation not a function.

Correct: Repeated outputs are allowed; repeated inputs with different outputs are not allowed.

Teachable Explanation: Check the exact function object first: ordered pairs, notation, equation, graph, table, or context. Then choose the method that matches that object.
