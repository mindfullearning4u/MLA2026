P04 Worked Example

Worked Example 1: Classify a Relationship

Question: Is (0, 3), (1, 5), (2, 7), (3, 9) a function?

Each input appears once: 0, 1, 2, and 3.

Answer: Yes. Each input has exactly one output.

Worked Example 2: Use a Graph Test

A graph is a function if no vertical line crosses the graph more than once.

A vertical line fails this test because one input has many outputs.

Common Mistakes

  • Thinking repeated outputs make a relationship not a function.
  • Ignoring repeated inputs with different outputs.
  • Using a horizontal line test instead of the vertical line test.
  • Classifying a relationship by appearance without checking inputs and outputs.
