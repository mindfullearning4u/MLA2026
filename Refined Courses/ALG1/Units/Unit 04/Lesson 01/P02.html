Notebook Title: Lesson 1: Introduction to Functions

Notebook Setup

Title your notes Introduction to Functions. Create sections for vocabulary, table tests, graph tests, and function types.

Vocabulary

  • Function: A relationship where each input has exactly one output.
  • Input: The value placed into a relationship, often x.
  • Output: The value produced by a relationship, often y.
  • Domain: The set of input values.
  • Range: The set of output values.
  • Vertical line test: A graph test for whether each x-value has only one y-value.

Key Idea

A relationship is a function if one input does not lead to two different outputs. Repeated outputs are allowed, but repeated inputs with different outputs are not allowed.
