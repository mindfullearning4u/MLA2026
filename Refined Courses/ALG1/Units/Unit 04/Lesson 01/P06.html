P06 Independent Work

Complete the following work independently in the same notebook used for your lesson notes.

Show your thinking clearly. Answer in complete sentences whenever an explanation is required.

Important Important:

The work completed below should be written in the same notebook as your lesson notes. Both your notes and your Independent Work will be included together when you submit your Notebook Evidence assignment.

Instructions

Show each step clearly. Use complete sentences when explaining reasoning or interpreting an answer.

Part A: Core Skill Practice

  1. Determine whether {(0, 4), (1, 6), (2, 8), (3, 10)} is a function. Explain why.
  2. Determine whether {(5, 1), (5, 3), (6, 4)} is a function. Explain why.
  3. Determine whether the table input 0 -> output 2, input 1 -> output 2, input 2 -> output 2 is a function.

Part B: Explain Your Reasoning

  1. For Part A item 1, list each input and output.
  2. Explain why repeated outputs do or do not matter.
  3. Write one sentence explaining the function rule in your own words.

Part C: Error Analysis

  1. A student says {(1, 4), (2, 4), (3, 4)} is not a function because the output 4 repeats.
  2. Identify the mistake.
  3. Correct the statement and explain why the relation is a function.
