P03 Notebook Task - Part 2

Testing Tables and Graphs

Tables, ordered pairs, graphs, and equations can all show whether a relationship is a function.

Example A: Table

The ordered pairs (1, 4), (2, 4), (3, 7), and (4, 7) form a function because each input appears with only one output.

Repeated outputs are allowed because different inputs may produce the same output.

Example B: Non-Function

The ordered pairs (2, 5), (2, 8), (3, 9), and (4, 10) do not form a function because input 2 has two different outputs.

Notebook Task

Decide whether each relationship is a function and explain why.

  1. (0, 1), (1, 3), (2, 5), (3, 7)
  2. (1, 2), (1, 4), (2, 6), (3, 8)
  3. (4, 9), (5, 9), (6, 9), (7, 9)
