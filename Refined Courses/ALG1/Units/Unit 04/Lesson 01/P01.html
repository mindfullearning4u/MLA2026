P01 Lesson Overview

Lesson Title

Lesson 1: Introduction to Functions

In this lesson, you will classify relationships and identify function types from equations, graphs, and tables.

Standards Covered in This Lesson

MLA.A1.FN.1: I can classify relationships and identify function types from equations, graphs, and tables.

Florida B.E.S.T. Benchmark: MA.912.F.1.1

Common Core Alignment: HSF.IF.A.1; HSF.IF.C.7

SAT Domain Connection: Algebra / Advanced Math.

ACT Domain Connection: Preparing for Higher Math - Functions / Modeling.

What You Will Learn

  • How a function pairs each input with exactly one output.
  • How to identify functions from tables, mappings, graphs, and equations.
  • How to use the vertical line test on graphs.
  • How to recognize linear and nonlinear function types.

What You Will Do

  • Sort relationships into functions and non-functions.
  • Explain why repeated inputs with different outputs do not form a function.
  • Classify basic function types from representations.
  • Connect function meaning to real-world input-output relationships.

How You Will Show Mastery

  • Complete notebook evidence identifying functions and non-functions.
  • Submit checkpoint responses that justify function classifications.
  • Complete the Lesson Quiz with at least 80% mastery.
