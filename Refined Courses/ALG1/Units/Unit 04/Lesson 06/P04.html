Worked Example 2: Connect context and equation

Problem: A fee starts at 2 dollars and adds 3 dollars each step. Write the function rule.

Step 1: The starting value is 2, so b = 2.

Step 2: The amount added each step is 3, so m = 3.

Step 3: The rule is y = 3x + 2.

Worked Example 3: Describe a transformation

Problem: Compare y = x and y = x + 4.

Step 1: Both graphs have the same slope, 1.

Step 2: The y-intercept changes from 0 to 4.

Step 3: The graph of y = x + 4 is shifted up 4 units from y = x.

Common Mistake

Incorrect: Saying representations match because one value matches.

Correct: Representations match only when the input-output pattern agrees consistently.

Teachable Explanation: Match the method to the exact function representation: ordered pairs, notation, equation, graph, table, or context.
