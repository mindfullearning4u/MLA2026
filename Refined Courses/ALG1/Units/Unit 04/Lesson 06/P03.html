P03 Notebook Task - Part 2

Transformations as Representation Changes

Changing a function rule changes the table and graph. If \(g(x)=f(x)+4\), every output of \(g\) is 4 more than the matching output of \(f\). If \(h(x)=2f(x)\), every output of \(h\) is twice the matching output of \(f\).

Notebook Task

Use \(f(x)=x+2\). Create a table for \(x=0,1,2\). Then create a second table for \(g(x)=f(x)+3\). Explain how each output changed.
