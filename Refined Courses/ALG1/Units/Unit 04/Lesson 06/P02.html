Notebook Title: Lesson 6: Multiple Representations of Functions

Notebook Task

Create a heading titled Multiple Representations of Functions. Write the function \(f(x)=2x+3\). Make a table for \(x=0,1,2,3\), list the ordered pairs, and describe the graph in words.

Then write one sentence explaining what the slope and y-intercept mean in the equation and in the table.

Representation Check

A table, graph, equation, and context represent the same function when they show the same input-output relationship. Matching representations means checking values, rates of change, intercepts, and units.
