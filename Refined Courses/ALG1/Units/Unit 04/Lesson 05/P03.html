Absolute Value Behavior

An absolute value function often has a V-shaped graph. The point where the graph changes direction is the vertex. Because absolute value represents distance, the output is often described as distance from a center or target value.

For example, \(d(x)=|x-4|\) gives the distance between \(x\) and 4. The minimum value is 0 because distance cannot be negative.

Notebook Task

Write the function \(d(x)=|x-4|\). Evaluate \(d(1)\), \(d(4)\), and \(d(7)\). Then explain why two different inputs can have the same output.
