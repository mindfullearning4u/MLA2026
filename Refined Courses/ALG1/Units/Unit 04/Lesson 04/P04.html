P04 Worked Example

How to Use These Examples

Read each example slowly. The goal is not just to get an answer; the goal is to understand how each step connects to identifying domain and range from representations.

Worked Example 1: Find domain from ordered pairs

  1. List the input values, or x-values.
  2. Do not repeat the same input in the list.
  3. The domain is the set of possible inputs.

Worked Example 2: Find range from a table

  1. List the output values, or y-values.
  2. Do not repeat the same output in the list.
  3. The range is the set of possible outputs.

Worked Example 3: Use context restrictions

  1. Decide what inputs make sense in the situation.
  2. A time input usually cannot be negative.
  3. State the domain using values that are reasonable for the context.

Common Mistake

Incorrect: The domain is always all real numbers, even in a real-world situation.

Correct: The domain depends on the representation and context. Some situations restrict which inputs are reasonable.

When you check your own work, ask whether your reasoning matches the definition, feature, or model type being used in the lesson.
