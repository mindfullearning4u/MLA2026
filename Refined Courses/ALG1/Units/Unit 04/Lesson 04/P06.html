P06 Independent Work

Independent Work

Complete each task independently. Use input-output language in your explanations.

Problems

  1. Find the domain and range of (-1, 2), (0, 5), (1, 8).
  2. Find the domain and range of x: 2, 4, 6 and y: 9, 13, 17.
  3. A student can buy 0, 1, 2, or 3 shirts. What is the reasonable domain?
  4. A height function gives height above ground. Why should the range not include negative heights in this context?
  5. Explain the difference between discrete and continuous inputs.
