Worked Example 2: Compare starting values

Problem: Function A is y = 2x + 5. Function B has y-intercept (0, 1).

Step 1: Function A starts at 5 because b = 5.

Step 2: Function B starts at 1.

Step 3: Function A has the greater starting value.

Worked Example 3: Compare outputs at a given input

Problem: Compare y = 2x + 5 and y = 3x + 1 when x = 4.

Step 1: First function: y = 2(4) + 5 = 13.

Step 2: Second function: y = 3(4) + 1 = 13.

Step 3: At x = 4, the functions have the same output.

Common Mistake

Incorrect: Comparing functions by looking at only the largest number shown.

Correct: Compare the feature requested: rate of change, starting value, or output at a specific input.

Teachable Explanation: Match the method to the exact function representation: ordered pairs, notation, equation, graph, table, or context.
