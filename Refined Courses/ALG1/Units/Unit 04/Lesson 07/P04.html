P04 Worked Example

Worked Example

Function A is \(A(x)=2x+9\). Function B has values \(B(0)=4\), \(B(1)=7\), \(B(2)=10\), and \(B(3)=13\).

Compare the functions.

  • Function A has slope 2 and y-intercept 9.
  • Function B increases by 3 each time, so its slope is 3. Its y-intercept is 4.
  • Function A has the greater starting value because 9 is greater than 4.
  • Function B has the greater rate of change because 3 is greater than 2.
