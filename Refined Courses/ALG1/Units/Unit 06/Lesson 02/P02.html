P02 Notebook Task - Part 1

Vocabulary

Substitution: replacing a variable with an equivalent expression.

Elimination: adding or subtracting equations to remove one variable.

Coefficient: the number multiplying a variable.

Ordered-pair solution: the x-value and y-value that satisfy both equations.

Notebook Task

Create a three-column table labeled Method, Best Used When, and First Move.

Add one row for substitution and one row for elimination. Use your own words to describe when each method is most efficient.

Substitution Setup

For y = 2x + 1 and x + y = 10, substitute 2x + 1 for y in the second equation. This gives x + 2x + 1 = 10.
