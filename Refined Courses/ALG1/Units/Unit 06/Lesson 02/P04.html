P04 Worked Example

Example: Solve by Substitution

Solve y = x + 4 and 2x + y = 19.

  1. Substitute x + 4 for y: 2x + x + 4 = 19.
  2. Combine like terms: 3x + 4 = 19.
  3. Solve: 3x = 15, so x = 5.
  4. Find y: y = 5 + 4 = 9.
  5. Check: 2(5) + 9 = 19.

Solution: (5, 9)

Example: Solve by Elimination

Solve 4x + y = 18 and 2x - y = 6. Add the equations to eliminate y: 6x = 24, so x = 4. Substitute into 2x - y = 6: 8 - y = 6, so y = 2. The solution is (4, 2).
