P04 Worked Example

Step-by-step explanation: Follow each example in order. Notice how the work identifies the structure, applies the correct algebraic process, and checks the result.

How to Use These Examples

Read each example slowly. The goal is not just to get an answer; the goal is to understand how each step connects to solving systems algebraically using substitution and elimination.

Worked Example 1: Use substitution

  1. Solve one equation for one variable when possible.
  2. Substitute that expression into the other equation.
  3. Solve for the remaining variable, then find the second value.

Worked Example 2: Use elimination

  1. Line up like variables.
  2. Add or subtract equations so one variable cancels.
  3. Solve the simpler equation and substitute back if needed.

Worked Example 3: Compare methods

  1. Use substitution when one variable is already isolated.
  2. Use elimination when coefficients line up or can be made to line up.
  3. Choose the method that creates fewer steps.

Common Mistake

Incorrect: After finding x, stop because the system is solved.

Correct: A system solution is an ordered pair. After finding one variable, substitute back to find the other variable.
