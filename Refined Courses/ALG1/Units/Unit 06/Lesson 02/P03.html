P03 Notebook Task - Part 2

Elimination Setup

For 2x + y = 11 and 3x - y = 9, the y-terms are opposites. Add the equations to eliminate y.

2x + y + 3x - y = 11 + 9, so 5x = 20 and x = 4.

Complete the Solution

Substitute x = 4 into 2x + y = 11. Then 8 + y = 11, so y = 3. The solution is (4, 3).

Common Mistakes

  • Substituting into the same equation that already defined the variable.
  • Eliminating a variable but forgetting to combine the constants.
  • Finding only x or only y and not writing an ordered pair.
  • Not checking the answer in both original equations.
