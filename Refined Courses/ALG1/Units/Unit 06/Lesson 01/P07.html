Checkpoint Prompt

Submit a response to this prompt: Graph the system y = 2x - 3 and y = -x + 6. State the solution and explain how you know the ordered pair satisfies both equations.

Success Criteria

  • Both lines are represented accurately.
  • The solution is written as an ordered pair.
  • The explanation connects the intersection to both equations.
  • The response uses complete mathematical sentences.
