P02 Notebook Task - Part 1

Notebook Title: Lesson 1: Solving Systems by Graphing

Vocabulary

System of equations: two or more equations that use the same variables.

Solution of a system: an ordered pair that makes every equation in the system true.

Intersection: the point where two graphs meet.

Consistent system: a system with at least one solution.

Inconsistent system: a system with no solution.

Notebook Setup

Create a two-column notebook table. Label the left column Graphing Step and the right column Why It Matters.

  1. Write each equation in slope-intercept form if needed.
  2. Graph both lines on the same coordinate plane.
  3. Locate the intersection point.
  4. Check the ordered pair in both equations.

Notebook Task

Graph the system y = x + 1 and y = -x + 5. Record the y-intercept and slope of each line, sketch both lines, and identify the intersection point.

Then substitute the ordered pair into both equations to prove that it is the solution.
