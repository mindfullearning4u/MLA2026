P04 Worked Example

Example: Solve by Graphing

Solve the system y = 2x + 1 and y = -x + 7 by graphing.

  1. Graph y = 2x + 1. Start at (0, 1), then use slope 2 to move up 2 and right 1.
  2. Graph y = -x + 7. Start at (0, 7), then use slope -1 to move down 1 and right 1.
  3. The lines intersect at (2, 5).
  4. Check: 5 = 2(2) + 1 and 5 = -2 + 7, so the ordered pair works in both equations.

Solution: (2, 5)

Reasoning Check

The point (2, 5) means x = 2 and y = 5. It is the solution because both lines pass through that same point.

Special Cases

If two lines are parallel, they never intersect, so the system has no solution. If two equations graph as the same line, every point on that line works, so the system has infinitely many solutions.
