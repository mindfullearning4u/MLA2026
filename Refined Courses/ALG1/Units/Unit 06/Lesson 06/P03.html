P03 Notebook Task - Part 2

Compound Interest

Compound interest grows by multiplying by a growth factor. In A = P(1 + r/n)^(nt), n is the number of compounding periods per year.

Context Connection

If $800 is invested at 5% compounded annually for 2 years, use A = 800(1 + 0.05)^2. The amount is A = 800(1.1025) = $882.00.

Common Mistakes

  • Using 5 instead of 0.05 for a 5% rate.
  • Confusing interest earned with total amount.
  • Using simple interest when the problem says compounded.
  • Forgetting to multiply years by compounding periods.
