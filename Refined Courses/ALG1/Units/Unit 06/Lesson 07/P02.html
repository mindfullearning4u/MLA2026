Vocabulary

Residual: the difference between an actual value and a predicted value. In this course, residual = actual - predicted.

Representative sample: a sample that reflects the larger population fairly.

Biased sample: a sample collected in a way that favors some responses or groups.

Simulation: a model of a chance process used to estimate likely outcomes.

Two-way table: a table that organizes data by two categorical variables.

Notebook Task

Create a four-column organizer labeled residuals, sampling, simulation, and two-way tables. For each column, write what the tool helps you decide and one warning about a common error.
