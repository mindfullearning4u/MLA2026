P04 Worked Example

Step-by-step explanation: Follow each example in order. Notice how the work identifies the structure, applies the correct algebraic process, and checks the result.

How to Use These Examples

Read each example slowly. The goal is not just to get an answer; the goal is to understand how each step connects to modeling constraints with systems of equations and inequalities.

Worked Example 1: Define variables

  1. Identify the two quantities that change.
  2. Choose clear variable names.
  3. State what each variable represents before writing equations or inequalities.

Worked Example 2: Write constraints

  1. Translate limits, totals, or requirements into equations or inequalities.
  2. Use inequality symbols when values can be less than or greater than a limit.
  3. Check that each constraint matches the context.

Worked Example 3: Interpret feasible solutions

  1. Graph or reason through the constraints.
  2. A feasible solution satisfies all conditions at the same time.
  3. Explain why the solution works in the real situation.

Common Mistake

Incorrect: Use only one condition from the problem and ignore the other limits.

Correct: A system model must include all important constraints because a solution must satisfy every condition in the situation.

When you check your own work, ask whether your reasoning matches the definition, model, display, or context being used in the lesson.
