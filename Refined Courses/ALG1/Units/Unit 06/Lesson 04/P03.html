Display Types

Bar graphs compare categories. Dot plots and histograms show distributions of numerical data. Box plots summarize numerical data using median, quartiles, and range. Line graphs show change over time.

Reading Carefully

Always check the title, axis labels, scale, and units before interpreting a display. A graph can be technically correct but still misleading if the scale is hard to read or the labels are missing.

Common Mistakes

  • Using a bar graph for numerical distribution when a dot plot or histogram would be clearer.
  • Comparing categories without checking the axis scale.
  • Treating categorical labels as if they had numerical distance.
  • Ignoring units when interpreting values.
