P07 Checkpoint

Checkpoint Prompt

A class collected two data sets: favorite fruit choices and minutes spent reading each night. Choose the best display for each data set and explain what information each display would make easiest to see.

Success Criteria

  • The response identifies categorical and numerical data correctly.
  • Each display choice fits the data type.
  • The explanation connects the display to the question being answered.
  • Labels, scales, or units are mentioned where appropriate.
