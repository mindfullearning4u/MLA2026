P04 Worked Example

Example: Comparing Plans

A school event has two cost plans: Plan A costs 120 + 4x dollars. Plan B costs 60 + 7x dollars, where x is the number of students.

Set the costs equal: 120 + 4x = 60 + 7x. Then 60 = 3x, so x = 20.

At 20 students, the plans cost the same. For more than 20 students, Plan A is less expensive because it has the smaller rate per student.

Reasonableness Check

Substitute x = 20 into both plans: Plan A is 120 + 80 = 200, and Plan B is 60 + 140 = 200. The solution checks.
