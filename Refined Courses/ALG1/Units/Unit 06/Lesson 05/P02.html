P02 Notebook Task - Part 1

Vocabulary

Scatterplot: a graph of ordered pairs used to compare two numerical variables.

Association: a pattern or relationship between two variables.

Correlation: a relationship where two variables tend to change together.

Line of fit: a line that models the trend of data in a scatterplot.

Notebook Setup

Create a table with columns for Direction, Strength, Possible Model, and Context Meaning.

Use this table to describe scatterplots in complete sentences.

Notebook Task

A scatterplot compares hours studied and quiz score. As study hours increase, quiz scores tend to increase. Describe the association, explain what the trend means, and identify one reason this does not automatically prove causation.
