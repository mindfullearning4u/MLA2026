P04 Worked Example

Study each example carefully. The interpretation matters as much as the calculation.

Worked Examples

Example 1: Find the slope through (0, 5) and (4, 17).
Change in y: 17 - 5 = 12.
Change in x: 4 - 0 = 4.
Slope = 12/4 = 3.

Example 2: A table shows (0, 12), (1, 9), (2, 6), (3, 3).
The output decreases by 3 each time the input increases by 1, so the slope is -3.

Example 3: A line through (2, 7) and (6, 7) has slope 0 because the y-value does not change.

Interpretation Check

A slope of 3 means the output increases by 3 for every 1-unit increase in the input. In context, always include units.
