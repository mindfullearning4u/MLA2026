Notebook Title

Lesson 4: Slope-Intercept Form

Key Vocabulary

  • Slope-intercept form: The form y = mx + b.
  • m: The slope or rate of change.
  • b: The y-intercept or starting value when x = 0.
  • Initial value: The output at the start of a context.
  • Linear model: An equation used to represent a linear relationship.

Process Notes

  • In y = mx + b, identify b first as the point (0, b).
  • Use m as rise over run to find another point.
  • Draw the line through the points.
  • Interpret m as the rate and b as the starting amount when the context supports it.
