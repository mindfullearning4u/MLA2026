P04 Worked Example

Study how each equation is built from the given information.

Worked Examples

Example 1: Write the equation of a line with slope -3 through (2, 1).
1 = -3(2) + b.
1 = -6 + b, so b = 7.
Equation: y = -3x + 7.

Example 2: Write a line parallel to y = 5x - 4 through (0, 2).
Parallel slope is 5, and the y-intercept is (0, 2).
Equation: y = 5x + 2.

Example 3: A service charges $20 plus $8 per hour.
Equation: y = 8x + 20, where x is hours and y is total cost.

Equation Check

A written equation should satisfy the given point and use the required slope relationship.
