P04 Worked Example

Step-by-step explanation: Follow each example in order. Notice how the work identifies the structure, applies the correct algebraic process, and checks the result.

Study all three worked examples. Each example shows the steps and reasoning you should use before working independently.

Worked Example 1: Use Slope and Intercept

Problem: Write the equation of a line with slope 2 and y-intercept 5.

Step 1: Start with y = mx + b.

Step 2: Substitute m = 2 and b = 5.

Step 3: The equation is y = 2x + 5.

Mathematical Visual: Substitution into y = mx + b

General FormSubstituteEquation
y = mx + bm = 2, b = 5y = 2x + 5

Worked Example 2: Use Slope and a Point

Problem: Write the equation of a line with slope 2 through (1, 7).

Step 1: Substitute into y = mx + b: 7 = 2(1) + b.

Step 2: Solve: 7 = 2 + b, so b = 5.

Step 3: The equation is y = 2x + 5.

Mathematical Visual: Algebra Work to Find b

7 = 2(1) + b
7 = 2 + b
5 = b
y = 2x + 5

Worked Example 3: Write a Context Equation

Problem: A service costs $15 to start and $4 per month.

Step 1: The monthly cost is the slope, 4.

Step 2: The starting fee is the y-intercept, 15.

Step 3: The equation is y = 4x + 15.

Mathematical Visual: Context to Equation

Common Mistake

Incorrect: Using the point y-value as b without checking.

Correct: Substitute the point into y = mx + b and solve for b unless the point is already the y-intercept.

Teachable Explanation: The worked examples model both the calculation and the reasoning needed to justify the answer.
