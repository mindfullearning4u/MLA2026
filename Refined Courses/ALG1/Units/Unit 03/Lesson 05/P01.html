P01 Lesson Overview

Lesson Title

Lesson 5: Writing Linear Equations

In this lesson, you will write linear equations from points, slopes, parallel and perpendicular relationships, and contexts.

Standards Covered in This Lesson

MLA.A1.LR.2: I can write linear equations from points, slopes, and contexts.

MLA.A1.LR.5: I can use parallel and perpendicular relationships to write and interpret linear equations.

Florida B.E.S.T. Benchmarks: MA.912.AR.2.3; MA.912.AR.2.5

Common Core Alignment: HSG.GPE.B.5; HSA.CED.A.2; HSF.LE.A.2

SAT/ACT Connection: Algebra; Preparing for Higher Math - Algebra.

What You Will Learn

  • How to write equations in slope-intercept form.
  • How to use a point and slope to find the y-intercept.
  • How parallel lines use equal slopes.
  • How perpendicular lines use opposite reciprocal slopes.

What You Will Do

  • Write equations from slope and y-intercept.
  • Write equations from a point and slope.
  • Use parallel and perpendicular slope relationships.
  • Build linear models from context.

How You Will Show Mastery

  • Complete notebook evidence showing equation-writing work.
  • Submit checkpoint responses that write and interpret equations.
  • Complete the Lesson Quiz with at least 80% mastery.

Student-Friendly Standard Connection

I can write a linear equation that matches the information I am given.
