Copy These Examples

Example 1: Write an equation with slope 3 and y-intercept (0, 4).
Use y = mx + b: y = 3x + 4.

Example 2: Write an equation with slope 2 through (1, 7).
Substitute: 7 = 2(1) + b.
7 = 2 + b, so b = 5.
Equation: y = 2x + 5.

Example 3: A line parallel to y = -4x + 1 has slope -4.

Example 4: A line perpendicular to slope 2 has slope -1/2.

Common Mistakes

Do not use the given point as the y-intercept unless its x-value is 0. A point like (2, 9) is on the line, but it is not the y-intercept.

Incorrect: Skipping a step or applying a rule before checking the structure of the expression, equation, graph, or situation.

Teachable Explanation: Algebra errors usually happen when a step is skipped or a rule is used without checking the expression, equation, graph, or context first.
