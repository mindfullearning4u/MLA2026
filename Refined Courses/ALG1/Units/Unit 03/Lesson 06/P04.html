P04 Worked Example

Worked Example 1: Reverse the Symbol

Solve: -2x > 8

Divide both sides by -2.

Because you divided by a negative number, reverse the symbol.

x < -4

Graph: Open circle at -4, shade left.

Worked Example 2: Compound Inequality

Solve: 1 < x + 3 ≤ 7

Subtract 3 from all three parts.

1 - 3 < x + 3 - 3 ≤ 7 - 3

-2 < x ≤ 4

Graph: Open circle at -2, closed circle at 4, shade between.

Common Mistakes

  • Forgetting to reverse the inequality symbol after multiplying or dividing by a negative number.
  • Using a closed circle for < or > when the boundary value is not included.
  • Using an open circle for ≤ or ≥ when the boundary value is included.
  • Solving only one side of a compound inequality instead of applying the same operation to all parts.
