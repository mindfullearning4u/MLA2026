Notebook Title: Lesson 6: Solving Linear Inequalities

Notebook Setup

Title your notes Solving Linear Inequalities. Create three sections: vocabulary, solving steps, and number line representations.

Vocabulary

  • Inequality: A mathematical statement that compares values using <, >, ≤, or ≥.
  • Solution set: All values that make an inequality true.
  • Boundary point: The value where the solution set begins or ends.
  • Open circle: Shows that the boundary value is not included.
  • Closed circle: Shows that the boundary value is included.
  • Compound inequality: Two inequalities joined together to describe a restricted range.

Key Idea

Solving an inequality is similar to solving an equation. The goal is to isolate the variable, but the answer is usually a range of values instead of one value.

Important rule: When you multiply or divide both sides of an inequality by a negative number, reverse the inequality symbol.
