Notebook Title

Lesson 2: Graphing Linear Equations

Key Vocabulary

  • Coordinate plane: The grid formed by the x-axis and y-axis.
  • x-axis: The horizontal axis.
  • y-axis: The vertical axis.
  • x-intercept: A point where a graph crosses the x-axis.
  • y-intercept: A point where a graph crosses the y-axis.

Graphing Process

  1. Choose input values for x.
  2. Substitute each x-value into the equation to find y.
  3. Write each result as an ordered pair.
  4. Plot the ordered pairs and connect them with a straight line.
