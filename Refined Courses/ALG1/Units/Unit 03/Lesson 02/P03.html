Example 2: Find the intercepts of y = -x + 4.

For the y-intercept, set x = 0.

y = -(0) + 4, so y = 4. The y-intercept is (0, 4).

For the x-intercept, set y = 0.

0 = -x + 4, so x = 4. The x-intercept is (4, 0).

Example 3: If a line contains (0, 6) and (2, 10), the point (0, 6) shows the output when the input is 0.

Because x = 0 in (0, 6), this point also shows where the graph crosses the y-axis.

Common Mistakes

Do not reverse the coordinates. In an ordered pair (x, y), the x-value moves left or right and the y-value moves up or down.

Incorrect: Skipping a step or applying a rule before checking the structure of the expression, equation, graph, or situation.

Teachable Explanation: Algebra errors usually happen when a step is skipped or a rule is used without checking the expression, equation, graph, or context first.
