Checkpoint Task: Graphing Linear Equations

Complete all parts. Show work clearly and explain your reasoning in complete sentences where required.

  1. Create a table for y = 3x + 2 using x = 0, 1, 2, and 3.
  2. Use the table to graph the equation.
  3. Identify the y-intercept and explain what it means in the equation.
  4. Determine whether (4, 14) is on the graph of y = 3x + 2 and explain how you know.

Mastery Criteria

  • Creates accurate tables from equations.
  • Plots ordered pairs correctly.
  • Identifies and interprets key graph features.
  • Checks whether a point satisfies an equation.
