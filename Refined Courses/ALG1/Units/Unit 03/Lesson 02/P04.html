P04 Worked Example

Study how the table, equation, and graph connect.

Worked Examples

Example 1: Graph y = x + 3.
Choose x = 0, 1, 2.
Table: (0, 3), (1, 4), (2, 5).
The y-intercept is (0, 3).

Example 2: Graph y = 3x.
Choose x = 0, 1, 2.
Table: (0, 0), (1, 3), (2, 6).
The line passes through the origin because when x = 0, y = 0.

Example 3: A graph crosses the y-axis at (0, 5). In context, this often represents a starting amount.

Graphing Check

A point belongs on the graph of an equation only if substituting its x-value gives its y-value.
