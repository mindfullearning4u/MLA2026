Worked Example 2: Find Intercepts for y = -x + 4

Problem: Identify the intercepts of y = -x + 4.

Step 1: To find the y-intercept, set x = 0.

y = -(0) + 4

y = 4

The y-intercept is (0, 4).

Step 2: To find the x-intercept, set y = 0.

0 = -x + 4

x = 4

The x-intercept is (4, 0).

Worked Example 3: Interpret a Point

Problem: A line contains (0, 6) and (2, 10). Explain what (0, 6) means.

Step 1: Read the point as input 0 and output 6.

Step 2: Explain that when the input is 0, the output is 6.

Step 3: Because x = 0, the point also represents the y-intercept of the line.

Common Mistake

Incorrect: Reversing the ordered pair and plotting (y, x).

Correct: Use (x, y): move horizontally for x first, then vertically for y.

Teachable Explanation: The worked examples model both the calculation and the reasoning needed to justify the answer.
