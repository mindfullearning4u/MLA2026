Unit Assessment

The Unit 3 Assessment measures mastery of linear relationships, graphing, slope, equation writing, and inequalities.

Assessment Expectations

  • Read each item carefully before choosing an answer.
  • Use scratch work for slope, equations, graphs, and inequalities.
  • Check whether inequality symbols include or exclude boundary values.
  • Interpret context questions using units and constraints.
  • Submit the assessment when all selected answers are complete.

Final Mastery Goal

Demonstrate that you can connect symbolic, graphical, and contextual linear reasoning before moving into formal functions.
