P04 Unit Review Practice

Mixed Practice

Use these tasks to prepare for the Unit Assessment. Decide which Unit 3 skill each problem requires.

Practice Set

  1. A line has slope -4 and passes through (0, 6). Write its equation.
  2. A line has slope 2 and passes through (3, 11). Write its equation.
  3. Solve: 4x + 9 > 21.
  4. Describe the graph of y ≤ -3x + 2.
  5. A plan costs $10 plus $5 per month. Write the equation for total cost after x months.

Correction Task

Choose two problems you found difficult. Write a correction explaining the mistake and the correct reasoning.
