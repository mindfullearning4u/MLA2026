Notebook Title

Lesson 1: Introduction to Linear Relationships

Key Vocabulary

  • Linear relationship: A relationship with a constant rate of change.
  • Input: The starting value or independent quantity.
  • Output: The resulting value or dependent quantity.
  • Ordered pair: A pair of values written as (input, output).
  • Rate of change: How much the output changes for each 1-unit change in input.

Process Notes

  • Identify the two quantities in the relationship.
  • Decide which quantity is the input and which is the output.
  • Organize matching values in a table.
  • Look for a constant change in the output when the input increases by 1.
