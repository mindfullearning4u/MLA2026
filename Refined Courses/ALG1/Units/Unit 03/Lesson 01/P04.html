P04 Worked Example

Study each example carefully. Every representation tells part of the relationship.

Worked Examples

Example 1: A bike rental costs $5 per hour.
Table: (1, 5), (2, 10), (3, 15), (4, 20).
Equation: y = 5x, where x is hours and y is cost.
The graph contains points that form a straight line.

Example 2: A taxi ride costs $3 to start plus $2 per mile.
Table: (0, 3), (1, 5), (2, 7), (3, 9).
Equation: y = 2x + 3, where x is miles and y is cost.
The output starts at 3 and increases by 2 for each mile.

Representation Check

A table, graph, equation, and description can represent the same relationship when the input-output pairs match.
