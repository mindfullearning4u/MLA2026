P04 Worked Example

Step-by-step explanation: Each worked example uses the actual table, ordered pairs, or context from the problem. Look for constant change in the output when the input increases by 1.

Study all three worked examples. Each example shows how to decide whether a relationship is linear and how to explain the rate of change.

Worked Example 1: Identify the Rate of Change

Problem: A parking garage charges 6 dollars per hour. Use the table to identify the rate of change.

HoursCost

Step 1: Identify the input and output. The input is hours. The output is cost.

Step 2: Compare the output changes: 0 to 6, 6 to 12, and 12 to 18. Each change is +6.

Step 3: State the rate of change. The cost increases by 6 dollars for each 1-hour increase.

Worked Example 3: Write a Rule from a Context

Problem: A plant is 6 inches tall and grows 2 inches each week. Write a rule for the height.

WeeksHeight
06

Step 1: Identify the starting value. At week 0, the plant is 6 inches tall.

Step 2: Identify the rate of change. The height increases by 2 inches each week.

Step 3: Write the rule. If w is the number of weeks and h is the height, then h = 2w + 6.

Common Mistake

Incorrect: "The outputs increase, so the relationship is linear."

Why this is wrong: A relationship is linear only when the output changes by a constant amount for equal input changes.

Teachable Explanation: Always compare each output change. Increasing values alone are not enough; the change must be constant.
