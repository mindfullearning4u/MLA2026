Boundary and Shading Examples

The boundary line shows where equality would happen. The shaded region shows where the inequality is true.

Example A

Graph: y > 2x + 1

Boundary line: y = 2x + 1.

Line type: dashed, because > does not include equality.

Shading: above the line, because y is greater than 2x + 1.

Example B

Graph: y ≤ -x + 4

Boundary line: y = -x + 4.

Line type: solid, because ≤ includes equality.

Shading: below the line, because y is less than or equal to -x + 4.

Notebook Task

For each inequality, identify the boundary line, line type, and shading direction.

  1. y < 3x - 2
  2. y ≥ 1/2x + 5
  3. y ≤ -2x + 1

Common Mistake

Incorrect: Skipping a step or applying a rule before checking the structure of the expression, equation, graph, or situation.

Teachable Explanation: Algebra errors usually happen when a step is skipped or a rule is used without checking the expression, equation, graph, or context first.

Teacher-Guided Thinking for Notebook Part 2

Use this page to make the process visible. In Graphing and Interpreting Inequalities, each example should show the decision, the operation, and the reason for the operation. Before copying an answer, ask: What changed from the previous step? What stayed equivalent? How does this connect to MLA.A1.AR.3, MLA.A1.AR.4?

Step 1: Read the example from left to right and label the first move. Step 2: Explain why that move is valid. Step 3: Simplify carefully and check whether the result answers the original question. If the lesson uses a graph, table, number line, or diagram, describe what the visual is showing before writing the numeric answer.

Common confusion to avoid: Do not copy a pattern from one example into a different structure. If the sign, exponent, slope, intercept, domain, table pattern, or context changes, the reasoning may also change. Slow down and re-identify the structure.
