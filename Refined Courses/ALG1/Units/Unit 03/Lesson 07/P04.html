P04 Worked Example

Worked Example 1: Test a Point

Question: Is (2, 5) a solution of y < 3x + 1?

Substitute x = 2 and y = 5.

5 < 3(2) + 1

5 < 7 is true.

Answer: Yes, (2, 5) is in the solution region.

Worked Example 2: Interpret a Constraint

A student can spend at most $20 on snacks. Apples cost $2 each and sandwiches cost $5 each.

Inequality: 2x + 5y ≤ 20

The solution region contains all combinations of apples and sandwiches that cost $20 or less.

The boundary is solid because spending exactly $20 is allowed.

Common Mistakes

  • Using a solid line for < or > when the boundary is not included.
  • Shading above when the inequality means below the boundary line.
  • Forgetting that every point in the shaded region should make the inequality true.
  • Ignoring context limits such as x and y needing to be nonnegative.
