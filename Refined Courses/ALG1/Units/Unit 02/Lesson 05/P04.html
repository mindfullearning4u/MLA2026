P04 Worked Example

Study all three worked examples. Each example shows the steps and reasoning you should use before working independently.

Worked Example 1: Solve for a Variable

Problem: Solve A = lw for l.

Divide both sides by w.

A⁄w = l

Answer: l = A⁄w

Worked Example 2: Isolate a Quantity

Problem: Solve P = 2l + 2w for l.

Subtract 2w from both sides.

P - 2w = 2l

Divide by 2.

l = P - 2w⁄2

Worked Example 3: Formula Interpretation

Problem: Solve d = rt for t.

Divide both sides by r.

t = d⁄r

The time equals distance divided by rate.

Common Mistake

Incorrect: "Move a number across the equal sign without doing the same operation to both sides."

Why this is wrong: This treats an equation like a shortcut instead of a balance.

Correct: "Use the same inverse operation on both sides of the equation."

Correction: Keep both sides balanced until the variable is isolated, then check the solution.
