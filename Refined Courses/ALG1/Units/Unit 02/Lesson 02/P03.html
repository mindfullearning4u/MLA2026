Copy These Examples

Example 1: Solve 4x + 3 = 19.
Subtract 3: 4x = 16.
Divide by 4: x = 4.

Example 2: Solve 5n - 7 = 18.
Add 7: 5n = 25.
Divide by 5: n = 5.

Example 3: Solve y⁄3 + 2 = 8.
Subtract 2: y⁄3 = 6.
Multiply by 3: y = 18.

Common Mistakes

Do not use the same operation again when an inverse operation is needed. Apply the same inverse operation to both sides, then check the solution in the original equation.
