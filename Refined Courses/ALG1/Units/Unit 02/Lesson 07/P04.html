P04 Worked Example

Study how the strategy is selected before solving.

Example 1: Context Equation

Problem: A class trip costs $120 plus $8 per student. The total cost is $296. How many students are going?

Strategy: This is a two-step application equation.

Equation: 120 + 8s = 296

Solve: 8s = 176, so s = 22.

Interpretation: 22 students are going on the trip.

Example 2: Variables on Both Sides

Problem: Solve 6x + 9 = 3x + 30.

Strategy: Move variable terms to one side and constants to the other.

Solve: 3x + 9 = 30, so 3x = 21 and x = 7.

Check: 6(7) + 9 = 51 and 3(7) + 30 = 51.

Decision Check

If the equation includes parentheses, distribute or simplify first. If variables appear on both sides, collect variable terms before isolating the variable. If the problem is a context, define the variable and interpret the final answer.
