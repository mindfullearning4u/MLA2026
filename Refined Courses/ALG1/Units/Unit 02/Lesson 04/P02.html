Notebook Title

Lesson 4: Equations with Variables on Both Sides

Key Vocabulary

  • Variables on both sides: An equation with variable terms on the left and right sides.
  • One solution: Exactly one value makes the equation true.
  • No solution: No value makes the equation true.
  • Infinitely many solutions: Every value makes the equation true.
  • Identity: A true statement after simplifying, such as 4 = 4.

Process Notes

  • Simplify both sides first.
  • Move variable terms to one side.
  • Move constants to the other side.
  • If the variable disappears, classify the statement as no solution or infinitely many solutions.
