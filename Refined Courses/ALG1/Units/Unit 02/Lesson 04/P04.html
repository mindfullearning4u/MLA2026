P04 Worked Example

Study all three worked examples. Each example shows the steps and reasoning you should use before working independently.

Worked Example 1: Move Variable Terms

Problem: Solve 5x + 3 = 2x + 18.

Subtract 2x from both sides.

3x + 3 = 18

Subtract 3, then divide by 3.

3x = 15, so x = 5

Worked Example 2: No Solution

Problem: Solve 4x + 2 = 4x + 9.

Subtract 4x from both sides.

2 = 9

This false statement means there is no solution.

Worked Example 3: Infinitely Many Solutions

Problem: Solve 3(x + 2) = 3x + 6.

Distribute the left side.

3x + 6 = 3x + 6

This true statement means infinitely many solutions.

Common Mistake

Incorrect: "Move a number across the equal sign without doing the same operation to both sides."

Why this is wrong: This treats an equation like a shortcut instead of a balance.
