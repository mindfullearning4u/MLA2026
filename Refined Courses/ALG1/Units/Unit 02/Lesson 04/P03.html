Copy These Examples

Example 1: Solve 5x + 3 = 2x + 18.
Subtract 2x: 3x + 3 = 18.
Subtract 3: 3x = 15.
Divide by 3: x = 5.

Example 2: Solve 4x + 7 = 4x - 2.
Subtract 4x from both sides: 7 = -2.
This is false, so there is no solution.

Example 3: Solve 3(x + 2) = 3x + 6.
Distribute: 3x + 6 = 3x + 6.
This is always true, so there are infinitely many solutions.

Common Mistakes

Do not assume every equation has one solution. If the variable terms cancel, the remaining statement determines the solution type.
