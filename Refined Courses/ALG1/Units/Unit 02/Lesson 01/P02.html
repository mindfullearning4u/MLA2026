Notebook Title

Lesson 1: One-Step Equations

Key Vocabulary

  • Equation: A mathematical statement that two expressions are equal.
  • Variable: A letter that represents an unknown value.
  • Solution: A value that makes an equation true.
  • Inverse operations: Operations that undo each other.
  • Isolate: Get the variable by itself on one side of the equation.

Process Notes

  • Write the equation.
  • Name the operation attached to the variable.
  • Use the inverse operation on both sides.
  • Write the solution and check it.
