Copy These Examples

Example 1: Solve x + 7 = 15.
Subtract 7 from both sides: x = 8.

Example 2: Solve y - 5 = 12.
Add 5 to both sides: y = 17.

Example 3: Solve 4n = 28.
Divide both sides by 4: n = 7.

Example 4: Solve r⁄5 = 6.
Multiply both sides by 5: r = 30.

Common Mistakes

Do not use the same operation again when an inverse operation is needed. Apply the same inverse operation to both sides, then check the solution in the original equation.
