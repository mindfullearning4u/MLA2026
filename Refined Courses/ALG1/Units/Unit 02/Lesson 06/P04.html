P04 Worked Example

Step-by-step explanation: Follow each example in order. Notice how the work identifies the structure, applies the correct algebraic process, and checks the result.

Study all three worked examples. Each example shows the steps and reasoning you should use before working independently.

Worked Example 1: Define the Variable

Problem: A ticket costs $8. A student spends $56. How many tickets?

Let t be the number of tickets.

8t = 56

Divide by 8, so t = 7.

Worked Example 2: Two-Step Context

Problem: A plan charges $12 plus $5 per month. The total is $42.

Let m be months.

12 + 5m = 42

Subtract 12, then divide by 5, so m = 6.

Worked Example 3: Interpret the Solution

Problem: 3x + 6 = 30 models total cost. Solve and interpret.

Subtract 6, then divide by 3.

3x = 24, so x = 8

The solution means 8 units in the context.

Common Mistake

Incorrect: "Move a number across the equal sign without doing the same operation to both sides."

Why this is wrong: This treats an equation like a shortcut instead of a balance.

Teachable Explanation: The worked examples model both the calculation and the reasoning needed to justify the answer.

Worked-Example Coaching Notes

Study the worked examples like a teacher is solving beside you. For Problem Solving with Equations, the goal is not only to get the final answer. The goal is to understand why each step follows from the previous step and how that supports Application Support.

Before Example 1: Identify the known information and the unknown. During each example: Pause after every step and say what mathematical idea was used: inverse operation, equivalent expression, slope, graph feature, function rule, factoring, model comparison, data interpretation, or financial formula. After each example: Check whether the answer is reasonable in the original problem.

Teacher move: When an error is shown, do not only mark it wrong. Explain the exact moment the reasoning stopped matching the structure of the problem. That explanation is what turns the mistake into mastery evidence.
