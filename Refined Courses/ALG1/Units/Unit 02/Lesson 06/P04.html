P04 Worked Example

Study how each equation connects to the context.

Example 1: Membership Cost

Problem: A gym charges a $15 sign-up fee plus $6 per class. A student pays $57. How many classes did the student take?

Variable: Let c represent the number of classes.

Equation: 15 + 6c = 57

Solve: 6c = 42, so c = 7.

Interpretation: The student took 7 classes.

Example 2: Phone Plan

Problem: A phone plan costs $25 each month plus $4 for each extra gigabyte of data. The total bill is $53. How many extra gigabytes were used?

Variable: Let g represent the number of extra gigabytes.

Equation: 25 + 4g = 53

Solve: 4g = 28, so g = 7.

Interpretation: The customer used 7 extra gigabytes of data.

Check the Model

Substitute the solution back into the original equation and reread the problem. The answer must satisfy the equation and make sense in the context.
