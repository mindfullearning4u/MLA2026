P03 Notebook Task - Part 2

Complete the translation practice in your notebook.

Translation Practice

For each situation, define the variable and write an equation. Then solve and interpret the solution.

  1. A school club has $20 and earns $5 for each ticket sold. The club has $75 after selling tickets.
  2. A taxi charges $4 to start and $3 per mile. The total cost is $25.
  3. Three less than twice a number is 17.
  4. A rectangle has perimeter 42 inches and width 8 inches.

Common Mistakes

  • Using a number as the variable instead of defining what the variable represents.
  • Reversing the operation when translating a phrase such as "less than" or "more than."
  • Solving correctly but leaving the answer without units or context.
  • Accepting an answer that does not make sense for the situation.

Incorrect: Skipping a step or applying a rule before checking the structure of the expression, equation, graph, or situation.

Teachable Explanation: Algebra errors usually happen when a step is skipped or a rule is used without checking the expression, equation, graph, or context first.

Teacher-Guided Thinking for Notebook Part 2

Use this page to make the process visible. In Problem Solving with Equations, each example should show the decision, the operation, and the reason for the operation. Before copying an answer, ask: What changed from the previous step? What stayed equivalent? How does this connect to Application Support?

Step 1: Read the example from left to right and label the first move. Step 2: Explain why that move is valid. Step 3: Simplify carefully and check whether the result answers the original question. If the lesson uses a graph, table, number line, or diagram, describe what the visual is showing before writing the numeric answer.

Common confusion to avoid: Do not copy a pattern from one example into a different structure. If the sign, exponent, slope, intercept, domain, table pattern, or context changes, the reasoning may also change. Slow down and re-identify the structure.
