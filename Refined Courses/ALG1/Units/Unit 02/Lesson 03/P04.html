P04 Worked Example

Step-by-step explanation: Follow each example in order. Notice how the work identifies the structure, applies the correct algebraic process, and checks the result.

Study all three worked examples. Each example shows the steps and reasoning you should use before working independently.

Worked Example 1: Combine Like Terms First

Problem: Solve 2x + 3x - 4 = 21.

Combine like terms.

5x - 4 = 21

Add 4, then divide by 5.

5x = 25, so x = 5

Worked Example 2: Distribute First

Problem: Solve 3(x + 2) = 18.

Distribute 3 to both terms.

3x + 6 = 18

Subtract 6, then divide by 3.

3x = 12, so x = 4

Worked Example 3: Context Equation

Problem: A fee is $10 plus $4 per ticket. The total is $34. Find the number of tickets.

Write and solve the equation.

10 + 4t = 34

Subtract 10, then divide by 4.

4t = 24, so t = 6

Common Mistake

Incorrect: "Move a number across the equal sign without doing the same operation to both sides."

Why this is wrong: This treats an equation like a shortcut instead of a balance.

Teachable Explanation: The worked examples model both the calculation and the reasoning needed to justify the answer.
