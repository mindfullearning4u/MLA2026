# Moodle Resource Requirements

- MathJax for equations, exponents, radicals, factoring forms, function notation, and inequalities.
- Responsive tables and graph/image handling with meaningful alternative text.
- Preserve passage, graph, table, and image dependencies with assessment items.
- Treat MathXL, Savvas interactives, videos, and editable/printable resources as licensed links unless copying is explicitly permitted.
- Provide accessible alternatives when an interactive cannot operate outside Savvas.
- Use manual grading for modeling, STEM, written justification, and performance tasks where appropriate.
- Maintain links to teacher-only answer keys separately from student resources.
- Record external URLs, required logins, browser requirements, and failure alternatives.
- Do not embed proprietary eText pages or assessment banks without permission.

Lesson shell rule: begin with Lesson Overview and Learning Objectives; end with Checkpoint and Help & TOR Support. Intermediate pages vary by objective and evidence need.
