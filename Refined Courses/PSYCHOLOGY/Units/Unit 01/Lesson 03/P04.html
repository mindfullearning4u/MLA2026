P04 Worked Example

Worked Example 1

Prompt: A student reads a psychology scenario and must explain behavior using evidence rather than opinion.

Step 1: Name the behavior. This identifies the psychology object before reasoning.

Step 2: Identify what can be observed or reported. This ties the answer to the embedded model, chart, or scenario evidence.

Step 3: Psychology begins with clear description. This is the teachable conclusion for MLA.PSY.FND.1.

Worked Example 2

Prompt: A student reads a psychology scenario and must explain behavior using evidence rather than opinion.

Step 1: Use the evidence. This identifies the psychology object before reasoning.

Step 2: Read the model, chart, or scenario details. This ties the answer to the embedded model, chart, or scenario evidence.

Step 3: Evidence protects against unsupported claims. This is the teachable conclusion for MLA.PSY.FND.1.

Worked Example 3

Prompt: A student reads a psychology scenario and must explain behavior using evidence rather than opinion.

Step 1: Apply the concept. This identifies the psychology object before reasoning.

Step 2: Connect the evidence to MLA.PSY.FND.1. This ties the answer to the embedded model, chart, or scenario evidence.

Step 3: A psychological explanation must stay inside the mapped standard. This is the teachable conclusion for MLA.PSY.FND.1.

Student check: Use this support before answering. Your explanation should name the behavior or mental process, cite one piece of evidence, and connect it to the mapped standard without diagnosing or guessing.

Common Mistake

Correct: using the psychology evidence to explain the behavior within the mapped standard.

Incorrect: making a personal opinion, diagnosis, or label without evidence.

Teachable Explanation

Each example uses the same mastery path: define the behavior or process, read the evidence, apply the correct concept, and state a careful conclusion.

Student Clarity and Mastery Check

Lesson focus: Psychological Questions, Claims, and Evidence. The goal is to explain behavior and mental processes using psychological evidence, research limits, biological/cognitive/social context, and ethical reasoning while staying inside MLA.PSY.FND.1; MLA.PSY.FND.2.
