# Math Lesson-Specific Help Refinement Report

## Executive Summary

A Math Department lesson-specific help refinement was completed after Moodle implementation review. The purpose was to keep the required academy-wide MLA TOR Support Box on every page while removing lesson-specific help reminders that did not add instructional value beyond the TOR box.

Final result: PASS.

Every reviewed Math lesson page retains exactly one MLA TOR Support Box. Weak generic lesson-specific help reminders were removed. Meaningful lesson-specific reminders were preserved only when they identified a specific skill challenge, decision point, misconception, theorem use, representation choice, or data interpretation issue.

## MLA Standard Applied

Every lesson page must contain the MLA TOR Support Box.

Lesson-specific help reminders are optional and should appear only when they provide meaningful instructional value beyond the TOR Support Box.

## Required MLA TOR Support Box Validation

The required compact MLA TOR Support Box remains on every reviewed page:

**🧑‍🏫 Need Help?**

Contact your Teacher of Record (TOR)  
if you need clarification,  
feedback, or support.

Ask for help as soon as you need it.

## Weak Generic Help Removed

The removed reminders included generic language such as:

- Ask your Teacher of Record if you are unsure how to apply the lesson skill from this lesson on this page.
- If you are unsure about any step, contact your TOR for help or guidance before moving forward.
- If you need help or guidance, contact your Teacher of Record before moving forward.

These statements repeated the purpose of the MLA TOR Support Box and did not identify a specific mathematical misconception, decision, or skill challenge.

## Meaningful Help Preserved

Meaningful reminders were preserved when they gave content-specific guidance, such as support for:

- Choosing the correct theorem or postulate
- Interpreting data or statistical displays
- Selecting a function representation
- Identifying operations or relationships in a problem
- Checking a diagram, model, graph, or calculation
- Avoiding predictable mistakes tied to lesson content
