# U.S. Government Build Notes

Built as a 0.5-credit course with 6 units and 5 lessons per unit.

Assessment structure per unit:
- Unit Pretest: 10 Moodle XML questions
- Lesson 01-04 Guided Practice: 5 Moodle XML questions each
- Lesson 01-04 Quiz: 25 Moodle XML questions each
- Lesson 05 Guided Practice: 5 Moodle XML questions
- Lesson 05 Unit Assessment: 40 Moodle XML questions
- No Lesson 05 quiz

All lessons include step-by-step student-facing instruction, embedded visual/source support, TOR support language, and no live-teacher dependency.
