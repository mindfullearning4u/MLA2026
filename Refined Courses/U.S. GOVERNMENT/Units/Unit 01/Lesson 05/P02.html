Detailed Teaching Sequence

  1. Name the actor. Write who is acting and at what level or branch. This prevents using a rule that belongs to someone else.
  2. Name the action. Describe exactly what the actor proposes, requires, prohibits, funds, or decides.
  3. Select the rule. Use the visual below to find the rule that directly addresses that action.
  4. Test the facts. Identify one fact supporting the action and one fact showing a possible limit.
  5. Write the reasoning link. Complete: “This evidence matters because the rule requires ___, and the facts show ___.”

Evidence Set: Foundations-to-structure synthesis map
