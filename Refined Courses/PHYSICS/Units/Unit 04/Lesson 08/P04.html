Before the Worked Examples

Do not start by hunting for an answer choice. Set up the physics first. Identify the visual evidence, read the labels, and choose the model or rule that belongs to that evidence.

Physics Unit 4 is visual. Strong physics reasoning does not guess from a word. It points to the crest, normal line, source-observer motion, spectrum row, frame label, focal point, or image point before choosing an answer.

Before SolvingReason
Choose the evidence typeWave, sound, EM, frame, and optics questions use different models.
Identify labels and unitsGraphs and tables control the answer.
Use the mapped lesson standardDo not pull in unrelated physics.
Explain with the visualThe diagram or table is part of the answer.

Student reasoning move: First name the visual evidence. Then state the rule. Then connect the evidence to the rule in one sentence.

Worked Example 1: Wave graph

Problem: A graph asks for crest-to-crest distance. Which concept fits?

  1. Step 1: Crest to crest is one repeating wave length.
  2. Step 2: This is a spacing measurement.
  3. Step 3: Name the property as wavelength.

Answer: Use wavelength.

Interpretation: This example shows how to slow down, identify the diagram or data, use the correct rule, and explain the result.

Worked Example 2: Doppler scenario

Problem: A source moves away from an observer. What happens?

  1. Step 1: Source and observer have relative motion.
  2. Step 2: Moving away spreads wavefronts.
  3. Step 3: Observed frequency decreases.

Answer: Observed frequency is lower.

Interpretation: This example shows how to slow down, identify the diagram or data, use the correct rule, and explain the result.

Worked Example 3: Ray diagram

Problem: Rays meet after passing through a lens. What does that show?

  1. Step 1: The rays physically meet.
  2. Step 2: Physical meeting creates a real image.
  3. Step 3: The image location is where the rays meet.

Answer: A real image is formed.

Interpretation: This example shows how to slow down, identify the diagram or data, use the correct rule, and explain the result.

Common Mistake

Incorrect: Use the same wave idea for every Unit 4 problem.

Correct: Choose the wave, sound, EM, frame, or optics model based on the embedded stimulus.

Teachable Explanation: The correct version uses the mapped Physics visual evidence. The incorrect version skips the diagram, table, rule, or observer frame.
