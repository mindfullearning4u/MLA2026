Before the Worked Examples

Do not start by hunting for an answer choice. Set up the physics first. Identify the visual evidence, read the labels, and choose the model or rule that belongs to that evidence.

Physics Unit 4 is visual. Strong physics reasoning does not guess from a word. It points to the crest, normal line, source-observer motion, spectrum row, frame label, focal point, or image point before choosing an answer.

Student Reasoning MoveWhy It Matters
Start with the diagram labelsStudents often confuse height with length.
Name amplitude firstAmplitude is vertical distance from rest to crest.
Name wavelength secondWavelength is horizontal spacing from matching points.
Use v = f x lambda only after reading unitsThe formula needs frequency in Hz and wavelength in meters.

Student reasoning move: First name the visual evidence. Then state the rule. Then connect the evidence to the rule in one sentence.

Worked Example 1: Find wavelength

Problem: A diagram marks crest-to-crest distance as 4 m. What property is shown?

  1. Step 1: Crest to crest means one full wave length.
  2. Step 2: The distance is horizontal along the wave.
  3. Step 3: Name the property as wavelength.

Answer: The wavelength is 4 m.

Interpretation: This example shows how to slow down, identify the diagram or data, use the correct rule, and explain the result.

Worked Example 2: Use wave speed

Problem: A wave has frequency 5 Hz and wavelength 2 m. What is its speed?

  1. Step 1: Write v = f x lambda.
  2. Step 2: Substitute v = 5 x 2.
  3. Step 3: Multiply and label the result in m/s.

Answer: The wave speed is 10 m/s.

Interpretation: This example shows how to slow down, identify the diagram or data, use the correct rule, and explain the result.

Worked Example 3: Interpret amplitude

Problem: Wave B has greater amplitude than Wave A. What does that usually mean?

  1. Step 1: Amplitude measures distance from rest to crest.
  2. Step 2: Greater amplitude means a larger disturbance.
  3. Step 3: A larger disturbance usually carries more energy.

Answer: Wave B usually has greater wave energy.

Interpretation: This example shows how to slow down, identify the diagram or data, use the correct rule, and explain the result.

Common Mistake

Incorrect: Wavelength is the height of the wave.

Correct: Wavelength is horizontal spacing between matching points; amplitude is height from rest position.

Teachable Explanation: The correct version uses the mapped Physics visual evidence. The incorrect version skips the diagram, table, rule, or observer frame.
