Step 4: Use the Unit 4 Reasoning Routine

Use this routine for every Unit 4 problem.

  1. Identify the stimulus type.
  2. Read labels, direction, units, and object positions.
  3. Choose the matching wave, sound, EM, frame, or optics rule.
  4. Solve or interpret using the visual.
  5. Explain why the visual evidence supports the answer.

How to use NASA: Electromagnetic Spectrum

  1. Click the link and use the NASA Electromagnetic Spectrum page that opens.
  2. Find the spectrum order from radio waves through gamma rays.
  3. Compare wavelength, frequency, or energy for two parts of the spectrum.
  4. Record one pattern from the spectrum and one example of how that wave type is used or observed.
  5. Connect the pattern to the lesson's wave or electromagnetic radiation concept.

How to use OpenStax: Electromagnetic Waves

  1. Click the link and stay on the exact OpenStax section that opens.
  2. Read the section title, first explanation, key equation or model, and any figure or table in the linked section.
  3. Identify the quantity, relationship, law, or model that matches the lesson.
  4. Record one formula, visual detail, or evidence statement from the section.
  5. Return to the lesson and use that evidence in the notebook task or checkpoint.

Support for Different Readiness Levels

Remedial support: Read one label, row, ray, or wavefront at a time. Say what it means before answering.

Standard support: Use the embedded diagram/table and explain the matching wave, sound, EM, frame, or optics rule.

Accelerated extension: Predict how the result changes if frequency, wavelength, medium, observer motion, focal length, or object location changes.

Question to ask yourself: What visual would remove confusion for the student, and what does that visual prove?

Common Mistake

Incorrect: Electromagnetic waves need air to travel.

This is incorrect because it ignores the visual evidence or applies the wrong Unit 4 model.

Correct: Electromagnetic waves can travel through empty space; mechanical waves need a medium.

Teachable explanation: Correct Physics reasoning names the visual feature, applies the rule, and explains the result in the mapped standard.
