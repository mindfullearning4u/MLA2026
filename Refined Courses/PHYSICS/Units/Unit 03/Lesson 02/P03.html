Step 4: Use an Energy Reasoning Routine

Use this routine for every Unit 3 problem.

  1. Choose the system or process.
  2. List the forms, quantities, or before/after values shown.
  3. Choose the matching model or formula.
  4. Solve or interpret using units.
  5. Explain why the evidence supports the answer.

Embedded Investigation Planning

Investigation focus: Energy transformation investigation using an energy flow diagram and transformation table.

This lesson uses safe virtual, data-based, or model-based investigation evidence. You are not required to create a physical heat, ramp, collision, or moving-object setup.

How to use PhET: Energy Skate Park

  1. Click the direct HTML simulation link. The activity opens directly, so begin on the first screen that loads.
  2. Start with the default screen or the first simulation screen. Turn on labels, vectors, values, paths, graphs, or field lines when those controls are available.
  3. Change only one variable at a time, such as mass, force, distance, charge, wavelength, or velocity. Watch what changes before adjusting another control.
  4. Record one observation from the model and identify the Physics relationship shown by that observation.
  5. Use the observation as evidence in the notebook task, guided practice, or checkpoint when the lesson asks for simulation evidence.

How to use OpenStax: Conservation of Energy

  1. Click the link and stay on the exact OpenStax section that opens.
  2. Read the section title, first explanation, key equation or model, and any figure or table in the linked section.
  3. Identify the quantity, relationship, law, or model that matches the lesson.
  4. Record one formula, visual detail, or evidence statement from the section.
  5. Return to the lesson and use that evidence in the notebook task or checkpoint.

Support for Different Readiness Levels

Remedial support: Read one row, energy form, variable, or particle-model feature at a time. Say what it means in words before calculating.

Standard support: Identify the system, choose the correct energy/momentum model, and explain the answer using the stimulus.

Accelerated extension: Explain how the answer changes if work, time, force, distance, temperature, mass, velocity, or the system boundary changes.

Question to ask yourself: What confusion might a student have, and what table, diagram, or formula removes that confusion?

Common Mistake

Incorrect: Energy disappears when it changes form.

This is incorrect because it ignores the system, model, unit, rate, or conservation relationship.

Correct: Energy changes form; the evidence shows what forms are present before and after.

Teachable explanation: Correct Physics reasoning names the system, uses the given stimulus, and applies the correct energy or momentum model.
