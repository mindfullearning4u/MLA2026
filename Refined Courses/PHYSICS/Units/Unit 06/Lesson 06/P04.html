Before the Worked Examples

Do not start by hunting for an answer choice. Set up the physics first. Identify the evidence type, read labels and limits, and choose the model or rule that belongs to that evidence.

Physics Unit 6 is about using evidence carefully at scales and contexts where students cannot rely on direct everyday observation. Strong physics reasoning first identifies the scale, evidence source, model, observer frame, or decision criteria before making a conclusion.

StepReason
Check sourceSource quality affects reliability.
Check methodA clear method allows evaluation.
Check replicationRepeated results are stronger.
Check claim sizeClaims must not go beyond evidence.

Student reasoning move: Name the evidence first, state the model or reliability rule second, then explain why the evidence supports the conclusion.

Worked Example 1: Replicated evidence

Problem: Why is a replicated result stronger?

  1. Step 1: The result was repeated.
  2. Step 2: Consistency reduces chance of error.
  3. Step 3: Reliability increases.

Answer: Replication strengthens reliability.

Interpretation: This example shows how to slow down, identify the evidence, use the correct rule, and explain the result.

Worked Example 2: Weak source

Problem: Why is an anonymous unsupported post weaker evidence?

  1. Step 1: The source is unclear.
  2. Step 2: The method is not shown.
  3. Step 3: The claim cannot be evaluated well.

Answer: It is weaker evidence.

Interpretation: This example shows how to slow down, identify the evidence, use the correct rule, and explain the result.

Worked Example 3: Scientific change

Problem: When should an explanation change?

  1. Step 1: New evidence appears.
  2. Step 2: The old explanation cannot fully account for it.
  3. Step 3: A better-supported explanation is adopted.

Answer: Science changes when evidence supports revision.

Interpretation: This example shows how to slow down, identify the evidence, use the correct rule, and explain the result.

Common Mistake

Incorrect: Scientific ideas should never change if they are reliable.

Correct: Reliable science can change when better evidence or explanations improve the model.

Teachable explanation: The correct version uses the mapped Physics evidence. The incorrect version skips scale, model limits, source quality, observer frame, or decision criteria.
