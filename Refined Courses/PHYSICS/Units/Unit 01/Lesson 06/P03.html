Step 4: Use a Clear Decision Routine

For this lesson, use the routine below each time you answer. This keeps your work from becoming a guess.

  1. Name the quantity, model, or safety issue in the question.
  2. Circle or copy the exact data, table row, direction, or diagram feature being used.
  3. Write the physics vocabulary that matches the evidence.
  4. Explain the answer using because, so the evidence is connected to the conclusion.

How to use PhET: The Moving Man

  1. Click the link, then click the play or launch button for the simulation. If the page offers versions, use the HTML5 version.
  2. Start with the default screen or the first simulation screen. Turn on labels, vectors, values, paths, graphs, or field lines when those controls are available.
  3. Change only one variable at a time, such as mass, force, distance, charge, wavelength, or velocity. Watch what changes before adjusting another control.
  4. Record one observation from the model and identify the Physics relationship shown by that observation.
  5. Use the observation as evidence in the notebook task, guided practice, or checkpoint when the lesson asks for simulation evidence.

How to use OpenStax: Position and Displacement

  1. Click the link and stay on the exact OpenStax section that opens.
  2. Read the section title, first explanation, key equation or model, and any figure or table in the linked section.
  3. Identify the quantity, relationship, law, or model that matches the lesson.
  4. Record one formula, visual detail, or evidence statement from the section.
  5. Return to the lesson and use that evidence in the notebook task or checkpoint.

Support for Different Readiness Levels

Remedial support: Read one row, one label, or one sentence at a time. Say what the number or model feature means in words before calculating.

Standard support: Use the lesson routine independently: identify the quantity, copy the evidence, choose the vocabulary or formula, and explain the answer.

Accelerated extension: Explain how the answer would change if one part of the evidence changed, such as a different direction, time, trial value, or graph pattern.

Question to ask yourself: What could a student misunderstand here, and what evidence in the lesson removes that confusion?

Common Mistake

Incorrect: Velocity is always the same as speed.

This is incorrect because it does not use the precise evidence required by the lesson standard.

Correct: Velocity includes direction; speed does not.

Teachable explanation: A correct physics explanation uses the data, unit, direction, model feature, or safety rule that actually appears in the question.
