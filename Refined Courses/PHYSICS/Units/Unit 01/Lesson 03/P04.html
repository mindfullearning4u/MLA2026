Before the Worked Examples

Do not start by hunting for an answer choice. Start by setting up the physics. The setup is part of the answer.

Physics often feels difficult because one sentence can contain several ideas at once. Slow the sentence down. First identify the object or system. Next identify the quantity being measured. Then identify the unit, direction, graph axis, table column, or model feature. Only after that should you calculate or choose an answer.

Graph DecisionHow To Decide
Horizontal axisUse the variable that is controlled, ordered, or used to compare the measurement. In motion, this is usually time.
Vertical axisUse the measured result, such as position or velocity.
UnitsPut units in the axis labels so the graph can be interpreted without guessing.
PatternLook for equal changes, increasing changes, decreasing changes, or no change.

Student reasoning move: Before graphing, read the table in a complete sentence: "At 0 seconds the position is 0 meters; at 1 second the position is 2 meters." That prevents students from graphing numbers without meaning.

Worked Example 1: Identify variables

Problem: In the motion table, which variable belongs on the horizontal axis?

  1. Step 1: Look for the variable that changes in regular steps. Why: time is usually the independent variable in motion data.
  2. Step 2: Confirm position depends on time. Why: the cart's position is measured at each time.
  3. Step 3: Place time on the horizontal axis. Why: graphs usually show the independent variable on x.

Answer: Time is the independent variable.

Interpretation: This example shows how to slow down, identify the evidence, and connect the evidence to the concept before choosing an answer.

Worked Example 2: Read a pattern

Problem: What pattern is shown by positions 0, 2, 4, and 6 m?

  1. Step 1: Compare each change. Why: a pattern is found by looking at differences.
  2. Step 2: Each second, position increases by 2 m. Why: equal changes indicate steady motion.
  3. Step 3: Describe the model. Why: the graph would be a straight rising line.

Answer: The cart moves at a constant rate of 2 m each second.

Interpretation: This example shows how to slow down, identify the evidence, and connect the evidence to the concept before choosing an answer.

Worked Example 3: Choose a graph

Problem: Which graph best represents time and position data?

  1. Step 1: Identify paired numerical variables. Why: two numerical variables fit a line graph or scatter/line display.
  2. Step 2: Use time on x and position on y. Why: that shows how position changes with time.
  3. Step 3: Choose a line graph. Why: continuous motion data can be represented by a line.

Answer: A position-time line graph is appropriate.

Interpretation: This example shows how to slow down, identify the evidence, and connect the evidence to the concept before choosing an answer.

Common Mistake

Incorrect: The graph does not need axis labels because the table has labels.

Correct: The graph needs labeled axes with units: time (s) and position (m).

Teachable Explanation: The correct version names the evidence and uses the mapped physics concept. The incorrect version is vague or ignores the evidence.
