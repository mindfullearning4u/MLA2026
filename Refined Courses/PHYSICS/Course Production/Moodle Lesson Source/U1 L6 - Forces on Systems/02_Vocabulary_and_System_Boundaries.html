Notebook Task 1

Vocabulary and System Boundaries

Write each term and a student-friendly definition: system, system boundary, environment, internal force, external force, interaction pair, tension, equilibrium, torque, lever arm, center of mass, Atwood machine.

Complete this organizer

  1. Draw a box around the object or objects you choose as the system.
  2. List every object inside the boundary.
  3. List every interacting object outside it.
  4. For each force, identify the agent and receiver.
  5. Classify the force as internal or external for that chosen boundary.
  6. Explain why changing the boundary can change the classification.
Required examples: two connected blocks; two hanging masses; a person standing on the floor; and a balanced meter stick.

Evidence: submit all definitions and four completed boundary analyses in U1 L6 Notebook Evidence.
