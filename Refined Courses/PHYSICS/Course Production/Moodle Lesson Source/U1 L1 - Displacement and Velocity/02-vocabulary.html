Notebook Task 1

Vocabulary and Motion Representations

Open the Displacement and Velocity eText

Set up your notebook:
  1. Title the page U1 L1 — Vocabulary and Motion Representations.
  2. Number the terms 1–16 in the order shown.
  3. Use the linked Savvas vocabulary entries and lesson text—not a general web search.
  4. For every term, write a definition in your own words and the required symbol, unit, comparison, or visual listed below.
  1. position: define it relative to a reference point; include an example position with meters.
  2. displacement: define it as change in position; copy Δd = df − di and define all variables.
  3. distance traveled: define it and write one sentence comparing it with displacement.
  4. scalar quantity: define it and give distance or speed as an example.
  5. vector quantity: define magnitude and direction; draw and label one vector arrow.
  6. vector component: define it and sketch x- and y-components forming a resultant.
  7. resultant: define it as the vector sum; show a simple head-to-tail sketch.
  8. motion: define it as change in position.
  9. motion diagram: define it and sketch four equally timed positions.
  10. dot diagram: define it and explain what equal versus increasing spacing means.
  11. uniform motion: define it and draw a small linear position-time graph.
  12. nonuniform motion: define it and draw a small curved position-time graph.
  13. speed: define it using distance and time; state that it is scalar and give the SI unit.
  14. velocity: define it using displacement and time; copy v = Δd/Δt, state that it is a vector, and give the SI unit.
  15. position-versus-time graph: identify both axes and explain what the slope represents.
  16. velocity-versus-time graph: identify both axes and explain what the area under the line represents for uniform motion.
Evidence checklist: 16 numbered terms; 16 definitions; both required equations; scalar/vector comparisons; four required sketches or graphs; and units where requested.
