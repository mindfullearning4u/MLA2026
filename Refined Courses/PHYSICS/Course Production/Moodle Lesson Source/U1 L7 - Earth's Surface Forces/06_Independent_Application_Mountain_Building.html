Mountain-Building Model

Open Modeling Activity: Mountain Building

  1. Read the complete model criteria.
  2. Create before, during, and after cross-sections.
  3. Label crust, mantle, density differences, compression, uplift, root, erosion, and equilibrium.
  4. Add force arrows and explain every arrow.
  5. Predict how erosion changes the root and elevation over time.
  6. Write a CER supported by the model and topography data.
  7. State two model limitations.
