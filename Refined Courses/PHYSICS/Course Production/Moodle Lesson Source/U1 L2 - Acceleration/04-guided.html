Acceleration From Data, Vectors, and a Ramp

Part A — Fast Cars

Open Analyzing Data: Fast Cars

  1. Read the complete setup and identify the quantities, units, and time interval used for each car.
  2. Reproduce the provided data table or clearly number every row.
  3. Complete every graph, calculation, comparison, and written question.
  4. Show how the acceleration values were obtained; do not submit only final numbers.
  5. Write a conclusion naming the strongest acceleration evidence and one limitation of the comparison.

Part B — PhET Acceleration

Open PhET Simulation PDF: Acceleration

  1. Open the linked Masses and Springs simulation and choose Vectors.
  2. Set gravity to none, attach a mass, and use the stop sign to stop motion.
  3. Select Slow, display the velocity vector, and align the ruler so 50 cm is at the bottom of the mass.
  4. Pull the mass a known distance and release it. Record where velocity magnitude is greatest and where velocity is zero.
  5. For Question 1, draw velocity versus time for one complete cycle from maximum height to minimum height and back. Treat up as positive and down as negative.
  6. Use the velocity graph to predict and draw acceleration versus time for the same cycle. Explain how the two graphs are related.
  7. Complete every remaining page and numbered prompt in the PDF.

Part C — Acceleration On a Ramp

Open Modeling Activity PDF: Acceleration On a Ramp

  1. Read the model setup and identify the system, motion direction, measured variables, and assumptions.
  2. Complete every labeled diagram, table, graph, calculation, and explanation in order.
  3. Use the model evidence to explain how ramp conditions affect velocity change and acceleration.
  4. Complete the evaluation/revision prompt; identify one model limitation and one improvement.
