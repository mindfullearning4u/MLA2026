# Phase 3A-B-1: English I Unit-Level Mapping

## Executive Summary

This document creates the English I unit-level mapping using the approved crosswalk, approved mapping framework, and approved English I blueprint.

This phase maps standards to units only. It identifies each standard's primary unit, support units, spiral units, and rationale. It does not create lesson mappings, lessons, assessments, HTML files, quizzes, or GIFT files.

The unit-level mapping is workable within the approved 6-unit structure, but workload concerns remain for Unit 2, Unit 3, and Unit 4. Unit 2 and Unit 3 carry the highest mastery-standard density. Unit 4 has fewer primary standards, but research, source-based writing, and collaborative publication create a heavier instructional load than the benchmark count alone suggests.

## Unit 2 Workload Review

Unit 2 contains the following primary standards:

- MLA.ENG1.R.01 Analyze Literary Elements
- MLA.ENG1.R.02 Analyze Theme Development
- MLA.ENG1.R.03 Analyze Narrator Perspective
- MLA.ENG1.R.04 Analyze Epic Poetry
- MLA.ENG1.R.09 Explain Figurative Language and Mood
- MLA.ENG1.R.11 Compare Literary Adaptations
- MLA.ENG1.W.01 Write Narrative Texts

Workload finding: **High workload risk**

Unit 2 is the heaviest unit by primary mastery-standard count. Its workload is manageable only if Phase 3A-B-2 protects the unit from isolated mini-units. Literary elements, theme, perspective, figurative language, mood, epic/classical material, adaptation, and narrative writing must be connected through carefully selected texts and natural pairings.

Key risk: literary analysis may become unsupported interpretation if paraphrase, evidence, vocabulary, and explanation are not reinforced from Unit 1.

## Unit 3 Workload Review

Unit 3 contains the following primary standards:

- MLA.ENG1.R.05 Analyze Text Structure
- MLA.ENG1.R.06 Evaluate Central Idea Support
- MLA.ENG1.R.07 Analyze Author Purpose and Rhetoric
- MLA.ENG1.R.08 Evaluate Opposing Arguments
- MLA.ENG1.R.12 Explain Rhetorical Choices
- MLA.ENG1.W.02 Write Arguments with Evidence

Workload finding: **High workload risk**

Unit 3 has fewer primary standards than Unit 2, but its cognitive load is comparable. Students must move from informational text analysis to rhetoric, argument evaluation, and argument writing. Phase 3A-B-2 must ensure that argument writing follows argument reading and that rhetoric is explicitly modeled before independent analysis.

Key risk: students may be asked to write arguments before they can evaluate claims, evidence, reasoning, and rhetorical choices.

## Unit 4 Workload Review

Unit 4 contains the following primary standards:

- MLA.ENG1.W.03 Write Expository Texts
- MLA.ENG1.RS.01 Conduct Reliable Research
- MLA.ENG1.C.03 Publish Collaborative Writing

Workload finding: **Moderate-high workload risk**

Unit 4 has only three primary standards, but each is multi-step. Research requires question development, source evaluation, reliability, validity, credibility, bias, note-taking, synthesis, and scope refinement. Expository writing requires organization, source integration, transitions, and appropriate tone. Collaborative publication adds audience awareness and digital production expectations.

Key risk: research, expository writing, and collaborative publication may become three separate heavy products instead of one connected source-based communication process.

## Recommendations for Phase 3A-B-2

Phase 3A-B-2 should create lesson-level mapping only after applying the workload protections from Phase 3A-A.

Recommended controls:

- Keep most lessons to one primary mastery standard.
- Pair two mastery standards only when they are naturally inseparable.
- Protect Unit 2 by combining literary craft standards around shared texts where appropriate.
- Protect Unit 3 by sequencing informational reading before argument writing.
- Treat Unit 4 as a connected research-to-expository-writing process.
- Keep Unit 5 support standards visible across earlier units without turning every lesson into grammar/vocabulary instruction.
- Ensure Unit 6 is a culmination of prior skills, not the first meaningful communication experience.
- Do not place untaught standards into Lesson 8 as a catch-all.
