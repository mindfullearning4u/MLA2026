Independent Work: Unit 2 Assessment Readiness

Use this page to make sure you are ready for the Unit 2 Assessment. This is review only. No new skill is introduced here.

Readiness Checklist

In your notebook, copy each sentence starter and complete it honestly.

  1. I can identify literary elements by looking for...
  2. I can explain theme by connecting...
  3. I can analyze narrator perspective by asking...
  4. I can explain mood and figurative language by identifying...
  5. I can compare an adaptation by looking for...
  6. I can write a narrative response that uses...

Before You Start the Assessment

  • Read each passage before answering the question.
  • Use the passage evidence included with the question.
  • Eliminate answers that are too broad, unsupported, or only partly correct.
  • For writing-craft questions, choose the option that best matches point of view, mood, and sequence.

Independent Work Parts

Part A: Identify the skill, passage detail, or writing move the task is asking you to use.

Part B: Complete the assigned response using evidence from the lesson or passage.

Part C: Check your work for clarity, complete sentences, and a direct explanation of your reasoning.
