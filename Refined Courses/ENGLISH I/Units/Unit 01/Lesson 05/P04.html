P04 Worked Example

This example shows how conventions improve a short response without changing the meaning.

Example 1: Check Capitalization and Punctuation

Passage: The cafeteria added a breakfast pickup table near the entrance. Students could grab breakfast before going to class.

Draft response: the pickup table helped students get breakfast before class

Revision: The pickup table helped students get breakfast before class.

Example 2: Fix a Fragment

Fragment: Because students could grab breakfast before class.

Problem: This begins with because, but it does not finish the thought.

Revision: The pickup table helped students because they could grab breakfast before class.

Example 3: Fix a Run-On

Run-on: The pickup table was useful students could grab breakfast quickly.

Revision: The pickup table was useful because students could grab breakfast quickly.

Why it works: The word because connects the idea and the reason.

Common Mistake to Avoid

Incorrect: Because the table helped students.

This is a fragment. The reader is left waiting for the rest of the thought.

Correct: The table helped students because they could pick up breakfast before class.

This is a complete sentence that keeps the response meaning clear.
