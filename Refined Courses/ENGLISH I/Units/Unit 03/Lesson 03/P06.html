P06 Independent Work

Use this task to practice before the checkpoint.

Passage

The library should stay open one hour later twice a week. Many students have sports or family responsibilities right after school, so they cannot use the library before it closes. Last semester, the after-school tutoring room served more than 300 student visits. Extending library hours would give students a quiet place for research, homework, and reading.

Part A

Write the author's purpose in one sentence.

Part B

Identify one rhetorical appeal and copy the words that show it.

Part C

Explain how the appeal supports the author's purpose.
