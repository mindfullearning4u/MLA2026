P04 Worked Example

This example shows how to evaluate validity in an argument.

Example Passage

The school should create a quiet study room in the library. During lunch, many students need a calm place to complete makeup work or read. Last semester, the library sign-in sheet showed more than 500 lunch visits, and several students wrote that noise made it difficult to focus.

Example 1: Identify the Claim

Claim: The school should create a quiet study room in the library.

The claim is the position the author wants readers to accept.

Example 2: Check Evidence

Evidence: More than 500 lunch visits were recorded, and students reported that noise made focus difficult.

This evidence is relevant because it shows both student use and a focus problem.

Example 3: Evaluate Validity

The argument is valid because the evidence connects directly to the claim. If many students use the library at lunch and noise makes focus difficult, a quiet study room is a reasonable solution.

Common Mistake

Incorrect: The argument is valid because I like quiet rooms.

Personal agreement is not the same as validity. Validity depends on reasoning and evidence.

Correct Approach

Correct: The argument is valid because the sign-in data and student comments support the need for a quiet study room.

This answer evaluates the argument using evidence.
