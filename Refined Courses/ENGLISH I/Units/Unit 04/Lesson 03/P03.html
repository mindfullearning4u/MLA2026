P03 Notebook Task Part 2

Now combine related information from two sources.

Source Set

Source A: A school report found that students used the media center most often when it was open before school.

Source B: A student survey found that many students said they needed a quiet place to work before first period.

Notebook Directions

  1. Write one note from Source A.
  2. Write one note from Source B.
  3. Write one synthesis sentence that combines both findings.

A synthesis sentence should show how the sources work together. It should not simply list two unrelated facts.

Common Mistake

Incorrect: Source A is about the media center. Source B is about students.

This is not synthesis. It names both sources but does not connect their ideas.

Correct Thinking

Correct: Together, the sources suggest that opening the media center before school could meet students' need for a quiet place to work.

This sentence combines the sources into one connected finding.
