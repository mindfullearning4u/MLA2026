# English I Moodle Resource Requirements

## Coursewide requirements

| Requirement | Implementation decision |
|---|---|
| Savvas licensing | Link to Savvas resources with exact click paths; do not reproduce proprietary texts |
| Stable navigation | State unit, selection, resource title, expected screen, and fallback help route |
| Accessibility | Alt text for instructional images; captions/transcripts for audio/video; accessible-text option where available |
| Responsive content | Responsive tables, readable line lengths, mobile-safe embeds, and downloadable alternatives |
| Passage-dependent questions | Keep excerpts/resources associated with their question sets and licensing permissions |
| External links | Verify each link and provide descriptive link text; note that Savvas login is required |
| Manual grading | Use Moodle assignments/rubrics for writing, speaking, projects, notebook evidence, and checkpoints |
| MathJax | Not generally required; use only if a source includes formulas/symbols needing semantic rendering |
| Audio/video | Provide captions/transcripts or an equivalent accessible route; avoid autoplay |
| Collaboration | Use asynchronous forum/workshop/TOR workflow or approved individual alternative |
| Randomized quizzes | Randomize only validated independent items from balanced standard-tagged pools |
| Mastery restrictions | Preserve 80% mastery and TOR-controlled reattempt rules where approved |

## Unit activity order for Units 2-6

1. Unit pretest
2. Instructional lessons and required evidence
3. Clustered quiz after each approved instructional cluster
4. Final synthesis lesson containing the unit assessment

Unit 1 is complete and excluded from Moodle implementation work arising from this proposal.

## Required lesson bookends

Every lesson begins with separate **Lesson Overview** and **Learning Objectives** pages. Every lesson ends with **Checkpoint** and **Help & TOR Support**. Intermediate pages vary by instructional need.

## Known risks

- Savvas `javascript://` interface actions cannot be treated as ordinary public URLs.
- Session/program routes may change; written click paths are required even when exact links are supplied.
- Teacher-only files cannot be assigned to students.
- Accessible Text, Spanish PDFs, and Language Lab resources have different assignment/access conditions.
- Savvas interactive activities may not embed or function outside Savvas.
- Current Moodle descriptions may reference obsolete unit names or skill-domain architecture.

## Activity-type guidance

- Moodle Book/Page: instruction, models, resource directions, and Help/TOR support.
- Assignment: notebook evidence, checkpoints, essays, projects, presentations, and research products.
- Quiz: validated diagnostic, cluster, lesson, and unit assessment items.
- Forum/Workshop: discussion, peer response, and collaborative publication when approved.
- URL: direct Savvas entry point with accompanying click-path directions.
