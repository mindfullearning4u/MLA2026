# English I Standards Gap and Redundancy Analysis

## Gap controls incorporated into the architecture

| Gap | Evidence | Architecture control / placement |
|---|---|---|
| Explicit etymology/derivation instruction may be underrepresented in thematic units | Savvas selection vocabulary does not automatically prove MLA.ENG1.V.02 mastery | V.02 is introduced in L2.2 and explicitly spiraled through the vocabulary/word-study component of L3.5, L4.10, L5.1, and L6.6; L6.9 assessment blueprint must sample it |
| Collaborative publication conditions are not guaranteed in a self-paced course | Savvas peer tasks assume classroom peers | C.03 is practiced through asynchronous peer/TOR review in L3.10 and L4.12 and mastered in L5.11; an individual TOR-reviewed route is the approved accessibility alternative |
| Florida-specific FAST/B.E.S.T. practice is outside most core unit selections | Support collection exists separately | Short FAST/B.E.S.T. practice is assigned on the cumulative-review page of each Pattern E lesson; it does not create an additional lesson |
| Research reliability/validity requires explicit source evaluation | The research product alone does not prove MLA.ENG1.RS.01 | L5.6 contains the source-evaluation checkpoint; L5.7 practices integration and L5.11 supplies publication evidence |
| Accessible/differentiated resources may not be linked consistently | Savvas resources exist but Moodle directions can be generic | Every P07 Help & TOR Support page must name the matching Accessible Text, Language Lab, ELL/Access Points route, and TOR contact/resubmission path |

## Redundancy risks

| Risk | Control |
|---|---|
| Repeating generic vocabulary worksheets for every selection | Use vocabulary only when it supports comprehension or the MLA vocabulary standards |
| Reassessing theme/evidence without increasing complexity | Track introduced, practiced, and mastered status across units |
| Duplicating Savvas comprehension quizzes and MLA quizzes | Choose the best evidence source; avoid two quizzes measuring the same target |
| Treating every text as a separate full Moodle lesson | Cluster selections by coherent objective and performance evidence |
| Repeating presentation instruction in every performance task | Teach a reusable presentation routine, then vary purpose/audience/media |

## Coverage progression

- **Introduced:** Unit 1 foundations; unit-specific genre and task launches.
- **Practiced:** Guided analysis, close reading, notebook work, discussion, and Savvas comprehension/analysis activities.
- **Mastered/assessed:** Checkpoints, writing products, performance tasks, cluster quizzes, and unit assessments.
- **Supporting:** Vocabulary, conventions, revision, Help/TOR intervention, accessible text, and Language Lab.

## Approval checks retained for academic review

- Florida wording is verified against FDOE and English 1 course applicability is verified in CPALMS; academic review confirms acceptance rather than performing the first verification.
- Assessment production must confirm which Savvas unit-test items validly measure each MLA standard before importing or rebuilding questions. The architecture defines source families and bank blueprints but intentionally does not transfer proprietary items.
- Confirm whether the school requires a specific standalone FAST practice requirement beyond embedded preparation.
- Confirm the acceptable asynchronous alternative for collaborative-writing mastery.

Unit 1 is excluded from this gap analysis because its lessons, content, pretest, clustered assessments, and final synthesis/unit assessment are complete.
