# English I Assessment Source Map

## Assessment design rules

- Savvas assessments are sources; questions are not transferred during architecture.
- Every selected question must later have a verified answer key, standard, source context, and required passage/visual.
- Duplicate MLA/Savvas assessment evidence should be removed during production review.
- Randomization is appropriate only when items are independent and equivalent in standard/rigor.

## Required item-level fields for later production

1. Savvas assessment and item identifier
2. MLA unit/lesson
3. MLA standard and Florida benchmark
4. Introduced/practiced/mastered status
5. Formative or summative purpose
6. Correct answer and verified rationale
7. Passage, table, image, audio, or graph dependency
8. Copyright/linking restriction
9. Randomization eligibility
10. Duplicate-item finding
11. Moodle question type
12. Manual-grading requirement

## Manual grading

Notebook evidence, extended written responses, narratives, arguments, research reports, collaborative publications, oral presentations, advertisements, instructions demonstrations, and poster presentations require TOR grading with rubrics. Automated quizzes should not replace these performance standards.
