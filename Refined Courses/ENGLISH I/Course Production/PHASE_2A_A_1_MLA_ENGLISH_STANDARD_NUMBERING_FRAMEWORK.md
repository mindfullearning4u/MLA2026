# Phase 2A-A-1 MLA English Standard Numbering Framework

## Scope Control

This report creates the MLA English standard numbering framework only.

It does not assign numbers to benchmarks.

It does not create crosswalks, mappings, lessons, assessments, unit files, HTML files, quizzes, or GIFT files.

The Algebra I crosswalk was used as a structural reference only. No Algebra content, Algebra standards, or Algebra numbering has been copied.

## Executive Summary

MLA English standards should use a stable, auditable identifier structure that is consistent across English I, English II, English III, and English IV while remaining flexible enough to support future English courses.

Recommended format:

`MLA.ENG1.R.01`

Framework components:

| Component | Meaning | Example |
|---|---|---|
| `MLA` | School/system prefix | `MLA` |
| `ENG1` | Course identifier | `ENG1`, `ENG2`, `ENG3`, `ENG4` |
| `R` | Domain identifier | `R`, `W`, `L`, `V`, `RS`, `C` |
| `01` | Two-digit sequential standard number within the domain | `01`, `02`, `03` |

This creates a clean English standard ID such as:

- `MLA.ENG1.R.01`
- `MLA.ENG1.W.03`
- `MLA.ENG2.RS.02`
- `MLA.ENG4.C.04`

These examples show structure only. They are not benchmark assignments.

## Recommended Numbering Framework

### 1. Prefix Structure

Official prefix:

`MLA`

Rationale:

- Matches existing MLA internal standards convention.
- Clearly distinguishes MLA standards from Florida B.E.S.T., Common Core, SAT, ACT, or other external standards.
- Supports audit trails across course files, future crosswalks, lesson metadata, assessments, and LMS records.

Required rule:

Every MLA English standard ID must begin with `MLA`.

### 2. Course Identifier Structure

Recommended course identifiers:

| Course | Course Identifier |
|---|---|
| English I | `ENG1` |
| English II | `ENG2` |
| English III | `ENG3` |
| English IV | `ENG4` |

Recommended full course segment:

`MLA.ENG1`

Rationale:

- Human-readable.
- More transparent than `E1`, `E2`, `E3`, `E4`.
- Avoids ambiguity with elementary or elective English courses.
- Aligns with existing course naming language.
- Scales naturally across English I-IV.

Required rule:

The course identifier must immediately follow the `MLA` prefix.

Approved pattern:

`MLA.[COURSE].[DOMAIN].[NUMBER]`

Example pattern:

`MLA.ENG1.R.01`

### 3. Domain Identifier Structure

The domain identifier must represent the major English skill domain.

Recommended domain segment:

`R`, `W`, `L`, `V`, `RS`, or `C`

The domain identifier must come after the course identifier and before the standard number.

Approved pattern:

`MLA.ENG1.R.01`

### 4. Standard Numbering Structure

Recommended numbering:

Two-digit sequential numbering within each course and domain.

Pattern:

`01`, `02`, `03`, etc.

Rationale:

- Two-digit numbers sort cleanly in files, spreadsheets, LMS fields, and audits.
- Each domain can grow beyond nine standards without disrupting order.
- Future insertions can be handled with reserved numbers or substandard suffixes if necessary.

Required rule:

Numbers must be sequential within each course-domain combination.

Example:

- `MLA.ENG1.R.01`
- `MLA.ENG1.R.02`
- `MLA.ENG1.R.03`

No benchmark numbers are assigned in this phase.

### 5. Optional Substandard Rule

Substandards should not be used unless future crosswalk development proves they are necessary.

If required, use lowercase suffixes:

- `MLA.ENG1.W.04a`
- `MLA.ENG1.W.04b`

Substandards should be reserved for cases where one MLA standard must be divided into auditable subskills without creating new top-level standards.

Default rule:

Avoid substandard suffixes unless required for audit clarity.

## Domain Naming Framework

### Official MLA English Domains

| Domain | Abbreviation | Purpose |
|---|---|---|
| Reading | `R` | Literary analysis, informational text analysis, evidence analysis, rhetoric, text structure, theme, character, perspective, central idea |
| Writing | `W` | Text-based responses, literary analysis writing, narrative writing, informative/explanatory writing, argument writing |
| Language | `L` | Grammar, usage, conventions, syntax, sentence clarity, style, revision mechanics |
| Vocabulary | `V` | Academic vocabulary, context clues, word relationships, etymology, derivation, connotation, denotation |
| Research | `RS` | Research questions, source evaluation, reliability, validity, credibility, bias, note-taking, source integration, synthesis |
| Communication | `C` | Discussion, oral presentation, digital presentation, audience awareness, publication-ready communication |

### Domain Selection Rationale

The domain set is based on the approved English I benchmark analysis and blueprint:

- Reading is the largest benchmark area and must remain distinct.
- Writing must be separated from Florida's Communication coding for instructional clarity.
- Language must be visible because conventions and style support all English performance.
- Vocabulary must be visible because word meaning and academic vocabulary are explicit English requirements.
- Research must be visible even though it may have fewer official benchmarks because it is a high-rigor, multi-step process.
- Communication must be visible because oral, digital, and collaborative communication are required readiness outcomes.

### Naming Rules

Domain names must be:

- Singular as a category label.
- Professional.
- Clear to students, teachers, curriculum developers, and auditors.
- Stable across English I-IV.

Approved names:

- Reading
- Writing
- Language
- Vocabulary
- Research
- Communication

Do not rename domains by unit title, genre, or assessment type.

### Abbreviation Rules

Abbreviations must be:

- Uppercase.
- Short.
- Stable.
- Distinct from one another.

Approved abbreviations:

- `R`
- `W`
- `L`
- `V`
- `RS`
- `C`

Research uses `RS` instead of `R` because `R` is reserved for Reading.

### Future Scalability

The framework supports future English expansion through:

- Additional standards within existing domains.
- Course identifiers beyond English IV if needed.
- Optional substandards for complex standards if future audit needs require them.
- Potential elective course identifiers using the same structure.

Future examples:

- `MLA.ENG5.R.01` if a future English V course exists.
- `MLA.CW.W.01` if a Creative Writing course is later approved.
- `MLA.JRN.C.01` if a Journalism course is later approved.

These are scalability examples only and are not active course identifiers.

## Standard Title Framework

### Purpose of Standard Titles

MLA standard titles must make the skill understandable without replacing the full standard description.

Titles should help:

- Students understand what they are learning.
- Teachers identify the skill quickly.
- Curriculum developers write aligned lessons.
- Auditors verify skill coverage.

### Title Requirements

MLA English standard titles must be:

- Skill-based.
- Student friendly.
- Professional.
- Concise.
- Auditable.
- Aligned to the domain.
- Free of lesson-specific wording.
- Free of text-specific wording unless the standard itself requires a genre or text type.

### Recommended Title Pattern

Preferred title pattern:

`Action Verb + Skill/Concept`

Examples:

- Analyze Theme Development
- Explain Character Development
- Evaluate Evidence Support
- Write Evidence-Based Responses
- Develop Research Questions
- Revise for Clarity and Cohesion
- Present Ideas with Evidence

### Title Length

Recommended length:

3-7 words.

Titles should be short enough for tables and metadata but clear enough for audit use.

### Approved Verb Style

Use measurable academic verbs such as:

- Analyze
- Explain
- Evaluate
- Compare
- Develop
- Write
- Revise
- Integrate
- Determine
- Present
- Synthesize

Avoid vague verbs such as:

- Understand
- Learn
- Know
- Explore
- Think about

### Student-Friendly Requirement

Titles should be understandable to a high school student.

Preferred:

- Analyze Author Purpose
- Write Arguments with Evidence
- Determine Word Meaning

Avoid:

- Demonstrate Metacognitive Rhetorical Awareness
- Operationalize Multimodal Interpretive Praxis
- Execute Formalized Discursive Production

### Professional/Auditable Requirement

Titles should remain formal enough for crosswalks, LMS records, and accreditation review.

Avoid casual wording:

- Figure Out Theme
- Make Your Writing Better
- Talk About Sources

Preferred:

- Analyze Theme Development
- Revise for Clarity and Cohesion
- Evaluate Source Credibility

## Scalability Review

### English I Support

The framework supports the approved English I benchmark inventory and blueprint because English I skills fall naturally into:

- Reading
- Writing
- Language
- Vocabulary
- Research
- Communication

The framework can represent all approved English I clusters:

- Foundational Reading and Academic Response
- Literary Analysis and Craft
- Informational Text and Rhetoric
- Argument Analysis and Argument Writing
- Narrative Writing and Literary Craft Application
- Research and Expository Communication
- Language, Vocabulary, and Revision
- Oral and Digital Communication

### English II Support

The framework supports English II because the same domains can scale upward in rigor:

- More complex literary and informational analysis.
- More advanced comparison and synthesis.
- Expanded argument and expository writing.
- Continued language, vocabulary, research, and communication growth.

Course example:

`MLA.ENG2.R.01`

### English III Support

The framework supports English III because the same domains can support American literature, rhetoric, historical context, argument, research, and presentation.

Course example:

`MLA.ENG3.RS.01`

### English IV Support

The framework supports English IV because the same domains can support advanced analysis, independent research, synthesis, college/career writing, and formal communication.

Course example:

`MLA.ENG4.W.01`

### Future Expansion Opportunities

The framework can expand to:

- English electives.
- Honors or accelerated variants.
- College readiness English.
- Creative writing.
- Journalism.
- Speech/communication.
- Test readiness modules.

Expansion should preserve the same four-part identifier pattern:

`MLA.[COURSE].[DOMAIN].[NUMBER]`

### Scalability Risks

Potential risks:

- Too many standards inside one domain could make numbering long.
- Courses may need subdomains for very large future crosswalks.
- Research and Communication may overlap with Writing if titles are vague.

Controls:

- Keep domain definitions stable.
- Keep standard titles skill-specific.
- Use two-digit numbering.
- Use substandards only when needed.
- Preserve one primary domain per MLA standard.
- Allow secondary domain notes in future crosswalks without changing the standard ID.
