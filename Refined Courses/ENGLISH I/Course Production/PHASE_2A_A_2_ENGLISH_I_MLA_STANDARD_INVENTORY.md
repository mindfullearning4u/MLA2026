# Phase 2A-A-2: English I MLA Standard Assignment

## Executive Summary

This report establishes the official MLA English I standard inventory using the approved MLA English numbering framework:

`MLA.[COURSE].[DOMAIN].[NUMBER]`

For English I, the course identifier is `ENG1`. Standards are numbered within the approved MLA English domains:

- `R` = Reading
- `W` = Writing
- `L` = Language
- `V` = Vocabulary
- `RS` = Research
- `C` = Communication

This inventory assigns MLA standard numbers to the approved English I benchmark inventory from Phase 1C-A. It does not create a crosswalk, mapping, unit placement, lesson sequence, assessment plan, or spiral placement. Its sole purpose is to establish the official MLA English I standard identifiers that will be used in future curriculum documentation.

### Domain Rationale

Reading standards include all approved `ELA.9.R` benchmarks because these benchmarks directly address literary analysis, informational text analysis, rhetoric, argument analysis, figurative language, paraphrasing, adaptation, and evidence-based reading.

Writing standards include the approved composition-focused `ELA.9.C.1` benchmarks because Phase 1C-A classified these as English I writing standards: narrative writing, argument writing, expository writing, and revision.

The language standard includes `ELA.9.C.3.1` because it directly governs grammar, punctuation, capitalization, spelling, and standard English conventions.

Vocabulary standards include all approved `ELA.9.V` benchmarks because these benchmarks govern academic vocabulary, etymology, derivation, context clues, figurative language, word relationships, reference materials, denotation, and connotation.

The research standard includes `ELA.9.C.4.1` because it directly governs question-based research, source reliability, source validity, and research scope refinement.

Communication standards include the approved presentation and digital communication benchmarks: oral presentation, digital presentation, and collaborative publication-ready writing.

Validation result: Passed.
