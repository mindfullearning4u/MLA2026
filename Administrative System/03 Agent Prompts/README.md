# Agent Prompts

## Purpose

This folder will contain administrative AI agent prompts organized by operating category.

## Categories

- `administrative-agents`: General administrative production and coordination agents.
- `repository-agents`: Agents responsible for repository structure, document control, and maintenance.
- `governance-agents`: Agents supporting governance documents, controlled exceptions, and policy alignment.
- `branding-agents`: Agents supporting brand standards, assets, and visual identity workflows.
- `finance-agents`: Agents supporting budgets, revenue, expenses, and financial reporting.
- `operations-agents`: Agents supporting SOPs, vendors, compliance, facilities, calendars, and projects.
- `student-agents`: Agents supporting admissions, enrollment, records, attendance, communication, and services.
- `workbook-agents`: Agents supporting workbook and spreadsheet development.
- `quality-assurance-agents`: Agents supporting review, audit, and quality control workflows.

Agent prompts will be developed separately.
