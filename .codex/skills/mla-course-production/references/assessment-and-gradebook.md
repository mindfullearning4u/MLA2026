# Assessment and Gradebook

## Unit pretest

- Cover the entire unit.
- Use 10 questions.
- Allow one attempt.
- Set the mastery/completion score to 100% for internal tracking.
- Give the activity zero course-grade weight.
- Students scoring 90% or higher are eligible for accelerated-course review; acceleration is not automatic.

## Lesson quiz

- Build one quiz after every lesson unless the approved mapping explicitly uses a cluster.
- Maintain 25 multiple-choice questions in the lesson bank.
- Release 5 random questions per attempt.
- Use four plausible answer choices.
- Allow one attempt initially.
- Set mastery at 80%.
- Avoid answer-position patterns and provide useful feedback.
- Base every question on the approved lesson content, including permitted Savvas question-bank material.

## Unit assessment

- Cover the complete unit.
- Maintain 40 questions in the unit bank.
- Release 10 random questions per attempt.
- Allow one attempt initially.
- Set mastery at 80%.
- Build during the final lesson-production stage, but assess the entire unit rather than only the final lesson.

## Additional attempts

For a lesson quiz or unit assessment below 80%, require the student to meet with the Teacher of Record. The TOR releases an additional attempt after remediation. Do not configure unlimited automatic attempts.

## Evidence submissions and rubrics

- Create a notebook evidence submission and a checkpoint submission for each lesson when the approved lesson workflow calls for both.
- Make each rubric lesson-specific.
- State the required artifact, evidence, units/labels, reasoning, completeness, and submission format.
- Include grading guidance or expected answers when appropriate so the TOR can grade efficiently and consistently.
- Never expose protected answer material on a student-facing page.

## Gradebook weights

Use these course-weight categories:

- Notebook Evidence: 20%.
- Checkpoint Submissions: 20%.
- Lesson Quizzes: 30%.
- Unit Assessments: 30%.
- Pretests: 0%.

Verify that every graded activity is in the correct category and that the category weights total 100%, excluding pretests. Inspect the actual gradebook calculation after saving.
