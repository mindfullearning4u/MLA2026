## Required use

For any Moodle dashboard, orientation, or lesson-page build:

1. Read the applicable written workflow reference.
2. Open the matching screenshots in this folder.
3. Compare the proposed HTML or saved Moodle page against the screenshots.
4. Preserve the approved dark course banner, bordered pastel cards, inline styling, content hierarchy, direct-action buttons, evidence language, TOR help box, and Next/Previous navigation placement.
5. Use exact course-specific content and verified deep links. Do not copy Biology facts into another course.
6. Report any intentional visual deviation and the reason.
